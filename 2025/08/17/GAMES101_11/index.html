估计性质

渲染方程本身是一个高维积分，实际渲染器只能用有限个样本近似它，因此任何渲染算法都对应一个统计估计量。设积分真值为 III，使用 NNN 个样本得到的估计量为 I^N\hat I_NI^N​，则偏差 Bias 定义为

Bias⁡(I^N)=E[I^N]−I.\operatorname{Bias}(\hat I_N) = \mathbb E[\hat I_N]-I. Bias(I^N​)=E[I^N​]−I.

偏差描述的是估计量的期望与真值之间的系统性差距，与单次实现的随机波动无关。无偏估计 Unbiased Estimator 在任意样本数下都满足 E[I^N]=I\mathbb E[\hat I_N]=IE[I^N​]=I：噪声会随样本改变，但不会系统性地偏亮、偏暗或模糊。路径追踪、双向路径追踪与 Metropolis 光路传输都属于无偏方法，它们的问题只在方差，增加样本时误差以统计方式下降，不会残留固定的模糊。有偏估计 Biased Estimator 允许有限样本期望偏离真值，光子映射的固定半径密度估计、以及各种滤波与降噪重建都是典型例子：有限样本下图像确实偏模糊，但偏差可以随参数一起收敛。若估计量按概率收敛，即

I^N→N→∞PI,\hat I_N\xrightarrow[N\to\infty]{\mathsf P}I, I^N​PN→∞​I,

则称为 一致估计 Consistent Estimator。这里采用统计学中常见的依概率收敛定义；若能证明几乎处处收敛或均方收敛，还可得到更强结论。三种性质描述的是不同维度：无偏只约束期望，一致约束极限行为，方差约束单次结果的离散程度。无偏并不保证方差小——一个无偏但方差巨大的估计量在有限样本下同样不可用；一致也不表示有限时间内误差一定更低——依概率收敛只说明样本数趋于无穷时的极限，有限样本的分布形状由方差与高阶矩决定。

有偏但不一致的估计量最需要警惕：它的偏差不会随样本增加而消失。固定半径的光子映射正属于这一类，误差会收敛到一个非零的下限。评估渲染算法时，需要同时考虑偏差、方差、收敛速度、单样本成本和误差的空间分布，其中最后一项指的是噪声是否在画面中均匀分布。

双向追踪

普通路径追踪只从相机建立路径。若光先在光源附近经过狭缝、镜面或复杂遮挡，再到达相机，反向路径很难随机找到这些高贡献方向：光线必须在光源附近以极小的立体角命中狭缝，然后才按正确方向继续传播，这类概率的乘积可能小到需要海量样本才能命中一次。焦散、间接光源照明与经过多次镜面反射的间接光都属于这种情形。

双向路径追踪 Bidirectional Path Tracing，简称 BDPT，同时从相机和光源生成子路径，再尝试连接不同长度的端点。一次完整路径可以由 sss 个光源端顶点和 ttt 个相机端顶点组成，连接时用一条可见性射线把两个端点相连，若中途没有遮挡就得到一条完整光路。构造这类路径不需要随机命中光源，而是通过显式的连接测试完成，因而原本概率极低的路径类型变得容易采样。不同连接策略对同一路径族的采样概率不同：同一条光路可能既被相机侧的漫反射采样命中，也被光源侧的连接命中，若直接相加就会重复计算能量，通常用 多重重要性采样 Multiple Importance Sampling 合并。多重重要性采样的思路是给每个采样策略分配权重，权重之和恒为 1，使估计量保持无偏，同时让在给定场景中更可靠的策略占更大比重。

BDPT 适合光源一侧结构复杂的间接光照，也能重用一对较长子路径形成多个连接，即用同一组端点尝试多种 sss、ttt 组合。代价是实现复杂、可见性测试多，含 delta 镜面事件的连接还需特殊处理：理想镜面方向上的积分是奇异的，连接两个镜面顶点几乎必然失败，必须改用镜面反射方向继续追踪而不能依赖随机连接。两种方法在同一组困难光路上的表现差异，可以通过以下对照图看出：

MLT

Metropolis Light Transport，简称 MLT，把完整光路当作状态，使用 Markov Chain Monte Carlo 在路径空间中采样。设当前路径为 xxx，按提议分布 q(x→y)q(x\to y)q(x→y) 变异出新路径 yyy，目标路径分布为 π\piπ。Metropolis–Hastings 接受率为

a(x→y)=min⁡(1,π(y)q(y→x)π(x)q(x→y)).a(x\to y) = \min\left( 1, \frac{ \pi(y)q(y\to x) }{ \pi(x)q(x\to y) } \right). a(x→y)=min(1,π(x)q(x→y)π(y)q(y→x)​).

链的每个状态由一个从 [0,1)[0,1)[0,1) 均匀采样的随机数决定接受或拒绝：随机数小于 aaa 就接受新路径，否则保留原路径并把原路径再次计入统计。π\piπ 通常与路径对图像的贡献相关，即把路径携带的能量作为目标分布的密度。若变异是对称的，q(x→y)=q(y→x)q(x\to y)=q(y\to x)q(x→y)=q(y→x)，提议概率可以约掉，接受率退化为 min⁡(1,π(y)/π(x))\min(1,\pi(y)/\pi(x))min(1,π(y)/π(x))：高贡献路径更容易被接受，但比值形式保证从高贡献区域走向低贡献区域的概率并不为零，从低贡献区域跳出仍保留正确概率，长期分布才会趋向 π\piπ。这种细致平衡条件是马尔可夫链收敛到目标分布的前提，也是 MLT 保持无偏的原因。

局部变异能在罕见而重要的路径附近持续探索，因为变异通常只改动路径的一个或少数几个顶点，得到的候选路径与原路径高度相关，不会像独立采样那样重新面对极低的命中概率，因此 MLT 很擅长焦散、狭缝照明等难采样效果。它也会带来新的问题：样本彼此相关，难以判断每个像素的收敛程度，常规的方差估计会把相关性误当作低噪声；不同区域得到的探索时间不均，图像可能出现块状噪声——某条链长时间停留在同一区域时，该区域的误差下降快，而其他区域几乎没有被访问。时间连续性也不容易控制，所以它很少直接用于要求稳定逐帧结果的动画。

光子映射

Photon Mapping 是两阶段方法：

  1. 从光源发射大量光子，在场景中随机反弹，并把到达漫反射表面的光子位置、方向和通量存入空间索引；
  2. 从相机追踪光线，在着色点附近收集光子，用局部密度估计还原入射能量。

第一阶段与相机无关，因此同一组光子可以被所有视角复用，这是光子映射在固定视角序列中效率较高的原因。第二阶段只使用光子统计信息，不需要为每个着色点重新追踪完整路径。

Lo(x,ωo)≈1πr2∑k=1Nfr(ωk,ωo)ΔΦk.L_o(\mathbf x,\boldsymbol\omega_o) \approx \frac1{\pi r^2} \sum_{k=1}^{N} f_r(\boldsymbol\omega_k,\boldsymbol\omega_o) \Delta\Phi_k. Lo​(x,ωo​)≈πr21​k=1∑N​fr​(ωk​,ωo​)ΔΦk​.

连接与合并

Vertex Connection and Merging 将 BDPT 的路径连接与 Photon Mapping 的邻域合并放在同一框架中。两个端点能直接互见时执行连接；无法精确连上、但空间位置足够接近时执行合并，此时用光子密度估计代替可见性连接。这样能覆盖纯连接或纯密度估计各自难以处理的路径类型：纯连接要求端点严格可见，在粗糙表面与焦散附近命中率低；纯密度估计则对镜面链无能为力。把两种策略放进同一个多重重要性采样框架后，可以按各自的路径概率分配权重，避免对同一路径重复计权，同时缓解光子映射原有的偏置。实现上需要区分三种情况并分别赋权：两个端点可见、两个端点邻近、以及两者都不成立。

Instant Radiosity 又称 Virtual Point Light 方法。它从光源追踪短路径，把每次反弹的端点视为 Virtual Point Light，简称 VPL，再用大量 VPL 照亮场景。渲染时每个着色点只需对所有 VPL 求直接光照之和，因此不需要在光源侧做可见性连接，在漫反射场景中计算快、效果稳定。主要限制有两点：VPL 离着色点过近时，1/r21/r^21/r2 型衰减会产生尖峰，需要限制最小距离或对贡献做夹紧；对高光和复杂可见性也不够理想，因为 VPL 表示的是点状光源，无法准确表示面光源在近场的遮挡关系。

参与介质

参与介质 Participating Media 包括雾、云、烟和浑浊液体，光在表面之间传播时会被吸收或散射。介质在位置 x\mathbf xx 的吸收系数为 σa\sigma_aσa​，散射系数为 σs\sigma_sσs​，二者的量纲都是长度的倒数，消光系数为

毛发

毛发不能简单视为普通表面。单根纤维近似细长透明圆柱，散射随纤维切线和方位角变化，常用 BCSDF Bidirectional Curve Scattering Distribution Function 描述穿过一条曲线截面的光传输。与表面 BRDF 相比，BCSDF 的散射分布围绕纤维切线方向定义，而不是围绕表面法线定义，因此需要一个切线坐标系表示入射与出射方向。

Kajiya–Kay 模型 以纤维切线构造经验漫反射与高光，计算便宜，但难以表达真实头发中的多条散射瓣：它把散射写成沿切线的漫反射加镜面项，无法表示透射光在纤维内部的路程差异。Marschner 模型 把人发视作具有鳞片表皮和吸收性皮质的玻璃状圆柱，区分三类主要光路：

  • RRR：在表面直接反射；
  • TTTTTT：折射进入纤维并穿出；
  • TRTTRTTRT：进入后发生一次内部反射再离开。

每条光路在纵向和方位角上形成不同散射瓣，纵向倾角主要由表面鳞片的倾斜决定，方位角分布则由圆柱折射与内部反射的几何决定。这样分解的意义在于把每条光路写成可解析计算的独立项，而不是用一个经验函数同时拟合所有散射。色素吸收主要作用于穿过皮质的路径，因此发色、逆光边缘和高光具有不同颜色：RRR 未进入皮质，几乎不带发色；TTTTTT 与 TRTTRTTRT 穿过含色素区域，随路径长度与色素密度发生选择性吸收。三类光路在纤维截面上的走向对应下图：

动物毛发常有明显髓质。髓质内部结构会产生扩散散射，使毛皮比按人发模型渲染时更饱和、更柔和。双圆柱模型用外层皮质与内层髓质表示纤维，除了 RRR、TTTTTT、TRTTRTTRT，还要考虑与髓质交互后的附加路径，例如光在髓质表面发生漫反射后重新穿出皮质，这些路径数量更多、分布更宽，是动物毛皮外观与人发的主要差别。

颗粒

沙、雪、糖等颗粒材料由数量巨大的离散颗粒组成。逐颗建模能保留轮廓、遮挡和闪烁，却需要极高的几何与求交成本：一个沙堆可能包含数以亿计的颗粒，逐颗求交会让光线的遍历代价不可接受。统计或程序化模型改为描述颗粒大小、形状、密度与散射特性，在需要时生成局部细节，从而把几何成本转化为散射参数的计算成本。

观察尺度决定合适表示：远处可用等效表面或参与介质，近景轮廓可能需要显式颗粒，中间尺度则可混合几何和统计散射。只用平滑 BRDF 往往会丢失颗粒间的多次反射和稀疏高光，因为颗粒之间的大量空隙产生了常规表面上不存在的传播路径，而这些路径正是颗粒材料在近距离下质感差异的来源。

Dipole Approximation 来自多次散射后的扩散近似，其成立前提是介质内部的光在几次散射后已接近各向同性，此时辐射传输可以用扩散方程描述。位于介质内的真实源表示入射能量，表面外的虚拟负源用于满足半无限介质的边界条件：把一个负源置于表面外侧，可以近似抵消表面处的入射通量，使解在半无限介质边界上满足菲克定律给出的条件。它适用于均匀、局部平坦、强散射且足够厚的材料；薄片、分层结构或弱散射材料需要随机游走等更完整模型，因为扩散近似在这些条件下不成立。

布料

布料是纤维加捻后织造或针织形成的层次结构。根据观察尺度和预算，可以采用三种表示：

  • 把织法的总体行为拟合为表面 BRDF，适合远景；
  • 根据纤维属性和分布推导体散射参数，把布看作参与介质；
  • 显式建模并渲染每根纤维，适合特写。

表面模型速度快，却难以得到绒毛轮廓、纱线间遮挡和透光。显式纤维最完整，几何量和路径复杂度也最高。实际资产常在不同细节层级间切换，并保留一致的平均能量和颜色，否则同一物体在不同距离下会出现亮度突变。三种表示中的中间层次对应下图：

微观细节

传统微表面模型使用统计法线分布 D(h)D(\mathbf h)D(h)。当一个像素覆盖海量、不可分辨的微表面时，这种平均是合理的；若像素 footprint 中只有少量金属亮片、划痕或波纹，真实法线分布会出现尖锐峰值，统计平均会把闪烁细节抹平，用一张全局 NDF 无法表示这种随位置变化的分布。

P-NDF Patch Normal Distribution Function 根据当前像素覆盖的表面区域 PPP 统计实际法线分布。若位置 x\mathbf xx 的局部分布为 Dx(h)D_{\mathbf x}(\mathbf h)Dx​(h)，像素范围内的平均为

DP(h)=1∣P∣∫PDx(h)dx.D_P(\mathbf h) = \frac1{|P|} \int_P D_{\mathbf x}(\mathbf h) \mathrm d\mathbf x. DP​(h)=∣P∣1​∫P​Dx​(h)dx.

这里的平均是在给定法线方向 h\mathbf hh 上逐点取值再对面积积分，因此每个 h\mathbf hh 方向都得到一个覆盖所有局部分布的权重，归一化条件对 h\mathbf hh 仍然成立。像素尺寸、观察距离和纹理频率变化时，区域 PPP 改变，P-NDF 也随之改变。渲染器可以对一个像素范围内的 BRDF 做预过滤，减少直接在超高分辨率法线贴图上盲目采样造成的 miss，即光线方向落在少量微表面之外而贡献被判为零的情况，同时仍保留 glint 等非平稳高光。

P-NDF 本身可能具有很多尖锐峰，用常规球面基函数或网格存储都会出现精度与内存的矛盾，重要性采样也不轻松，因为尖锐峰的分布难以用低维解析形式抽样。层次表示、局部解析近似和按 footprint 查询可以在细节与成本之间取得平衡。同一张法线贴图在不同 pixel footprint 下统计得到的 P-NDF 如下：

波动光学

微结构尺寸接近可见光波长时，波动光学 Wave Optics 不能再简化为独立光线。光程差会转化为相位差，叠加后产生干涉和衍射。光盘彩虹、金属薄膜、屏幕像素结构和细密划痕都可能表现出随波长和角度变化的颜色。几何光学假设微观结构远大于波长，光线之间互不影响，因而无法描述这类现象。

该图并排给出三类由微观结构产生的颜色：左侧是光盘，盘面反射在后方墙面与地面上投出环状彩色条纹；中间是表面覆有金属薄膜的模型，其外壳在高光附近呈现随角度变化的青蓝色调；右侧是手机屏幕的高光，中心亮斑周围向多个方向伸出彩色放射状条纹。每张图下方标注了对应的来源文献。

三者的共同点是颜色由结构尺度与观察角度共同决定，而不是由表面的基色贴图决定：光盘的轨道间距与金属薄膜的厚度分别固定了各自的光程差，同一结构在不同观察角度下对应不同的相位差，于是某些波长相长干涉、另一些相消，表现为环状条纹或随视角移动的彩带；屏幕像素阵列的周期性则把高光分解成衍射级次，形成放射状的多色条纹。普通的 RGB 漫反射贴色无法复现这种变化，因为贴色不包含相位信息，也不会随观察方向改变。

程序外观

程序化外观 Procedural Appearance 在着色时计算函数，不必存储完整纹理。二维噪声可以生成表面花纹，三维噪声定义在物体内部，模型被切开或破碎后仍能露出连续结构：新暴露的表面只需用同一空间函数在对应坐标处求值即可。阈值操作还能把连续噪声变成孔洞、斑点或两相材料：

m(x)={1,n(x)>τ,0,n(x)≤τ.m(\mathbf x)= \begin{cases} 1,&n(\mathbf x)>\tau,\\ 0,&n(\mathbf x)\le\tau. \end{cases} m(x)={1,0,​n(x)>τ,n(x)≤τ.​

其中 n(x)n(\mathbf x)n(x) 是归一化到固定区间的噪声函数，τ\tauτ 是阈值，mmm 是得到的材料指示函数。取值的边界由阈值位置控制，因而调整一个标量就能改变孔洞的占比与连通性。

多频噪声、Worley noise 和域扭曲可以构造木纹、石材、云层与细胞状结构。程序表示分辨率不受固定图像限制，参数也易于编辑；若函数缺少抗锯齿处理，高频细节仍会在远处产生闪烁，因此需要按像素 footprint 过滤或限制最高频率。用三维噪声直接定义材质内部结构的实例如下：


该图是一个白色陶罐，表面布满不规则的深色细线，这些线条在罐体、瓶颈与罐口内壁连续延伸，没有出现接缝或方向突变；画面标注为 Solid noise，幻灯片正文说明三维噪声可以给出内部结构，使模型在切开或破碎后仍保持连续。

这个结果对应三维噪声的定义域选择。3D noise 直接定义在物体空间坐标上，切开、拉伸或破碎模型时，截面仍能接上同一连续结构，因为函数在空间中处处有定义；每个面独立贴一张 2D 纹理则会在接缝处断开，因为各面的参数化互不相关。同一组线条在不同曲率处保持宽度与走向的连续，说明它来自空间函数而非投影图像。连续空间函数也必须结合 pixel footprint 过滤，否则高频噪声仍会产生远景闪烁。
