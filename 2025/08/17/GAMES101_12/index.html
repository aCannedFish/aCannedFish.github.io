计算机图形学-12：相机与透镜

发表于2025-08-17|更新于2026-10-10|Note计算机图形学
|浏览量:

成像过程

图像形成可分为场景光的生成与相机对光的采集。渲染器通常负责前者，相机模型负责后者：同一个场景在不同光圈、快门和焦距设置下会得到不同图像。相机内部主要包含：

  • 光圈：限制进入系统的光束范围，决定像面照度上限，也决定焦外模糊的程度；
  • 透镜：把来自场景的光聚焦到传感器，使某一深度范围内的物点重新汇聚；
  • 快门：控制传感器接收光的时间，决定曝光量，也决定运动物体在曝光期间的积分长度；
  • 传感器：把到达各像素的光转换成电信号，并在采样、量化后输出数字图像。

针孔相机 Pinhole Camera 只用一个小孔选择光线，几何关系简单，景物在成像平面上倒立。针孔过大会让一个场景点覆盖多个传感器位置而模糊，过小则进光量不足，并最终受到衍射限制。透镜能够在保持较大通光孔径的同时，让某个深度的点重新汇聚到传感器上。

这四个元件的参数相互耦合：光圈和快门同时决定曝光量，光圈还同时决定景深，快门还同时决定运动模糊。因此相机的成像模型不能只当作一组独立的旋钮，它对应一组需要联立考虑的光学量。

视场角

焦距 fff 与传感器尺寸共同决定 视场角 Field of View。若传感器某一方向的长度为 hhh，对应视场角为

FOV=2arctan⁡h2f.\mathrm{FOV} = 2\arctan\frac{h}{2f}. FOV=2arctan2fh​.

推导来自一个直角三角形：从光心到该方向传感器边缘的距离为 h/2h/2h/2，到传感器平面的垂直距离为 fff，二者之间的半张角正是 arctan⁡h2f\arctan\frac{h}{2f}arctan2fh​，整个方向的张角是它的两倍。式中 fff 和 hhh 必须使用同一长度单位，FOV\mathrm{FOV}FOV 的单位是弧度或度。

焦距越短或传感器越大，视场越宽；焦距越长或传感器越小，画面范围越窄。实际相机常分别给出水平、垂直和对角视场，因为三者使用的传感器尺寸不同。

相同镜头装在更小传感器上，只截取原成像圆中心的一部分，看起来像使用了更长焦距。裁切系数描述其视场相对某个参考画幅的比例，并不会改变镜头真实焦距或透视关系。透视主要由相机位置决定；为了保持相同构图而移动相机，才会改变前后景物的相对大小。

曝光

传感器在 曝光 Exposure 期间累计辐照度。一般曝光量为

H=∫t0t0+TE(t) dt.H = \int_{t_0}^{t_0+T} E(t)\,\mathrm dt. H=∫t0​t0​+T​E(t)dt.

积分形式说明曝光量是时间上的累加：只要快门开启期间辐照度随时间变化，就必须按时间积分而不能只看某一时刻的瞬时值。符号 HHH 表示曝光量，EEE 表示传感器平面上的辐照度。若辐照度在快门区间内近似不变，才可化为

H=TE,H=T E, H=TE,

其中 TTT 是曝光时间，EEE 是传感器上的辐照度。摄影中主要通过光圈、快门和 ISO 控制最终亮度。

光圈 Aperture、快门 Shutter 与 ISO 在这套记号下扮演不同角色：光圈改变 EEE，快门改变 TTT，二者共同改变 HHH；ISO 既不改变 EEE 也不改变 TTT，它作用在传感器信号或数字信号上，因此不会改变实际入射的光子数。

光圈改变镜头开口面积，同时影响进光量与景深；快门改变积分时间，同时影响运动模糊；ISO 是传感器信号的增益或后续标度，不会增加实际收到的光子。提高 ISO 会让已有的光子噪声、暗电流噪声和读出链路噪声在输出中更明显，可用动态范围通常也会下降；模拟增益与数字增益所处位置不同，不能笼统理解为把所有读出噪声按同一倍数放大。

在响应近似线性的范围内，减半通光面积并加倍曝光时间可保持总曝光相近，但图像效果不同：前者改变景深，后者改变运动模糊。高速摄影需要很短快门和充足照明；长曝光则能记录光轨、流水平均和微弱天体信号。

光圈值

镜头焦距为 fff、有效孔径直径为 DDD 时，f-number 定义为

N=fD.N=\frac fD. N=Df​.

常写作 f/NNN。NNN 越小，孔径越大。圆孔面积与 D2D^2D2 成正比，而成像几何还带来 1/f21/f^21/f2 的扩散，因此理想情况下

E∝D2f2=1N2.E \propto \frac{D^2}{f^2} = \frac1{N^2}. E∝f2D2​=N21​.

式中 NNN 是无量纲的比值，DDD 与 fff 使用同一长度单位。像面照度与 N2N^2N2 成反比可以从两步看出：进入镜头的能量与通光面积成正比，即与 D2D^2D2 成正比；同一个物方张角内的光被成像到距离镜头 fff 的像面上，像面上的面积按 f2f^2f2 缩放，于是辐照度再乘上 1/f21/f^21/f2。把 D=f/ND=f/ND=f/N 代入即得 E∝1/N2E\propto 1/N^2E∝1/N2，即光圈开大一档（NNN 除以 2\sqrt22​）时像面照度翻倍。这说明 f-number 相同的不同焦距镜头，在忽略透过率差异时具有近似相同的像面照度。

标准整档序列约为

1, 2, 2, 22, 4, 42,…1,\ \sqrt2,\ 2,\ 2\sqrt2,\ 4,\ 4\sqrt2,\ldots 1, 2​, 2, 22​, 4, 42​,…

相邻档的 f-number 相差 2\sqrt22​，孔径面积正好相差两倍。镜头标记的光圈是有效入瞳与焦距的比值，不一定等于直接量到的机械开口。

快门方式

物理快门在一段时间内允许光到达传感器。Global Shutter 让所有像素使用同一时间区间，运动物体沿轨迹形成连续模糊。Rolling Shutter 按行或按区域依次曝光，每一行对应略有不同的时刻，快速运动或相机转动会让直线倾斜、物体扭曲。

理想像素的 运动模糊 Motion Blur 是时间积分：

I(x)=1T∫t0t0+TL(x,t) dt.I(\mathbf x) = \frac1T \int_{t_0}^{t_0+T} L(\mathbf x,t)\,\mathrm dt. I(x)=T1​∫t0​t0​+T​L(x,t)dt.

式中 L(x,t)L(\mathbf x,t)L(x,t) 是 ttt 时刻沿像素 x\mathbf xx 所对应视线到达传感器的辐亮度，TTT 是曝光时间，前置因子 1/T1/T1/T 把结果化为时间平均值，避免总能量随曝光时间线性增大。物理含义是：曝光期间物体、相机或光源的任何变化都会在积分中被平均，而不会被选择性地记录下来。

这条式子对应所有像素共享曝光区间的 Global Shutter。Rolling Shutter 的第 yyy 行具有自己的起始时刻 t0(y)t_0(y)t0​(y)：

I(x,y)=1T∫t0(y)t0(y)+TL(x,y,t) dt.I(x,y) = \frac1T \int_{t_0(y)}^{t_0(y)+T} L(x,y,t)\,\mathrm dt. I(x,y)=T1​∫t0​(y)t0​(y)+T​L(x,y,t)dt.

两式的差别只在积分起点：全局快门各行共用 t0t_0t0​，滚动快门各行使用不同的 t0(y)t_0(y)t0​(y)。当场景在曝光期间静止时两者完全等价；一旦物体或相机在曝光期间发生位移，起点不同就会使同一瞬间的几何关系在不同扫描行之间产生偏差。

渲染时应在每个像素或扫描行的快门区间内采样时间，并在该时刻更新物体和相机状态。只把静止图像做二维模糊无法正确处理遮挡关系、反射变化和非线性运动。

薄透镜

真实镜头由多片曲面透镜组成，用来修正球差、色差和畸变。课程采用 薄透镜 Thin Lens 近似：

  • 透镜厚度相对焦距可忽略；
  • 平行于光轴的入射光经过透镜后汇聚到像方焦点；
  • 通过光心的光线近似不偏折；
  • 光路可逆。

聚焦

传感器固定在某个像距时，只有与该像距满足薄透镜方程的物平面能够精确聚焦。其他深度的光束会在传感器之前或之后会聚，到达传感器时形成 弥散圆 Circle of Confusion。

设某场景点本应在距透镜 zi′z_i'zi′​ 处成像，而传感器位于 ziz_izi​，透镜孔径直径为 DDD。会聚光锥在透镜平面处直径为 DDD，在理想像面 zi′z_i'zi′​ 处缩为零；传感器与理想像面的距离为 ∣zi−zi′∣|z_i-z_i'|∣zi​−zi′​∣。由相似三角形，

透镜采样

用光线追踪模拟薄透镜相机，可以按以下过程生成一条相机光线：

  1. 在像素覆盖区域内采样传感器点；
  2. 从针孔中心穿过该点，求它与选定焦平面的交点 pf\mathbf p_fpf​；
  3. 在透镜孔径圆盘上采样点 pl\mathbf p_lpl​；
  4. 从 pl\mathbf p_lpl​ 向 pf\mathbf p_fpf​ 发射光线。

同一像素使用不同透镜样本时，所有光线仍在焦平面交于同一点；焦外几何的交点则随孔径样本变化，平均后形成散焦模糊。这一构造可以理解为反演成像过程：真实相机中从物点出发、经过孔径不同位置的光线最终汇聚到传感器的同一点，光线追踪则从传感器出发把这些路径反向延长，因此孔径上的采样点越多，对真实光锥的近似越充分。

生成相机光线时，传感器、透镜孔径、焦平面和场景必须先变换到同一个 scene/world 坐标系，再进行求交。相机的局部坐标只用于构造初始光线；不能机械套用某个图形 API 的 NDC 到世界变换，因为不同 API 的手性、轴方向、深度范围和屏幕原点约定可能不同。

圆盘面积在半径 rrr 内的比例为 r2/R2r^2/R^2r2/R2。令 ξ1,ξ2∼U[0,1)\xi_1,\xi_2\sim U[0,1)ξ1​,ξ2​∼U[0,1)，均匀面积采样可取

r=Rξ1,θ=2πξ2.r=R\sqrt{\xi_1}, \qquad \theta=2\pi\xi_2. r=Rξ1​​,θ=2πξ2​.

式中 RRR 是孔径半径，ξ1,ξ2\xi_1,\xi_2ξ1​,ξ2​ 是两个相互独立、在 [0,1)[0,1)[0,1) 上均匀分布的随机数；θ\thetaθ 是圆盘上的极角，rrr 是采样点到圆心的距离。对 ξ1\xi_1ξ1​ 取平方根来自面积元 dA=r dr dθ\mathrm dA=r\,\mathrm dr\,\mathrm d\thetadA=rdrdθ：以 rrr 为变量的概率密度必须正比于 rrr，其累积分布函数为 r2/R2r^2/R^2r2/R2，反解即得 r=Rξ1r=R\sqrt{\xi_1}r=Rξ1​​。

若直接令 r=Rξ1r=R\xi_1r=Rξ1​，每个半径区间得到的样本数相同，却没有补偿外圈更大的面积，样本会过度集中在中心。若此时仍按均匀面积 PDF 加权，估计值就会偏离真实的孔径积分，等效于给透镜加了一个中心透光更强的透过率分布，散焦斑的亮度分布随之出现偏差。

针孔相机每个像素只对应一个原点，薄透镜相机则同时对像素面积和孔径面积积分。这两个二维积分是散焦与像素抗锯齿的共同来源，实际渲染通常用同一组样本同时覆盖二者，以降低所需采样数。有限样本会让散景出现颗粒，提高 SPP 或采用分层采样可以改善。

景深

允许的弥散圆不超过阈值 Cmax⁡C_{\max}Cmax​ 时，人眼会把一段物方距离都视为清晰，这段范围称为 景深 Depth of Field。Cmax⁡C_{\max}Cmax​ 是观看条件给出的判据，取决于输出尺寸、观看距离与可接受的模糊程度，本身没有唯一取值。

以下推导假设 ds>fd_s>fds​>f，场景点是真实物体，允许弥散圆阈值 Cmax⁡>0C_{\max}>0Cmax​>0，并沿用前文全部距离取正的约定。符号 ddd 表示物方距离，dsd_sds​ 表示对焦距离，vvv 表示对应的像距。设相机对焦在物距 dsd_sds​，由薄透镜方程，传感器固定在

vs=fdsds−f.v_s = \frac{fd_s}{d_s-f}. vs​=ds​−ffds​​.

该式由 1f=1ds+1vs\frac1f=\frac1{d_s}+\frac1{v_s}f1​=ds​1​+vs​1​ 解出 vsv_svs​ 得到，分母 ds−fd_s-fds​−f 为正保证了成像是真实像。

对满足 d>fd>fd>f、能够形成真实像的物距 ddd，理想像距为

v(d)=fdd−f.v(d) = \frac{fd}{d-f}. v(d)=d−ffd​.

该物点在传感器上的弥散圆为

C(d)=D∣vs−v(d)v(d)∣=f2N∣d−ds∣d(ds−f).\begin{aligned} C(d) &= D \left| \frac{v_s-v(d)}{v(d)} \right|\\ &= \frac{f^2}{N} \frac{|d-d_s|} {d(d_s-f)}. \end{aligned} C(d)​=D​v(d)vs​−v(d)​​=Nf2​d(ds​−f)∣d−ds​∣​.​

第二个等号是代入 D=f/ND=f/ND=f/N 并化简的结果：分子中的 ∣vs−v(d)∣|v_s-v(d)|∣vs​−v(d)∣ 化为 f2∣d−ds∣(ds−f)(d−f)\frac{f^2|d-d_s|}{(d_s-f)(d-f)}(ds​−f)(d−f)f2∣d−ds​∣​，除以 v(d)=fdd−fv(d)=\frac{fd}{d-f}v(d)=d−ffd​ 时该分母被约去，于是 f2f^2f2 落回分子、d(ds−f)d(d_s-f)d(ds​−f) 落回分母。式中 C(d)C(d)C(d) 随 ∣d−ds∣|d-d_s|∣d−ds​∣ 单调增加，因此对焦距离处的弥散圆最小；同时分母中的 ddd 说明同样大小的一对 ∣d−ds∣|d-d_s|∣d−ds​∣，在近处物体上产生的弥散圆大于远处物体，这是景深近界比远界更靠近对焦点的原因。

令 C(d)=Cmax⁡C(d)=C_{\max}C(d)=Cmax​。对相机与焦平面之间的近界 dN<dsd_N<d_sdN​<ds​，去掉绝对值得

NCmax⁡dN(ds−f)=f2(ds−dN),NC_{\max}d_N(d_s-f) = f^2(d_s-d_N), NCmax​dN​(ds​−f)=f2(ds​−dN​),

所以

dN=dsf2f2+NCmax⁡(ds−f).d_N = \frac{ d_sf^2 }{ f^2+NC_{\max}(d_s-f) }. dN​=f2+NCmax​(ds​−f)ds​f2​.

对远界 dF>dsd_F>d_sdF​>ds​，

NCmax⁡dF(ds−f)=f2(dF−ds),NC_{\max}d_F(d_s-f) = f^2(d_F-d_s), NCmax​dF​(ds​−f)=f2(dF​−ds​),

因此

dF=dsf2f2−NCmax⁡(ds−f).d_F = \frac{ d_sf^2 }{ f^2-NC_{\max}(d_s-f) }. dF​=f2−NCmax​(ds​−f)ds​f2​.

对比两式可见差别只在分母中 NCmax⁡(ds−f)NC_{\max}(d_s-f)NCmax​(ds​−f) 的符号：近界分母为两项相加，恒为正，因此 dNd_NdN​ 总是有限且小于 dsd_sds​；远界分母为两项相减，可能变号，这正是下一段讨论的来源。

只有远界分母为正时，上式才给出有限的正距离；分母等于零时，远景深延伸到无穷远，分母为负时也应把远界解释为无穷远，而非使用公式得到的负距离。对应的临界对焦距离称为 超焦距 Hyperfocal Distance：

H=f+f2NCmax⁡.H = f+\frac{f^2}{NC_{\max}}. H=f+NCmax​f2​.

把 ds=Hd_s=Hds​=H 代入 dFd_FdF​ 的分母可以验证它正好为零，即对焦在超焦距上时远界落在无穷远，而从 H/2H/2H/2 到无穷远都落在可接受清晰范围内，这是广角镜头估算对焦位置的常用依据。

这些式子给出定性规律的来源：

  • NNN 增大，即光圈缩小，近界变近、远界变远；
  • dsd_sds​ 增大时，景深通常变宽；
  • 焦距变短时，在固定物距和弥散圆标准下景深增大；
  • 放宽 Cmax⁡C_{\max}Cmax​ 会扩大被判为清晰的范围。

四条规律都可以直接在近界与远界公式中检验：第一、二、四条通过 NCmax⁡(ds−f)NC_{\max}(d_s-f)NCmax​(ds​−f) 这一项进入分母，该量越小，两界越远离 dsd_sds​；第三条则需要同时按 fdd−f\frac{fd}{d-f}d−ffd​ 重算 vsv_svs​ 与 v(d)v(d)v(d)，因为改变焦距会同时改变视场，严格比较必须在保持构图的前提下进行。

物方的可接受距离范围是 Depth of Field；传感器一侧允许前后移动的范围称为 Depth of Focus。景深边界依赖输出尺寸、观看距离、传感器与允许弥散圆标准，物理清晰度本身仍是连续变化的。

图的上半部分是薄透镜光路的交互示意，水平轴左段标为 Object space、右段标为 Image space；三束来自不同物方距离的红色光线由左侧进入透镜，透镜上下边缘的蓝色短划标出了参与成像的孔径范围，各束光线在像方会聚到光轴上不同位置，其中一束正好汇聚于传感器所在的成像平面，另外两束则在传感器之前或之后成锥尖，在传感器平面上留下大小不同的截口。图的下半部分给出该组参数下的数值，焦距 f=75 mmf=75\ \mathrm{mm}f=75 mm、f-number N=0.5N=0.5N=0.5、对焦距离 U=200 mmU=200\ \mathrm{mm}U=200 mm、允许弥散圆 C=20 mmC=20\ \mathrm{mm}C=20 mm，按 2NCU2f2\frac{2NCU^2}{f^2}f22NCU2​ 算得 142 mm，景深为 73 mm（其中 UUU 即对焦距离 dsd_sds​，结果相当于 dF−dNd_F-d_NdF​−dN​）。这两部分把 C(d)C(d)C(d)、dNd_NdN​、dFd_FdF​ 与图中粉色所示的可接受物方区间联系起来：只有孔径边缘那对光线所夹的锥角参与弥散圆的形成，因此收小光圈（增大 NNN）会缩小同一离焦量对应的截口直径，使可接受的前后景范围变宽，开大光圈的效果则相反。图中数值同时说明景深边界依赖 Cmax⁡C_{\max}Cmax​ 这一观看判据，光学系统中的清晰度本身是连续变化的，不存在突然出现的清晰与模糊分界。

景深公式并不只由光圈决定。比较不同相机时，必须同时固定构图、对焦距离和最终观看条件。
