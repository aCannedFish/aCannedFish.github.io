相机约定

在三维渲染管线中，模型变换首先将各个独立图元从局部坐标系转换至统一的世界坐标系。为了从特定视角观察场景并生成二维画面，需要建立虚拟相机，将世界坐标系下的所有顶点进一步转换至以相机为基准的相机坐标系。

虚拟相机的空间状态由三个基本要素唯一定义：

  • 相机所在的空间位置 e=(ex,ey,ez)T\mathbf e = (e_x, e_y, e_z)^Te=(ex​,ey​,ez​)T；
  • 相机的视线观察方向 g=(gx,gy,gz)T\mathbf g = (g_x, g_y, g_z)^Tg=(gx​,gy​,gz​)T；
  • 相机的向上参考向量 t=(tx,ty,tz)T\mathbf t = (t_x, t_y, t_z)^Tt=(tx​,ty​,tz​)T。

采用右手坐标系标准：相机位于坐标原点，视线朝向 −z-z−z 轴方向观察，+y+y+y 轴垂直向上，+x+x+x 轴水平向右。根据相机的空间参数，可以构造出相机坐标系的三组标准正交基底向量 u,v,w\mathbf u, \mathbf v, \mathbf wu,v,w：

w=−g∥g∥,u=t×w∥t×w∥,v=w×u.\mathbf w = -\frac{\mathbf g}{\lVert\mathbf g\rVert}, \qquad \mathbf u = \frac{\mathbf t \times \mathbf w}{\lVert\mathbf t \times \mathbf w\rVert}, \qquad \mathbf v = \mathbf w \times \mathbf u. w=−∥g∥g​,u=∥t×w∥t×w​,v=w×u.

各向量的几何意义如下：

  • 基向量 w\mathbf ww：由于相机朝向自身的 −z-z−z 方向观察，因此 +z+z+z 轴的正向必须与视线方向严格相反，即 w=−g^\mathbf w = -\hat{\mathbf g}w=−g^​，指向相机的正后方；
  • 基向量 u\mathbf uu：由向上向量 t\mathbf tt 叉乘后向向量 w\mathbf ww，根据右手定则，得到指向相机右侧的正交单位向量；
  • 基向量 v\mathbf vv：由后向向量 w\mathbf ww 叉乘右向向量 u\mathbf uu，得到严格垂直于视线和平面的实际向上正交单位向量。

上述叉积构造过程本质上对输入的参考向上向量 t\mathbf tt 完成了一次施密特正交化，纠正了用户指定的参考向上向量可能未与视线严格垂直的问题。当 t\mathbf tt 与 g\mathbf gg 平行共线时，叉积为零向量，此时相机的侧向无法确定，程序中需对该退化状态进行容错校验。

视图矩阵

视图矩阵用于将世界坐标系中的几何顶点转换到相机坐标系中。在几何上，将世界中的相机移动到原点并对齐标准主轴，等价于对世界中的所有物体施加反向变换：

  • 旋转部分：以相机的三个正交基为列向量构成旋转矩阵 Rcam→worldR_{\mathrm{cam}\rightarrow\mathrm{world}}Rcam→world​；
  • 平移部分：将原点平移到相机位置 e\mathbf ee。

正交投影

在正交投影下，所有投影光线相互平行且垂直于投影平面，物体的视觉大小不随其与相机的距离发生改变。正交投影的可见区域由空间中的一个轴对齐长方体包围盒确定：

[l,r]×[b,t]×[f,n].[l, r] \times [b, t] \times [f, n]. [l,r]×[b,t]×[f,n].

约定相机朝向 −z-z−z 轴观察，因此近裁剪面深度 nnn 与远裁剪面深度 fff 均为负数，且近平面离相机更近，满足 n>fn > fn>f（即 ∣n∣<∣f∣|n| < |f|∣n∣<∣f∣）。正交投影矩阵的目标是将该长方体空间线性映射为中心位于原点的规范视见体（即规范立方体 [−1,1]3[-1, 1]^3[−1,1]3）：

该映射仅由平移与缩放两个基础仿射变换复合而成：

  1. 平移变换：将长方体的几何中心平移至坐标原点。长方体中心点坐标为：

    c=(l+r2,b+t2,n+f2)；\mathbf c = \left(\frac{l+r}{2}, \frac{b+t}{2}, \frac{n+f}{2}\right)； c=(2l+r​,2b+t​,2n+f​)；

  2. 缩放变换：长方体在三个轴上的跨度分别为 r−lr - lr−l、t−bt - bt−b 以及 n−fn - fn−f，将其各轴长度分别缩放至规范立方体的边长 2。

透视目标

透视投影模拟人眼与真实相机的成像特性，具有“近大远小”的几何透视特征。透视投影的视锥体为一个平截头体。为了推导透视投影矩阵，图形学采用两步分解法：

  1. 首先施加一个透视压缩变换 Mpersp→orthoM_{\mathrm{persp}\rightarrow\mathrm{ortho}}Mpersp→ortho​，将平截头体压缩挤压为一个规整的长方体；
  2. 随后直接复用已有的正交投影矩阵 MorthoM_{\mathrm{ortho}}Mortho​，将长方体映射为规范立方体。

在挤压变换中，近裁剪面保持不动，远裁剪面被压缩为与近裁剪面相同的大小：

取相机空间中的任意三维点 P=(x,y,z)TP = (x, y, z)^TP=(x,y,z)T。连接相机原点与点 PPP 的视线与近裁剪平面 z=nz = nz=n 相交于投影点 P′=(x′,y′,n)TP' = (x', y', n)^TP′=(x′,y′,n)T。分别在 xzxzxz 平面与 yzyzyz 平面分析相似三角形几何关系：

x′x=nz  ⟹  x′=nxz,y′y=nz  ⟹  y′=nyz.\frac{x'}{x} = \frac{n}{z} \implies x' = \frac{n x}{z}, \qquad \frac{y'}{y} = \frac{n}{z} \implies y' = \frac{n y}{z}. xx′​=zn​⟹x′=znx​,yy′​=zn​⟹y′=zny​.

由于相机朝向 −z-z−z 轴观察，在可见视锥体内 nnn 与 zzz 均为负数，比例系数 n/zn/zn/z 为正。当物体的深度绝对值 ∣z∣|z|∣z∣ 增大时，分母增大，使得投影坐标 x′,y′x', y'x′,y′ 缩小，形成远小近大的视觉收缩。

由于映射涉及除以变元 zzz，常规三维笛卡尔线性变换无法表达该非线性操作。借助四维齐次坐标，可以将坐标乘以非零常数 zzz：

深度求解

挤压变换不能破坏空间深度的先后顺序，以便后续光栅化阶段进行遮挡剔除。根据透视对称性，变换后的深度 z′z'z′ 应只取决于原始深度 zzz，而与横向坐标 x,yx, yx,y 无关。因此矩阵第三行形如 (0,0,A,B)(0, 0, A, B)(0,0,A,B)，齐次分量计算为：

zc=Az+B.z_c = A z + B. zc​=Az+B.

经过齐次除法除以第四分量 wc=zw_c = zwc​=z 后，变换后的三维深度值为：

z′=zcwc=Az+Bz.z' = \frac{z_c}{w_c} = \frac{A z + B}{z}. z′=wc​zc​​=zAz+B​.

设定挤压变换满足两条边界几何约束：

  1. 近平面深度保持不变：近裁剪平面 z=nz = nz=n 上的任意点，变换后其深度仍为 nnn；
  2. 远平面深度保持不变：远裁剪平面 z=fz = fz=f 上的任意点，变换后其深度仍为 fff。

将两处边界条件代入公式：

z=f  ⟹  Af+Bf=f  ⟹  Af+B=f2.z = f \implies \frac{A f + B}{f} = f \implies A f + B = f^2. z=f⟹fAf+B​=f⟹Af+B=f2.

联立上述二元一次方程组，两式相减：

A(n−f)=n2−f2=(n−f)(n+f).A(n - f) = n^2 - f^2 = (n - f)(n + f). A(n−f)=n2−f2=(n−f)(n+f).

因为近平面与远平面不重合（n−f≠0n - f \ne 0n−f=0），解得：

将 AAA 代回近平面方程：

  • 近处区域（∣z∣|z|∣z∣ 较小）：导数极大，曲线陡峭。微小的世界空间距离变化就会占据极大的规范化深度范围，深度分辨率非常高；
  • 远处区域（∣z∣|z|∣z∣ 较大）：导数急剧衰减，曲线平缓。大跨度的空间距离被压缩进极小的深度数值区间内，导致远处的深度分辨率急剧下降。

这一数学特性对深度缓冲具有重要影响：若将近裁剪面距离 ∣n∣|n|∣n∣ 设置得过小（过于靠近相机眼睛），会导致有限位宽的深度缓冲区（如 24 位定点深度缓冲）将绝大部分数值精度分配给相机贴面附近的微小空间，从而使远处的物体极易产生深度精度冲突与重叠闪烁（即深度冲突，Z-fighting）。在工程实践中，应合理增大近裁剪面的距离，或采用反向深度（Reversed-Z）与浮点深度缓冲来改善远处数值精度。

视场参数

在三维建模与游戏引擎中，对称视锥体通常不直接提供 l,r,b,tl, r, b, tl,r,b,t 边界值，而是通过三个直观的物理相机参数来定义：

  • 垂直视场角 fovY⁡\operatorname{fovY}fovY（垂直方向的视野开角）；
  • 视口宽高比 a=WHa = \frac{W}{H}a=HW​（画面宽度与高度的比值）；
  • 近裁剪面距离 ∣n∣|n|∣n∣ 与远裁剪面距离 ∣f∣|f|∣f∣。

在 yzyzyz 垂直剖面中，相机视点与近裁剪面的上下边界构成对称直角三角形：

tan⁡fovY⁡2=t∣n∣.\tan\frac{\operatorname{fovY}}{2} = \frac{t}{|n|}. tan2fovY​=∣n∣t​.

由此解得上边界 ttt 与下边界 bbb：

t=∣n∣tan⁡fovY⁡2,b=−t.t = |n| \tan\frac{\operatorname{fovY}}{2}, \qquad b = -t. t=∣n∣tan2fovY​,b=−t.

根据视口宽高比一致性条件：

a=r−lt−b=2r2t=rt.a = \frac{r - l}{t - b} = \frac{2r}{2t} = \frac{r}{t}. a=t−br−l​=2t2r​=tr​.

由此解得右边界 rrr 与左边界 lll：

r=a⋅t,l=−r.r = a \cdot t, \qquad l = -r. r=a⋅t,l=−r.

增大垂直视场角 fovY⁡\operatorname{fovY}fovY 会使近裁剪平面尺寸扩大，视野容纳更多物体，画面边缘产生强烈的透视畸变；反之，减小视场角具有长焦望远镜效果。

裁剪除法

MVP 变换将局部几何顶点逐步映射至屏幕：

pclip=MprojMviewMmodelplocal.\mathbf p_{\mathrm{clip}} = M_{\mathrm{proj}} M_{\mathrm{view}} M_{\mathrm{model}} \mathbf p_{\mathrm{local}}. pclip​=Mproj​Mview​Mmodel​plocal​.

计算得到的四维列向量 pclip=(xc,yc,zc,wc)T\mathbf p_{\mathrm{clip}} = (x_c, y_c, z_c, w_c)^Tpclip​=(xc​,yc​,zc​,wc​)T 处于裁剪坐标系中。硬件管线在此阶段执行视锥体视见体裁剪：

  • 任何完全位于视锥体外部的多边形图元直接被剔除丢弃；
  • 跨越视锥体边界（尤其是穿透近裁剪平面 z=nz = nz=n）的多边形必须在四维裁剪空间中被重新裁切为新的图元顶点。若直接在除法后做裁剪，穿透近平面的顶点会因除以零或产生坐标反转而引发严重的投影拓扑撕裂。

通过裁剪测试后，管线硬件自动执行透视除法，各个分量分别除以齐次第四分量 wcw_cwc​：

(xndcyndczndc)=(xc/wcyc/wczc/wc).\begin{pmatrix}x_{ndc}\\y_{ndc}\\z_{ndc}\end{pmatrix} = \begin{pmatrix} x_c / w_c \\ y_c / w_c \\ z_c / w_c \end{pmatrix}. ​xndc​yndc​zndc​​​=​xc​/wc​yc​/wc​zc​/wc​​​.

透视除法将四维射影坐标归一化为三维规范化设备坐标（NDC），三维坐标范围被约束在标准立方体 [−1,1]3[-1, 1]^3[−1,1]3 之中。

视口变换

规范化设备坐标系与具体的屏幕分辨率无关。视口变换负责将二维连续平面坐标从 [−1,1]2[-1, 1]^2[−1,1]2 映射至物理屏幕上宽为 WWW、高为 HHH 的连续像素坐标区间 [0,W]×[0,H][0, W] \times [0, H][0,W]×[0,H]：

xs=W2(xndc+1),ys=H2(yndc+1).x_s = \frac{W}{2}(x_{ndc} + 1), \qquad y_s = \frac{H}{2}(y_{ndc} + 1). xs​=2W​(xndc​+1),ys​=2H​(yndc​+1).

写成二维仿射齐次变换矩阵形式为：

Mviewport=(W200W20H20H200100001).M_{\mathrm{viewport}} = \begin{pmatrix} \frac{W}{2}&0&0&\frac{W}{2}\\ 0&\frac{H}{2}&0&\frac{H}{2}\\ 0&0&1&0\\ 0&0&0&1 \end{pmatrix}. Mviewport​=​2W​000​02H​00​0010​2W​2H​01​​.

对于深度分量 zndc∈[−1,1]z_{ndc} \in [-1, 1]zndc​∈[−1,1]，视口变换通常将其重新线性缩放到 [0,1][0, 1][0,1] 区间供深度缓冲存储与深度测试使用：

zwin=zndc+12.z_{\mathrm{win}} = \frac{z_{ndc} + 1}{2}. zwin​=2zndc​+1​.

在屏幕像素网格中，像素索引为整数 (x,y)(x, y)(x,y)，其几何采样点中心定义在半整数偏移处：

(x+0.5,y+0.5).(x + 0.5, y + 0.5). (x+0.5,y+0.5).

视口变换完成后，三维连续几何图元已完全投影至二维屏幕坐标系。后续渲染管线进入光栅化阶段，通过采样算法判断哪些像素中心被图元覆盖，并对顶点的颜色、法线和纹理坐标等属性进行透视校正插值。
