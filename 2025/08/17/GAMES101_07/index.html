贝塞尔曲线

在三维建模与计算机视觉中，光滑曲线是描述几何轮廓的基本数学工具，广泛应用于字体矢量排版（如 TrueType 与 PostScript 轮廓）、关键帧动画运动轨迹、虚拟相机游走路径以及汽车与工业外形设计。这些场景有一个共同的需求：形状要在任意放大倍率下保持光滑，同时只允许用很少的数据来描述和调整。字体轮廓放大到整屏仍然看不到台阶，相机路径拖拽一两个控制点就能改变走向，都要求曲线能够按需重新求值。

参数曲线可以在任意缩放下重新求值，不受固定图像分辨率限制；实际屏幕渲染仍需采样和抗锯齿，不保证没有阶梯。控制点较少时可紧凑表示平滑轮廓。多段低阶样条把编辑影响限制在局部，通常比单条高阶曲线容易控制；这与高阶等距多项式插值中的 Runge 现象需区分。

把轮廓存成密集的离散点，分辨率在导出时就固定下来，相邻点之间只能线性连接，放大后必然出现折角；存成控制点加求值规则，同一份数据就能在任意参数处重新求值。字体是最典型的使用者：TrueType 用二次 B 样条描述字形轮廓，PostScript 与 CFF 用三次贝塞尔描述轮廓，两者都以少量控制点表示一段光滑边界。沿曲线运动的相机或模型除了位置还需要朝向，实现上通常再给出一条曲线或一个角度函数，把位置与朝向分别求值后合成完整的运动。参数曲线属于显式几何表示，逐点采样与求交都很直接，代价是判断内外仍要另想办法。

轮廓放大不失真靠的是控制点加求值规则，把这条思路形式化就得到本篇最基本的一种曲线。贝塞尔曲线（Bézier Curve）是一种由一组给定的离散控制多边形顶点定义的参数多项式曲线。三维空间中最通用的是三次贝塞尔曲线，由四个控制点 p0,p1,p2,p3\mathbf p_0, \mathbf p_1, \mathbf p_2, \mathbf p_3p0​,p1​,p2​,p3​ 唯一定义：

  • 曲线严格通过起点 p0\mathbf p_0p0​ 与终点 p3\mathbf p_3p3​；
  • 中间控制点 p1,p2\mathbf p_1,\mathbf p_2p1​,p2​ 通常不在曲线上，分别控制端点导数，并共同影响整段形状；
  • 移动其中任意一个控制点，整条三次曲线的形态均会发生全局改变。这种强控制性适合短小的独立曲线段，在复杂工程中通过多段三次曲线首尾拼接来实现局部形状编辑。控制点的个数没有上限，n+1n + 1n+1 个控制点定义一条 nnn 次贝塞尔曲线；只有两个控制点时，曲线退化为连接这两点的线段。

指定曲线最直接的想法是给出一批曲线上的点，让曲线穿过它们。这种做法得到的是一组插值条件：要让曲线通过每个指定点，就得解一个线性方程组；改动其中一个点，整个方程组要重解；点的数量增加还会抬高多项式次数，曲线中段容易出现多余的振荡。控制点换了一种思路，把「曲线经过哪些点」改成「曲线被哪些点牵引」：给定任意多个控制点，曲线按固定规则生成，规则与点数无关，改动一个控制点不需要重解任何方程，形状则由控制点的位置间接决定。代价是控制点本身通常不在曲线上，只能通过牵引的方式调节。

端点的行为由规则直接规定：参数 t=0t = 0t=0 时曲线落在 p0\mathbf p_0p0​，t=1t = 1t=1 时落在 p3\mathbf p_3p3​，离开与到达的方向分别沿第一条控制边 p0p1\mathbf p_0\mathbf p_1p0​p1​ 与最后一条控制边 p2p3\mathbf p_2\mathbf p_3p2​p3​。控制点的顺序决定了参数前进的走向，把顺序整体颠倒，得到的是同一条几何曲线沿相反方向走过。

求值算法

贝塞尔曲线的几何点可以通过德卡斯特里奥算法（de Casteljau Algorithm）通过纯粹的递归线性插值稳定求出。

显示曲线时还需选择参数步长。相同 Δt\Delta tΔt 在高曲率或高参数速度处跨度可能较大，应按屏幕误差自适应细分。过密样本重复写同一像素只增加开销，抗锯齿仍需估计覆盖，不能无条件累加亮度。按参数均匀采样还会让屏幕上的运动速度忽快忽慢，若需要匀速运动，要先沿曲线累积一张弧长表，记录弧长与参数的对应关系，再按弧长反查参数，用重参数化之后的参数驱动位置。

将德卡斯特里奥算法的递推公式逐层代入展开，贝塞尔曲线可以等价写为由伯恩斯坦基函数（Bernstein Basis）加权求和的显式代数形式：

b(t)=∑i=0nBin(t)pi,Bin(t)=(ni)ti(1−t)n−i.\mathbf b(t) = \sum_{i=0}^{n} B_i^n(t) \mathbf p_i, \qquad B_i^n(t) = \binom{n}{i} t^i (1 - t)^{n-i}. b(t)=i=0∑n​Bin​(t)pi​,Bin​(t)=(in​)ti(1−t)n−i.

这个形式说明曲线上任意一点都是控制点的线性组合，组合系数只由 ttt 决定、与控制点位置无关；控制点位置变化时只需重新组合，不必重新推导整条曲线。对于三次贝塞尔曲线（n=3n = 3n=3），显式展开为：

b(t)=(1−t)3p0+3t(1−t)2p1+3t2(1−t)p2+t3p3.\mathbf b(t) = (1 - t)^3 \mathbf p_0 + 3t(1 - t)^2 \mathbf p_1 + 3t^2(1 - t) \mathbf p_2 + t^3 \mathbf p_3. b(t)=(1−t)3p0​+3t(1−t)2p1​+3t2(1−t)p2​+t3p3​.

伯恩斯坦基函数具备优良的数学性质：

凸组合 Convex Combination 是非负且和为 1 的加权和；凸包 Convex Hull 是包含全部控制点的最小凸集合。凸包可以借助一个直观模型理解：把控制点看成钉在板上的钉子，用一根橡皮筋把所有钉子套住再松手，橡皮筋收缩后卡在最外层的几个钉子上，围出的区域就是凸包。因此下面的非负性与单位分解共同给出凸包性质，既能限制曲线范围，也可用于碰撞的粗筛选。

  • 非负性：在定义域 t∈[0,1]t \in [0, 1]t∈[0,1] 内，每个基函数恒满足 Bin(t)≥0B_i^n(t) \ge 0Bin​(t)≥0；

  • 权性（单位分解性）：所有基函数之和由二项式定理严格等于 1：

    ∑i=0nBin(t)=(t+(1−t))n=1n=1.\sum_{i=0}^{n} B_i^n(t) = \big(t + (1 - t)\big)^n = 1^n = 1. i=0∑n​Bin​(t)=(t+(1−t))n=1n=1.

    这意味着曲线上任意一点都是控制顶点集的一个凸组合，因此整条贝塞尔曲线严格落在其控制顶点多边形构成的凸包内部（凸包性）。这在几何碰撞检测中具有重要价值：若两组控制点凸包互不相交，则曲线自身绝不可能相交；

  • 仿射不变性：对曲线施加平移或旋转等仿射变换，等价于直接对其控制点施加相同变换再构建曲线。

基函数的和式本身就是 (t+(1−t))n(t + (1 - t))^n(t+(1−t))n 的二项展开，所以二次与三次情形的系数分别是 1,2,11, 2, 11,2,1 与 1,3,3,11, 3, 3, 11,3,3,1，全部落在曲线上各控制点所乘的权重上；单位分解由此自动成立。组合数的对称性 (ni)=(nn−i)\binom{n}{i} = \binom{n}{n-i}(in​)=(n−in​) 给出 Bin(t)=Bn−in(t)B_i^n(t) = B_{n-i}^n(t)Bin​(t)=Bn−in​(t)，这解释了为什么把控制点顺序整体颠倒只是让曲线反向走过。

凸包性质还有一个直接的应用：如果全部控制点共线，那么凸包退化成这条直线（或其中的一段），整条曲线也只能落在这条直线上，此时曲线就是一段直线。凸包同时给出了误差估计的边界：控制点受到扰动时，曲线不会跑出扰动前后的凸包之外，自适应细分可以用它来判断一段曲线是否还需要继续细分。

仿射不变性带来的好处是变换只需作用在控制点上：平移、旋转、缩放、错切之后重新求值，与先求值再逐点变换的结果完全相同，曲线数据不需要在每次变换时重新采样。这个性质只对仿射变换成立。透视投影这类带除法的变换不具备它：先把控制点投影、再用同样的规则重建曲线，得到的曲线与把原曲线逐点投影的结果并不重合。实际管线因此先在三维空间中求值、再对求出的点做投影，在需要投影不变的场合则改用带权重的有理形式。

分段与连续

控制点数量增加会让单条贝塞尔曲线的可调性迅速变差。十一个控制点画出的曲线对每个点都很敏感，拖动其中一个点，整条曲线跟着改变，希望只修改某一段时没有对应的操作；高阶曲线在中段还容易被拉平，形状不直观。可行的做法是把曲线拆成若干段，每段只用少量控制点，再按需要对齐端点与导数。三次曲线每段四个控制点，中间两个点相当于控制杆，牵引本段形状而不影响其他段，矢量绘图软件中的钢笔工具就是这种操作方式。

样条 Spline 一词来自早期制图使用的弹性木条：用压铁把细木条固定在少数几个点上，木条自然弯曲成一条光滑曲线，被压住的点相当于控制点，中间的弯曲形状由木条自身的最小能量状态决定。这解释了样条类曲线的定义方式：由一组控制点控制，并在各个位置保证一定阶数的连续。贝塞尔曲线是样条中的一种，它的基函数是伯恩斯坦多项式。

B 样条把伯恩斯坦多项式推广为分段多项式，每个基函数只在有限个节点区间上非零，这就是局部支撑 Local Support：移动一个控制点，只有对应参数区间内的曲线发生变化，其余部分完全不受影响。

网格操作

曲面片适合描述少量光滑的形状，而空间中复杂物体的表面通常交给网格。在多边形网格处理中，三大核心几何操作为：

  • 网格细分（Mesh Subdivision）：在保持或逼近原始几何形态的同时成倍增加多边形面数，生成光滑平整的曲面网格。细分同时是位移贴图的前提：几何采样密度跟不上高度场的频率时，表面上的高频细节只会被抹平或退化成锯齿。反过来，靠近相机时把粗模型临时加密，比一开始就保存最细的网格更省存储，这也是多细节层次向上取细节的手段；

  • 网格简化（Mesh Simplification）：在严格限制几何形状误差的前提下大幅削减三角形面数，生成轻量级多细节层次（LOD）模型。顶点变换与逐片元着色都要为每个三角形付出时间，移动端一类算力受限的设备对此尤其敏感，很多场合也确实不需要高复杂度的模型：

    图中同一个骷髅用 30,000、3,000、300 与 30 个三角形表示。面数降到 3,000 时整体外形基本保持，鼻子、牙齿这些细节开始变差；300 个面时轮廓仍可辨认；30 个面只剩一个大致块状。每列下方的小图把模型缩到实际观看尺寸，此时 300 个三角形与 30,000 个几乎无法区分，说明所需面数取决于物体在屏幕上占多大，这与图像的 mipmap 层次出于同一种考虑。差别在于两张图像层次之间可以做三线性插值，两套网格之间没有天然的插值方式，层次切换时会出现可见的跳变，常用做法是在切换区间内让顶点位置在两个层次之间过渡，这类过渡称为 geomorph。第一个模型即使有 30,000 个三角形，在平面着色（flat shading）下仍能看到分面：每个三角形共用一个法线时，面数再多也会显露多边形的棱边，改用逐像素插值法线的着色方式可以减轻分面感，视觉效果同时取决于面数与着色方式；

  • 网格规则化（Mesh Regularization）：保持顶点数量大致恒定，优化三角形的长宽比与内角分布，消除病态狭长三角形。面积接近零或一条边远长于其余两边的三角形会让重心坐标插值外推、法线估计不稳定、纹理被拉伸，数值计算也更容易出问题。规则化把三角形推向接近正三角形的形状，但质量提升不能以形状损失为代价，耳朵一类薄结构在重新划分时容易被削掉，需要在质量指标之外加上形状误差约束。

细分增加面数，简化减少面数，两者都要求结果仍然表示同一个形状，具体做法从细分开始。

Loop 细分

Loop 细分（Loop Subdivision）是一种专门针对三角形网格的近似型曲面细分算法，名称来自提出者 Charles Loop 的姓氏，与循环无关。在每次细分迭代中，算法执行两步核心操作：

  1. 拓扑剖分：在网格的每一条边上插入一个新的中间顶点，将每一个原始三角形连接剖分为 4 个全新的小三角形；
  2. 顶点位置加权平滑：分别依据预设权重更新新插入的顶点以及原有的旧顶点位置。

两步各自承担不同职责。只做第一步，模型被拆成更多更小的三角形，形状与原来完全相同，看上去分辨率更高而棱角依旧；只有第二步按邻域位置重新放置顶点，表面才会向光滑的极限曲面收敛。一次迭代后面数变为原来的四倍，顶点数增加的数量等于原有边数。

Loop 细分假定输入是三角网格，而建模软件导出的网格常常混有四边形、三角形乃至更多边的面。Catmull-Clark 的处理对象是任意多边形网格。描述它需要两个概念：四边形面 Quad Face 是边数为 4 的面，非四边形面 Non-Quad Face 是边数不为 4 的面；奇异点 Extraordinary Vertex 则是度数不为 4 的顶点，在纯四边形网格中它对应形状无法继续规则化的位置。

上排 Loop 使用三角网格，下排 Catmull–Clark 使用四边形网格。每排最左侧是控制网格，向右依次是迭代若干次的结果：面数不断增加，圆环的截面与立方体的转角逐渐变圆，收敛到平滑曲面；被标记为锐边的黑色边界在每一列都保持尖锐，没有被平滑规则抹掉。Crease 锐边规则 对标记过的边使用特殊权重，让这些边在极限曲面上保留折角，边界边可以按同一套规则处理，这与上一节边界边的做法一致。四边形面本身不保证形状规则，度数异常的顶点会影响该处的局部连续性。

网格简化

细分之后还需要反向操作。网格简化减少面数，同时控制轮廓和局部几何误差。二次误差测度 Quadric Error Metrics，简称 QEM，是常见的边折叠代价：将候选顶点到一组局部平面的距离平方累加，选择误差较小的折叠。直接删除三角形会在模型上留下空洞，只删除顶点又会破坏连接关系，可行的做法是把一条边的两个端点合并成一个顶点，这一操作称为边折叠（edge collapse）。

合并之后新顶点放在哪里是一个可以自由选择的位置，这一步决定了简化的质量。取两个端点的中点最简单，但相当于默认折叠不改变轮廓；取所有相关顶点的平均，会把原本鼓起的部分压平；只平均被替换掉的几个顶点，又会让轮廓整体向内收缩。把位置选择写成一个优化问题：让新顶点到它所代表的那些原始平面的距离平方和最小，这个和就是二次误差，最优位置由目标函数直接给出。

阴影贴图

几何部分的最后回到光栅化遗留的一个问题。着色模型处理的是局部关系：一个点的亮度由它自身的材质、法线、光源方向和视线方向决定，场景中其他物体的存在不参与计算。只要光源与着色点之间夹着遮挡物，该点就接收不到来自那个方向的光，算出的结果应当接近于零，这种现象就是阴影。光栅化按图元逐个处理屏幕像素，本身没有机制回答「从光源看这个点是否被挡住」，阴影贴图用一次额外的深度渲染把这个几何可见性问题变成一次查表，代价是场景要被渲染两遍。阴影同时是画面中物体接触关系的主要线索，缺少阴影时物体看上去像悬浮在地面上。这一方法长期是实时渲染中应用最广的阴影方案，早期影视制作也采用它。

阴影贴图（Shadow Mapping）是一种两阶段图像空间阴影渲染算法：判定过程只使用投影矩阵与深度信息，不需要场景的几何结构；如果一个表面点能够被相机看见且能够被点光源“看见”，则该点处于光照中；若该点能被相机看见却被遮挡物挡住而无法被光源直视，则其处于阴影之中：

图中是光源视角下的一次可见性测试结果：绿色区域里的着色点到光源的距离与阴影图上记录的深度一致，判定为可见；球体背面与地面上的黑色斑块是与记录深度不一致的位置，判定为遮挡，也就是阴影应当出现的地方。球体朝向光源一侧散布的黑色斑点来自深度比较的误差，本该受光的表面上出现了自遮挡，这正是下面深度偏移要处理的现象。

算法执行步骤如下：

  1. 光源视角渲染（第一阶段）：将虚拟相机放置在点光源位置，朝向照射方向，仅渲染场景中各图元的深度分布。将从光源视角测得的最近可见深度值记录并保存到一张二维纹理中，该纹理称为阴影图（Shadow Map）。这一步与相机视角的光栅化过程相同，只是把输出从颜色换成深度，得到的是一张深度图，也就是光源视角的深度缓冲（depth buffer，又称 z-buffer）。经典算法面向点光源与方向光源：方向光用正交投影即可覆盖场景，点光源需要覆盖四周的深度图或至少覆盖其照射范围。每个像素只保留一次比较结果，可见性只有全有与全无两种取值，这样的阴影边缘非常锐利，称为硬阴影 Hard Shadow；
  2. 相机视角渲染（第二阶段）：从真实相机视角正常执行光栅化渲染。对于屏幕上的每一个可见表面片元 p\mathbf pp，使用光源的 MVP 矩阵将其变换至光源的裁剪空间与纹理坐标 (u,v)(u, v)(u,v)。这一步等价于把该片元重新投影到光源的成像平面上，用它查出第一阶段记录的那张可见性表；
  3. 可见性深度比较：计算该片元距离光源的实际归一化深度值 dlightd_{\mathrm{light}}dlight​，并与阴影图中预存的深度采样值 dmap(u,v)d_{\mathrm{map}}(u, v)dmap​(u,v) 进行比较：

    dlight>dmap(u,v)+ε  ⟹  该点处于遮挡阴影中,d_{\mathrm{light}} > d_{\mathrm{map}}(u, v) + \varepsilon \implies \text{该点处于遮挡阴影中}, dlight​>dmap​(u,v)+ε⟹该点处于遮挡阴影中,

    其中 ε\varepsilonε 为防止由于离散数值精度引起的自阴影粉刺（Shadow Acne）而引入的微小深度偏移偏置（Depth Bias）。比较的两个深度必须来自同一种深度映射，即同一套投影与归一化方式；把世界空间距离与投影后的深度直接相比会得到错误结果。点光源使用透视投影时，深度在近处精度高、远处精度低，离开光源较远的接收面更容易出现比较误差。

阴影贴图的两类典型误差分别来自数值精度与分辨率。

自遮挡（Shadow Acne）：阴影图的一个纹素只记录一个深度值，而着色点位于连续表面上。当一个纹素覆盖的曲面在光源方向上深度跨度较大时（表面与光线接近平行），纹素里记录的最近深度可能来自比着色点更靠近光源的位置，比较结果就会把该点判为被遮挡；深度经过透视除法与量化以后也会带来同量级的误差。于是受光面上出现条纹或斑点状的自阴影，图中球面上的黑点就是这种情形。处理办法是给记录深度加上偏移量 ε\varepsilonε，把判据改为「实际深度大于记录深度加 ε\varepsilonε」。偏移量必须与表面的倾斜程度匹配：曲面越接近与光线平行，单个纹素内的深度跨度越大，需要的偏移越大；偏移过大会让接触处的阴影提前消失，物体看起来浮在地面上（peter-panning）。工程实现常用按斜率缩放的偏移、沿法线方向的偏移，或把偏移限制在最小必要值，这些手段都只是缓解数值比较的困难，不能从原理上消除它。

走样（Aliasing）：阴影图有固定分辨率，把它的比较结果投影回相机画面相当于对一个二值函数重新采样。阴影图分辨率偏低时，一个纹素覆盖相机画面上的多个像素，阴影边界出现块状台阶；分辨率相对相机画面过高时，一个像素跨越多个纹素，边界随物体与相机运动而闪烁。提高阴影图分辨率能直接减小误差，代价是渲染时间与显存开销按像素数增长；按视锥距离分档、为不同距离范围各生成一张深度图（近处用高分辨率），能在同等预算下把有限的分辨率用在最需要的地方，游戏设置中的阴影质量选项通常就对应阴影图的分辨率。

PCF Percentage-Closer Filtering 在目标纹理邻域采样多个深度值，分别比较后平均 0/1 可见性。它过滤比较结果，不是直接模糊深度：

VPCF(u,v)=1M∑j=1M1(dlight≤dmap(uj,vj)+ε).V_{\mathrm{PCF}}(u, v) = \frac{1}{M} \sum_{j=1}^{M} \mathbf 1\big(d_{\mathrm{light}} \le d_{\mathrm{map}}(u_j, v_j) + \varepsilon\big). VPCF​(u,v)=M1​j=1∑M​1(dlight​≤dmap​(uj​,vj​)+ε).

直接模糊深度图会得到没有明确几何含义的中间深度，比较之后仍然是二值结果；先比较再平均，得到的才是介于 0 与 1 之间的可见性，等价于对二值遮挡函数做一次滤波，阴影边界因此出现渐变。滤波窗口越大，边界越软，但窗口宽度固定，不随光源尺寸或遮挡距离变化，因此它只能近似半影，还会把可见性泄漏到本应完全被遮挡的区域；分辨率不足时，PCF 掩盖的是边界锯齿，栏杆、树叶一类细结构的阴影仍然可能整体消失。

PCF 过滤的是深度比较后的二值遮挡因子，能够生成柔和渐变的抗锯齿半影边缘，在实时游戏引擎中被广泛作为基础阴影管线方案。

硬阴影 Hard Shadow 的可见性只有 0 与 1 两种取值，软阴影 Soft Shadow 的可见性在边界附近连续过渡。物理上把完全看不到光源的区域称为本影 Umbra，只能看到光源一部分的区域称为半影 Penumbra：光源有面积时，遮挡物在不同位置上挡住的发光面比例不同，投影边缘才出现过渡区域。点光源的可见性只有全有与全无两种取值，因此经典阴影贴图在设计上只能产生硬阴影。半影还有一个自然特征：越靠近遮挡物与接收面的接触位置越窄，越远离接触位置越宽。要得到真实的软阴影，需要按面积光源采样，在光源面上取多个点分别做一次可见性判断再平均；PCF 只是在固定窗口上做滤波，属于开销更低的近似手段。把可见性交给光线求交直接判定，可以绕开图像空间的分辨率限制，代价是每次着色都要做一次求交计算。

采样阴影图时还会遇到光源视角之外的区域：相机画面里位于光源视野之外的片元没有对应的记录，不能按阴影处理；纹理坐标越界应使用合适的 clamp 或 border 寻址，如果使用 repeat 之类的寻址方式，越界坐标会绕回纹理的另一侧，产生重复出现的假阴影。深度偏移过大同样会使阴影与物体分离。这两类问题都属于边界与数值处理，与深度比较本身的精度问题要分开对待。
