曲线用途

在三维建模与计算机视觉中，光滑曲线是描述几何轮廓的基本数学工具，广泛应用于字体矢量排版（如 TrueType 与 PostScript 轮廓）、关键帧动画运动轨迹、虚拟相机游走路径以及汽车与工业外形设计。

与逐像素采样的光栅位图相比，参数曲线具备数学上的无限分辨率：在任意缩放比例或视角距离下均可重新动态采样，永不出现像素阶梯失真；与简单的离散折线相比，参数曲线仅需极少量的控制顶点即可精确表达光滑连续的高阶曲率形态。在工业界实践中，通常采用由多段低阶（三次）曲线光滑拼接而成的样条曲线，以避免单个高阶多项式引发的龙格现象与剧烈数值震荡。

贝塞尔曲线

贝塞尔曲线是一种由一组给定的离散控制多边形顶点定义的参数多项式曲线。三维空间中最通用的是三次贝塞尔曲线，由四个控制点 p0,p1,p2,p3\mathbf p_0, \mathbf p_1, \mathbf p_2, \mathbf p_3p0​,p1​,p2​,p3​ 唯一定义：

  • 曲线严格通过起点 p0\mathbf p_0p0​ 与终点 p3\mathbf p_3p3​；
  • 中间的两个控制点 p1\mathbf p_1p1​ 与 p2\mathbf p_2p2​ 通常不落在曲线上，其物理作用是分别控制曲线在起点与终点处的切线方向和弯曲饱满度；
  • 移动其中任意一个控制点，整条三次曲线的形态均会发生全局改变。这种强控制性适合短小的独立曲线段，在复杂工程中通过多段三次曲线首尾拼接来实现局部形状编辑。

几何求值

贝塞尔曲线的几何点可以通过德卡斯特里奥算法（de Casteljau Algorithm）通过纯粹的递归线性插值稳定求出。

给定控制顶点集 p0,p1,…,pn\mathbf p_0, \mathbf p_1, \dots, \mathbf p_np0​,p1​,…,pn​ 与归一化时间参数 t∈[0,1]t \in [0, 1]t∈[0,1]。设第 0 层点集即为原始控制点 pi0=pi\mathbf p_i^0 = \mathbf p_ipi0​=pi​。在后续各层中，对上一层中所有相邻的点对执行参数为 ttt 的线性插值：

pir(t)=(1−t)pir−1(t)+tpi+1r−1(t)(r=1,…,n;  i=0,…,n−r).\mathbf p_i^r(t) = (1 - t)\mathbf p_i^{r-1}(t) + t\mathbf p_{i+1}^{r-1}(t) \qquad (r = 1, \dots, n; \; i = 0, \dots, n - r). pir​(t)=(1−t)pir−1​(t)+tpi+1r−1​(t)(r=1,…,n;i=0,…,n−r).

对于三次贝塞尔曲线，递推过程包含三层插值金字塔：

递推代数计算如下：

  1. 第一层：在三个控制线段上分别求得点：

    p01(t)=(1−t)p0+tp1,p11(t)=(1−t)p1+tp2,p21(t)=(1−t)p2+tp3；\mathbf p_0^1(t) = (1 - t)\mathbf p_0 + t\mathbf p_1, \quad \mathbf p_1^1(t) = (1 - t)\mathbf p_1 + t\mathbf p_2, \quad \mathbf p_2^1(t) = (1 - t)\mathbf p_2 + t\mathbf p_3； p01​(t)=(1−t)p0​+tp1​,p11​(t)=(1−t)p1​+tp2​,p21​(t)=(1−t)p2​+tp3​；

  2. 第二层：连接上述三个新点构成两个新线段，再次求插值点：

    p02(t)=(1−t)p01(t)+tp11(t),p12(t)=(1−t)p11(t)+tp21(t)；\mathbf p_0^2(t) = (1 - t)\mathbf p_0^1(t) + t\mathbf p_1^1(t), \quad \mathbf p_1^2(t) = (1 - t)\mathbf p_1^1(t) + t\mathbf p_2^1(t)； p02​(t)=(1−t)p01​(t)+tp11​(t),p12​(t)=(1−t)p11​(t)+tp21​(t)；

  3. 第三层：连接最后两个点，执行最终线性插值：

    p03(t)=(1−t)p02(t)+tp12(t)。\mathbf p_0^3(t) = (1 - t)\mathbf p_0^2(t) + t\mathbf p_1^2(t)。 p03​(t)=(1−t)p02​(t)+tp12​(t)。

最终计算得到的单一点 p03(t)\mathbf p_0^3(t)p03​(t) 即为曲线在参数 ttt 处的精确三维空间坐标。德卡斯特里奥算法不仅数值计算极为稳定，还具备重要的几何细分性质：递推金字塔左侧边缘的一组点 (p0,p01,p02,p03)(\mathbf p_0, \mathbf p_0^1, \mathbf p_0^2, \mathbf p_0^3)(p0​,p01​,p02​,p03​) 与右侧边缘的一组点 (p03,p12,p21,p3)(\mathbf p_0^3, \mathbf p_1^2, \mathbf p_2^1, \mathbf p_3)(p03​,p12​,p21​,p3​)，恰好分别构成了原曲线在参数 ttt 处剖分得到的两段子贝塞尔曲线的完整控制多边形。

代数形式

将德卡斯特里奥算法的递推公式逐层代入展开，贝塞尔曲线可以等价写为由伯恩斯坦基函数加权求和的显式代数形式：

对于三次贝塞尔曲线（n=3n = 3n=3），显式展开为：

伯恩斯坦基函数具备优良的数学性质：

  • 非负性：在定义域 t∈[0,1]t \in [0, 1]t∈[0,1] 内，每个基函数恒满足 Bin(t)≥0B_i^n(t) \ge 0Bin​(t)≥0；
  • 权性（单位分解性）：所有基函数之和由二项式定理严格等于 1：

    ∑i=0nBin(t)=(t+(1−t))n=1n=1。\sum_{i=0}^{n} B_i^n(t) = \big(t + (1 - t)\big)^n = 1^n = 1。 i=0∑n​Bin​(t)=(t+(1−t))n=1n=1。

    这意味着曲线上任意一点都是控制顶点集的一个凸组合，因此整条贝塞尔曲线严格落在其控制顶点多边形构成的凸包内部（凸包性）。这在几何碰撞检测中具有重要价值：若两组控制点凸包互不相交，则曲线自身绝不可能相交；
  • 仿射不变性：对曲线施加平移或旋转等仿射变换，等价于直接对其控制点施加相同变换再构建曲线。

端点导数性质由对代数式求一阶导数直接导出：

求导可得：

b′(t)=3(1−t)2(p1−p0)+6t(1−t)(p2−p1)+3t2(p3−p2).\mathbf b'(t) = 3(1 - t)^2 (\mathbf p_1 - \mathbf p_0) + 6t(1 - t)(\mathbf p_2 - \mathbf p_1) + 3t^2 (\mathbf p_3 - \mathbf p_2). b′(t)=3(1−t)2(p1​−p0​)+6t(1−t)(p2​−p1​)+3t2(p3​−p2​).

  • 起点切向量：b′(0)=3(p1−p0)\mathbf b'(0) = 3(\mathbf p_1 - \mathbf p_0)b′(0)=3(p1​−p0​)；
  • 终点切向量：b′(1)=3(p3−p2)\mathbf b'(1) = 3(\mathbf p_3 - \mathbf p_2)b′(1)=3(p3​−p2​)。

这证明贝塞尔曲线在起点处的切线方向严格平行于第一条控制边 p0p1\mathbf p_0\mathbf p_1p0​p1​，在终点处的切线方向严格平行于最后一条控制边 p2p3\mathbf p_2\mathbf p_3p2​p3​。

分段连续

为了构建任意复杂的长曲线，通常将多段三次贝塞尔曲线首尾依次拼接。设前一段曲线控制点为 A0,A1,A2,A3A_0, A_1, A_2, A_3A0​,A1​,A2​,A3​，后一段曲线控制点为 B0,B1,B2,B3B_0, B_1, B_2, B_3B0​,B1​,B2​,B3​。两段曲线在连接处的平滑程度分为以下几何与参数连续性等级：

各等级的数学判定条件如下：

  • 位置连续（C0C^0C0 连续）：两段曲线首尾相接，仅要求连接点位置重合：

    A3=B0；A_3 = B_0； A3​=B0​；

  • 几何切向连续（G1G^1G1 连续）：两段曲线在连接处的切线方向共线同向，允许切线模长不相等。控制点 A2,A3(B0),B1A_2, A_3 (B_0), B_1A2​,A3​(B0​),B1​ 必须三点严格共线，且连接点居于两者之间：

    A3−A2=λ(B1−B0)(λ>0)；A_3 - A_2 = \lambda (B_1 - B_0) \qquad (\lambda > 0)； A3​−A2​=λ(B1​−B0​)(λ>0)；

  • 一阶参数连续（C1C^1C1 连续）：两段曲线不仅切线方向相同，且一阶导数向量模长严格相等（λ=1\lambda = 1λ=1）：

    A3−A2=B1−B0。A_3 - A_2 = B_1 - B_0。 A3​−A2​=B1​−B0​。

    即连接点 A3A_3A3​ 必须恰好是线段 A2B1A_2 B_1A2​B1​ 的几何中点；
  • 二阶参数连续（C2C^2C2 连续）：连接处的二阶导数相同，曲率连续变化无突变。在相机运动路径中，C2C^2C2 连续能确保运动加速度连续，消除镜头晃动中的顿挫感。

B 样条曲线通过引入局部支撑基函数，从根本上克服了单段贝塞尔曲线全局控制的缺陷，支持局部控制点编辑；非均匀有理 B 样条（NURBS）进一步引入投影权重与非均匀节点向量，成为 CAD 工业建模中精确表示圆锥曲线的标准工具。

贝塞尔曲面

将一维贝塞尔曲线通过张量积拓展至二维参数域，即可得到双三次贝塞尔曲面。曲面由一个 4×4=164\times4 = 164×4=16 个控制顶点的网格矩阵 {pij}\{\mathbf p_{ij}\}{pij​}（i,j∈{0,1,2,3}i, j \in \{0, 1, 2, 3\}i,j∈{0,1,2,3}）定义，其参数域为 (u,v)∈[0,1]2(u, v) \in [0, 1]^2(u,v)∈[0,1]2：

网格操作

在多边形网格处理中，三大核心几何操作为：

  • 网格细分：在保持或逼近原始几何形态的同时成倍增加多边形面数，生成光滑平整的曲面网格；
  • 网格简化：在严格限制几何形状误差的前提下大幅削减三角形面数，生成轻量级多细节层次（LOD）模型：
  • 网格规则化：保持顶点数量大致恒定，优化三角形的长宽比与内角分布，消除病态狭长三角形。

Loop 细分

Loop 细分是一种专门针对三角形网格的近似型曲面细分算法。在每次细分迭代中，算法执行两步核心操作：

  1. 拓扑剖分：在网格的每一条边上插入一个新的中间顶点，将每一个原始三角形连接剖分为 4 个全新的小三角形；
  2. 顶点位置加权平滑：分别依据预设权重更新新插入的顶点以及原有的旧顶点位置。

新边点位置更新

设待细分的内部边两端顶点为 AAA 与 BBB，共享该边的两个相邻三角形的对向顶点分别为 CCC 与 DDD。新生成的边顶点位置计算为两邻域顶点的加权和：

vnew=38(A+B)+18(C+D).\mathbf v_{\mathrm{new}} = \frac{3}{8}(A + B) + \frac{1}{8}(C + D). vnew​=83​(A+B)+81​(C+D).

权重分配突出所处边端点（各占 3/83/83/8），两侧顶点提供平滑支撑（各占 1/81/81/8），总权重和为 1。

Catmull-Clark

Catmull-Clark 细分支持包含任意 nnn 边形的多边形网格，且在执行一次细分后，网格中的所有多边形面将全部被转化为规整的四边形：

算法在每一次迭代中定义并生成三类顶点：

  1. 面点（Face Point）：每个多边形面内部取其所有顶点的算术平均几何中心：

    F=1m∑j=1mvj；\mathbf F = \frac{1}{m} \sum_{j=1}^{m} \mathbf v_j； F=m1​j=1∑m​vj​；

    E=v1+v2+F1+F24；\mathbf E = \frac{\mathbf v_1 + \mathbf v_2 + \mathbf F_1 + \mathbf F_2}{4}； E=4v1​+v2​+F1​+F2​​；

  3. 旧顶点更新：度数为 nnn 的旧顶点 P\mathbf PP，设 Fˉ\bar{\mathbf F}Fˉ 为与其相邻的所有面点的平均，Rˉ\bar{\mathbf R}Rˉ 为与其相连的所有边的中点的平均，旧顶点新位置更新为：

    P′=Fˉ+2Rˉ+(n−3)Pn。\mathbf P' = \frac{\bar{\mathbf F} + 2\bar{\mathbf R} + (n - 3)\mathbf P}{n}。 P′=nFˉ+2Rˉ+(n−3)P​。

拓扑连接规则为：将每个新面点连接至其周围各边的新边点，同时将新边点连接至对应旧顶点的更新点。网格中度数不等于 4 的顶点称为奇异点，在首次细分后奇异点的总数量便固定不再增加。

网格简化

网格简化旨在减少几何面数的同时最大化维持原始模型的视觉轮廓与几何特征。工业界最核心的标准算法是基于二次误差测度（QEM）的边折叠算法。

阴影贴图

阴影贴图是一种两阶段图像空间阴影渲染算法：如果一个表面点能够被相机看见且能够被点光源“看见”，则该点处于光照中；若该点能被相机看见却被遮挡物挡住而无法被光源直视，则其处于阴影之中：

算法执行步骤如下：

  1. 光源视角渲染（第一阶段）：将虚拟相机放置在点光源位置，朝向照射方向，仅渲染场景中各图元的深度分布。将从光源视角测得的最近可见深度值记录并保存到一张二维纹理中，该纹理称为阴影图（Shadow Map）；
  2. 相机视角渲染（第二阶段）：从真实相机视角正常执行光栅化渲染。对于屏幕上的每一个可见表面片元 p\mathbf pp，使用光源的 MVP 矩阵将其变换至光源的裁剪空间与纹理坐标 (u,v)(u, v)(u,v)；
  3. 可见性深度比较：计算该片元距离光源的实际归一化深度值 dlightd_{\mathrm{light}}dlight​，并与阴影图中预存的深度采样值 dmap(u,v)d_{\mathrm{map}}(u, v)dmap​(u,v) 进行比较：

    dlight>dmap(u,v)+ε  ⟹  该点处于遮挡阴影中，d_{\mathrm{light}} > d_{\mathrm{map}}(u, v) + \varepsilon \implies \text{该点处于遮挡阴影中}， dlight​>dmap​(u,v)+ε⟹该点处于遮挡阴影中，

    其中 ε\varepsilonε 为防止由于离散数值精度引起的自阴影粉刺（Shadow Acne）而引入的微小深度偏移偏置（Depth Bias）。

为了改善阴影边界因离散采样产生的锯齿边缘，百分比渐近过滤（PCF）在采样阴影图时，在目标纹理坐标邻域采样多个纹素，分别进行深度可见性测试，最后对 0 或 1 的二值测试结果计算加权平均：

VPCF(u,v)=1M∑j=1M1(dlight≤dmap(uj,vj)+ε).V_{\mathrm{PCF}}(u, v) = \frac{1}{M} \sum_{j=1}^{M} \mathbf 1\big(d_{\mathrm{light}} \le d_{\mathrm{map}}(u_j, v_j) + \varepsilon\big). VPCF​(u,v)=M1​j=1∑M​1(dlight​≤dmap​(uj​,vj​)+ε).

PCF 过滤的是深度比较后的二值遮挡因子，能够生成柔和渐变的抗锯齿半影边缘，在实时游戏引擎中被广泛作为基础阴影管线方案。
