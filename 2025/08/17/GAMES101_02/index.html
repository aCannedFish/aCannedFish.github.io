计算机图形学-02：几何变换

发表于2025-08-17|更新于2026-10-11|Note计算机图形学
|浏览量:

变换的用途

几何变换把物体在空间中的位置与姿态换算成一组新坐标。动画里关节的摆动与相机的行进轨迹、卡通角色被压扁又弹回的过程、把三维场景拍成二维图像，都是矩阵乘法在不同参数下的结果；摆好场景中的物体与确定相机的取景共用同一套代数，后面的视图变换与投影变换也沿用这一形式。要回答的问题可以归结为：给定变换前的一点 p\mathbf pp，求出变换后的坐标 p′\mathbf p'p′，并把这条对应关系写成可以批量计算、可以复合、可以求逆的代数形式。

写出变换矩阵

写出一个变换的常见做法是先找对应关系：把变换前的坐标逐分量与变换后的坐标联系起来，再整理成矩阵。二维变换的矩阵形式统一写成：

(x′y′)=(abcd)(xy).\begin{pmatrix}x'\\y'\end{pmatrix} = \begin{pmatrix}a&b\\c&d\end{pmatrix} \begin{pmatrix}x\\y\end{pmatrix}. (x′y′​)=(ac​bd​)(xy​).

矩阵的每一列对应一个基向量经过变换后得到的坐标，把 ex=(1,0)T\mathbf e_x=(1,0)^Tex​=(1,0)T 与 ey=(0,1)T\mathbf e_y=(0,1)^Tey​=(0,1)T 分别代入即可读出两列。这条性质是后面推导各变换矩阵的主要工具，也解释了为什么四个元素的含义可以逐列辨认。下面的缩放、错切与旋转都按这条线索逐个求出。

缩放与反射

沿 xxx 轴与 yyy 轴分别以系数 sxs_xsx​ 和 sys_ysy​ 进行缩放：

S(sx,sy)=(sx00sy).S(s_x, s_y) = \begin{pmatrix}s_x&0\\0&s_y\end{pmatrix}. S(sx​,sy​)=(sx​0​0sy​​).

每个坐标只被自己方向上的系数放大或压缩，两个方向互不干扰，所以矩阵是对角阵。sx=sys_x=s_ysx​=sy​ 时为均匀缩放，图形的长宽比与夹角都不变；两者不等时为非均匀缩放，图形被拉长或压扁，夹角随之改变。动画中常见的挤压拉伸效果正是非均匀缩放：物体在一个方向上被压扁的过程中，另一方向相应变宽，落下与弹起的动作因此带有弹性。diag⁡(−1,1)\operatorname{diag}(-1,1)diag(−1,1) 关于 yyy 轴反射，diag⁡(1,−1)\operatorname{diag}(1,-1)diag(1,−1) 关于 xxx 轴反射。奇数个负系数翻转手性；两个负系数等价于正缩放后旋转 180∘180^\circ180∘。零系数压扁一个维度，使变换不可逆。手性 Handedness 指有序坐标轴的朝向关系，影响叉积、旋转符号与正反面约定。

矩阵行列式 det⁡S=sxsy\det S = s_x s_ydetS=sx​sy​ 概括了上面几种情况：为正时保持定向，为负时翻转定向，为零时把平面压到一条直线或一个点上，变换不可逆。反射把 xxx 换成 −x-x−x 而 yyy 保持不变，按同样的“找对应关系”方法写出 x′=−xx'=-xx′=−x、y′=yy'=yy′=y，对角线自然取 (−1,1)(-1,1)(−1,1)。

错切

缩放只让对角线上的元素起作用，把非对角元打开就得到错切。水平错切将点的横坐标按其纵坐标的线性倍数偏移，而纵坐标保持不变：

H(k)=(1k01),(x′y′)=(x+kyy).H(k) = \begin{pmatrix}1&k\\0&1\end{pmatrix}, \qquad \begin{pmatrix}x'\\y'\end{pmatrix} = \begin{pmatrix}x + ky\\y\end{pmatrix}. H(k)=(10​k1​),(x′y′​)=(x+kyy​).

直观上可以把它想象成抓住一个方块的顶边向右拉，方块因此被拉歪。三条观察就能定出矩阵：沿水平方向施力，竖直方向不受影响，故 y′=yy'=yy′=y；底边 y=0y=0y=0 完全没有移动；顶边 y=1y=1y=1 上的点整体右移 kkk，而中间高度按比例过渡，y=0.5y=0.5y=0.5 处右移 k/2k/2k/2。位移量随高度线性增长，写成 x′=x+kyx' = x + kyx′=x+ky 后即为上面的矩阵。

错切变换保持图形面积不变，但改变线段之间的夹角。面积不变可以由 det⁡H(k)=1\det H(k)=1detH(k)=1 直接看出，它连符号也一并保持；夹角改变则是因为正方形被压成了平行四边形。相应地还存在竖直错切 (10k1)\begin{pmatrix}1&0\\k&1\end{pmatrix}(1k​01​)，它让 y′=y+kxy' = y + kxy′=y+kx，改变的是纵坐标，两者合起来可以表示更一般的错切。

旋转

旋转保持长度与夹角，只由一个角度参数决定，矩阵的四个元素则要借助基向量逐列求出。绕坐标原点按逆时针方向旋转 θ\thetaθ 角：

R(θ)=(cos⁡θ−sin⁡θsin⁡θcos⁡θ).R(\theta) = \begin{pmatrix} \cos\theta&-\sin\theta\\ \sin\theta&\cos\theta \end{pmatrix}. R(θ)=(cosθsinθ​−sinθcosθ​).

这句描述里有两个必须交代的约定：不额外说明时，旋转中心默认为原点；不额外说明时，正方向默认为逆时针。换成顺时针或换一个旋转中心，矩阵与结果都会变，约定不明确时矩阵本身没有意义。

推导可以从四个未知元素入手。既然旋转公式对任意点都成立，它对两个特殊点也必然成立，把这四个数写成 (abcd)\begin{pmatrix}a&b\\c&d\end{pmatrix}(ac​bd​) 后用基向量求解即可。固定坐标轴，主动旋转基向量 ex=(1,0)T\mathbf e_x=(1,0)^Tex​=(1,0)T 与 ey=(0,1)T\mathbf e_y=(0,1)^Tey​=(0,1)T，即可推导矩阵的两列：

  • 基向量 ex\mathbf e_xex​ 旋转至：

    Rex=(cos⁡θsin⁡θ);R\mathbf e_x = \begin{pmatrix}\cos\theta\\\sin\theta\end{pmatrix}; Rex​=(cosθsinθ​);

  • 基向量 ey\mathbf e_yey​ 与之垂直且同向旋转，到达：

    Rey=(−sin⁡θcos⁡θ).R\mathbf e_y = \begin{pmatrix}-\sin\theta\\\cos\theta\end{pmatrix}. Rey​=(−sinθcosθ​).

第一步的几何依据是旋转不改变长度，ex\mathbf e_xex​ 旋转后仍是单位向量，与 xxx 轴夹角为 θ\thetaθ，由直角三角形即可读出 cos⁡θ\cos\thetacosθ 与 sin⁡θ\sin\thetasinθ。把这对坐标代入矩阵乘法，a⋅1+b⋅0=cos⁡θa\cdot 1 + b\cdot 0 = \cos\thetaa⋅1+b⋅0=cosθ 给出 a=cos⁡θa=\cos\thetaa=cosθ，c⋅1+d⋅0=sin⁡θc\cdot 1 + d\cdot 0 = \sin\thetac⋅1+d⋅0=sinθ 给出 c=sin⁡θc=\sin\thetac=sinθ，第一列就此确定；对 ey\mathbf e_yey​ 重复一次得到第二列。由于矩阵的各列正是各基向量经变换后的坐标像，将两列直接拼接即得到 R(θ)R(\theta)R(θ)。旋转矩阵不需要记忆，忘记时按上面的步骤重新推一遍即可。旋转矩阵满足正交性 R(θ)−1=R(θ)TR(\theta)^{-1} = R(\theta)^TR(θ)−1=R(θ)T，且反向旋转矩阵为 R(−θ)=R(θ)−1R(-\theta) = R(\theta)^{-1}R(−θ)=R(θ)−1。满足 M−1=MTM^{-1} = M^{T}M−1=MT 的方阵称为正交矩阵 Orthogonal Matrix，旋转矩阵的列是一组单位正交向量，因而属于这一类；这条性质在求逆变换、构造视图矩阵与变换法线时都会反复用到。此外 det⁡R(θ)=1\det R(\theta)=1detR(θ)=1，旋转既保持面积也保持定向。

线性变换

缩放、错切、旋转以及镜像的输出坐标都是输入坐标的一次齐次式：x′=ax+byx' = ax + byx′=ax+by、y′=cx+dyy' = cx + dyy′=cx+dy，都不含常数项。二维线性变换 Linear Transformation 将输入位置坐标映射为输出位置坐标，其代数形式可统一表示为矩阵乘法 p′=Ap\mathbf p' = A\mathbf pp′=Ap，即前面写出的 2×22\times22×2 矩阵模板。

线性映射必须满足两个基本性质：

  1. 可加性：f(u+v)=f(u)+f(v)f(\mathbf u + \mathbf v) = f(\mathbf u) + f(\mathbf v)f(u+v)=f(u)+f(v)；
  2. 齐次性：f(ku)=kf(u)f(k\mathbf u) = kf(\mathbf u)f(ku)=kf(u)。

两条性质合起来等价于保持任意线性组合不变，即 f(αu+βv)=αf(u)+βf(v)f(\alpha \mathbf u + \beta \mathbf v) = \alpha f(\mathbf u) + \beta f(\mathbf v)f(αu+βv)=αf(u)+βf(v)；矩阵乘法恰好满足这一点，所以有限维空间上的线性映射与矩阵一一对应。判断一个操作是否为线性变换，最快的办法是看它是否保持线性组合、并把原点固定住。

线性变换的一个直接几何推论是：它必然保持坐标系原点不变，即 (0,0)T(0, 0)^T(0,0)T 在变换后仍然映射为 (0,0)T(0, 0)^T(0,0)T。代数上也能直接读出这一点：p′=Ap\mathbf p' = A\mathbf pp′=Ap 展开后每个分量都是 ax+byax + byax+by 形式的一次齐次式，不含常数项，x=y=0x = y = 0x=y=0 时只能得到 000。因此，包含常数位移项的平移操作无法仅用二维方阵直接表示：只要仍用 (x,y)(x, y)(x,y) 两个数描述位置，任何矩阵乘法的结果都逃不出 ax+byax + byax+by 的形式，而平移要求 x′=x+txx' = x + t_xx′=x+tx​ 这样的常数项。缩放、旋转、镜像与错切均属于线性变换，可完整表示为 2×22\times22×2 阶矩阵。

齐次坐标

空间平移变换定义为给位置坐标加上固定的位移常数向量：

(x′y′)=(x+txy+ty).\begin{pmatrix}x'\\y'\end{pmatrix} = \begin{pmatrix}x + t_x\\y + t_y\end{pmatrix}. (x′y′​)=(x+tx​y+ty​​).

平移的形式极其简单，却带来一个表示上的麻烦。由于存在常数项加法，平移无法用 2×22\times22×2 阶矩阵乘法统一表示：矩阵乘法只能给出线性组合，缺少容纳常数的位置。若接受这种特殊性，每次都要写成“矩阵乘向量再加一个向量”的带尾巴形式，多步变换复合时也要反复展开，与缩放、旋转的写法不一致。为了在代数形式上将平移、旋转与缩放纳入相同的矩阵乘法管线，引入齐次坐标 Homogeneous Coordinates：

  • 二维点的齐次坐标表示为三维列向量 (x,y,1)T(x, y, 1)^T(x,y,1)T；
  • 二维向量的齐次坐标表示为三维列向量 (x,y,0)T(x, y, 0)^T(x,y,0)T。

多出来的第三个分量承担实际职责。向量表示方向，把一个向量平移之后它仍是同一个向量，这种平移不变性要求平移操作作用在向量上时必须自动失效；分量取 000 正好把矩阵里承载平移的那一列乘成零。点是位置，平移必须对它生效，所以分量取 111。二维平移操作由此可统一写为 3×33\times33×3 阶矩阵：

T(tx,ty)=(10tx01ty001).T(t_x, t_y) = \begin{pmatrix} 1&0&t_x\\ 0&1&t_y\\ 0&0&1 \end{pmatrix}. T(tx​,ty​)=​100​010​tx​ty​1​​.

当该矩阵作用于点时：

(10tx01ty001)(xy1)=(x+txy+ty1),\begin{pmatrix} 1&0&t_x\\ 0&1&t_y\\ 0&0&1 \end{pmatrix} \begin{pmatrix}x\\y\\1\end{pmatrix} = \begin{pmatrix}x + t_x\\y + t_y\\1\end{pmatrix}, ​100​010​tx​ty​1​​​xy1​​=​x+tx​y+ty​1​​,

位置坐标被正确平移；当该矩阵作用于方向向量时，由于末位分量为 0，平移分量被消除：

(10tx01ty001)(xy0)=(xy0),\begin{pmatrix} 1&0&t_x\\ 0&1&t_y\\ 0&0&1 \end{pmatrix} \begin{pmatrix}x\\y\\0\end{pmatrix} = \begin{pmatrix}x\\y\\0\end{pmatrix}, ​100​010​tx​ty​1​​​xy0​​=​xy0​​,

保证方向向量不受原点平移的影响。齐次坐标的第三分量自然赋予了空间运算严格的代数含义：

  • 点减去点：(x1,y1,1)T−(x2,y2,1)T=(x1−x2,y1−y2,0)T(x_1, y_1, 1)^T - (x_2, y_2, 1)^T = (x_1 - x_2, y_1 - y_2, 0)^T(x1​,y1​,1)T−(x2​,y2​,1)T=(x1​−x2​,y1​−y2​,0)T，结果为从一个点指向另一个点的位移向量；
  • 点加上向量：(x1,y1,1)T+(vx,vy,0)T=(x1+vx,y1+vy,1)T(x_1, y_1, 1)^T + (v_x, v_y, 0)^T = (x_1 + v_x, y_1 + v_y, 1)^T(x1​,y1​,1)T+(vx​,vy​,0)T=(x1​+vx​,y1​+vy​,1)T，结果为沿向量移动后的新位置点；
  • 向量加上向量：末位为 0+0=00+0=00+0=0，结果仍是向量，符合首尾相接的三角形法则；
  • 两个采用 w=1w=1w=1 的点相加后末分量为 2，除以 2 得到中点。这依赖所选归一化表示，任意齐次代表元直接相加不一定表示中点。

齐次除法

更一般地，对于齐次坐标 (X,Y,w)T(X, Y, w)^T(X,Y,w)T（其中 w≠0w \ne 0w=0），其对应的二维欧几里得空间笛卡尔坐标通过齐次除法 Homogeneous Division 得到：

(x,y)=(Xw,Yw).(x, y) = \left(\frac{X}{w}, \frac{Y}{w}\right). (x,y)=(wX​,wY​).

因此，任意非零标量缩放 (kX,kY,kw)T(kX, kY, kw)^T(kX,kY,kw)T 均等价于同一个二维空间点。当 w=0w = 0w=0 时，该点代表射影平面上的无穷远点（即纯粹的方向向量）。这条扩充定义解释了为什么点加点是合法运算：两个点相加得到末分量 2，再做一次齐次除法就落到中点；推广到不相等的权重，(w1p1+w2p2)/(w1+w2)(w_1 \mathbf p_1 + w_2 \mathbf p_2)/(w_1 + w_2)(w1​p1​+w2​p2​)/(w1​+w2​) 表示按权重加权的平均位置，这正是后续重心坐标插值所依赖的形式。

引入齐次坐标是有代价的：每个点与向量多存一个分量，二维变换矩阵从 2×22\times22×2 变成 3×33\times33×3。不过在仿射变换下最后一行恒为 (0,0,1)(0, 0, 1)(0,0,1)，真正承载信息的仍是六个元素，多出的三个分量只是把平移安置进了统一的位置，实际开销很小。这里需要留意一个容易走偏的推论：末位分量并不总等于 111，矩阵最后一行也不一定是 (0,0,1)(0, 0, 1)(0,0,1)；后者只是仿射变换的特征，齐次坐标允许更一般的矩阵，那时 www 会被改写，齐次除法才真正发挥作用。

仿射变换

有了第三个分量，线性变换与平移可以装进同一个矩阵。将线性变换与平移操作组合而成的空间映射称为仿射变换 Affine Transformation，在齐次坐标下用统一的矩阵乘积表示：

(x′y′1)=(abtxcdty001)(xy1).\begin{pmatrix}x'\\y'\\1\end{pmatrix} = \begin{pmatrix} a&b&t_x\\ c&d&t_y\\ 0&0&1 \end{pmatrix} \begin{pmatrix}x\\y\\1\end{pmatrix}. ​x′y′1​​=​ac0​bd0​tx​ty​1​​​xy1​​.

把右边的乘积按第一行展开得到 ax+by+txax + by + t_xax+by+tx​，可见一个仿射矩阵作用在点上时先施加线性变换，再叠加平移，tx,tyt_x, t_ytx​,ty​ 不会参与任何旋转或缩放。矩阵的各部分因此有固定分工：左上角 2×22\times22×2 块是线性部分，最后一列前两个数是平移量，最后一行是补齐维度的 (0,0,1)(0, 0, 1)(0,0,1)。判断一个矩阵描述的是先平移还是先线性变换，看展开式即可，这个顺序在三维情形下完全相同。

仿射变换具有如下几何不变性：

  • 映射后直线仍然为直线（保共线性）；
  • 变换前相互平行的直线在变换后依然相互平行（保平行性）；
  • 同一条直线上各线段的长度比例在变换后保持不变。

三条不变性都能从矩阵形式推出。直线上的点可以写成 p(t)=(1−t)p0+tp1\mathbf p(t) = (1-t)\mathbf p_0 + t \mathbf p_1p(t)=(1−t)p0​+tp1​，仿射映射作用后参数 ttt 原封不动地保留下来，端点仍是端点，比例也仍是比例，所以共线性与长度比同时成立；两条平行直线只相差一个平移，而它们的方向向量相同，线性部分作用在相同方向上得到相同结果，因此平行关系不被破坏。这也说明仿射变换无法产生近大远小的效果，平行线在仿射变换下不会相交。

仿射变换矩阵的最后一行始终为 (0,0,1)(0, 0, 1)(0,0,1)。由于所有仿射变换均采用统一的矩阵形式，多步连续变换可以通过矩阵乘法预先相乘，合并为单一的综合变换矩阵。合并的规律可以直接写出来：若先把 p\mathbf pp 按 (A1,t1)(\mathbf A_1, \mathbf t_1)(A1​,t1​) 变换，再按 (A2,t2)(\mathbf A_2, \mathbf t_2)(A2​,t2​) 变换，等价于一次线性部分为 A2A1\mathbf A_2\mathbf A_1A2​A1​、平移部分为 A2t1+t2\mathbf A_2\mathbf t_1 + \mathbf t_2A2​t1​+t2​ 的仿射变换，

A=A2A1,t=A2t1+t2.\mathbf A = \mathbf A_2 \mathbf A_1, \qquad \mathbf t = \mathbf A_2 \mathbf t_1 + \mathbf t_2. A=A2​A1​,t=A2​t1​+t2​.

右边第二项里的 A2\mathbf A_2A2​ 说明前一步的平移量会被后一步的线性部分继续加工，这也是两个矩阵不能随意对调的根源。仿射变换的集合在复合下封闭，任意有限次复合的结果仍是仿射变换，最后一行仍为 (0,0,1)(0, 0, 1)(0,0,1)，因此可以放心地把整条变换链压成一个矩阵。

变换次序

在列向量表示法中，多个矩阵依次作用于向量 p\mathbf pp 时，变换顺序从右向左执行。若首先施加变换 A1A_1A1​，接着施加变换 A2A_2A2​，最终变换结果为：

p′=A2A1p.\mathbf p' = A_2 A_1 \mathbf p. p′=A2​A1​p.

分析物体在空间中的相对运动：

  • 先平移后旋转（即 R⋅T⋅pR \cdot T \cdot \mathbf pR⋅T⋅p）：物体首先沿平移向量脱离原点，随后绕全局坐标原点旋转 θ\thetaθ 角，物体将沿着以原点为中心的圆周公转，最终到达右上方的目标位置；
  • 先旋转后平移（即 T⋅R⋅pT \cdot R \cdot \mathbf pT⋅R⋅p）：物体首先在原点自转 θ\thetaθ 角，随后直接按照预设向量平移，物体停留在右侧不同的几何空间位置。

复合与分解

顺序不可交换，整条链本身却可以合并。把同一组变换预先相乘后，每个顶点只需与综合矩阵相乘，减少重复计算。这一步之所以可行，是因为矩阵乘法满足结合律，An⋯A1pA_n \cdots A_1 \mathbf pAn​⋯A1​p 中先算哪一段乘积都不影响结果，而所有中间结果仍是同阶矩阵。假设用齐次坐标描述二维变换，每个矩阵都是 3×33\times33×3，无论乘多少个，乘积依然是 3×33\times33×3，一次变换与一百次变换的存储代价相同；在顶点数量很大时，逐顶点执行一条长长的矩阵链与执行一次矩阵乘法之间的差距非常明显。这里预乘只适用于共享这组变换的顶点，骨骼蒙皮等仍可能使用多组矩阵。层次化场景的做法也是如此：父节点的世界矩阵左乘子节点的局部矩阵，就得到子节点的世界矩阵，每个节点只需存一个局部变换。

反方向的技巧同样常用：一个不好直接写出的变换，可以拆成几步已经会写的变换。若需要让物体绕其自身的局部几何中心 c=(cx,cy)T\mathbf c = (c_x, c_y)^Tc=(cx​,cy​)T 旋转 θ\thetaθ 角，不能直接施加 R(θ)R(\theta)R(θ)，而应构建三步复合变换：

  1. 先平移物体，使其旋转中心移至全局坐标原点：T(−c)T(-\mathbf c)T(−c)；
  2. 绕全局坐标原点进行标准旋转：R(θ)R(\theta)R(θ)；
  3. 将旋转后的物体平移回原始中心位置：T(c)T(\mathbf c)T(c)。

综合变换矩阵表示为：

M=T(c)R(θ)T(−c).M = T(\mathbf c) R(\theta) T(-\mathbf c). M=T(c)R(θ)T(−c).

这里的思路是把不熟悉的问题化成已经解决的问题：只会绕原点旋转，就先把旋转中心搬到原点，转完再搬回去。同一个综合矩阵可以对应多种变换序列，分解方式并不唯一，T(c)R(θ)T(−c)T(\mathbf c) R(\theta) T(-\mathbf c)T(c)R(θ)T(−c) 只是其中最容易理解的一种。同样的思路在后面处理绕任意轴旋转时还会出现，构造视图矩阵时也会用到类似的先平移后旋转的复合。

逆变换

复合把若干变换压成一个矩阵，逆变换则回答如何把它撤销。逆变换 Inverse Transformation 用于从目标状态精确还原回变换前的原始坐标系。做完一个变换再做它对应的逆变换，等于什么都没做，这在代数上就是矩阵与其逆矩阵相乘得到单位阵。其代数表示即为对应变换矩阵的逆矩阵：

  • 平移变换的逆为反向平移：T(tx,ty)−1=T(−tx,−ty)T(t_x, t_y)^{-1} = T(-t_x, -t_y)T(tx​,ty​)−1=T(−tx​,−ty​)；
  • 缩放变换的逆为倒数缩放：S(sx,sy)−1=S(1/sx,1/sy)S(s_x, s_y)^{-1} = S(1/s_x, 1/s_y)S(sx​,sy​)−1=S(1/sx​,1/sy​)；
  • 旋转变换的逆为其转置矩阵：R(θ)−1=R(−θ)=R(θ)TR(\theta)^{-1} = R(-\theta) = R(\theta)^TR(θ)−1=R(−θ)=R(θ)T。

对于由多个基础变换复合而成的综合矩阵，其逆变换矩阵由各分量逆矩阵按相反次序相乘得到：

(TRS)−1=S−1R−1T−1.(T R S)^{-1} = S^{-1} R^{-1} T^{-1}. (TRS)−1=S−1R−1T−1.

顺序必须颠倒，因为还原要按施加顺序倒着撤销：最后做的变换最先被抵消。仿射矩阵的逆有闭式写法，把矩阵写成线性部分与平移部分 (At01)\begin{pmatrix}\mathbf A & \mathbf t\\ \mathbf 0 & 1\end{pmatrix}(A0​t1​) 后，

(At01)−1=(A−1−A−1t01).\begin{pmatrix}\mathbf A & \mathbf t\\ \mathbf 0 & 1\end{pmatrix}^{-1} = \begin{pmatrix}\mathbf A^{-1} & -\mathbf A^{-1}\mathbf t\\ \mathbf 0 & 1\end{pmatrix}. (A0​t1​)−1=(A−10​−A−1t1​).

逆变换的线性部分是原线性部分的逆，平移部分先被 A−1\mathbf A^{-1}A−1 加工再取负，这正好落实了上面“反向且反序”的规则，也说明仿射变换的逆仍然是仿射变换，最后一行依旧为 (0,0,1)(0, 0, 1)(0,0,1)。旋转的逆只需转置，不涉及除法，在数值上比一般求逆更稳定；一般矩阵求逆则要除以行列式。

若缩放系数中存在 0，矩阵行列式为 0，空间几何维度发生坍缩，此时逆矩阵不存在。在构建视锥体拾取或光线投射等需要逆变换的算法中，必须保证模型变换矩阵非奇异。这类算法把逆变换当作进入物体局部坐标系的入口：世界空间中的一条光线经 M−1\mathbf M^{-1}M−1 变换后，可以在单位球、单位立方体这类标准形体上求交，再把交点变换回世界空间，省去为每个物体单独推导求交公式；同理，法线的变换需要用到逆转置矩阵，原因见后文。

值得区分的是另一类反向问题：给定末端位置反解关节角度时，正向映射一般不可逆，解可能不存在，也可能有多组，需要借助反向运动学的数值方法处理，与矩阵求逆属于两类不同的问题。

欧拉角

通过将物体依次绕三个主轴旋转特定角度，可以合成任意三维朝向，这组角度被称为欧拉角 Euler Angles：

Rxyz(α,β,γ)=Rx(α)Ry(β)Rz(γ).\mathbf R_{xyz}(\alpha, \beta, \gamma) = \mathbf R_x(\alpha) \mathbf R_y(\beta) \mathbf R_z(\gamma). Rxyz​(α,β,γ)=Rx​(α)Ry​(β)Rz​(γ).

绕 xxx、yyy、zzz 轴旋转的量分别是 α,β,γ\alpha, \beta, \gammaα,β,γ，右到左依次施加。三个角足以确定任意朝向，直观依据来自飞机的姿态：抬头或低头、向左或向右转向、机身向一侧倾斜，这三种动作合起来可以把机头指向任何方向。飞行模拟一类应用就用这三个角描述姿态，飞机图中可以看到它们各自对应的转轴：

  1. 次序敏感：绕不同坐标轴旋转的复合顺序（如 RxRyRzR_x R_y R_zRx​Ry​Rz​ 与 RzRyRxR_z R_y R_xRz​Ry​Rx​）会产生截然不同的朝向；
  2. 万向节锁 Gimbal Lock：对三个互异轴的常见序列，中间角达到 ±90∘\pm90^\circ±90∘ 时第一和第三次旋转的轴重合，两个参数表达同一方向的变化。物体仍能旋转，退化的是参数独立性；其他序列的奇异角度可能不同。

中间角取到 ±90∘\pm90^\circ±90∘ 时，第一与第三次旋转的轴被转到了同一条直线上，三个角里只有两个还能独立改变姿态，姿态到角度的反解不再唯一，插值时也会出现某一方向无法转动的情况。此时物体本身仍可到达任意姿态，失效的是这组参数。

在需要平滑插值旋转姿态的高级渲染与动画系统中，通常采用单位四元数来替代欧拉角表示三维旋转。插值的需求来自一个具体困难：把旋转 15∘15^\circ15∘ 与旋转 25∘25^\circ25∘ 的两个矩阵逐元素取平均，得到的矩阵不再正交，也不对应任何旋转，更不等于旋转 20∘20^\circ20∘，所以旋转矩阵不能像普通标量那样线性插值。

四元数 Quaternion 用四个分量表示旋转，单位四元数模长为 1，其分量不能分别理解成四个角。组合与插值方法见关键帧。

p⊥′=cos⁡αp⊥+sin⁡α(n×p⊥)=cos⁡α(p−nnTp)+sin⁡α(n×p).\mathbf p_\perp' = \cos\alpha \mathbf p_\perp + \sin\alpha (\mathbf n \times \mathbf p_\perp) = \cos\alpha (\mathbf p - \mathbf n \mathbf n^T \mathbf p) + \sin\alpha (\mathbf n \times \mathbf p). p⊥′​=cosαp⊥​+sinα(n×p⊥​)=cosα(p−nnTp)+sinα(n×p).

这里的正方向由右手定则确定，与 Rx,Ry,Rz\mathbf R_x, \mathbf R_y, \mathbf R_zRx​,Ry​,Rz​ 的约定一致。将不变的平行分量与旋转后的垂直分量重新合成：

p′=p∥+p⊥′=nnTp+cos⁡α(p−nnTp)+sin⁡α(n×p)=cos⁡αp+(1−cos⁡α)nnTp+sin⁡α(n×p).\begin{aligned} \mathbf p' &= \mathbf p_\parallel + \mathbf p_\perp' \\ &= \mathbf n \mathbf n^T \mathbf p + \cos\alpha (\mathbf p - \mathbf n \mathbf n^T \mathbf p) + \sin\alpha (\mathbf n \times \mathbf p) \\ &= \cos\alpha \mathbf p + (1 - \cos\alpha) \mathbf n \mathbf n^T \mathbf p + \sin\alpha (\mathbf n \times \mathbf p). \end{aligned} p′​=p∥​+p⊥′​=nnTp+cosα(p−nnTp)+sinα(n×p)=cosαp+(1−cosα)nnTp+sinα(n×p).​

将叉积运算写成反对称矩阵乘法形式：

[n]×=(0−nznynz0−nx−nynx0),[n]×p=n×p.[\mathbf n]_\times = \begin{pmatrix} 0&-n_z&n_y\\ n_z&0&-n_x\\ -n_y&n_x&0 \end{pmatrix}, \qquad [\mathbf n]_\times \mathbf p = \mathbf n \times \mathbf p. [n]×​=​0nz​−ny​​−nz​0nx​​ny​−nx​0​​,[n]×​p=n×p.

[n]×[\mathbf n]_\times[n]×​ 称为反对称矩阵 Skew-Symmetric Matrix，满足 [n]×T=−[n]×[\mathbf n]_\times^T = -[\mathbf n]_\times[n]×T​=−[n]×​。把叉积写成矩阵乘法之后，整个旋转不再含有非线性运算，可以与其他矩阵一起参与复合。提取公因式 p\mathbf pp，即可得到罗德里格斯旋转矩阵：

R(n,α)=cos⁡αI+(1−cos⁡α)nnT+sin⁡α(0−nznynz0−nx−nynx0).R(\mathbf n, \alpha) = \cos\alpha I + (1 - \cos\alpha) \mathbf n \mathbf n^T + \sin\alpha \begin{pmatrix} 0&-n_z&n_y\\ n_z&0&-n_x\\ -n_y&n_x&0 \end{pmatrix}. R(n,α)=cosαI+(1−cosα)nnT+sinα​0nz​−ny​​−nz​0nx​​ny​−nx​0​​.

验证其极限情况：

  • 当旋转角 α=0\alpha = 0α=0 时，cos⁡0=1,sin⁡0=0\cos 0 = 1, \sin 0 = 0cos0=1,sin0=0，矩阵退化为单位阵 III；
  • 当待旋转向量为轴向量 p=n\mathbf p = \mathbf np=n 时，因 nnTn=n\mathbf n \mathbf n^T \mathbf n = \mathbf nnnTn=n 且 n×n=0\mathbf n \times \mathbf n = \mathbf 0n×n=0，计算得 R(n,α)n=nR(\mathbf n, \alpha)\mathbf n = \mathbf nR(n,α)n=n，旋转轴自身保持不动。

再取 α=180∘\alpha = 180^\circα=180∘，cos⁡α=−1\cos\alpha = -1cosα=−1、sin⁡α=0\sin\alpha = 0sinα=0，矩阵化为 2nnT−I2\mathbf n \mathbf n^T - I2nnT−I，它并不等于 −I-I−I：绕 n\mathbf nn 轴转半圈只把垂直于轴的平面翻转，沿轴的分量必须保持不变，这与上面的极限检查一致。

公式中有一处冗余：把轴反向并同时让角度取负，即 R(−n,−α)=R(n,α)R(-\mathbf n, -\alpha) = R(\mathbf n, \alpha)R(−n,−α)=R(n,α)，同一个旋转有两组轴角参数，单位四元数里 qqq 与 −q-q−q 表示同一旋转也是同一回事。

若旋转轴通过任意空间点 c\mathbf cc 而非原点，则通过前后平移复合实现：

M=T(c)R(n,α)T(−c).M = T(\mathbf c) R(\mathbf n, \alpha) T(-\mathbf c). M=T(c)R(n,α)T(−c).

这三步与二维中绕任意点旋转的做法一致：先把轴搬到原点，施加只对原点轴成立的罗德里格斯公式，再把结果搬回原处。

法线变换

位置与方向在齐次坐标下由末位分量区分，变换它们所用的矩阵还有一处差别：切向量与位置一样直接由模型矩阵变换，法向量却需要另算一个矩阵。模型表面顶点的切向量 t\mathbf tt 随模型局部的线性变换矩阵 MMM 同步改变：

t′=Mt.\mathbf t' = M \mathbf t. t′=Mt.

表面法向量 n\mathbf nn 在几何上定义为与该点所有局部切向量严格正交垂直：

n⋅t=nTt=0.\mathbf n \cdot \mathbf t = \mathbf n^T \mathbf t = 0. n⋅t=nTt=0.

法向量由“垂直于该点所有切向量”这一条件定义，长度可以任意缩放。变换之后，这个垂直条件必须继续成立，法向量该往哪个方向偏转，取决于切向量被怎样改变。以非均匀缩放为例，把 xxx 方向拉伸两倍会让斜面上的切向量变得更平缓，法向量若按同样的规则拉伸，只会朝被拉伸的方向偏得更多，反而与切向量不再垂直；要维持正交，法向量必须朝相反的方向偏。缩放拉伸的是切向量，法向量需要在同一方向上“收缩”，这正是逆转置矩阵要做的事。

若直接使用变换矩阵 MMM 变换法向量（即令 n′=Mn\mathbf n' = M \mathbf nn′=Mn），在模型发生非均匀缩放时，由于各坐标轴拉伸比例不同，切向量被倾斜拉伸，原本垂直的法向量将失去正交性：

(Mn)T(Mt)=nTMTMt≠0.(M\mathbf n)^T (M\mathbf t) = \mathbf n^T M^T M \mathbf t \ne 0. (Mn)T(Mt)=nTMTMt=0.

只要 MTMM^T MMTM 不等于单位阵，点积就不再为零。设正确的法向量变换矩阵为 GGG，即 n′=Gn\mathbf n' = G \mathbf nn′=Gn。要求变换后的法向量与变换后的切向量在任意情况下均保持垂直：

(n′)Tt′=(Gn)T(Mt)=nTGTMt=0.(\mathbf n')^T \mathbf t' = (G \mathbf n)^T (M \mathbf t) = \mathbf n^T G^T M \mathbf t = 0. (n′)Tt′=(Gn)T(Mt)=nTGTMt=0.

由于原始向量始终满足 nTt=0\mathbf n^T \mathbf t = 0nTt=0，为了使上述恒等式对任意切向量与法向量恒成立，只需满足：

GTM=I  ⟹  GT=M−1  ⟹  G=(M−1)T=M−T.G^T M = I \implies G^T = M^{-1} \implies G = (M^{-1})^T = M^{-T}. GTM=I⟹GT=M−1⟹G=(M−1)T=M−T.

因此，法向量的正确变换矩阵为模型线性变换矩阵的逆转置矩阵 Inverse Transpose：

n′=normalize⁡(M−Tn).\mathbf n' = \operatorname{normalize}\left(M^{-T} \mathbf n\right). n′=normalize(M−Tn).

这里假设 MMM 可逆。例如切向量 (1,1,0)(1,1,0)(1,1,0) 与法线 (1,−1,0)(1,-1,0)(1,−1,0) 垂直，在 M=diag⁡(2,1,1)M=\operatorname{diag}(2,1,1)M=diag(2,1,1) 下切向量变为 (2,1,0)(2,1,0)(2,1,0)；直接变换法线得 (2,−1,0)(2,-1,0)(2,−1,0)，点积为 3，逆转置得 (1/2,−1,0)(1/2,-1,0)(1/2,−1,0)，点积仍为 0。对照这两个结果，(2,−1,0)(2,-1,0)(2,−1,0) 沿拉伸方向偏得更多，(1/2,−1,0)(1/2,-1,0)(1/2,−1,0) 在该方向上被压短，方向相应变陡，正好补上切向量变平缓的那部分。

在实际工程计算中：

  • 平移操作不改变法向量方向，因此只需提取 4×44\times44×4 仿射变换矩阵左上角的 3×33\times33×3 线性部分；法向量是方向向量，齐次分量取 0，平移那一列对它没有作用，用 4×44\times44×4 的逆转置作用在 (n,0)(\mathbf n, 0)(n,0) 上时，前三个分量恰好等于左上角 3×33\times33×3 部分的逆转置乘 n\mathbf nn；
  • 当变换仅包含旋转与均匀缩放时，旋转矩阵满足 R−T=RR^{-T} = RR−T=R，均匀缩放后法线方向不变，只需对变换结果重新归一化即可；
  • 当存在非均匀缩放或错切时，必须严格使用逆转置矩阵计算法向量，单纯在着色器中对结果进行归一化无法纠正方向偏差。

实际实现通常预先算出左上角 3×33\times33×3 部分的逆转置并作为矩阵常量传给着色器（例如 three.js 中的 normalMatrix），每个顶点做一次 3×33\times33×3 乘法后再归一化，省去逐顶点求逆。需要留意 MMM 不可逆的情形：某个轴的缩放系数取 0 时曲面已被压塌，法向量失去定义，逆转置也不存在，这类矩阵要在导出模型时排除。
