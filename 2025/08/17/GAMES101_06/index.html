计算机图形学-06：几何表示

发表于2025-08-17|更新于2026-10-10|Note计算机图形学
|浏览量:

表示选择

在计算机图形学中，几何形体的数学表示方式必须服务于具体的算法与计算需求。实时渲染注重表面的快速光栅化采样与光线求交，物理模拟注重内外空间判定与碰撞距离检测，几何建模系统强调局部曲面的连续性控制，而流体动画则需要适应剧烈的拓扑断裂与合并。

几何表示可划分为两大基础数学流派：

两大流派的数学定义与特性如下：

  • 隐式表示：通过空间标量方程 f(x,y,z)=0f(x, y, z) = 0f(x,y,z)=0 隐式定义形体表面。其优势在于内外测试与光线求交极其高效（只需评估代数符号或执行求根），易于描述闭合实体与拓扑形变；缺陷在于难以直接枚举并遍历表面顶点，显示时需要借助光线步进或等值面抽取算法；
  • 显式表示：通过显式列举几何顶点与拓扑连接关系（如多边形网格），或通过二维参数域映射 p=f(u,v)\mathbf p = f(u, v)p=f(u,v)（如贝塞尔曲面）显式给出表面坐标。其优势在于表面点采样和光栅化渲染极快；缺陷在于空间内外判定通常需要执行复杂射线穿透计数，且拓扑结构编辑难度高。

在纹理与几何交界处，环境光贴图使用球面或立方体参数化存储全景信息：

立方体贴图将空间全景颜色投影到包围立方体的六个二维正方形面上。给定以原点为起点的三维方向向量，通过寻找绝对值最大的分量定位目标面，并在面内换算归一化坐标采样环境辐射。立方体贴图记录的是无限远处的方向辐射场，不定义具备空间深度的物理碰撞几何。

代数曲面

代数曲面是最基础的隐式表示形式，通过三维实多项式方程定义：

f(x,y,z)=0.f(x, y, z) = 0. f(x,y,z)=0.

例如，中心位于原点、半径为 RRR 的三维球面定义为二次代数曲面：

f(x,y,z)=x2+y2+z2−R2=0.f(x, y, z) = x^2 + y^2 + z^2 - R^2 = 0. f(x,y,z)=x2+y2+z2−R2=0.

代数符号自然划定了三维空间：

  • f(x,y,z)<0f(x, y, z) < 0f(x,y,z)<0：点落在物体几何内部；
  • f(x,y,z)=0f(x, y, z) = 0f(x,y,z)=0：点严格落在物体表面上；
  • f(x,y,z)>0f(x, y, z) > 0f(x,y,z)>0：点落在物体几何外部。

通过更高阶的多项式可以解析定义圆环面、双曲面及各类三次或四次曲面。解析代数曲面的数学形式极度紧凑，将空间射线方程 r(t)=o+td\mathbf r(t) = \mathbf o + t\mathbf dr(t)=o+td 代入曲面方程即可直接化为关于距离参数 ttt 的一元多项式求根问题。但随着多项式次数升高，高次方程根的解析与数值稳定性求解难度急剧上升，无法灵活表达具有局部细节的自由造型。

实体构造

构造实体几何（CSG）通过将简单的原生几何体（如立方体、球体、圆柱体、圆锥体）通过布尔集合运算组合出复杂的机械工程与实体模型：

构造实体几何的三种基础布尔集合运算包括：

  • 并集 A∪BA \cup BA∪B：将两个几何体的体元合并为一个复合实体；
  • 交集 A∩BA \cap BA∩B：仅保留两个几何体空间重叠相交的公共体元；
  • 差集 A∖BA \setminus BA∖B：从实体 AAA 中切除挖去与实体 BBB 相交重叠的体元部分。

在数据结构中，CSG 模型组织为一棵层次化 CSG 二叉树：叶子节点存放简单的几何基元，内部节点存放布尔运算规则。CSG 能够保证模型始终具备严格流形与封闭体积，广泛应用于 CAD 机械工程建模；在进入光栅化渲染管线前，通常需要将其求交离散转换为显式三角网格。

距离函数

有符号距离函数（SDF）为空间中任意点 x\mathbf xx 赋予其到目标几何表面 SSS 的欧几里得最短空间距离，并依据点在实体内部还是外部赋予正负符号：

d(x)={−dist⁡(x,S),x 位于物体内部,0,x∈S（位于几何表面）,+dist⁡(x,S),x 位于物体外部.d(\mathbf x) = \begin{cases} -\operatorname{dist}(\mathbf x, S), & \mathbf x \text{ 位于物体内部}, \\ 0, & \mathbf x \in S \text{（位于几何表面）}, \\ +\operatorname{dist}(\mathbf x, S), & \mathbf x \text{ 位于物体外部}. \end{cases} d(x)=⎩⎨⎧​−dist(x,S),0,+dist(x,S),​x 位于物体内部,x∈S（位于几何表面）,x 位于物体外部.​

物体的几何物理边界恰好由零等值面 d(x)=0d(\mathbf x) = 0d(x)=0 确定。若约定物体内部距离为负、外部为正，则两个几何体 AAA 与 BBB 的布尔集合操作可直接表述为标量场的极值运算：

  • 并集：dA∪B(x)=min⁡(dA(x),dB(x))d_{A \cup B}(\mathbf x) = \min(d_A(\mathbf x), d_B(\mathbf x))dA∪B​(x)=min(dA​(x),dB​(x))；
  • 交集：dA∩B(x)=max⁡(dA(x),dB(x))d_{A \cap B}(\mathbf x) = \max(d_A(\mathbf x), d_B(\mathbf x))dA∩B​(x)=max(dA​(x),dB​(x))；
  • 差集：dA∖B(x)=max⁡(dA(x),−dB(x))d_{A \setminus B}(\mathbf x) = \max(d_A(\mathbf x), -d_B(\mathbf x))dA∖B​(x)=max(dA​(x),−dB​(x))。

极值运算构造了复合距离场的上包络与下包络，能够精确确定布尔运算后的零等值面位置。但在曲面交界相接处，min⁡/max⁡\min/\maxmin/max 操作引入了非光滑折线，导致高维导数不连续。

在空间连续可微的区域内，真实的欧氏距离函数满足程函方程（Eikonal Equation）：

∥∇d(x)∥=1.\lVert\nabla d(\mathbf x)\rVert = 1. ∥∇d(x)∥=1.

这意味着距离场的空间梯度模长处处恒等于 1，且梯度的方向直接指向离开表面距离增加最快的法向。因此，表面处的外法向量可通过梯度的归一化直接获取：

n=∇d(x)∥∇d(x)∥.\mathbf n = \frac{\nabla d(\mathbf x)}{\lVert\nabla d(\mathbf x)\rVert}. n=∥∇d(x)∥∇d(x)​.

在数值实现中，梯度通常通过沿三个轴的中心差分近似计算：∇d(x)≈12ε(d(x+εex)−d(x−εex),…)T\nabla d(\mathbf x) \approx \frac{1}{2\varepsilon}\big(d(\mathbf x + \varepsilon \mathbf e_x) - d(\mathbf x - \varepsilon \mathbf e_x), \dots\big)^T∇d(x)≈2ε1​(d(x+εex​)−d(x−εex​),…)T。

两个不同物体的距离标量场可以直接进行加权线性插值：

dt(x)=(1−t)d0(x)+td1(x),t∈[0,1].d_t(\mathbf x) = (1 - t) d_0(\mathbf x) + t d_1(\mathbf x), \qquad t \in [0, 1]. dt​(x)=(1−t)d0​(x)+td1​(x),t∈[0,1].

在光线追踪中，隐式距离函数表面通过球体追踪（Sphere Tracing，光线步进算法）高效求交。设相机光线参数方程为 x(t)=o+td\mathbf x(t) = \mathbf o + t \mathbf dx(t)=o+td（满足 ∥d∥=1\lVert\mathbf d\rVert = 1∥d∥=1）。若光线当前处于步进点 x(tk)\mathbf x(t_k)x(tk​)，计算当前位置的距离函数值 dk=d(x(tk))d_k = d(\mathbf x(t_k))dk​=d(x(tk​))：

  • 因此，光线沿前进方向安全推进距离 dkd_kdk​ 绝不会跨过或穿透物体表面。

等值面

当隐式标量函数过于复杂而无法用代数多项式解析表达时，可以将连续场离散化采样在三维规则体素网格顶点上，再通过三线性插值重建空间连续标量场 f(x)f(\mathbf x)f(x)。空间中满足方程的点集构成等值面：

f(x)=c.f(\mathbf x) = c. f(x)=c.

等值面广泛应用于医学 CT/MRI 断层扫描重建与基于网格的纳维-斯托克斯流体物理模拟：

为了将体素网格中的隐式等值面转换为标准的显式三角网格，经典的移动立方体算法（Marching Cubes）逐个遍历空间立方体微元：

  1. 检查立方体 8 个顶点的标量值与目标等值阈值 ccc 的大小关系，确定每个顶点处于内部还是外部（对应 28=2562^8 = 25628=256 种状态，利用空间对称性归纳为 15 种基本拓扑拓扑构型）；
  2. 根据边两端顶点值的线性插值，精确定位等值面穿过立方体各条棱边的交点空间坐标；
  3. 按照预设的拓扑查找表将交点连接为一组三角形面片输出。

分形

分形几何通过递归迭代系统或确定性噪声函数构建在不同观测尺度上呈现自相似特征的几何结构。自然界中的海岸线、山脉地形、雪花晶体、植物树枝均呈现典型的分形特征。

分形具有分数空间维数（豪斯多夫维数）与无限的局部细节。在渲染分形几何时，由于其包含无限高频的空间波动，必须依据当前视口的屏幕像素覆盖尺度进行层次化几何过滤或多尺度烘焙，否则极易在光栅化阶段引发严重的亚像素几何混叠闪烁。

参数曲面

参数曲面是显式几何表达的重要形式。通过定义在二维矩形参数域 (u,v)∈[0,1]2(u, v) \in [0, 1]^2(u,v)∈[0,1]2 上的连续向量函数，显式映射出三维空间中的曲面点坐标：

p(u,v)=(x(u,v)y(u,v)z(u,v)).\mathbf p(u, v) = \begin{pmatrix} x(u, v) \\ y(u, v) \\ z(u, v) \end{pmatrix}. p(u,v)=​x(u,v)y(u,v)z(u,v)​​.

给定参数对 (u,v)(u, v)(u,v) 即可直接求得表面点坐标，使参数曲面的逐点采样、纹理坐标映射以及规则网格剖分极为直接。

通过对两个参数方向分别求一阶偏导数，可以求得曲面局部的两条切线向量：

pu=∂p∂u,pv=∂p∂v.\mathbf p_u = \frac{\partial\mathbf p}{\partial u}, \qquad \mathbf p_v = \frac{\partial\mathbf p}{\partial v}. pu​=∂u∂p​,pv​=∂v∂p​.

只要局部参数化未发生退化，曲面的单位外法向量由两切线向量的叉积归一化确定：

n=pu×pv∥pu×pv∥.\mathbf n = \frac{\mathbf p_u \times \mathbf p_v}{\lVert\mathbf p_u \times \mathbf p_v\rVert}. n=∥pu​×pv​∥pu​×pv​​.

在参数曲面上附加几何细节时，必须严格区分法线扰动与物理置换：

两者差异体现在：

  • 凹凸贴图：仅在片元着色器中扰动光照计算所使用的表面法线，底层的空间几何顶点未发生任何物理位移。明暗光影真实，但物体外轮廓边缘依然平直光滑，且无法产生真实的自遮挡阴影；
  • 置换贴图：在顶点处理或曲面细分阶段，根据高度图真实沿几何法线方向位移网格顶点 p′=p+s⋅h(u,v)n\mathbf p' = \mathbf p + s \cdot h(u, v)\mathbf np′=p+s⋅h(u,v)n。物体的几何外边缘轮廓产生物理凹凸起伏，且支持光线投射下的真实自阴影计算。

点云

点云直接由三维空间中大量离散无序的点坐标集合 {pi}\{\mathbf p_i\}{pi​} 构成，每个点可附带法向量、漫反射颜色及激光反射强度。点云是激光雷达（LiDAR）扫描仪与多视角三维立体视觉重建（MVS）的直接原始输出数据。

点云不显式存储拓扑连接关系，对任意复杂的几何拓扑具备通用的包容性。但由于缺乏表面连通性定义，点云在近景放大观察时容易暴露出穿透空洞，难以直接应用传统的薄壳物理模拟、平滑着色以及纹理坐标展开。通常需要借助泊松曲面重建等算法将点云重新重构为流形三角网格后再投入工业生产。

多边形网格

多边形网格是计算机图形学中最通用的显式几何表示方式，由几何顶点（Vertices）、拓扑边（Edges）和多边形面（Faces）共同组成，工业界普遍使用全三角形网格。网格显式记录空间连通拓扑，高效适配 GPU 的硬件并行光栅化管线。

在高级网格编辑、曲面细分与拓扑流形处理中，传统的顶点-面索引列表无法支持高效的拓扑邻域查询。为此，学术界与工业界广泛采用半边数据结构（Half-Edge Data Structure）。

半边数据结构将网格中的每条无向边拆解为两条方向严格相反的有向半边。每个半边对象存储四个核心拓扑指针：

  • twin：指向该边对应的反向孪生半边；
  • next：指向当前多边形面内按逆时针绕序排列的下一条半边；
  • vertex：指向该半边的起点（或终点）顶点；
  • face：指向该半边归属的多边形面。

借助半边指针链表，可以在 O(1)O(1)O(1) 常数时间复杂度内完成顶点一环邻接面遍历、面所有边遍历以及共享边的邻接面跳转，为曲面细分、边折叠网格简化以及曲率流计算提供了高效的数据结构支撑。

OBJ 格式

Wavefront OBJ 是一种通用的 ASCII 文本几何数据交换格式。其常见的标准定义语句包括：

  • v x y z：声明一个三维顶点的几何空间坐标；
  • vt u v：声明一个二维顶点的纹理贴图坐标；
  • vn x y z：声明一个顶点的单位法向量；
  • f v1/vt1/vn1 v2/vt2/vn2 v3/vt3/vn3：声明一个面图元，通过斜杠组合索引引用顶点、纹理及法线数据。

在解析 OBJ 格式时需注意：

  • OBJ 允许定义四边形甚至多边形面（通过给出 4 个或更多索引），而在现代图形 API 中必须将其预先剖分为三角形；
  • OBJ 文件中顶点位置、UV 与法线使用的是相互独立的索引计数系统，而现代 GPU 的顶点缓冲区（VBO）要求顶点属性必须严格一一对齐绑定于同一全局索引。因此加载器通常需要对具有不同 UV 或法线的三元组执行顶点拆分与去重。

表示转换

图形学在实际工业应用中从不拘泥于单一的几何表示，而是根据管线各阶段的任务特征进行动态混合转换：

  • 在雕刻建模与布尔实体造型阶段，利用 CSG 与 SDF 执行无拓扑限制的交并差集合运算与形态融合；
  • 在进入渲染与物理碰撞管线前，通过移动立方体算法或曲面自适应网格剖分将隐式等值面转换为轻量显式三角网格；
  • 在实时着色阶段，通过法线贴图与位移贴图将微观几何细节动态叠加至宏观粗模表面之上。
