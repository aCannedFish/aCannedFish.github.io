VGG-T³: Offline Feed-Forward 3D Reconstruction at Scale

发表于2026-08-09|更新于2026-08-17|Note3DVision 论文阅读
|浏览量:

VGGT 将相机估计、深度预测和 point map 重建统一到一个多视图 Transformer 中。输入一组无标定图像后，模型通过帧内注意力整理单张图像的局部信息，再通过全局注意力让所有视图交换特征，最终一次性输出相机与稠密几何。

问题出现在图像数量继续增加时。若每张图包含 SSS 个 token，NNN 张图会形成 L=NSL=NSL=NS 个全局 token。标准全局注意力需要计算 L×LL\times LL×L 的相关关系，其主要计算量为：

O(L2d)=O(N2S2d)O(L^2d)=O(N^2S^2d) O(L2d)=O(N2S2d)

ddd 是单个注意力头的通道数。图像数量扩大十倍，全局注意力的计算量近似扩大一百倍，长图像集合会很快触及计算和显存上限。FastVGGT 的 token merging 和 SparseVGGT 的块稀疏注意力可以减少常数开销，但其复杂度仍然含有 N2N^2N2。

VGG-T³ 研究另一条路线：先把整组图像的 Key-Value 关系压缩进一组固定大小的 MLP 权重，再用 query 查询这个 MLP。压缩过程通过 **Test-Time Training（TTT）**在当前场景上完成。名称 VGG-T³ 也来自 Visual Geometry Grounded Test Time Training。VGGT-Ω 用少量 scene token 缓解部分全局层的成本，VGG-T³ 则进一步替换全部全局注意力，专门处理单场景输入视图数的扩展问题。

模型沿用已经训练好的 VGGT 图像编码器、帧内注意力和几何输出头，将所有全局 softmax attention 替换为 TTT 层。对于每个全局层，推理包含两个阶段：

  1. Update：利用当前场景全部 token 构造自监督任务，在测试时更新一个小型 MLP，使其学习从 key 到 value 的映射；
  2. Apply：将每个 query 输入更新后的 MLP，得到全局聚合后的 token。

MLP 的参数量不随图像数量变化，Update 与 Apply 都可以逐 token 或逐小批次完成。因此，帧内注意力、TTT 全局层和输出头相对于视图数量均为线性复杂度，超长图像集合也不再需要构造全局的二次注意力矩阵。

任务定义

输入是同一场景的无序图像集合：

I={Ii}i=1N,Ii∈RH×W×3\mathcal I=\{I_i\}_{i=1}^{N}, \qquad I_i\in\mathbb R^{H\times W\times3} I={Ii​}i=1N​,Ii​∈RH×W×3

模型需要为每张图像预测相机外参 PiP_iPi​、针孔相机内参 KiK_iKi​ 和稠密深度 DiD_iDi​。其中外参包含旋转 Ri∈SO(3)R_i\in SO(3)Ri​∈SO(3) 与平移 ti∈R3t_i\in\mathbb R^3ti​∈R3。像素齐次坐标记为 u~=(u,v,1)⊤\tilde{\mathbf u}=(u,v,1)^\topu~=(u,v,1)⊤，则该像素对应的世界坐标可以由深度反投影得到：

Xi(u,v)=Ri⊤(Di(u,v)Ki−1u~−ti)X_i(u,v) =R_i^\top \left( D_i(u,v)K_i^{-1}\tilde{\mathbf u}-t_i \right) Xi​(u,v)=Ri⊤​(Di​(u,v)Ki−1​u~−ti​)

将所有像素的 Xi(u,v)X_i(u,v)Xi​(u,v) 排列起来，就得到与图像对齐的 point map。官方模型接口同时返回 pose、intrinsics、depth、pts3d 和置信度，因此它与 VGGT 的主要使用方式兼容。

这里的 offline 表示建图时能同时利用整组无序图像。TTT3R、CUT3R 等 online 方法按时间顺序更新固定状态，适合流式输入；VGG-T³ 汇总全部图像的 TTT 梯度，使未来观测也能参与同一场景状态的形成。

KV 瓶颈

VGGT 先用 DINOv2 将每张图像切分成 patch token，再交替执行帧内注意力和全局注意力。设某层的输入 token 为 xix_ixi​，标准注意力先得到 query、key 和 value：

qi=LN⁡q(Wqxi),ki=LN⁡k(Wkxi),vi=Wvxiq_i=\operatorname{LN}_q(W_qx_i), \qquad k_i=\operatorname{LN}_k(W_kx_i), \qquad v_i=W_vx_i qi​=LNq​(Wq​xi​),ki​=LNk​(Wk​xi​),vi​=Wv​xi​

随后对第 iii 个 query 计算：

oi=∑jsoftmax⁡j(qi⊤kjd)vjo_i =\sum_j \operatorname{softmax}_j \left( \frac{q_i^\top k_j}{\sqrt d} \right)v_j oi​=j∑​softmaxj​(d​qi⊤​kj​​)vj​

这一步可以理解为两次操作。qi⊤kjq_i^\top k_jqi⊤​kj​ 先判断 query iii 与各个 key jjj 的相关程度，softmax 再将所有 value 按相关程度加权求和。全局层中的 jjj 遍历所有图像的 token，所以每个 query 都能直接读取其他视图中的任意局部区域。这种全连接交互有利于跨视图匹配，也产生了二次复杂度。

论文从“场景表示”的角度重新解释 KV。所有图像产生的 (kj,vj)(k_j,v_j)(kj​,vj​) 共同构成一份长度随图像数量变化的场景记忆。对每个 query 执行 softmax attention，相当于反复在这份大表中检索。输入越多，表越长，query 数量也越多，最终得到 O(L2)O(L^2)O(L2) 的访问成本。

token merging 和稀疏注意力主要压缩表长或减少允许访问的表项。例如把 token 数量缩小为原来的 1/r1/r1/r，全局注意力可以从 O(L2)O(L^2)O(L2) 降到约 O(L2/r2)O(L^2/r^2)O(L2/r2)，但 LLL 随视图数增长这一事实没有改变。VGG-T³ 希望构造一个大小不依赖 LLL 的场景状态，使一次查询的成本不再随已经写入多少图像而增长。

TTT 状态

Test-Time Training 通常指模型在部署时利用当前样本上的自监督信号进行少量参数更新。VGG-T³ 只更新每个全局层内部的小型 MLP 权重，完整 VGGT、相机参数和三维点都不作为内层优化变量。论文称这些临时参数为 fast weights，用 TθT_\thetaTθ​ 表示。

给定当前层的 key 和 value，TTT 先求解：

θ∗=arg⁡min⁡θ∑i=1LLt(Tθ(ki),vi)\theta^* =\arg\min_\theta \sum_{i=1}^{L} \mathcal L_t \left( T_\theta(k_i),v_i \right) θ∗=argθmin​i=1∑L​Lt​(Tθ​(ki​),vi​)

再将 query 输入更新后的 MLP：

oi=Tθ∗(qi)o_i=T_{\theta^*}(q_i) oi​=Tθ∗​(qi​)

论文实现使用 SwiGLU MLP 和 Muon 优化器，并采用点积形式的内层目标。可以先把上式理解成一个键值回归任务：模型看到许多 (ki,vi)(k_i,v_i)(ki​,vi​)，通过一到两步更新，将“什么 key 应该取回什么 value”写进参数 θ∗\theta^*θ∗；之后 query 不必再与所有 key 计算相似度，只需经过 MLP 即可读出聚合结果。

需要注意，场景并非只存储在一个 MLP 中。VGGT 有多层交替注意力，每个被替换的全局层都有自己的 fast-weight MLP。早期层记录较低级的跨视图外观与对应关系，深层状态逐渐承载相机、布局和三维结构。整个场景表示分布在这些层的 θ1∗,θ2∗,…\theta_1^*,\theta_2^*,\ldotsθ1∗​,θ2∗​,… 中。

这一结构与 DeepSDF 的思路有相似之处。DeepSDF 用一个固定维度、可优化的 latent code 表示某个物体，再让共享解码器根据坐标查询几何；VGG-T³ 将可变长度 KV 映射压进固定大小的 MLP 权重，再根据 query 读取多视图信息。区别在于 VGG-T³ 的隐式状态位于 Transformer 的多个中间层中，且它编码的是支持相机、深度和 point map 解码的视觉几何特征。

两层优化

这里同时存在两种参数更新，构成双层优化，很容易混淆。

外层训练发生在模型发布之前。作者从公开的 VGGT checkpoint 开始，将全局注意力换成 TTT 层，用三维训练数据继续训练 100K 次，使投影、MLP 初始化、学习率和更新规则学会“怎样通过少量内层步骤形成有效场景状态”。这部分得到的是可跨场景复用的慢参数。

内层更新发生在每次重建新场景时。给定当前图像集合，模型在每个全局层上用 K→VK\rightarrow VK→V 自监督目标更新 fast weights。当前场景处理完后，这些权重可以丢弃，也可以保留下来供后续定位查询。内层更新没有读取相机或深度真值，因此测试数据不需要标签。

用双层优化的形式表示，外层过程近似为：

θs∗(ϕ)=TTT⁡(Ks(ϕ),Vs(ϕ))\theta_s^*(\phi) =\operatorname{TTT} \left( K_s(\phi),V_s(\phi) \right) θs∗​(ϕ)=TTT(Ks​(ϕ),Vs​(ϕ))

ϕ∗=arg⁡min⁡ϕ∑s∈DL3D(fϕ,θs∗(ϕ)(Is),Ys)\phi^* =\arg\min_\phi \sum_{s\in\mathcal D} \mathcal L_{3D} \left( f_{\phi,\theta_s^*(\phi)}(\mathcal I_s), Y_s \right) ϕ∗=argϕmin​s∈D∑​L3D​(fϕ,θs∗​(ϕ)​(Is​),Ys​)

ϕ\phiϕ 表示跨场景保留的慢参数，θs∗\theta_s^*θs∗​ 是场景 sss 在测试时临时生成的快参数，YsY_sYs​ 是相机、深度和 point map 等三维监督。外层损失保证内层 K→VK\rightarrow VK→V 更新最终能服务于三维预测，避免 MLP 只把 value 数值机械记住。

论文所说的 feed-forward 强调几何结果由统一网络解码，无需运行完整 SfM 或逐场景优化几何。推理仍包含固定次数的 fast-weight 梯度更新，因此严格说来并非参数完全固定的单次普通前向传播。

预训练转换

直接用随机初始化的 TTT 网络替换 softmax attention，会同时丢掉原模型的多视图特征空间和全局读取机制。VGGT 已经通过大规模三维训练学会了有效的 Wq,Wk,WvW_q,W_k,W_vWq​,Wk​,Wv​ 投影；若全部重新训练，新的线性模型还要从头建立基础视觉、跨视图对应和几何关系，优化目标会复杂许多。

VGG-T³ 因此保留 VGGT 的预训练权重，并只转换全局注意力。作者冻结原有 VGGT 参数，主要训练新的全局 TTT 组件。训练使用与 VGGT 原始数据规模相当的数据，计算成本约为从头训练 VGGT 的 12%。这种做法更接近 post-training linearization：先训练高精度的 softmax 模型，再把其中的全局检索机制转换为线性时间状态。

转换时还有一个关键细节。VGGT 使用带可学习仿射参数的 LayerNorm 处理 query 和 key：

LN⁡(x)=γ⊙x−μ(x)σ2(x)+ϵ+β\operatorname{LN}(x) =\gamma\odot \frac{x-\mu(x)}{\sqrt{\sigma^2(x)+\epsilon}} +\beta LN(x)=γ⊙σ2(x)+ϵ​x−μ(x)​+β

γ\gammaγ 和 β\betaβ 会缩放、平移特征空间。softmax attention 可以在训练中适应这种变化，但测试时 MLP 只有一两步更新，需要迅速拟合稳定的 K→VK\rightarrow VK→V 关系。为消除这组随通道学习的仿射畸变，VGG-T³ 改用无可学习参数的 L2 归一化：

qˉi=Wqxi∥Wqxi∥2+ϵ,kˉi=Wkxi∥Wkxi∥2+ϵ\bar q_i=\frac{W_qx_i}{\|W_qx_i\|_2+\epsilon}, \qquad \bar k_i=\frac{W_kx_i}{\|W_kx_i\|_2+\epsilon} qˉ​i​=∥Wq​xi​∥2​+ϵWq​xi​​,kˉi​=∥Wk​xi​∥2​+ϵWk​xi​​

经过 L2 归一化的 token 位于单位球面附近，尺度更加稳定，预训练投影也能继续使用。这一步的重点是把 softmax checkpoint 已经学到的三维特征空间转换到线性键值关系中；若直接随机初始化 TTT 层，外层训练还要同时重新学习跨视图几何和新的场景记忆机制，优化难度会显著增加。

空间混合

朴素 K→VK\rightarrow VK→V 预测存在一个容易忽略的退化解。key 和 value 都由同一个输入 xxx 经过线性投影得到：

K=Wkx,V=WvxK=W_kx, \qquad V=W_vx K=Wk​x,V=Wv​x

若 WkW_kWk​ 可逆，则二者满足：

V=WvWk−1KV=W_vW_k^{-1}K V=Wv​Wk−1​K

这意味着 K→VK\rightarrow VK→V 本身可能只是一个与场景无关的固定线性变换。MLP 即使把内层损失降得很低，也未必汇总了跨视图几何；它可能只学会复现两个投影矩阵之间的代数关系。

VGG-T³ 在 value 一侧加入 ShortConv2D。对于每张图，先把一维 value token 恢复成二维 patch 网格：

Vi∈R(H/p)(W/p)×d⟶V~i∈RH/p×W/p×dV_i \in\mathbb R^{(H/p)(W/p)\times d} \longrightarrow \widetilde V_i \in\mathbb R^{H/p\times W/p\times d} Vi​∈R(H/p)(W/p)×d⟶Vi​∈RH/p×W/p×d

ppp 是图像 tokenizer 的 patch size。随后使用一个 3×33\times33×3 的二维短卷积聚合邻域：

Vi′=Flatten⁡(ShortConv2D⁡(V~i))V_i' =\operatorname{Flatten} \left( \operatorname{ShortConv2D}(\widetilde V_i) \right) Vi′​=Flatten(ShortConv2D(Vi​))

官方实现采用单层 3×33\times33×3 ShortConv2D，只在每张图像恢复出的局部 patch 网格内混合，不会把不同视图按输入顺序卷在一起；论文没有将其限定为 depthwise 卷积。TTT 目标改为：

θ∗=arg⁡min⁡θ∑iLt(Tθ(ki),vi′)\theta^* =\arg\min_\theta \sum_i \mathcal L_t \left( T_\theta(k_i),v_i' \right) θ∗=argθmin​i∑​Lt​(Tθ​(ki​),vi′​)

现在单个 kik_iki​ 对应的目标 vi′v_i'vi′​ 包含周围 patch 的上下文，无法再由 WvWk−1W_vW_k^{-1}Wv​Wk−1​ 直接得到。fast weights 必须综合整组 token 的统计关系，才能形成更有用的场景表示。二维卷积也保留了图像的空间结构，比把所有 token 当作普通一维序列做短卷积更适合边缘、表面和局部纹理。

ShortConv2D 用极小的局部计算补回 value 对邻域结构的依赖，使 K→V′K\rightarrow V'K→V′ 目标无法仅靠逐 token 的固定线性映射求解。内层更新必须读取当前图像的局部布局，写入 fast weights 的信息因而更接近场景内容。

测试扩展

VGGT 训练时每个样本通常只有 2 到 24 张图像，VGG-T³ 的转换训练沿用相近的视图范围。推理时突然输入 1000 张图，相当于把序列长度扩大几十倍。虽然 MLP 的参数量固定，要求同样一次梯度更新把更多场景信息压进有限容量中，仍会造成分布外退化。

当图像数量远超训练长度时，一次内层更新可能不足以将包含更多样本的梯度转化为合适的 fast weights。问题来自固定容量状态与有限优化步数的共同约束，并不改变每一步关于 token 数的线性复杂度。

解决方法很直接。训练长度附近使用一步 TTT，1000 张图等超长输入使用两步：

θ(r+1)=Muon⁡(θ(r),∇θLTTT),r=0,1\theta^{(r+1)} =\operatorname{Muon} \left( \theta^{(r)}, \nabla_\theta\mathcal L_{\mathrm{TTT}} \right), \qquad r=0,1 θ(r+1)=Muon(θ(r),∇θ​LTTT​),r=0,1

论文在大规模推理中默认执行两步更新。更新次数由常数 1 变成 2，只会增加线性项的常数，不改变 O(N)O(N)O(N) 的渐近复杂度；第二步使用第一步得到的 fast weights 继续拟合同一场景，使参数有机会吸收超长集合中尚未写入的关系。

作者将这种做法称为 test-time scaling：面对更大的测试样本，允许模型在推理时投入更多固定轮次的计算，从而提高固定容量状态的压缩质量。MLP 容量仍然有限，更大的城市级集合可能需要分区、更大 fast weights 或其他层次化表示。

分批推理

TTT 目标具有可加性。将全部 token 划分为若干小批次 sss：

LTTT(θ)=∑i=1Lℓi(θ)=∑s∑i∈sℓi(θ)\mathcal L_{\mathrm{TTT}}(\theta) =\sum_{i=1}^{L}\ell_i(\theta) =\sum_s\sum_{i\in s}\ell_i(\theta) LTTT​(θ)=i=1∑L​ℓi​(θ)=s∑​i∈s∑​ℓi​(θ)

其梯度同样可以分批求和：

∇θLTTT=∑s(∑i∈s∇θℓi(θ))\nabla_\theta\mathcal L_{\mathrm{TTT}} =\sum_s \left( \sum_{i\in s} \nabla_\theta\ell_i(\theta) \right) ∇θ​LTTT​=s∑​(i∈s∑​∇θ​ℓi​(θ))

这条性质带来两种大规模推理方式。

单 GPU 推理时，图像 token 可以暂存在主机内存。GPU 每次只载入一个小批次，计算该批次对 MLP 的梯度，再把中间结果移回主机；遍历全部批次后汇总梯度并更新 fast weights。显存只需容纳当前批次和固定大小的 MLP，不必同时容纳整组图像的 Q、K、V。

多 GPU 推理时，可以将不同图像批次分给不同 GPU，各设备独立计算局部梯度，再同步小型 MLP 的梯度或权重。通信对象是固定大小的 fast weights，因此无需在设备之间交换所有图像的注意力矩阵。

设每张图的 token 数 SSS 和 MLP 隐藏维度 hhh 固定。帧内注意力的总成本约为 O(NS2d)O(NS^2d)O(NS2d)，TTT Update 与 Apply 约为 O(NSdh)O(NSdh)O(NSdh)，输出解码也随 NNN 线性增长。因此整体关于图像数 NNN 为线性复杂度。这里的“固定显存”只指 GPU 工作集可以由小批次大小控制；主机侧 token、最终的 NNN 张深度图和 point map 仍然会随输入数量线性增长。

softmax attention 即使使用 FlashAttention，也只是通过分块计算避免显式保存完整注意力矩阵，所有 query 仍要与全部 key 发生交互，总计算量没有摆脱二次增长。对超大图像集合，VGG-T³ 改变的是场景访问方式本身，而不只是更节省地执行同一矩阵运算。

查询定位

固定大小的 MLP 场景状态还带来一个额外能力。建立地图时，模型在一组无标定图像上完成 TTT，得到每个全局层的场景权重 θℓ∗\theta_\ell^*θℓ∗​。之后输入一张未参与建图的新图像，可以冻结这些权重，只处理该图的 token：

oq(ℓ)=Tθℓ∗(qq(ℓ))o_{q}^{(\ell)} =T_{\theta_\ell^*} \left( q_q^{(\ell)} \right) oq(ℓ)​=Tθℓ∗​​(qq(ℓ)​)

新图像在各层查询已经建立的场景状态，最终输出相对于现有重建的相机位姿、内参和几何。查询过程无需重新读取全部建图图像，也不需要显式特征数据库、最近邻搜索和 PnP，因此单次定位的主要计算不随地图图像数量增长。

这可以看成一种隐式视觉地图。传统 SfM 地图通常显式保存三维点、描述子和观测关系；场景坐标回归方法会训练一个从 RGB 像素到三维世界坐标的场景专用网络。VGG-T³ 的地图存储在多个 TTT 层的 MLP 权重中，同一个模型负责建图和查询，且建图图像本身无需已知相机位姿。

实验结果

VGG-T³ 的 point map 与视频深度明显优于线性在线基线，并接近完整 VGGT；相机位姿仍落后于完整 VGGT 和按正确时序运行的 TTT3R。消融中，预训练线性化与 ShortConv2D 依次将 Chamfer Distance 从 0.262 降至 0.074 和 0.066，验证了继承原模型特征与破除逐 token 退化的必要性。

在 7Scenes 的千图测试中，重建约需 58 秒，相比 VGGT 加速 11.6 倍，分批与多 GPU 执行保持近线性扩展。完整注意力的几何通常略好，实际速度也受 CPU offload 与数据搬运影响，因此该结果体现的是大规模无序集合上的精度—效率折中。

特点与局限

VGG-T³ 将全局注意力中的可变长度 KV 视为场景表示，并通过测试时训练把它压缩进固定大小的多层 MLP 权重；Update 阶段写入场景，Apply 阶段查询场景，两者对 token 数均呈线性复杂度。方法只转换 VGGT 的全局层，能够继承原模型的大部分三维能力，并支持分批更新、CPU offload 与多 GPU 图像分片；建图后的 fast-weight 状态还可冻结并查询新图，用于统一的重建和视觉定位。

固定容量 MLP 的表达上限低于完整 KV，在宽基线、重复纹理和复杂场景中可能丢失关键对应，相机位姿与视觉定位精度也仍落后于部分原模型或专用方法。推理必须保留梯度计算和内层优化，超长集合依赖额外 TTT 步数及 CPU offload，主机内存、传输和稠密输出成本仍会增长；离线建图方式不适合持续流式更新，论文对城市级复杂场景的验证有限，并且继承了 VGGT 在相机模型、相对尺度、透明反射与遮挡表面方面的能力边界。
