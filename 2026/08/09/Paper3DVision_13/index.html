VGGT-Ω: Scaling Feed-Forward Reconstruction

发表于2026-08-09|更新于2026-08-17|Note3DVision 论文阅读
|浏览量:

VGGT 已经表明，相机估计、深度预测、point map 和跨视图跟踪可以由同一个模型联合完成。经过大规模三维数据训练的 Transformer，能够通过一次前向传播从无标定图像中预测这些几何量。在此基础上，VGGT-Ω 进一步研究前馈三维重建能否像语言模型和二维视觉基础模型一样，随着模型规模与数据规模扩大而持续改善。

这一研究不只涉及将参数量从 1B 扩大至 10B。原始 VGGT 的多视图全局注意力、多个高分辨率 DPT 输出头和以静态场景为主的监督数据，都会使大规模训练很快触及显存与数据上限。因此，VGGT-Ω 同时修改了三个部分：

  1. 用 scene token 汇总跨帧信息，并让部分层只在 scene token 之间执行 register attention；
  2. 推理时只输出相机与深度，但在训练时继续使用 point map 和匹配损失提供多任务监督；
  3. 建立可处理静态与动态视频的数据标注流水线，再通过教师—学生自监督利用无标签视频。

模型最终保留一个相当紧凑的输出接口：

f ⁣(I1,…,IN)={(gi,Di)}i=1N,gi=(qi,ti,fi)∈R9f\!\left(I_1,\ldots,I_N\right) =\{(g_i,D_i)\}_{i=1}^{N}, \qquad g_i=(q_i,t_i,f_i)\in\mathbb{R}^{9} f(I1​,…,IN​)={(gi​,Di​)}i=1N​,gi​=(qi​,ti​,fi​)∈R9

Di∈RH×WD_i\in\mathbb{R}^{H\times W}Di​∈RH×W 是第 iii 帧的深度图；qi∈R4q_i\in\mathbb{R}^{4}qi​∈R4、ti∈R3t_i\in\mathbb{R}^{3}ti​∈R3 和 fi∈R2f_i\in\mathbb{R}^{2}fi​∈R2 分别表示旋转四元数、平移与水平/垂直视场角。与 VGGT 相同，第一帧定义参考坐标系，主点假设位于图像中心。point map 和跟踪特征不再作为推理输出，但对应的几何知识没有被删除，而是改成训练期损失压入共享特征。该接口仍描述逐帧可见表面；NOVA3R、VolFill 和 Surflo 一类方法关注遮挡补全或完整表面，可将更强的相机、深度与场景特征作为上游条件，解决的输出目标并不相同。

这里的 scaling 同时依赖参数、数据质量和训练系统。单独增加参数量，如果监督仍然稀少或噪声较大，通常无法得到同等幅度的几何收益。

核心瓶颈

设每帧经过 patch embedding 后有 K=H′W′K=H'W'K=H′W′ 个图像 token，每帧另有 RRR 个 register、一个 camera token，总 token 数近似为：

L=N(K+R+1)L=N(K+R+1) L=N(K+R+1)

原始 VGGT 的 Global Attention 会让全部 LLL 个 token 两两交互。忽略多头拆分和常数项，一层注意力的主要计算量为：

O(L2C)=O ⁣(N2(K+R+1)2C)O(L^2C) =O\!\left(N^2(K+R+1)^2C\right) O(L2C)=O(N2(K+R+1)2C)

图像数 NNN 翻倍时，注意力计算近似变成四倍。更重要的是，训练不仅要保存当前层的输出，还要保留反向传播所需的中间激活；模型越深、帧数越多，这部分显存越大。

第二个瓶颈来自 dense prediction head。VGGT 用多个 DPT 分支分别预测深度、point map、置信度和跟踪特征。DPT 后段需要在接近输入图像分辨率的特征图上执行卷积。虽然这些卷积占参数量不高，却要保存大量 H×W×CH\times W\times CH×W×C 激活。FSDP 可以把参数和优化器状态分散到多张卡，gradient checkpointing 可以用重算换显存，但都不能让每个高分辨率输出头的激活凭空消失。

第三个瓶颈是数据。互联网视频数量巨大，但大部分包含人、车、动物或其他运动物体；经典 SfM/MVS 又以静态世界为基本假设。若训练数据只接受完全静态、纹理充分、相机平稳移动的视频，可用数据会被大幅压缩。反过来，直接把失败的 COLMAP 重建当作真值，模型又会学到错误弯曲、漂移深度和前景—背景泄漏。

VGGT-Ω 针对这些瓶颈分别进行调整：Register Attention 减少跨帧计算，轻量输出头减少高分辨率激活，数据与自监督流水线则扩展可靠监督的来源。

场景 Token

输入图像先由 DINOv3 初始化的视觉 Transformer 编码。若 patch size 为 r=16r=16r=16，则第 iii 帧的图像 token 为：

ziF=DINO⁡(Ii)∈RH′W′×C,H′=H/r,W′=W/rz_i^F=\operatorname{DINO}(I_i) \in\mathbb{R}^{H'W'\times C}, \qquad H'=H/r,\quad W'=W/r ziF​=DINO(Ii​)∈RH′W′×C,H′=H/r,W′=W/r

每帧再附加一个 camera token 和 16 个 scene token：

zi=[ziF,zicam,ziscene]∈R(H′W′+17)×C,ziscene∈R16×Cz_i=\left[z_i^F,z_i^{\mathrm{cam}},z_i^{\mathrm{scene}}\right] \in\mathbb{R}^{(H'W'+17)\times C}, \qquad z_i^{\mathrm{scene}}\in\mathbb{R}^{16\times C} zi​=[ziF​,zicam​,ziscene​]∈R(H′W′+17)×C,ziscene​∈R16×C

这些 scene token 在形式上仍是 register。普通 ViT 中，register 常用于承接原本会挤进少数高范数 patch token 的全局信息，最后可以丢弃。VGGT-Ω 则明确要求它们承担“场景信息中转站”的作用，并在重建以外继续读取它们，所以论文也把 register 称为 scene token。

第一帧的 camera/scene token 使用一组专门的可学习参数，其余帧共享另一组参数。这个区别只表示“是否为参考帧”，模型没有为第 2、3、4 帧分别设置位置编码，也不输入视频时间戳。因此除参考帧外，其他图像保持置换等变：交换输入次序会相应交换逐帧输出，不应改变场景的相对几何。

原始交替注意力仍然保留。Frame Attention 在每张图内部独立工作：

FrameAttn⁡(z)=(Attn⁡(z1),…,Attn⁡(zN))\operatorname{FrameAttn}(z) =\left( \operatorname{Attn}(z_1),\ldots, \operatorname{Attn}(z_N) \right) FrameAttn(z)=(Attn(z1​),…,Attn(zN​))

Global Attention 则把所有帧的 token 拼在一起：

GlobalAttn⁡(z)=Attn⁡ ⁣([z1;…;zN])\operatorname{GlobalAttn}(z) =\operatorname{Attn}\!\left([z_1;\ldots;z_N]\right) GlobalAttn(z)=Attn([z1​;…;zN​])

前者整理单帧内的边界、纹理和局部深度，后者建立跨帧对应、相机关系和全局尺度。VGGT-Ω 新增的 Register Attention 只取所有帧的 scene token：

S=[z1scene;…;zNscene]∈RNR×CS=[z_1^{\mathrm{scene}};\ldots;z_N^{\mathrm{scene}}] \in\mathbb{R}^{NR\times C} S=[z1scene​;…;zNscene​]∈RNR×C

S′=Attn⁡(S),R=16S'=\operatorname{Attn}(S), \qquad R=16 S′=Attn(S),R=16

这一层不直接更新图像 patch。下一层 Frame Attention 再让更新后的 scene token 与本帧 patch 交互，把全局信息送回每个像素。于是第 iii 帧的信息可以沿着下面的路径到达第 jjj 帧：

ziF→FrameAttnziscene→RegisterAttnzjscene→FrameAttnzjFz_i^F \xrightarrow{\mathrm{FrameAttn}} z_i^{\mathrm{scene}} \xrightarrow{\mathrm{RegisterAttn}} z_j^{\mathrm{scene}} \xrightarrow{\mathrm{FrameAttn}} z_j^F ziF​FrameAttn​ziscene​RegisterAttn​zjscene​FrameAttn​zjF​

它与完整 Global Attention 的区别是：patch 不再跨帧逐一通信，而是先把内容压进少数中转 token。Register Attention 的跨帧注意力成本约为：

O ⁣((NR)2C)O\!\left((NR)^2C\right) O((NR)2C)

当每帧有上千个 patch、只有 16 个 scene token 时，这比 O(N2K2C)O(N^2K^2C)O(N2K2C) 小得多。不过这种压缩也会丢失精细对应。如果两帧中各有多个相似窗户，16 个全局 token 未必能保留“这个 patch 对应那一个窗户”的全部局部关系。

因此，默认模型只将 25% 的 Global Attention 替换为 Register Attention，其余层仍允许所有 patch 进行跨帧直接匹配。低带宽场景状态适合汇总布局和语义，精细像素对应仍需要一定比例的完整跨帧注意力；部分替换由此在通信成本与局部几何之间形成折中。

轻量输出

主干最终只保留两个实际输出头：camera head 和 depth head。

camera head 读取所有帧的 camera token 与 scene token，先通过一个轻量 Transformer 联合更新，再在每个 camera token 上用 MLP 回归 gig_igi​：

{g^i}i=1N=hcam ⁣({zicam,ziscene}i=1N)\{\hat g_i\}_{i=1}^{N} =h_{\mathrm{cam}}\!\left( \{z_i^{\mathrm{cam}},z_i^{\mathrm{scene}}\}_{i=1}^{N} \right) {g^​i​}i=1N​=hcam​({zicam​,ziscene​}i=1N​)

相机必须联合预测，因为单台相机的旋转和平移只有放在共同参考系中才有意义。与 VGGT 的相机头相比，VGGT-Ω 去掉了迭代 refinement，一次给出最终参数。这样可以缩短反向传播链条，并让相机头保持轻量，使主干更容易作为基础模型复用。

深度分支仍读取 Transformer 的多层特征并使用 DPT 的低分辨率卷积部分，但在分辨率超过输入的 1/41/41/4 后，不再维持多级高分辨率卷积图。设低分辨率特征为 F∈RH′×W′×CF\in\mathbb{R}^{H'\times W'\times C}F∈RH′×W′×C，最后的 MLP 输出 2u22u^22u2 个通道，论文取 u=4u=4u=4：

Y=MLP⁡(F)∈RH′×W′×2u2Y=\operatorname{MLP}(F) \in\mathbb{R}^{H'\times W'\times 2u^2} Y=MLP(F)∈RH′×W′×2u2

Pixel Shuffle 将通道重新排列为空间位置：

PixelShuffle⁡(Y)∈RuH′×uW′×2\operatorname{PixelShuffle}(Y) \in\mathbb{R}^{uH'\times uW'\times2} PixelShuffle(Y)∈RuH′×uW′×2

两个输出通道分别是深度与置信度。Pixel Shuffle 本身不执行昂贵卷积，只把每个低分辨率位置携带的 u×uu\times uu×u 子像素值展开到高分辨率网格，因此显著减少需要保存的高分辨率激活。

若完全去掉卷积、只用 MLP 独立展开每个 patch，邻接 patch 之间缺少显式局部混合，输出容易沿边界出现块状断层。图像像素值位于有限范围，深度却可以从近处延伸到近似无穷远；远距离区域的微小逆深度差异也可能对应很大的绝对距离变化。最终方案因此保留便宜的低分辨率卷积，用它协调相邻 patch，只删除最昂贵的高分辨率部分。

这些修改主要降低训练阶段需要保存的高分辨率激活与多输出头状态。推理时，Flash Attention 已经避免显式保存完整注意力矩阵，峰值还会受到随 token 数线性增长的 FFN、帧内注意力和输出激活影响；因此训练与推理的显存收益不能直接等同。

多任务监督

只保留两个输出头不等于只训练两个任务。VGGT-Ω 的总损失为：

L=λcamLcam+λdepthLdepth+λpointLpoint+λmatchLmatch\mathcal L =\lambda_{\mathrm{cam}}\mathcal L_{\mathrm{cam}} +\lambda_{\mathrm{depth}}\mathcal L_{\mathrm{depth}} +\lambda_{\mathrm{point}}\mathcal L_{\mathrm{point}} +\lambda_{\mathrm{match}}\mathcal L_{\mathrm{match}} L=λcam​Lcam​+λdepth​Ldepth​+λpoint​Lpoint​+λmatch​Lmatch​

附录给出的权重为：

λcam=5.0,λdepth=1.0,λpoint=0.5,λmatch=0.1\lambda_{\mathrm{cam}}=5.0, \qquad \lambda_{\mathrm{depth}}=1.0, \qquad \lambda_{\mathrm{point}}=0.5, \qquad \lambda_{\mathrm{match}}=0.1 λcam​=5.0,λdepth​=1.0,λpoint​=0.5,λmatch​=0.1

相机损失改用 L1：

Lcam=∑i=1N∥g^i−gi∥1\mathcal L_{\mathrm{cam}} =\sum_{i=1}^{N}\|\hat g_i-g_i\|_1 Lcam​=i=1∑N​∥g^​i​−gi​∥1​

原始 VGGT 使用 Huber loss，VGGT-Ω 改为 L1。L1 的梯度幅值不会随大残差继续线性增大，因此在混合大量来源、尺度和标注质量各异的数据时，更不容易让少数异常相机样本支配更新。对旋转、平移和视场角的直接监督，会把跨帧全局关系集中到 camera/scene token 中。

令深度残差为 eiD=D^i−Die_i^D=\hat D_i-D_ieiD​=D^i​−Di​，预测置信度为 ciD>0c_i^D>0ciD​>0。忽略无效像素掩码，深度损失可以写成：

point loss 没有对应的 point-map 输出头。模型先用预测相机和深度反投影：

P^i(u,v)=R^i⊤(D^i(u,v)K^i−1u~−t^i),u~=(u,v,1)⊤\hat P_i(u,v) =\hat R_i^\top \left( \hat D_i(u,v)\hat K_i^{-1}\tilde{\mathbf u} -\hat t_i \right), \qquad \tilde{\mathbf u}=(u,v,1)^\top P^i​(u,v)=R^i⊤​(D^i​(u,v)K^i−1​u~−t^i​),u~=(u,v,1)⊤

eiP=π−1(D^i,g^i)−Pie_i^P =\pi^{-1}(\hat D_i,\hat g_i)-P_i eiP​=π−1(D^i​,g^​i​)−Pi​

Lpoint\mathcal L_{\mathrm{point}}Lpoint​ 沿用深度损失的置信度加权、数值误差与梯度误差形式。它的重要性在于同时检查相机与深度：一张深度图可能在自己的相机坐标系中看起来合理，但只要相机位姿错误，反投影到全局坐标后就无法与 PiP_iPi​ 对齐。梯度会同时回传到 depth head、camera head 和共享主干。

matching loss 直接施加在最后一层 patch token 上。先将两个 token 做 L2 归一化，其余弦相似度为：

sab=za⊤zb∥za∥2∥zb∥2s_{ab} =\frac{z_a^\top z_b}{\|z_a\|_2\|z_b\|_2} sab​=∥za​∥2​∥zb​∥2​za⊤​zb​​

正负样本使用二元交叉熵：

Lmatch=E(a,b)∼P[−log⁡σ(sab)]+E(a,b)∼N[−log⁡(1−σ(sab))]\mathcal L_{\mathrm{match}} =\mathbb E_{(a,b)\sim\mathcal P} [-\log\sigma(s_{ab})] +\mathbb E_{(a,b)\sim\mathcal N} [-\log(1-\sigma(s_{ab}))] Lmatch​=E(a,b)∼P​[−logσ(sab​)]+E(a,b)∼N​[−log(1−σ(sab​))]

正样本不是简单按颜色相似度取得。训练数据已知深度和相机，因此可以把 query patch 中的三维点投影到其他帧，要求投影位于图内、与目标深度的相对误差在 1% 内，并统计落入目标 patch 的点数；投影重叠比例超过 10% 的 patch 才组成正对。

未被判定为正样本的 patch 不能直接视为负样本，因为对应点可能被遮挡、移出画面或属于运动物体。论文要求负样本同时满足两个条件：目标 patch 中心与 query patch 对应极线的距离足够大，并且两块 patch 的平均 RGB 距离也足够大。只有几何和外观均不支持对应关系时，才将其视为可靠负对。

这两个训练期损失把原本需要单独 point-map head 和 tracking head 才能提供的监督，转化为对现有输出与中间特征的约束。VGGT-Ω 因而采用训练期多任务、推理期轻输出的设计：共享主干仍要学习跨视图三维一致性和像素对应，部署时却只保留真正需要的稠密解码分支。

动态重建

静态场景中，深度与相机可以把所有帧反投影到同一个世界：

Xi(u,v)=Ri⊤(Di(u,v)Ki−1u~−ti)X_i(u,v) =R_i^\top\left(D_i(u,v)K_i^{-1}\tilde{\mathbf u}-t_i\right) Xi​(u,v)=Ri⊤​(Di​(u,v)Ki−1​u~−ti​)

如果物体在运动，同一个物体像素在不同时刻得到的 XiX_iXi​ 可以位于不同位置，而相机参数只描述拍摄设备的运动。于是“相机动了”和“物体动了”可以由两个变量分开解释：gig_igi​ 负责相机，DiD_iDi​ 负责每帧当时的场景表面。

这也是论文没有继续把 point map 作为主要输出的原因。静态 point map 把每个像素直接绑定到参考坐标中的三维点，若用 point map 反求相机，动态物体的位移容易与相机运动纠缠。ray map 可以分离射线与深度，却又增加一个逐像素稠密输出。VGGT-Ω 选择更简洁的 camera + depth，并让大规模动态数据提供运动先验。

“动态重建”在本文中表示逐帧深度与共同相机坐标。模型没有显式输出物体身份、场景流、轨迹或连续时间形变场，直接叠加各帧点云会保留运动物体的多个时间状态。

另一个特点是模型既不接收帧号，也不接收时间顺序，训练与推理时都可以重排非参考帧。因此，模型学习的动态先验不依赖“第 ttt 帧之后是第 t+1t+1t+1 帧”这样的固定时序，而是从无序观测中判断哪些外观变化更可能来自物体运动，哪些几何变化更可能由相机运动造成。

自监督学习

标注相机和深度很贵，普通视频却几乎无限。VGGT-Ω 使用 momentum teacher–student 方案，把无标签视频转成一致性训练信号。

教师和学生都从已经完成监督训练的 VGGT-Ω 初始化。对同一组视频帧，两条分支分别执行随机增强，包括颜色扰动、模糊、90∘90^\circ90∘ 旋转、patch mask 和帧重排。帧重排还会改变哪张图充当参考坐标系。设两条分支的排列分别为 πS,πT\pi_S,\pi_TπS​,πT​，预测完成后先逆排列到共同顺序：

zˉS=πS−1(zS),zˉT=πT−1(zT)\bar z_S=\pi_S^{-1}(z_S), \qquad \bar z_T=\pi_T^{-1}(z_T) zˉS​=πS−1​(zS​),zˉT​=πT−1​(zT​)

学生需要在多个中间层匹配教师 token，并匹配教师的相机与深度预测。用示意形式表示：

EMA 教师变化缓慢，相当于为学生提供一个平滑目标。颜色与模糊不同但场景相同，要求特征一致，会抑制模型过度依赖外观；帧顺序和参考帧不同但相对几何相同，要求还原顺序后预测一致，会强化置换等变与坐标变换的稳定性。

自监督阶段冻结 camera/depth head，只更新主干等部分。这会保留监督阶段已经建立的几何输出坐标，降低教师和学生共同把预测头收缩到无意义常数的风险。论文使用约 1800 万条无标签视频执行这部分训练。

当前自监督协议仍需要监督预训练模型作为起点。冻结几何输出头能够维持已有坐标语义，教师—学生一致性则继续调整主干对外观、帧顺序和参考坐标变化的鲁棒性；它扩展的是监督模型的覆盖范围，并未给出从随机参数学习三维坐标系的完整方案。

数据引擎

VGGT-Ω 先整合真实、合成、室内、室外、自动驾驶、具身和动态数据。公开数据包括 Aria、Co3D、DL3DV、Dynamic Replica、Hypersim、MegaDepth、MegaSynth、ScanNet、TartanAir、Waymo 等，加上内部真实与合成数据，总计约 300 万个序列，每个序列可包含 10 到 2 万张图像。

仅把数据集名字堆在一起并不能保证质量。对非合成数据，论文会检查多视图深度一致性并删除噪声像素；背景几何明显虚假的 Kubric、PointOdyssey 等数据被移出训练。合成数据通常提供准确几何，真实数据则提供丰富外观、相机轨迹和传感器分布，论文经验上建议每个 epoch 约采样 80% 合成、20% 真实。

为了继续扩大视频监督，作者从约 4000 万条互联网风格视频开始构造伪真值。VLM 先判断视频是否是连续实拍，是否存在剪辑、水印、严重模糊或缺少视差等情况，约 50% 被硬拒绝、40% 被软拒绝，质量最高的约 10% 进入几何标注；通过基础过滤但不够可靠的更多视频仍可用于自监督。Grounding DINO 检测人、车等可能运动的类别，这些区域不参与相机匹配与伪真值验证。随后联合 SIFT、SuperPoint + SuperGlue、ALIKED + LightGlue 等多种特征匹配器产生跨帧轨迹，降低单一匹配器的偏差。若基于本质矩阵的 RANSAC 内点不足，就用原始 VGGT 初始化相机，再由 COLMAP 做 Bundle Adjustment 和几何过滤，只保留图像注册率至少 99.5%、视场角位于 [30∘,120∘][30^\circ,120^\circ][30∘,120∘] 等严格条件的序列。PatchMatch MVS 生成逐帧稠密深度，每个深度点反投影后投影到其他视图检查一致性，有效深度少于 5% 的序列被丢弃。最后用相机上方向、视差角、轨迹平滑度、点云形状等特征描述重建质量，作者手工标注 500 个静态和 500 个动态序列，训练分类器集成来筛除几何失败案例。

最终得到约 60 万个静态、20 万个动态的高质量标注序列，与已有数据合并后约为 400 万个监督序列，是 VGGT 的 15 倍以上。真实视频中的动态区域通常被掩掉，动态像素的精确深度主要由合成数据补充；真实动态视频仍提供相机、背景与真实外观分布。

附录还总结了几种很容易被普通 benchmark 掩盖的标注错误：深度传感器会把椅背边缘泄漏到后方墙面；合成渲染会漏掉细栏杆；HDRI 背景可能实际只是一层假球面；弱视差和错误径向畸变会让 BA 在低重投影误差下仍产生整体弯曲的 doming effect；旅游照片中的行人边界若被错误标为墙面，模型会学会把人“贴进墙里”。大模型不仅学习正确几何，也能记住少量系统性噪声，所以数据筛选是方法本身的一部分，而不只是预处理。

实验结果

在静态与动态多视图基准上，模型由 0.2B 扩展至 10B、训练序列继续增加时，相机与深度的 point error 持续下降，呈现论文所称的近似幂律趋势。曲线只覆盖当前参数量与数据范围，尚不能外推为普适 scaling law。

轻量输出头与部分 Register Attention 将训练显存降至原 VGGT 的约 30%，point error 仅由 0.071 变为 0.073；教师—学生自监督再将其改善到 0.070，增益相对有限。高质量监督数据与保留部分完整 Global Attention 仍是当前性能的主要支撑。

特点与局限

VGGT-Ω 从模型、数据和训练方式三方面系统研究三维重建的 scaling，并在 0.2B 至 10B 参数、数千至数百万序列的范围内观察到稳定收益。每帧 scene token 与 Register Attention 提供低带宽的跨帧通信，精简的深度和相机输出头降低训练显存；高质量视频标注、自监督学习和静动态统一训练进一步扩大了数据来源，得到的空间 token 还能迁移到视觉语言动作等下游任务。

模型仍受针孔相机、相对尺度和可见表面表示限制，动态输入也没有形成带物体身份、场景流与遮挡拓扑的连续四维场景；默认多数跨帧层仍使用完整 Global Attention，超长序列成本尚未线性化。10B 训练依赖大规模算力，自监督增益、伪标注偏差和动态数据覆盖仍有改进空间，现有 scaling 曲线也不足以可靠外推；在匹配充分的场景中，传统束调整依然可能提供更高的最终相机精度。
