TRELLIS: Structured 3D Latents for Scalable and Versatile 3D Generation

发表于2026-08-10|更新于2026-08-17|Note3DVision 论文阅读
|浏览量:

二维生成已经形成较稳定的技术路线：把图像压缩到规则 latent grid，在统一潜空间中训练大规模生成模型，再由 decoder 还原像素。三维生成更难形成类似范式，因为三维资产没有唯一的数据格式。网格适合编辑、动画和几何处理；Radiance Field 擅长连续视图合成；3D Gaussian Splatting 具有较高渲染效率；SDF 和 Occupancy Field 又便于用神经网络表示平滑表面。它们的数据结构、训练损失和输出用途差异很大。

如果直接在某一种表示上训练生成模型，潜空间会继承该表示的优势和缺陷。以 3D Gaussian 为生成目标，外观通常很好，导出的网格却可能不可靠；以 SDF 或 mesh latent 为目标，几何更明确，细腻纹理和实时新视角渲染又会变弱。为每种输出分别训练大型生成模型会重复学习物体形状、语义和外观，也不利于统一扩展。

TRELLIS 提出的 Structured LATent（SLat） 在稀疏三维网格的活跃体素上挂接局部潜向量。活跃位置描述粗几何，潜向量由多视图 DINOv2 特征学习，记录局部形状和外观。生成模型只负责产生这套中间表示，后端可以使用不同 decoder 将同一个 SLat 转成 3D Gaussian、Radiance Field 或网格。

围绕这一表示，论文把生成过程拆成 sparse structure 与 local latent 两阶段，分别用 rectified flow Transformer 建模，并在约 50 万个公开三维资产上训练最高 2B 参数的模型。文本、图像条件和免微调局部编辑都建立在同一潜空间上。

核心问题

一个通用三维潜变量需要同时满足四个要求。

第一，潜变量要携带明确的 空间锚点。无序 point latent 或固定数量 latent set 具有很强压缩能力，但每个 token 没有稳定局部归属，复杂表面解码和局部编辑都较困难。

第二，潜变量要足够 稀疏。若直接使用 N3N^3N3 致密体素，分辨率从 64 提高到 256 时，网格单元数量会增加 64 倍，Transformer 和三维卷积都很快失去可扩展性。

第三，潜变量要同时包含 geometry 与 appearance。只记录 occupancy 或 SDF 时，decoder 还需另行推断颜色和材质；只记录从渲染拟合出的 radiance feature 时，表面位置又可能不够精确。

第四，潜变量不应与一种最终格式完全绑定。同一份中间状态最好能解码为适合渲染的表示，也能解码为适合编辑的网格。

TRELLIS 的基本选择是把 粗结构 和 局部内容 分开。稀疏活跃体素决定物体表面大致经过哪些空间区域，每个体素中的 latent 负责说明该区域具体长什么样。这种表示保留了规则三维坐标，又把计算限制在表面附近。

可以把 SLat 想成一张稀疏的三维索引表：坐标回答“哪里需要描述”，局部向量回答“那里是什么”。前者适合控制形状和编辑范围，后者负责承载难以用一个占用位表示的细节。

任务定义

输入条件可以是文本 ctextc_{\mathrm{text}}ctext​ 或图像 cimgc_{\mathrm{img}}cimg​。模型先生成结构化潜变量：

z^=GΘ(c)\hat{\mathbf z} = G_\Theta(c) z^=GΘ​(c)

再选择一个输出 decoder：

A^r=Dr(z^),r∈{GS,RF,Mesh}\hat{\mathcal A}_{r} = D_r(\hat{\mathbf z}), \qquad r\in \{\mathrm{GS},\mathrm{RF},\mathrm{Mesh}\} A^r​=Dr​(z^),r∈{GS,RF,Mesh}

DGSD_{\mathrm{GS}}DGS​ 输出 3D Gaussian，DRFD_{\mathrm{RF}}DRF​ 输出 Radiance Field，DMeshD_{\mathrm{Mesh}}DMesh​ 输出网格。同一生成结果可以按下游需要选择表示：预览和新视角渲染可以使用 GS，连续体渲染可以使用 RF，几何编辑与常规 DCC 流程可以使用 mesh。

这里的 generation 与 single-image reconstruction 有联系，也有任务差别。参考图只提供一个或少数视角，不可见区域没有真实观测，模型会根据训练分布补全背面和遮挡结构。因此结果应理解为与条件一致的三维资产样本，而非对真实物体所有隐藏细节的确定性恢复。

SLat 表示

对一个三维资产 O\mathcal OO，SLat 定义为：

z={(zi,pi)}i=1L,zi∈RC,pi∈{0,1,…,N−1}3\mathbf z = \left\{ \left( \mathbf z_i,\mathbf p_i \right) \right\}_{i=1}^{L}, \qquad \mathbf z_i\in\mathbb R^C, \quad \mathbf p_i\in \{0,1,\ldots,N-1\}^3 z={(zi​,pi​)}i=1L​,zi​∈RC,pi​∈{0,1,…,N−1}3

pi\mathbf p_ipi​ 是与物体表面相交的活跃体素坐标，zi\mathbf z_izi​ 是该体素的局部潜向量，LLL 是活跃体素总数。默认配置为：

N=64,C=8,E[L]≈20 000N=64, \qquad C=8, \qquad \mathbb E[L]\approx 20\,000 N=64,C=8,E[L]≈20000

完整 64364^3643 网格有 262,144 个体素，平均只使用约 20K 个。空体素完全跳过，潜序列长度由物体表面积和复杂度决定。

活跃位置 {pi}\{\mathbf p_i\}{pi​} 构成粗轮廓。若只显示这些体素，已经能辨认物体的大体形状和部件布局。zi\mathbf z_izi​ 进一步记录体素内部的表面方向、曲率、颜色、纹理和其他外观线索。二者的分工可以写成：

{pi}i=1L⏟coarse structure+{zi}i=1L⏟local detail\underbrace{\{\mathbf p_i\}_{i=1}^{L}}_{\text{coarse structure}} \quad+\quad \underbrace{\{\mathbf z_i\}_{i=1}^{L}}_{\text{local detail}} coarse structure{pi​}i=1L​​​+local detail{zi​}i=1L​​​

这种局部性有两个直接作用。decoder 可以围绕 pi\mathbf p_ipi​ 只输出附近的三维 primitive；编辑时也可以选定一个空间区域，只修改区域内的体素和 latent。由于 token 的身份由坐标固定，局部修改无需先在无序 latent set 中寻找与目标部件对应的 token。

视觉编码

训练 SLat 需要先把已有三维资产编码成潜变量。TRELLIS 没有要求每个训练资产预先拟合一套 NeRF 或 3DGS，而是借助二维视觉基础模型构造三维特征。

对资产 O\mathcal OO 从球面上的多个相机渲染图像：

{Iv}v=1V=RenderViews⁡(O)\{I_v\}_{v=1}^{V} = \operatorname{RenderViews}(\mathcal O) {Iv​}v=1V​=RenderViews(O)

每张图经过冻结的 DINOv2，得到 dense feature map：

Fv=DINOv2⁡(Iv)F_v = \operatorname{DINOv2}(I_v) Fv​=DINOv2(Iv​)

对于活跃体素 pi\mathbf p_ipi​，利用相机投影 πv\pi_vπv​ 找到其在各视图特征图中的位置，对有效观测做聚合：

fi=1∣Vi∣∑v∈ViSample⁡(Fv,πv(pi))\mathbf f_i = \frac{1}{|\mathcal V_i|} \sum_{v\in\mathcal V_i} \operatorname{Sample} \left( F_v,\pi_v(\mathbf p_i) \right) fi​=∣Vi​∣1​v∈Vi​∑​Sample(Fv​,πv​(pi​))

Vi\mathcal V_iVi​ 是能够为该体素提供有效特征的视图集合。最终得到稀疏体素特征：

f={(fi,pi)}i=1L\mathbf f = \{(\mathbf f_i,\mathbf p_i)\}_{i=1}^{L} f={(fi​,pi​)}i=1L​

DINOv2 特征比原始 RGB 更适合作为中间监督。它同时保留局部边界、纹理与较高层语义，且不同视角下的对应区域更容易落到相近特征空间。活跃体素提供明确三维位置，多视图平均则把来自不同投影的二维信息汇入同一个局部槽位。

这套编码方式也存在明显特点：SLat 是从“资产的多视图视觉表现”学习出来的。它能同时服务 GS、RF 和 mesh，因为视觉特征没有预先限定最终 primitive；光照、反射和纹理烘焙痕迹也可能进入潜变量，这一点后来成为 TRELLIS.2 引入原生 PBR 表示的重要原因。

论文的数据流水线为 VAE 训练中的每个资产渲染多张固定 FoV 的球面视图，用于多视图特征聚合和重建监督；图像条件生成模型另用一组 FoV 增强视图作为 prompt。作者将这一流程称为 fitting-free training，含义是省去逐资产的 NeRF 或 3DGS 梯度优化，离线渲染与特征预计算仍然存在。

稀疏 VAE

稀疏特征 f\mathbf ff 经过 VAE encoder E\mathcal EE 得到 SLat：

qϕ(z∣f)=Eϕ(f),O^=Dψ(z)q_\phi(\mathbf z\mid\mathbf f) = \mathcal E_\phi(\mathbf f), \qquad \hat{\mathcal O} = \mathcal D_\psi(\mathbf z) qϕ​(z∣f)=Eϕ​(f),O^=Dψ​(z)

训练目标包含具体输出表示的重建损失和 KL 正则：

LVAE=Lrecon+λKLDKL(qϕ(z∣f)∥N(0,I))\mathcal L_{\mathrm{VAE}} = \mathcal L_{\mathrm{recon}} +\lambda_{\mathrm{KL}} D_{\mathrm{KL}} \left( q_\phi(\mathbf z\mid\mathbf f) \| \mathcal N(\mathbf 0,\mathbf I) \right) LVAE​=Lrecon​+λKL​DKL​(qϕ​(z∣f)∥N(0,I))

KL 项让各局部 latent 接近统一高斯先验，从而形成较连续、便于后续流模型学习的空间。权重过大时，后验会忽略输入细节；权重过小时，latent 虽能重建训练样本，分布却可能出现彼此分离的尖锐区域，使生成器难以从噪声平滑到达。

encoder 与 decoder 都以 Transformer 为主。网络把活跃体素按固定空间顺序序列化，将 fi\mathbf f_ifi​ 与由 pi\mathbf p_ipi​ 计算的正弦位置编码相加，再进入 Transformer block。直接对约 20K token 做全局 self-attention 成本很高，因此网络使用三维 shifted-window attention：

  1. 在每个局部三维窗口内做 self-attention；
  2. 下一层平移窗口边界；
  3. 原先分属不同窗口的邻域在后续层交换信息。

这一结构与二维 Swin Transformer 类似，窗口从图像平面扩展到稀疏三维网格。单层只处理局部邻域，下一层移动窗口后，原先隔在边界两侧的 token 才能通信；多层堆叠让信息逐步跨越整个物体，同时避免一次构造 L×LL\times LL×L 的注意力矩阵。

论文先以 3D Gaussian decoder 联合训练 encoder 和 latent decoder。GS 的可微渲染速度快，外观监督丰富，适合让 encoder 学到同时含有几何与纹理的 SLat。训练完成后冻结 encoder，Radiance Field 与 mesh decoder 从同一 SLat 单独训练。由此得到的“通用”含义是共享 encoder 和 latent space，三个 decoder 仍有各自参数与训练损失。

多格式解码

3D Gaussian

每个局部 latent zi\mathbf z_izi​ 解码成 KKK 个 Gaussian：

DGS:{(zi,pi)}i=1L↦{{oik,cik,sik,αik,rik}k=1K}i=1L\mathcal D_{\mathrm{GS}}: \{(\mathbf z_i,\mathbf p_i)\}_{i=1}^{L} \mapsto \left\{ \left\{ \mathbf o_i^k, \mathbf c_i^k, \mathbf s_i^k, \alpha_i^k, \mathbf r_i^k \right\}_{k=1}^{K} \right\}_{i=1}^{L} DGS​:{(zi​,pi​)}i=1L​↦{{oik​,cik​,sik​,αik​,rik​}k=1K​}i=1L​

o\mathbf oo 是相对体素的中心偏移，c\mathbf cc 是颜色，s\mathbf ss 是尺度，α\alphaα 是不透明度，r\mathbf rr 是旋转。实现中每个活跃体素预测 K=32K=32K=32 个 Gaussian。最终中心被限制在对应体素附近：

xik=pi+tanh⁡(oik)\mathbf x_i^k = \mathbf p_i+\tanh(\mathbf o_i^k) xik​=pi​+tanh(oik​)

局部约束防止一个 token 跨越整个物体输出 primitive，保留 SLat 的空间可解释性。训练用渲染图的 L1L_1L1​、D-SSIM 与 LPIPS，并对 Gaussian 体积和 opacity 做正则，抑制过大或近乎透明的退化 primitive。

网格分支展示了 SLat 能迁移到显式表面，但它仍继承等值面表示的拓扑先验。开口面、非流形结构和内部多层表面并非这一版本的重点，这也是阅读 TRELLIS 与 TRELLIS.2 时必须保留的边界。

结构生成

直接联合生成 {pi,zi}\{\mathbf p_i,\mathbf z_i\}{pi​,zi​} 较难，因为位置是离散集合，latent 是连续向量，序列长度还随物体变化。TRELLIS 将任务拆成两个条件生成模型。

第一阶段只生成活跃位置。先把 sparse structure 写成致密二值网格：

O(p)={1,p∈{pi}i=1L0,otherwise,O∈{0,1}N×N×NO(\mathbf p) = \begin{cases} 1,&\mathbf p\in\{\mathbf p_i\}_{i=1}^{L}\\ 0,&\text{otherwise} \end{cases}, \qquad O\in\{0,1\}^{N\times N\times N} O(p)={1,0,​p∈{pi​}i=1L​otherwise​,O∈{0,1}N×N×N

由于 OOO 只表示粗轮廓，作者用一个三维卷积 VAE 将它压缩为低分辨率连续特征：

S=ES(O)∈RD×D×D×CS\mathbf S = \mathcal E_S(O) \in \mathbb R^{D\times D\times D\times C_S} S=ES​(O)∈RD×D×D×CS​

structure flow Transformer GS\mathcal G_SGS​ 在 S\mathbf SS 的连续空间中生成，再由 DS\mathcal D_SDS​ 解码回二值 occupancy。VAE 的解码目标对应活跃/非活跃二分类，正负样本极不平衡，因此使用 Dice loss：

LDice=1−2∑pO^(p)O(p)+ϵ∑pO^(p)+∑pO(p)+ϵ\mathcal L_{\mathrm{Dice}} = 1- \frac{ 2\sum_{\mathbf p}\hat O(\mathbf p)O(\mathbf p)+\epsilon }{ \sum_{\mathbf p}\hat O(\mathbf p) +\sum_{\mathbf p}O(\mathbf p)+\epsilon } LDice​=1−∑p​O^(p)+∑p​O(p)+ϵ2∑p​O^(p)O(p)+ϵ​

Dice loss 直接比较预测集合与真实集合的重叠比例，空体素再多也不会像普通逐体素准确率那样淹没少量表面体素。GS\mathcal G_SGS​ 接收序列化的低分辨率 grid token，时间步通过 adaLN 和门控注入，文本或图像特征作为 cross-attention 的 key/value；输出解码并阈值化后，重新获得活跃体素集合。

结构生成决定对象级拓扑和粗部件。如果第一阶段遗漏把手、车轮或细杆，第二阶段没有活跃位置承载对应 latent，通常无法完整补回。因此两阶段虽然降低了建模难度，也引入了清晰的误差传递路径。

潜变量生成

第二阶段在给定 {pi}\{\mathbf p_i\}{pi​} 的前提下生成局部潜向量：

{z^i}i=1L=GL({pi}i=1L,c)\{\hat{\mathbf z}_i\}_{i=1}^{L} = \mathcal G_L \left( \{\mathbf p_i\}_{i=1}^{L},c \right) {z^i​}i=1L​=GL​({pi​}i=1L​,c)

平均 20K 个 token 直接进入大型 Transformer 仍然昂贵。GL\mathcal G_LGL​ 先用 sparse convolution 将每个 232^323 邻域内的 active latent packing 到更短序列，空间边长从 64 降到 32。Transformer 在压缩序列上执行 time-modulated self-attention 与 condition cross-attention，末端再用 sparse upsampler 恢复原活跃结构。

下采样与上采样之间保留 skip connection。低分辨率 Transformer 负责全局部件关系和条件一致性，skip path 保存精确活跃位置与局部布局，避免压缩后边界漂移。

结构模型与 latent 模型分开训练。推理时先从噪声采样 S\mathbf SS 并得到 {pi}\{\mathbf p_i\}{pi​}，再根据这组位置采样 {zi}\{\mathbf z_i\}{zi​}。最后将完整 SLat 送入所选 decoder。

流匹配

两阶段生成都采用 conditional flow matching。给定真实数据 x0\mathbf x_0x0​ 和高斯噪声 ϵ\boldsymbol\epsilonϵ，定义线性路径：

x(t)=(1−t)x0+tϵ,t∈[0,1]\mathbf x(t) =(1-t)\mathbf x_0+t\boldsymbol\epsilon, \qquad t\in[0,1] x(t)=(1−t)x0​+tϵ,t∈[0,1]

vθ(x(t),t,c)v_\theta(\mathbf x(t),t,c) vθ​(x(t),t,c)

训练损失为：

LCFM=Et,x0,ϵ[∥vθ(x(t),t,c)−(ϵ−x0)∥22]\mathcal L_{\mathrm{CFM}} = \mathbb E_{t,\mathbf x_0,\boldsymbol\epsilon} \left[ \left\| v_\theta(\mathbf x(t),t,c) - (\boldsymbol\epsilon-\mathbf x_0) \right\|_2^2 \right] LCFM​=Et,x0​,ϵ​[∥vθ​(x(t),t,c)−(ϵ−x0​)∥22​]

由于线性路径对 ttt 的导数就是 ϵ−x0\boldsymbol\epsilon-\mathbf x_0ϵ−x0​，训练目标可以直接监督速度，无需先估计每个噪声时刻的 score。推理时从 ϵ\boldsymbol\epsilonϵ 出发，沿学习到的 ODE 从 t=1t=1t=1 积分到 t=0t=0t=0，逐步把噪声运输到数据分布。

Rectified flow 的“直”描述训练时选用的插值路径。神经网络学到的是覆盖整个数据分布的条件速度场，实际采样轨迹仍会随条件和当前位置变化。

结构阶段的速度场先决定 occupancy layout，这个全局分布又规定了后续所有 latent 的空间落点。结构误差会沿级联链路传递：第二阶段即使生成了合理的局部细节，也无法将它们放回正确部件。

论文还将时间步采样从 SD3 常用的 logitNorm⁡(0,1)\operatorname{logitNorm}(0,1)logitNorm(0,1) 改为 logitNorm⁡(1,1)\operatorname{logitNorm}(1,1)logitNorm(1,1)，把更多训练权重放到三维稀疏潜变量更需要学习的噪声区间。这一设定同时用于结构与 latent 两个速度场。

条件控制

文本条件来自预训练 CLIP text encoder，图像条件来自 DINOv2。条件 token 通过 cross-attention 注入两个生成阶段，因此文本或图像都会影响粗结构和局部细节。

训练使用 classifier-free guidance。以 0.1 概率丢弃条件，使同一网络同时学到有条件速度 vcv_cvc​ 和无条件速度 v∅v_\varnothingv∅​。推理时采用：

v~=v∅+s(vc−v∅)\tilde v = v_\varnothing +s\left(v_c-v_\varnothing\right) v~=v∅​+s(vc​−v∅​)

论文默认 guidance strength s=3s=3s=3。较大的 sss 通常提高 prompt alignment，也可能减少多样性并放大条件图像中的局部伪影。

官方仓库后续同时发布了 text 与 image 模型，但明确建议实际 text-to-3D 时先用成熟的 text-to-image 模型生成参考图，再运行 TRELLIS-image。原因是高质量三维文本数据有限，直接 text-conditioned 模型的创造力和细节通常弱于图像条件路线。论文证明两类条件可以统一，工程上仍需根据数据质量选择入口。

局部编辑

SLat 的结构和细节分离带来两种免微调编辑方式。

detail variation 固定活跃位置 {pi}\{\mathbf p_i\}{pi​}，只重新运行第二阶段：

z^(k)∼pθ(z∣{pi},ck)\hat{\mathbf z}^{(k)} \sim p_\theta \left( \mathbf z\mid\{\mathbf p_i\},c_k \right) z^(k)∼pθ​(z∣{pi​},ck​)

粗轮廓保持不变，新的文本条件改变材质、风格和局部形状。它适合在同一对象结构上生成木制、金属、废旧或低多边形等版本。

region-specific editing 给出三维 bounding box B\mathcal BB，保留区域外的结构和 latent，只对区域内进行条件重采样。方法将 RePaint 的已知区域约束扩展到两阶段 flow；用区域掩码示意一次状态合成，可以写成：

xt=MB⊙xtnew+(1−MB)⊙xtknown\mathbf x_t = \mathbf M_{\mathcal B}\odot\mathbf x_t^{\mathrm{new}} + (1-\mathbf M_{\mathcal B}) \odot \mathbf x_t^{\mathrm{known}} xt​=MB​⊙xtnew​+(1−MB​)⊙xtknown​

第一阶段在框内生成新的 occupancy，第二阶段在更新后的结构上补充 latent。删除、添加和替换操作可以统一为“框内重新采样，框外保持”。局部空间索引使这一过程无需训练专用编辑网络。

编辑仍受两点约束：bounding box 是较粗的空间控制，无法直接表达精确部件语义；区域内外的接缝依赖 flow model 自行协调，复杂连接处可能出现结构或纹理不连续。

数据训练

训练集来自 ObjaverseXL、ABO、3D-FUTURE 和 HSSD。作者根据多视图美学分数过滤纹理缺失、几何过于简单和明显损坏的模型，最终得到约 50 万个训练资产；Toys4k 过滤后只用于测试，以免直接在训练资产上评价生成分布。

VAE 训练为每个资产渲染 150 张 40∘40^\circ40∘ FoV 的球面视图；图像条件生成另渲染 10∘10^\circ10∘ 到 70∘70^\circ70∘ 的 FoV 增强视图。GPT-4o 根据输入渲染图生成详细 caption，再提炼到不超过约 40 个英文词，并进一步摘要成不同长度。caption 质量决定 text model 能否学习部件、材质和风格词与三维结构之间的关系。

模型有三个规模：Basic 约 342M，Large 约 1.1B，X-Large 约 2B。这里的总参数量包含 structure generator 与 latent generator。XL 在 64 张 40GB A100 上训练 400K step，总 batch size 256，AdamW 学习率为 10−410^{-4}10−4。

实验结果

SLat 的重建与条件生成均达到当时领先水平：GS 解码 PSNR 约为 32.7 dB，encoder 冻结后改接 RF 或 mesh decoder 仍保持较好质量，说明 SLat 中的局部信息能被多种三维表示读取。在未见 Toys4k 资产上，图像条件结果获得约 95%95\%95% 的用户偏好。

643×864^3\times8643×8 的 SLat 重建 PSNR 约为 32.7 dB，高于 323×1632^3\times16323×16 的约 31.6 dB，表明增加空间锚点比在粗网格上堆通道更能保留局部归属；两阶段的 rectified flow 也优于对应 diffusion 版本。

特点与局限

TRELLIS 的 SLat 用稀疏活跃体素描述粗结构，以局部潜变量保存形状和外观细节，并通过多视图 DINOv2 特征与稀疏 Transformer VAE 学得可扩展的三维潜空间。离散结构和连续潜变量由两级 rectified flow 分别生成，同一 SLat 可解码为 3D Gaussian、辐射场和网格，也支持文本或图像条件、细节变体及基于三维区域的免微调编辑，体现了统一潜空间的跨表示复用能力。

两阶段串行流程会传播结构遗漏，GS、RF 和 mesh decoder 仍需分别训练，格式间也无法保证无损转换；其中基于 SDF 与 FlexiCubes 的网格分支对开口面、非流形和极薄结构支持有限。大规模多视图渲染及 DINOv2 特征预计算成本依然可观，图像条件还会混合光照与材质；训练数据和 caption 偏差使模型更擅长艺术化单体资产，对逼真物体、语义部件、关节动画、物理属性及多物体关系的建模仍不充分。
