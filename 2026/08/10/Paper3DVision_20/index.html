Fast3R: Towards 3D Reconstruction of 1000+ Images in One Forward Pass

发表于2026-08-10|更新于2026-08-17|Note3DVision 论文阅读
|浏览量:

DUSt3R 将两张无标定图像直接映射到同一个三维坐标系，使相机估计和稠密重建可以从 point map 中统一导出。处理多视图时，它仍要选择大量图像对、逐对运行网络，再通过全局优化把成对预测对齐。对于 NNN 张图像，候选图像对最多有 O(N2)O(N^2)O(N2) 个；即使只保留部分边，重复编码和迭代对齐也会让时间、显存与工程复杂度迅速增长。

Fast3R 将整组图像一次送入一个多视图 Transformer，把重建改写为 集合到集合 的预测任务。每张图先独立编码，随后全部 patch token 在融合 Transformer 中执行 all-to-all self-attention，最终同时预测每一张图的局部 point map、全局 point map 和置信度。全局 point map 已位于第一张图的相机坐标系，因而省去了 DUSt3R 的成对重建图和测试时全局对齐。

这项工作的重点在于把大规模三维重建改写为标准 Transformer 前向计算，并利用 FlashAttention、ZeRO 和输出头并行等成熟基础设施扩大视图数。论文模型只用 20 视图样本训练，却能在单次前向中处理 1000 到 1500 张图像。

标题中的 one forward pass 只覆盖神经网络主体：全部 point map 由一次模型调用产生。完整相机参数仍由 RANSAC-PnP 提取，高质量点云还会用 ICP 对齐局部与全局 point map。

任务定义

输入为同一场景的 NNN 张无标定、无位姿 RGB 图像：

I={Ii}i=1N,Ii∈RH×W×3\mathcal{I} = \{I_i\}_{i=1}^{N}, \qquad I_i \in \mathbb{R}^{H \times W \times 3} I={Ii​}i=1N​,Ii​∈RH×W×3

论文把 Fast3R 的输出写成：

fθ(I)=(XL,ΣL,XG,ΣG)f_\theta(\mathcal I) = \left( X_L,\Sigma_L, X_G,\Sigma_G \right) fθ​(I)=(XL​,ΣL​,XG​,ΣG​)

整体流程

模型由三个部分组成：共享图像编码器、全局融合 Transformer 和两个 point map 解码头。计算过程可以概括为：

Hi←E(Ii),i=1,…,NH~i←Hi+PiZ←F(Concat⁡(H~1,…,H~N))(XL,ΣL)←DL(Z)(XG,ΣG)←DG(Z)\begin{array}{l} H_i\leftarrow E(I_i),\quad i=1,\ldots,N\\ \tilde H_i\leftarrow H_i+P_i\\ Z\leftarrow F\left(\operatorname{Concat}(\tilde H_1,\ldots,\tilde H_N)\right)\\ (X_L,\Sigma_L)\leftarrow D_L(Z)\\ (X_G,\Sigma_G)\leftarrow D_G(Z) \end{array} Hi​←E(Ii​),i=1,…,NH~i​←Hi​+Pi​Z←F(Concat(H~1​,…,H~N​))(XL​,ΣL​)←DL​(Z)(XG​,ΣG​)←DG​(Z)​

EEE 对每张图独立提取 patch 特征，PiP_iPi​ 是视图索引嵌入，FFF 让所有视图的 token 全局交互，DLD_LDL​ 和 DGD_GDG​ 分别恢复局部与全局三维坐标。全部图像的输出同时产生，没有按时间递归，也没有先选图像对再逐对处理。

第一张图具有特殊作用。它既是输入集合中的一个普通观测，又定义全局坐标系。在真值几何中有：

R1=I,t1=0,XG,1=XL,1R_1=I, \qquad t_1=0, \qquad X_{G,1}=X_{L,1} R1​=I,t1​=0,XG,1​=XL,1​

两个 point map 由不同的预测头输出，模型没有施加逐像素的硬等式约束，因此预测的 X^G,1\hat X_{G,1}X^G,1​ 与 X^L,1\hat X_{L,1}X^L,1​ 仍可能存在差异。模型可以接受没有时间顺序的照片集合，但输入排列会改变锚点和视图索引。论文中的 unordered 表示网络不依赖相邻帧或固定采集顺序，并不表示模型在数学上对任意置换完全不变。

图像编码

每张图首先独立切分为 16×1616\times1616×16 patch。若 patch 数为 S=HW/P2S=HW/P^2S=HW/P2，共享编码器输出：

Hi=E(Ii)={hi,j}j=1S,hi,j∈RdH_i=E(I_i) =\{h_{i,j}\}_{j=1}^{S}, \qquad h_{i,j}\in\mathbb R^d Hi​=E(Ii​)={hi,j​}j=1S​,hi,j​∈Rd

论文采用 CroCo ViT-L 编码器，并从 DUSt3R 预训练权重初始化。该编码器包含 24 层、16 个注意力头，特征维度为 1024，MLP expansion ratio 为 4。CroCo 的跨视图预训练和 DUSt3R 的三维监督为单图 token 提供了较强的几何先验，避免大规模融合模块从零学习全部低层视觉特征。

编码过程在视图之间互相独立，适合沿图像维并行。它的计算量近似为：

O(NS2d)O(NS^2d) O(NS2d)

每张图内部保留二维 patch 位置，所以编码器能够区分图像中的空间结构。此时不同图像还没有交换信息，单张图中遮挡、尺度歧义和相机运动要等到后续全局融合阶段才能借助多视图上下文消解。

论文也测试了 DINOv2 编码器，结果相近；最终模型保留 CroCo/DUSt3R 初始化，便于继承已经验证过的 point map 表征。官方实现把图像编码、融合和输出头保持为标准 Transformer 与 DPT 组件，这也是 Fast3R 能直接采用现有并行和高效注意力实现的基础。

全局融合

所有视图特征拼成一条长序列：

H=Concat⁡(H1,H2,…,HN)∈RNS×dH= \operatorname{Concat}(H_1,H_2,\ldots,H_N) \in\mathbb R^{NS\times d} H=Concat(H1​,H2​,…,HN​)∈RNS×d

融合模块采用另一套 24 层 ViT-L，维度与前述图像 token 保持一致，并从头训练。图像编码器提供 DUSt3R 几何先验，融合 Transformer 则专门学习多视图之间的全局交互。融合过程写成：

Z=F(H)Z=F(H) Z=F(H)

融合层执行 all-to-all self-attention。任意图像中的 patch 都能直接关注任意其他图像的 patch，因此网络可以同时利用高重叠近邻视图、跨越较远的回环视图以及多张图共同确定的高阶对应关系。成对方法先在每条图像边上形成局部结论，再由优化传播；Fast3R 让所有相关证据在多层注意力中共同更新同一 token，使三张及以上视图可以直接消除两视图中仍存在的尺度或遮挡歧义。

对单层单头注意力，设：

Q=HWQ,K=HWK,V=HWVQ=HW_Q, \qquad K=HW_K, \qquad V=HW_V Q=HWQ​,K=HWK​,V=HWV​

其输出为：

Attn⁡(H)=softmax⁡(QK⊤d)V\operatorname{Attn}(H) =\operatorname{softmax} \left(\frac{QK^\top}{\sqrt d}\right)V Attn(H)=softmax(d​QK⊤​)V

这项操作也是模型主要的计算来源。全局 token 数为 L=NSL=NSL=NS，标准注意力计算量为：

O(L2d)=O(N2S2d)O(L^2d)=O(N^2S^2d) O(L2d)=O(N2S2d)

Fast3R 的“可扩展”主要来自一次性共享编码、取消图像对流水线，以及高效 GPU 实现。它仍保留全局注意力的二次计算复杂度。FlashAttention 可以避免显式保存完整 L×LL\times LL×L 注意力矩阵，并减少显存访问，却不会删掉全部 query-key 点积，视图数继续扩大时，计算时间仍会加速增长。

FlashAttention 改写的是注意力的分块计算和访存方式，精确结果与标准 softmax attention 一致。它显著降低中间矩阵显存，却不会把 O(L2)O(L^2)O(L2) 的乘法数量变成 O(L)O(L)O(L)。

视图索引

融合 Transformer 需要知道某个 token 来自哪张图，也要识别定义世界坐标系的 I1I_1I1​。Fast3R 在 patch 特征上加入一维 image-index positional embedding：

h~i,j=hi,j+pki\tilde h_{i,j}=h_{i,j}+p_{k_i} h~i,j​=hi,j​+pki​​

pkip_{k_i}pki​​ 在同一张图的所有 patch 间共享。视图内部的二维位置由原有 patch position encoding 表示，pkip_{k_i}pki​​ 只负责标记视图身份。第一张图固定使用 p1p_1p1​，保证全局头能够稳定识别锚点。

如果训练只使用 Ntrain=20N_{\mathrm{train}}=20Ntrain​=20 张图，并始终使用位置 111 到 202020，推理时第 21 张图开始就会落到未见索引。Fast3R 借鉴长上下文模型的位置外推思路，把论文记作 SH(k)SH(k)SH(k) 的一维视图索引编码扩展到 N′=1000N'=1000N′=1000 个候选位置；公开代码用固定的 sine-cosine embedding 实现，并在训练时从更大的索引范围随机抽取当前 NNN 个位置：

{ki}i=1N∼UniformSubset⁡({1,…,N′}),k1=1\{k_i\}_{i=1}^{N} \sim \operatorname{UniformSubset} \left(\{1,\ldots,N'\}\right), \qquad k_1=1 {ki​}i=1N​∼UniformSubset({1,…,N′}),k1​=1

这种 随机视图索引让同一训练视图在不同 batch 中落到不同位置，网络便无法把某个索引记成固定相机关系。大量未抽到的位置相当于空槽位，模型虽只看到 20 张图，却能学习整个候选范围内的位置编码；它解决了索引未见问题，并没有提供千视图场景中的真实长上下文训练。

这项策略解决的是位置编码外推，并没有让模型在训练时真实经历 1000 视图注意力。20 视图和 1000 视图之间仍存在 token 数量、场景范围与对应关系密度的分布差异。第一视图固定、其他图像获得不同 index embedding，也使输出对排列保留一定敏感性。若输入长度超出预计算的索引池，还需要扩展位置编码范围。

双重几何

融合后的 token 分别进入两个 DPT 解码头：

(XL,ΣL)=DL(Z),(XG,ΣG)=DG(Z)(X_L,\Sigma_L)=D_L(Z), \qquad (X_G,\Sigma_G)=D_G(Z) (XL​,ΣL​)=DL​(Z),(XG​,ΣG​)=DG​(Z)

两个头都把低分辨率 patch token 逐级融合并上采样到像素分辨率，每个像素输出 XYZ 和一个可靠性值。全局头从 DUSt3R 权重初始化，局部头从头训练。

局部头的任务相对稳定。无论哪一张图被选为锚点，第 iii 张图在自身相机坐标系中的真值 XL,iX_{L,i}XL,i​ 都不变。全局头除了恢复单图几何，还要估计从第 iii 个相机到第一相机的刚体关系；一旦更换 I1I_1I1​，同一个像素的全局 XYZ 监督也随之改变。可以把两者的学习难度写成：

DL:Ii⟶XL,i,DG:(I1,…,IN)⟶RiXL,i+ti\begin{aligned} D_L &: I_i\longrightarrow X_{L,i},\\ D_G &: (I_1,\ldots,I_N)\longrightarrow R_iX_{L,i}+t_i \end{aligned} DL​DG​​:Ii​⟶XL,i​,:(I1​,…,IN​)⟶Ri​XL,i​+ti​​

局部头面向单相机坐标系中的细粒度表面，全局头面向锚点坐标系中的场景布局和跨视图关系。双重几何将精细形状与统一坐标分给两个监督目标：全局图提供对齐参考，局部图提供最终表面。两个头共享融合特征，但不会被硬约束成完全一致，因此主重建流程仍要把局部图对齐到全局图。

相机恢复

Fast3R 没有相机参数预测头。对第 iii 张图，像素 uuu 与全局 point map 中的三维点 XG,i(u)X_{G,i}(u)XG,i​(u) 形成大量 2D-3D 对应，随后通过 PnP 求解：

min⁡Ki,Ri,ti∑u∈Ωiwi(u)∥π ⁣(Ki(RiXG,i(u)+ti))−u~∥22\min_{K_i,R_i,t_i} \sum_{u\in\Omega_i} w_i(u) \left\| \pi\!\left(K_i(R_iX_{G,i}(u)+t_i)\right)-\tilde u \right\|_2^2 Ki​,Ri​,ti​min​u∈Ωi​∑​wi​(u)∥π(Ki​(Ri​XG,i​(u)+ti​))−u~∥22​

该目标要求三维点经过外参变换和内参投影后回到原像素位置。作者先根据图像分辨率生成一组焦距候选，再对每个候选运行 RANSAC-PnP；RANSAC 反复抽取最小对应集，用重投影误差区分内点与外点，最终选择外点较少的焦距与位姿。PnP 只保留预测可靠性最高的 15%15\%15% 像素，以减少计算并排除错误几何。

若全部图像由同一台物理相机拍摄，论文使用第一视图估计的焦距作为所有视图的共享焦距，避免每张图的独立估计噪声破坏内参一致性；若相机来源不同，则逐图独立估计。多张图的 PnP 彼此独立，可以在 CPU 上多线程并行。

因此，论文标题中的 one forward pass 指 point map 网络主体。相机恢复仍有一个经典几何步骤，只是它按视图独立并行，无需建立全局图像对或运行束调整。官方代码的示例接口也先调用模型得到 point map，再单独调用 estimate_camera_poses 执行 PnP。

重建融合

直接融合 XGX_GXG​ 最简单，因为所有全局点已经位于第一相机坐标系。全局头负责跨视图统一布局，局部表面容易受到长程融合的平滑影响，因此论文用它确定高层结构，再逐图通过 ICP 把局部图对齐到对应全局图。对第 iii 张图，可以把目标概括为：

TiT_iTi​ 是局部相机坐标到锚点坐标的刚体变换，wiw_iwi​ 可以结合有效掩码和预测可靠性。ICP 在“根据当前 TiT_iTi​ 更新最近点对应”与“固定对应求最优刚体变换”之间迭代。全局图提供粗坐标，局部图保留表面细节；完成逐图对齐后，使用 Ti∗XL,iT_i^*X_{L,i}Ti∗​XL,i​ 生成最终点云，因此完整流程仍包含每视图后处理。

这套组合让全局头提供粗坐标和跨视图约束，局部头补回单图坐标系中保留较好的表面细节。阅读输出时需要区分原始全局 point map、经 ICP 对齐的局部 point map 与进一步筛选后的最终点云，它们对应不同程度的后处理。

训练设置

训练数据来自六个数据集：CO3D、ScanNet++、ARKitScenes、Habitat、BlendedMVS 和 MegaDepth，覆盖物体中心场景、室内扫描、移动设备采集、合成环境与室外照片集合。它们是 DUSt3R 所用九个数据集的一个子集。数据类型多样有利于开放场景泛化，也会引入扫描缺失、透明表面和相机注册误差，因此损失中的可靠性建模十分重要。

输入图像最长边为 512。模型用 AdamW 训练 174K step，初始学习率为 10−410^{-4}10−4，再按余弦策略衰减。每个训练样本包含 N=20N=20N=20 张图，总 batch size 为 128。整个过程没有 DUSt3R 式分阶段训练，在 128 张 A100 80GB GPU 上耗时 6.13 天。

训练阶段采用 FlashAttention 和 DeepSpeed ZeRO Stage 2。朴素实现即使每卡 batch size 为 1，在单样本超过 16 视图时也会耗尽显存；ZeRO-2 将优化器状态、动量和梯度分片后，论文训练系统最多可以容纳每样本 28 视图。最终配置选择 20 视图，以便维持更大的总 batch 和稳定优化。

这组数字说明“训练短、测试长”的必要性。直接用 1000 视图训练会同时面对全局注意力、激活保存和高分辨率 DPT 输出的巨大成本。Fast3R 通过随机视图索引让位置编码覆盖长范围，再依靠 Transformer 在推理阶段外推到更多 token；模型并未消除长上下文训练本身的资源障碍。

工程扩展

Fast3R 的大视图推理同时处理三个瓶颈。

第一项是全局注意力。FlashAttention 按块计算 softmax attention，避免把完整注意力矩阵写回显存，并改善 GPU 访存效率。它使较长 token 序列能够放入显存，但总点积数仍随 N2N^2N2 增长。

第二项是模型与训练状态。ZeRO-2 在多机训练时切分优化器状态与梯度，数据并行负责提高总 batch。标准 Transformer 结构还可以直接采用张量并行和模型并行，无需为三维几何重新设计专用算子。

第三项是 DPT 输出头。每张图的低分辨率 patch token 都要逐级上采样为高分辨率 XYZ 与可靠性图，因此视图增多后，DPT 激活会成为主要显存开销。作者把编码器和全局融合模块放在 GPU 0，再把 DPT 头复制到其余 GPU，将不同视图的融合特征分片解码。官方实现还允许按视图分块运行输出头，限制单次并行解码的视图数，从而降低峰值显存。

输出头并行不会改变融合注意力的计算图，却能把接近线性的高分辨率解码开销分摊到多张 GPU。Fast3R 的扩展能力由模型结构与系统实现共同构成，不能只归因于新的网络模块。

复杂度

Fast3R 与 DUSt3R 都可能出现二次项，但二次项的位置不同。DUSt3R 对图像对运行网络：

Cost⁡pair≈O(E⋅Cpair)\operatorname{Cost}_{\mathrm{pair}} \approx O(E\cdot C_{\mathrm{pair}}) Costpair​≈O(E⋅Cpair​)

EEE 是选择的图像对数量，稠密连接时接近 N(N−1)/2N(N-1)/2N(N−1)/2，之后还有全局对齐。Fast3R 只编码每张图一次，再让所有 patch 全局注意：

Cost⁡Fast3R≈O(NS2d)+O(N2S2d)+O(NSCDPT)\operatorname{Cost}_{\mathrm{Fast3R}} \approx O(NS^2d)+O(N^2S^2d)+O(NSC_{\mathrm{DPT}}) CostFast3R​≈O(NS2d)+O(N2S2d)+O(NSCDPT​)

它取消了重复成对编码和测试时全局优化，GPU 上的大矩阵计算也比复杂流水线更容易并行。渐近上，融合项仍为 O(N2)O(N^2)O(N2)；当视图从数百扩展到千级时，注意力耗时会比视图数增长得更快。

因此，Fast3R 适合被理解为“以标准密集 Transformer 实现的大规模离线重建基线”。它证明 1000 级视图在合适硬件和实现上可行，也为后续稀疏注意力、token 压缩和线性状态模型提供了明确参照。

实验结果

Fast3R 最突出的结果是规模与吞吐量：单张 A100、512×384512\times384512×384 输入下，处理 1000 张图约需 138 秒和 63 GiB 显存，省去了成对网络的重复编码与全局对齐，说明千图级单次前向已能在现实硬件上运行。CO3Dv2 的 RRA@15 约为 96%96\%96%，相对位姿精度仍具竞争力。

7Scenes 的 Accuracy / Completeness 约为 1.58 / 0.93，覆盖度有竞争力，局部精度有时落后于成对匹配和优化型方法，且最终结果还包含 PnP 与 ICP 后处理。

特点与局限

Fast3R 将无标定多视图重建统一为集合到集合的前向预测任务，通过全视图自注意力直接建模高阶对应，并同时输出负责整体布局的全局 point map 与保留表面细节的局部 point map。随机视图索引与 FlashAttention、输出头分片等工程设计，使模型仅用 20 视图样本训练后仍能扩展到千图级输入，在保持有竞争力的几何和相机估计精度时显著提高吞吐量。

其核心融合仍具有 O(N2S2)O(N^2S^2)O(N2S2) 的计算复杂度，千图级输入在单张 GPU 上仍需显著的时间与显存，长序列也存在明显的训练与测试规模差距。模型依赖首图锚点，超大场景可能出现 point map 漂移且缺少显式回环和束调整；相机恢复与最终融合仍需焦距搜索、RANSAC-PnP 和 ICP 等后处理，同时无法稳定恢复绝对尺度，主要适用于静态场景。
