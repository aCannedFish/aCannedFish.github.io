TRELLIS.2: Native and Compact Structured Latents for 3D Generation

发表于2026-08-10|更新于2026-08-17|Note3DVision 论文阅读
|浏览量:

三维生成模型最终要交付可用资产，而可用资产同时包含几何、拓扑和材质。几何决定表面位于哪里，拓扑描述表面怎样连接，材质则决定物体在不同光照下如何反射、透射和呈现颜色。很多方法只在其中一两项上表现突出：SDF、Occupancy Field 和 FlexiCubes 适合提取规整表面，却不擅长开口面、非流形连接与彼此靠近的多层结构；Radiance Field 和 3D Gaussian Splatting 可以合成逼真的视图，却很难稳定导出干净网格；基于纹理颜色的生成又无法区分“物体本身的颜色”和“输入图像中的光照效果”。

原始 TRELLIS 用 Structured LATent，简称 SLat，将稀疏体素位置与多视图 DINOv2 特征结合起来，再分别解码成 3D Gaussian、Radiance Field 或网格。这套表示解决了多种输出格式共享潜空间的问题，但训练 SLat 需要先把三维资产渲染成大量二维视图，再从二维特征反投影回三维；它的网格分支仍以 SDF 和 FlexiCubes 提取等值面，材质主要来自带有光照烘焙痕迹的外观特征。

TRELLIS.2 重新设计了底层表示。它从原生三角网格和 PBR 纹理直接构造 O-Voxel，用一套无标量场的稀疏体素结构联合记录几何与材质，再通过 Sparse Compression VAE（SC-VAE） 将高分辨率 O-Voxel 压缩成紧凑潜变量。生成模型在这套潜空间中依次预测稀疏布局、几何和材质，最后快速还原为带 PBR 纹理的网格。

具体来说，O-Voxel 用 Flexible Dual Grid 保存开放、非流形和内部表面，并在同一批活跃体素上对齐 base color、metallic、roughness 与 alpha。SC-VAE 通过 16 倍空间下采样把 102431024^310243 全纹理资产压缩到平均约 9.6K 个潜 token，再由结构、几何和材质三个条件生成器逐级恢复。

表示瓶颈

许多三维生成方法先预测一个标量场，再提取零等值面。以 Signed Distance Function（SDF） 为例，空间位置 x\mathbf{x}x 的值 s(x)s(\mathbf{x})s(x) 表示它到最近表面的带符号距离，表面由

S={x∣s(x)=0}\mathcal S=\{\mathbf{x}\mid s(\mathbf{x})=0\} S={x∣s(x)=0}

给出。只要 s(x)s(\mathbf{x})s(x) 在空间中连续，零等值面通常会形成封闭、可定向的二维流形。这种先验有利于获得干净表面，也会限制能够表达的拓扑。

“带符号”要求空间能被一致地分成内部与外部。纸张、开口衣物和 T 形连接没有天然满足这一要求，因此困难来自表示假设，单纯增加网络容量无法完全消除。

开口的树叶、纸张和衣物没有明确“内部”和“外部”，带 T 形连接的非流形网格无法由单个连续内外符号自然描述，物体内部完全封闭的零件还可能在体素化或 flood fill 时被误删。若两层平行表面的间距小于体素尺寸，单个标量场也容易把它们合并。分辨率提高可以缓解细节丢失，却不能消除表示本身对符号场和等值面的依赖。

外观方面，单张 RGB 图像可以写成材质、光照、相机与几何共同作用的结果：

I=R(G,M,L,C)I=\mathcal R(G,M,L,C) I=R(G,M,L,C)

GGG 是几何，MMM 是材质，LLL 是光照，CCC 是相机，R\mathcal RR 表示渲染过程。若模型只学习最终 RGB，金属高光、阴影和环境反射很容易被烘焙进纹理。改变照明后，这些旧光照痕迹仍留在表面，无法得到物理一致的重光照结果。

TRELLIS.2 因此把目标设为 原生三维资产潜变量：编码器直接读取网格及其 PBR 属性，几何通道保存表面的局部连接信息，材质通道保存尽量与光照解耦的表面参数。二维图像只作为生成条件，潜变量真值直接来自资产本身。

任务概览

模型主要完成 image-to-3D。给定去除背景后的参考图像 III，它预测一个带 PBR 材质的三维资产：

A^=FΘ(I)=(M^,T^base,T^metal,T^rough,T^α)\hat{\mathcal A} =F_\Theta(I) =\left(\hat{\mathcal M}, \hat T_{\mathrm{base}}, \hat T_{\mathrm{metal}}, \hat T_{\mathrm{rough}}, \hat T_{\alpha}\right) A^=FΘ​(I)=(M^,T^base​,T^metal​,T^rough​,T^α​)

M^\hat{\mathcal M}M^ 是三角网格，其余项分别为基础色、金属度、粗糙度和透明度纹理。官方实现最终可以导出 GLB，使材质随网格一同进入常用实时渲染管线。

完整生成过程包含三个阶段：

  1. sparse structure generation 预测哪些粗网格单元与物体相交；
  2. geometry generation 在活跃位置预测形状潜变量，并由 shape SC-VAE 解码成高分辨率 O-Voxel 几何；
  3. material generation 读取输入图像与已经生成的几何，在相同活跃位置预测材质潜变量，再由 material SC-VAE 恢复 PBR 属性。

这一级联先确定“哪里有表面”，再确定“表面如何连接”，最后估计“表面怎样反光”。第三阶段也可以单独使用：已有网格先转换成 O-Voxel 几何，再根据参考图生成与形状对齐的 PBR 材质，因此同一系统兼顾 image-to-3D 与 shape-conditioned texturing。

O-Voxel

设规则三维网格分辨率为 N×N×NN\times N\times NN×N×N，只保留与表面相交的活跃体素。O-Voxel 写成：

F={(fishape,fimat,pi)}i=1L\mathcal F = \left\{ \left( \mathbf f_i^{\mathrm{shape}}, \mathbf f_i^{\mathrm{mat}}, \mathbf p_i \right) \right\}_{i=1}^{L} F={(fishape​,fimat​,pi​)}i=1L​

其中：

  • pi∈{0,1,…,N−1}3\mathbf p_i\in\{0,1,\ldots,N-1\}^3pi​∈{0,1,…,N−1}3 是第 iii 个活跃体素的整数坐标；
  • fishape\mathbf f_i^{\mathrm{shape}}fishape​ 保存局部表面几何与连接信息；
  • fimat\mathbf f_i^{\mathrm{mat}}fimat​ 保存与该处表面对齐的材质参数；
  • L≪N3L\ll N^3L≪N3 是活跃体素数量。

稀疏性来自三维表面只占据体积中的薄层。一个边长为 NNN 的致密网格包含 N3N^3N3 个单元，而普通物体的表面积随分辨率近似按 N2N^2N2 增长。忽略复杂拓扑和常数项，活跃体素数量更接近 O(N2)O(N^2)O(N2)。这使模型可以使用 5123512^35123、102431024^310243 甚至 153631536^315363 的名义分辨率，同时只在表面附近计算。

名称中的 omni 表示它同时覆盖多个资产要素：体素位置给出稀疏布局，shape feature 给出可直接组装的表面，material feature 给出表面属性。它也被称为 field-free，因为几何无需在全空间定义 SDF、Occupancy 或 Density Field。

双重网格

O-Voxel 的几何部分采用 Flexible Dual Grid。先将规则体素网格视为 primal grid，每个活跃 primal cell 对应一个 dual vertex。若一条 primal edge 被表面穿过，围绕该边的相邻体素便用 dual face 相连。primal grid 负责检测相交事件，dual grid 负责放置最终顶点和面，因此表面连接关系可由“哪些网格边被穿过”直接恢复。

每个活跃体素的几何特征包含三部分：

fishape=(vi,δi,γi)\mathbf f_i^{\mathrm{shape}} = \left( \mathbf v_i,\boldsymbol\delta_i,\gamma_i \right) fishape​=(vi​,δi​,γi​)

其中：

  • vi∈[0,1]3\mathbf v_i\in[0,1]^3vi​∈[0,1]3 是体素中的 dual vertex，采用当前体素内的归一化局部坐标；
  • δi∈{0,1}3\boldsymbol\delta_i\in\{0,1\}^3δi​∈{0,1}3 记录沿 XXX、YYY、ZZZ 三个预定义边的表面相交标志；
  • γi∈R>0\gamma_i\in\mathbb R_{>0}γi​∈R>0​ 是 splitting weight，控制四边形 dual face 怎样拆分为三角形。

这里只为每个体素保存三个相交标志，是因为其余边的状态可从相邻体素读取。δi\boldsymbol\delta_iδi​ 决定是否连接相邻 dual vertex，γi\gamma_iγi​ 决定三角剖分方式，vi\mathbf v_ivi​ 决定顶点的精确位置。三者共同给出网格的顶点、面和局部拓扑。

它在局部约束不足或 QEF 接近奇异时提供稳定解，也避免顶点过度偏离当前体素。三项合在一起可视为一个带正则的最小二乘问题：切平面决定表面趋势，边界直线保护开口轮廓，均值项在证据不足时提供温和先验。

Dual Contouring 通常通过检测 SDF 符号变化获得 Hermite data。TRELLIS.2 直接让输入三角形与网格边求交，交点与法向来自网格本身，因此整个转换不需要预先构造标量场。开口面两侧没有内外符号也不会妨碍求交。

还原网格

从 O-Voxel 还原网格时，算法先为每个活跃体素建立一个顶点 vi\mathbf v_ivi​，随后遍历三个预定义方向：

  1. 若 δia=1\delta_i^a=1δia​=1，说明方向 a∈{X,Y,Z}a\in\{X,Y,Z\}a∈{X,Y,Z} 对应的 primal edge 被表面穿过；
  2. 找到围绕这条边的四个活跃体素及其 dual vertex；
  3. 将四个顶点连接成四边形；
  4. 根据当前体素的 splitting weight γi\gamma_iγi​ 选择拆分方式，得到两个三角形。

表面可以在同一体素邻域中形成开口边，也可以出现非流形连接。算法不执行 flood fill，不要求最终网格水密，也没有反复优化顶点或等值面提取。网格到 O-Voxel 的转换在单核 CPU 上低于 10 秒，CUDA 加速的 O-Voxel 到纹理网格转换低于 100 毫秒；论文将这类过程称为 instant bidirectional conversion。

材质属性

每个活跃体素还保存一组 volumetric surface attribute：

fimat=(ci,mi,ri,αi)\mathbf f_i^{\mathrm{mat}} = \left( \mathbf c_i,m_i,r_i,\alpha_i \right) fimat​=(ci​,mi​,ri​,αi​)

ci∈[0,1]3\mathbf c_i\in[0,1]^3ci​∈[0,1]3 是 base color，mi∈[0,1]m_i\in[0,1]mi​∈[0,1] 是 metallic，ri∈[0,1]r_i\in[0,1]ri​∈[0,1] 是 roughness，αi∈[0,1]\alpha_i\in[0,1]αi​∈[0,1] 是 opacity。它们遵循常见 metallic-roughness PBR 工作流。

base color 表示尽量不含环境阴影的固有颜色；metallic 决定材质按导体还是电介质的方式反射；roughness 控制微表面法线的分散程度，从而影响高光宽窄；alpha 支持透明与半透明区域。四类属性均与活跃体素对齐，内部表面和遮挡表面也有自己的材质槽位。

PBR 参数描述的是渲染模型需要的表面属性，并不等同于输入照片中的最终 RGB。模型必须从高光、阴影和环境反射混合后的观测中反推出较稳定的材质参数，这比复制纹理颜色更困难。

从纹理网格转成 O-Voxel 时，算法将体素中心投影到相交三角形，在 UV 纹理上按合适 mip level 采样 PBR 参数，再根据点到表面的距离加权平均。若同一体素与两层极近表面相交，平均仍可能混合材质，这是体素分辨率带来的剩余误差。

反向转换有两种方式：

  • vertex mode 在每个网格顶点处对邻近体素属性做三线性插值，直接得到顶点材质；
  • map mode 先为网格生成 UV，再对每个 texel 对应的表面点查询三线性插值，生成 PBR 纹理图。

材质查询发生在几何表面上，生成出的 base color、metallic、roughness 和 alpha 共享同一坐标关系。它省去了多视图纹理融合常见的视图接缝、重影和 UV chart 间不一致问题。

稀疏 VAE

O-Voxel 适合精确表示资产，但 102431024^310243 表面仍可能包含数十万活跃体素，直接用 Transformer 生成代价过高。SC-VAE 将 O-Voxel 压缩到更稀疏、更低空间分辨率的 structured latent：

qϕ(z∣F),F^=pψ(z)q_\phi(\mathbf z\mid\mathcal F), \qquad \hat{\mathcal F}=p_\psi(\mathbf z) qϕ​(z∣F),F^=pψ​(z)

shape 与 material 使用两个分开的 SC-VAE。shape SC-VAE 学习几何，material SC-VAE 在 shape VAE 的细分结构条件下学习 PBR 属性。这种 形状—材质解耦让已有网格能够跳过几何生成，也允许两类信息使用不同损失和容量。

网络采用 U 形全稀疏卷积结构。编码器逐级下采样，解码器对称上采样，空间边长总计缩小 16 倍。若输入 O-Voxel 的名义分辨率为 102431024^310243，潜空间位于约 64364^3643 的稀疏网格中；只有存在表面的单元产生 token，平均约 9.6K 个。153631536^315363 输入对应约 96396^3963 潜空间，token 数仍远低于原始活跃体素。

论文选择稀疏卷积而非原始 TRELLIS 的 Transformer VAE，原因在于局部卷积的计算只与活跃邻域相关，结构也能自然跨分辨率复用。训练时在 5123512^35123 学到的 SC-VAE 可以直接应用到更高分辨率，无需为每个输出尺度重新训练一套编码器。

残差压缩

16 倍空间下采样意味着一个潜网格单元需要概括 163=409616^3=4096163=4096 个高分辨率位置。普通池化会把局部表面位置、边缘方向和拓扑状态混在一起。SC-VAE 引入 Sparse Residual Autoencoding，将空间信息暂时搬到通道维，再建立非参数残差捷径。

对一次 2×2\times2× 下采样，设细网格特征为 Ffine∈RCF_{\mathrm{fine}}\in\mathbb R^{C}Ffine​∈RC。一个父单元最多对应八个子单元，将它们按固定顺序堆叠：

Fcoarseraw=stack⁡(Fchild1,…,Fchild8)∈R8CF_{\mathrm{coarse}}^{\mathrm{raw}} = \operatorname{stack} \left( F_{\mathrm{child}_1},\ldots,F_{\mathrm{child}_8} \right) \in\mathbb R^{8C} Fcoarseraw​=stack(Fchild1​​,…,Fchild8​​)∈R8C

随后把通道分组平均，得到与目标通道数 C′C'C′ 一致的粗残差：

Fcoarse=avg_groups⁡(Fcoarseraw)∈RC′F_{\mathrm{coarse}} = \operatorname{avg\_groups} \left( F_{\mathrm{coarse}}^{\mathrm{raw}} \right) \in\mathbb R^{C'} Fcoarse​=avg_groups(Fcoarseraw​)∈RC′

不存在的子体素以零向量填充。stack 操作把“八个子位置的区别”转换成通道分组，平均值提供确定性的粗估计，神经网络只需学习丢失的高频残差。这样即使多次下采样，局部占用模式仍有一条无需训练的传递路径。

上采样执行对称操作。先把粗特征拆分到八个子位置，再按需要复制通道组：

Ffineraw=unstack⁡(Fcoarse)∈R8×(C′/8)F_{\mathrm{fine}}^{\mathrm{raw}} = \operatorname{unstack}(F_{\mathrm{coarse}}) \in\mathbb R^{8\times(C'/8)} Ffineraw​=unstack(Fcoarse​)∈R8×(C′/8)

Ffine=dup_groups⁡(Ffineraw)∈RCF_{\mathrm{fine}} = \operatorname{dup\_groups} \left( F_{\mathrm{fine}}^{\mathrm{raw}} \right) \in\mathbb R^{C} Ffine​=dup_groups(Ffineraw​)∈RC

unstack⁡\operatorname{unstack}unstack 将 C′C'C′ 个粗通道分成八组，分别送到八个子位置，因此每个子位置先得到 C′/8C'/8C′/8 个通道；dup_groups⁡\operatorname{dup\_groups}dup_groups 再在各组内复制通道，使每个子体素恢复到目标维度 CCC。这条捷径不含可学习参数，却为编码器和解码器提供了贯穿空间尺度的近似恒等路径；高压缩时，普通池化与反卷积很难独立恢复同等精细的局部布局。

解码器还在每级上采样前预测八个子体素是否活跃。被判定为空的分支会提前裁剪，不再执行后续稀疏卷积。early pruning 将计算集中到可能存在表面的区域，输出分辨率越高，节省越明显。

普通稀疏 ResBlock 中的两层卷积参数利用率偏低。论文保留一层 submanifold convolution 处理邻域，将第二层改成宽 point-wise MLP，结构类似 Transformer FFN。卷积负责空间混合，MLP 负责通道扩展和非线性变换，从而将昂贵的稀疏邻域访问限制在一层卷积内。

SC-VAE 分两阶段训练。第一阶段在 2563256^32563 低分辨率上稳定直接回归：

v^\hat{\mathbf v}v^ 是 dual vertex，δ^\hat{\boldsymbol\delta}δ^ 是相交标志，ρ^\hat{\boldsymbol\rho}ρ^​ 是 early-pruning 活跃掩码。材质用 L1L_1L1​ 回归，KL 项将潜变量规整到便于后续流模型学习的分布。

第二阶段把分辨率提高到 5123512^35123，加入渲染感知监督：

Ls2=Ls1+Lrender\mathcal L_{\mathrm{s2}} = \mathcal L_{\mathrm{s1}} +\mathcal L_{\mathrm{render}} Ls2​=Ls1​+Lrender​

模型分别渲染 silhouette mask、depth、normal 和 PBR 材质结果。一个通用感知距离写成：

dp(a,b)=∥a−b∥1+0.2 dSSIM(a,b)+0.2 dLPIPS(a,b)d_p(a,b) = \|a-b\|_1 +0.2\,d_{\mathrm{SSIM}}(a,b) +0.2\,d_{\mathrm{LPIPS}}(a,b) dp​(a,b)=∥a−b∥1​+0.2dSSIM​(a,b)+0.2dLPIPS​(a,b)

补充材料给出的两类渲染损失为：

Lrendershape=∥m^−m∥1+10∥d^−d∥1+dp(n^,n)\mathcal L_{\mathrm{render}}^{\mathrm{shape}} = \|\hat m-m\|_1 +10\|\hat d-d\|_1 +d_p(\hat n,n) Lrendershape​=∥m^−m∥1​+10∥d^−d∥1​+dp​(n^,n)

Lrendermat=dp(c^,c)+dp(mra^,mra)\mathcal L_{\mathrm{render}}^{\mathrm{mat}} = d_p(\hat c,c) +d_p(\widehat{\mathrm{mra}},\mathrm{mra}) Lrendermat​=dp​(c^,c)+dp​(mra,mra)

mmm、ddd、nnn 分别是 silhouette mask、depth 和 normal，ccc 是 base color，mra\mathrm{mra}mra 将 metallic、roughness 与 alpha 合并为一组属性。深度项的权重为 10，说明小幅几何偏移在这一阶段会受到较强惩罚。训练相机的近裁剪面会随机穿过物体，使内部结构也出现在监督图中；否则只从外部观察，解码器可能忽略完全封闭在物体内部的表面。

这两个阶段分别约束字段数值和最终成像。直接特征损失保证 O-Voxel 字段可还原，渲染感知损失进一步放大微小顶点偏移、法向不连续和材质模糊对图像的影响；随机穿过物体的裁剪面则让内部表面也能获得监督。

三段生成

在 SC-VAE 潜空间上，TRELLIS.2 训练三个 条件流模型。

第一阶段预测 sparse structure。输入图像先由 DINOv3-L 提取条件特征，结构 DiT 从噪声生成低分辨率占用布局。它决定物体的大体轮廓、各部件所在位置以及哪些空间块需要进入后续计算。

第二阶段预测 geometry latent。模型只在第一阶段给出的活跃位置上运行，生成 shape SC-VAE 的潜 token。shape decoder 再将其恢复为高分辨率 O-Voxel，包括 dual vertex、edge intersection flags、splitting weights 和活跃掩码。

第三阶段预测 material latent。material DiT 同时读取图像条件与已经生成的 geometry latent，在相同结构上预测 material SC-VAE token。解码器恢复 base color、metallic、roughness 和 alpha，最终与 O-Voxel 网格共同导出。

前两阶段形成几何主干，第三阶段原生地进行三维材质推理。多视图纹理方法通常先生成若干二维视图，再做 UV 投影、可见性选择和融合；这里的材质 token 直接位于三维稀疏结构中，可以为背面、内部面和遮挡区域建立一致属性。

三个 DiT 均采用约 30 个 Transformer block、1536 隐藏维、12 个 attention head 和 8192 维 MLP，单个模型约 1.3B 参数。总规模约 4B。高压缩 SC-VAE 已将序列缩短，生成器可以使用相对朴素的 vanilla-style DiT，无需原始 TRELLIS 的 token packing、稀疏卷积下采样和 U 形 skip connection。

流匹配

三个生成器都采用 rectified flow。设数据潜变量为 x0\mathbf x_0x0​，高斯噪声为 ϵ\boldsymbol\epsilonϵ，训练时沿直线路径插值：

x(t)=(1−t)x0+tϵ,t∈[0,1]\mathbf x(t) =(1-t)\mathbf x_0+t\boldsymbol\epsilon, \qquad t\in[0,1] x(t)=(1−t)x0​+tϵ,t∈[0,1]

这条路径的真实速度为：

dx(t)dt=ϵ−x0\frac{\mathrm d\mathbf x(t)}{\mathrm dt} = \boldsymbol\epsilon-\mathbf x_0 dtdx(t)​=ϵ−x0​

网络 vθ(x(t),t,c)v_\theta(\mathbf x(t),t,c)vθ​(x(t),t,c) 在图像条件 ccc 下预测速度，目标为：

LCFM=Et,x0,ϵ[∥vθ(x(t),t,c)−(ϵ−x0)∥22]\mathcal L_{\mathrm{CFM}} = \mathbb E_{t,\mathbf x_0,\boldsymbol\epsilon} \left[ \left\| v_\theta(\mathbf x(t),t,c) - (\boldsymbol\epsilon-\mathbf x_0) \right\|_2^2 \right] LCFM​=Et,x0​,ϵ​[∥vθ​(x(t),t,c)−(ϵ−x0​)∥22​]

线性插值的导数恒为 ϵ−x0\boldsymbol\epsilon-\mathbf x_0ϵ−x0​，因此网络可以直接回归速度。推理从噪声端 t=1t=1t=1 向数据端 t=0t=0t=0 数值积分；classifier-free guidance 通过组合有条件和无条件速度，加强输出与参考图像的一致性。

几何和材质模型采用 progressive training。先在 5123512^35123 O-Voxel、32332^3323 潜分辨率和 512×512512\times512512×512 图像条件上学习，再把 O-Voxel 提升到 102431024^310243、潜分辨率提升到 64364^3643，条件图像也提高到 1024×10241024\times10241024×1024。前一尺度学到的结构和外观先验可以迁移到后一尺度，避免直接从超长高分辨率序列开始训练。

级联推理

SC-VAE 具有跨分辨率泛化能力，TRELLIS.2 因而可以在测试时调整分辨率和计算量。若模型先生成 102431024^310243 O-Voxel，可将其最大池化成 96396^3963 稀疏布局，再重新运行 geometry stage，得到 153631536^315363 几何。训练阶段没有直接使用这一输出分辨率，解码器仍能依靠局部、全卷积结构完成放大。

同一策略也能用于质量精修。直接由第一阶段预测的 64364^3643 结构可能含有孤立活跃块或局部缺口。可以先生成一次 5123512^35123 O-Voxel，再将它下采样回较干净的 64364^3643 结构，随后重新运行高分辨率几何与材质阶段。额外计算会改善细节和结构稳定性。

级联会增加几何与材质阶段的计算量，几何分辨率越高，稀疏活跃体素和局部解码开销越大。它提供的是可调节的质量—成本路径，最高分辨率结果需要额外推理和后处理，不能与单次中等分辨率生成按同一成本比较。

数据训练

SC-VAE 数据沿用 TRELLIS-500K 中的 ObjaverseXL Sketchfab、ObjaverseXL GitHub、ABO 和 HSSD 子集，并排除缺少合适 PBR 材质的 3D-FUTURE。约 473K 个资产用于 shape SC-VAE；只有采用标准 metallic-roughness PBR 工作流且材质可解析的资产进入 material SC-VAE，约 355K 个。

生成模型进一步加入 TexVerse 扩展 PBR 多样性，并按美学分数过滤低质量资产，最终使用约 800K 规模的三维资产集合。论文渲染每个资产的 16 个条件视图，随机改变 10∘10^\circ10∘ 到 70∘70^\circ70∘ 的视场角，并随机化环境光源位置、强度和数量。视场角增强减轻未知相机内参带来的偏差，光照增强迫使模型从成像结果中分离材质和照明。

三个生成 DiT 各约 1.3B 参数，在 32 张 H100 上以总 batch size 256 训练。SC-VAE 在 16 张 H100 上训练。官方实现还提供 FlexGEMM：它用 Triton 将特征 gather 与 GEMM 融合，并通过 Gray-code 排序改善相似稀疏邻域的内存访问。这是稀疏算子的工程优化，不改变 O-Voxel 或生成目标。

实验结果

102431024^310243 模型平均只用约 9.6K token，all-surface F-score 达到 0.971，原始 TRELLIS 在相近 token 数下约为 0.074；差距主要来自 O-Voxel 对顶点、边相交和面连接的显式保存。Image-to-3D 的 CLIP 相似度也由 0.876 提高到约 0.894。

移除稀疏残差捷径后，16 倍压缩时的 Mesh Distance 增加约 69%69\%69%，表明高分辨率细节不能只依赖最深层瓶颈恢复。独立材质阶段还能改善 PBR 属性和跨视角一致性。

特点与局限

TRELLIS.2 以 O-Voxel 将复杂拓扑、几何和 metallic-roughness PBR 材质组织到统一的稀疏体素索引中，Flexible Dual Grid 因而能够绕开 SDF 符号场对开口面和非流形结构的限制。形状与材质 SC-VAE 通过稀疏残差压缩将 102431024^310243 资产缩减到平均约 9.6K token，再由结构、几何和材质三级生成模型逐步恢复；同一体系还可扩展到 5123512^35123、102431024^310243 与 153631536^315363，并支持独立的网格 PBR 材质生成。

O-Voxel 仍受体素分辨率约束，细线、薄层和相邻表面可能被合并，稀疏激活遗漏也会形成孔洞；field-free 表示可以容纳开放或非流形结构，却不自动保证水密、流形和可打印。三级生成会传递上游结构错误，当前材质通道和单物体建模范围也有限；约 4B 参数、CUDA 扩展依赖及后续网格简化、UV 展开和纹理烘焙带来较高生产门槛，而不可见区域的真实性仍取决于训练数据先验。
