Gen3R: 3D Scene Generation Meets Feed-Forward Reconstruction

发表于2026-08-10|更新于2026-08-17|Note3DVision 论文阅读
|浏览量:

场景级三维生成一直面临一个数据与表示的矛盾。二维图像和视频数据规模大，扩散模型已经学会高质量外观与丰富语义，但单纯的视频生成很难保证严格多视几何。具有深度、相机和完整三维真值的大规模场景数据少得多，从头训练一个几何 VAE 容易将表面细节、全局结构和外观质量同时压坏。

另一边，VGGT 这类重建基础模型已经用大量几何监督学得紧凑、信息丰富的中间 token。它们能从多张无标定图像中联合估计相机、深度和 point map，这意味着这些 token 已经是一种高度压缩的多任务几何表示。如果能将它们转换到视频扩散模型熟悉的潜空间，就可以同时利用重建先验和视频生成先验。

Gen3R 沿着这个思路设计。它先为 VGGT 训练一个 geometry adapter，将几何 token 编码为与 Wan 视频 VAE 同形状、统计尺度相近的 geometry latent；随后对 Wan2.1 的视频 DiT 进行微调，让它在同一扩散过程中联合生成 appearance latent 和 geometry latent。前者解码为 RGB 视频，后者解码为相机、深度与全局点云。

任务变迁

设条件图像序列为 IcondI_{\mathrm{cond}}Icond​，可用视图由二值掩码 MMM 指示，文本提示为 yyy，可选相机条件为 TcondT_{\mathrm{cond}}Tcond​。Gen3R 学习一个条件分布：

pΘ(I,P,D,T∣Icond,M,y,Tcond),p_\Theta \left( I,P,D,T \mid I_{\mathrm{cond}},M,y,T_{\mathrm{cond}} \right), pΘ​(I,P,D,T∣Icond​,M,y,Tcond​),

其中 III 是完整 RGB 序列，PPP 是全局 point map 序列，DDD 是每视图深度，TTT 是相机参数。同一个模型覆盖三种条件设置：

  1. 只给第一帧，从单图生成一条视频及其对应三维。
  2. 给第一帧与最后一帧，生成中间视角及整体几何。
  3. 给出全部帧，以扩散先验执行多视图前馈重建。

前两种设置中，模型需要生成未观测的外观和几何；第三种设置中，每帧 RGB 都已经提供，任务更接近重建与几何去噪。训练时这三种条件等概率采样，所以模型不需要为单图、双图和全视图分别保存 checkpoint。

这里的 feed-forward reconstruction 表示模型参数在测试时保持不变，不再为新场景单独优化 NeRF 或 3DGS。一次结果仍需经过多步扩散去噪，因此它和 VGGT 的单次确定性前向具有不同的计算含义。

几何 VAE

VGGT 可拆成编码器 EVE_VEV​ 和多个几何解码头 DVD_VDV​。对 NNN 张图像 I∈RN×H×W×3I\in\mathbb R^{N\times H\times W\times3}I∈RN×H×W×3，主干从第 4、11、17、23 个 Transformer block 取出四层中间 token：

EV:I⟶V∈RN×L×hv×wv×C,L=4,C=2048.E_V:I\longrightarrow V\in\mathbb R^{N\times L\times h_v\times w_v\times C}, \qquad L=4, C=2048. EV​:I⟶V∈RN×L×hv​×wv​×C,L=4,C=2048.

这些多层 token 进入已训练的 DPT 头：

DV:V⟶(P,D,T).D_V:V\longrightarrow(P,D,T). DV​:V⟶(P,D,T).

P∈RN×H×W×3P\in\mathbb R^{N\times H\times W\times3}P∈RN×H×W×3 是 point map，D∈RN×H×WD\in\mathbb R^{N\times H\times W}D∈RN×H×W 是深度，T∈RN×9T\in\mathbb R^{N\times9}T∈RN×9 是相机参数。中间 token 同时支撑这些输出，因而比单独压缩一份深度图或显式点云保留更完整的几何先验。

Gen3R 在 EVE_VEV​ 与 DVD_VDV​ 之间插入一对 adapter：

Eadp:V⟶G∈Rn×h×w×c,E_{\mathrm{adp}}:V\longrightarrow G\in\mathbb R^{n\times h\times w\times c}, Eadp​:V⟶G∈Rn×h×w×c,

Dadp:G⟶V^,DV(V^)=(P^,D^,T^).D_{\mathrm{adp}}:G\longrightarrow\hat V, \qquad D_V(\hat V)=(\hat P,\hat D,\hat T). Dadp​:G⟶V^,DV​(V^)=(P^,D^,T^).

GGG 是 geometry latent，其时间长度、空间分辨率和通道数与 Wan 视频 VAE 的 appearance latent 完全一致。系统因此可看成一个 非对称几何 VAE：编码端由 VGGT 和小型 adapter 组成，解码端则复用 adapter 与冻结的 VGGT 输出头。所谓“非对称”，指编码和解码没有镜像结构；真正需要保持的是信息接口，即 GGG 必须足以恢复多层 token 及其相机、深度和 point map 输出。

普通图像 VAE 关心“潜变量能否还原像素”；这里更关心“潜变量能否还原几何模型的内部判断”。监督中同时包含 token 与任务头输出，正是为了避免平均特征误差很小、关键几何信息却已经丢失。

中间 Token

主文为简化记号省略了 camera token。官方补充材料和已发布代码使用了更完整的形式：每帧 camera token 被广播到 hv×wvh_v\times w_vhv​×wv​ 网格，与四层图像 token 合并，所以 adapter 实际处理 L=5L=5L=5 份特征。

在 560×560560\times560560×560 输入下，hv=wv=40h_v=w_v=40hv​=wv​=40。五份、2048 维 token 先拼接到通道维：

V:N×5×40×40×2048⟶N×40×40×10240.V: N\times5\times40\times40\times2048 \longrightarrow N\times40\times40\times10240. V:N×5×40×40×2048⟶N×40×40×10240.

官方实现用 nearest-exact interpolation 将空间网格重采样为 70×7070\times7070×70，经二维卷积投影到 1024 维，再送入由 Wan causal VAE 改造而来的时空压缩器。adapter 的中间通道配置为 [512,256,128,128][512,256,128,128][512,256,128,128]，最终输出 c=16c=16c=16 个通道。

将 camera token 与多层 image token 一起压缩很重要。几何 latent 需要同时携带局部表面和全局相机系；如果仅压缩最后一层稠密 token，相机信息必须经过更窄的间接通道恢复。多层 token 也类似 DPT 中的多尺度 skip feature，浅层偏局部，深层偏全局。

几何适配

geometry adapter 的基本目标是在强压缩后保留 VGGT 的几何能力。设 V^=Dadp(G)\hat V=D_{\mathrm{adp}}(G)V^=Dadp​(G)，重建损失为：

Lrec=  E∥V^−V∥22+E∥T^−T∥1+E∥D^−D∥22+E∥P^−P∥22.\begin{aligned} \mathcal L_{\mathrm{rec}} =&\;\mathbb E\left\|\hat V-V\right\|_2^2 +\mathbb E\left\|\hat T-T\right\|_1\\ &+\mathbb E\left\|\hat D-D\right\|_2^2 +\mathbb E\left\|\hat P-P\right\|_2^2. \end{aligned} Lrec​=​E​V^−V​22​+E​T^−T​1​+E​D^−D​22​+E​P^−P​22​.​

这里的 T,D,PT,D,PT,D,P 均由原始、冻结的 VGGT 头从 VVV 解码，T^,D^,P^\hat T,\hat D,\hat PT^,D^,P^ 由同一组头从 V^\hat VV^ 解码。训练 adapter 不需要对每个数据集统一建立显式网格、深度真值或稠密 point-map 真值，VGGT 自己提供了表征级和输出级监督。

主文用上式概括训练，已公开实现还加入了 image token / camera token 的 cosine similarity，并对不同输出损失设置了实际权重。代码中的几何项近似写成：

Limpl=Limgtok+Lcamtok+10Lcam+2Ldepth+Lpoint+λcos⁡Lcos⁡.\mathcal L_{\mathrm{impl}} =\mathcal L_{\mathrm{imgtok}} +\mathcal L_{\mathrm{camtok}} +10\mathcal L_{\mathrm{cam}} +2\mathcal L_{\mathrm{depth}} +\mathcal L_{\mathrm{point}} +\lambda_{\cos}\mathcal L_{\cos}. 这些辅助项在实现中保证 10240 维多层特征经过 16 通道潜变量后，不会只为降低平均 token 误差而丢掉对相机或边界尤其重要的少量方向。

潜变量对齐

仅使用 Lrec\mathcal L_{\mathrm{rec}}Lrec​ 可以让 GGG 保留几何，却没有限制其均值、方差和各维相关性。预训练视频 DiT 已经适应 Wan VAE 的 appearance latent；若 geometry latent 的数值尺度完全不同，同一噪声强度在两个半区便代表不同的信噪比，优化时也会产生明显的梯度失衡。Gen3R 因此加入 分布对齐，让几何后验靠近外观后验所处的统计区域。

对同一段训练序列，设 Wan RGB VAE 的后验为 qAq_AqA​，geometry adapter 的后验为 qGq_GqG​。Gen3R 最小化：

LKL=DKL ⁣(qG ∥ qA),\mathcal L_{\mathrm{KL}} =D_{\mathrm{KL}}\!\left(q_G\,\|\,q_A\right), LKL​=DKL​(qG​∥qA​),

完整 adapter 损失为：

Ladp=λ1Lrec+λ2LKL.\mathcal L_{\mathrm{adp}} =\lambda_1\mathcal L_{\mathrm{rec}} +\lambda_2\mathcal L_{\mathrm{KL}}. Ladp​=λ1​Lrec​+λ2​LKL​.

若两侧后验都按对角高斯参数化，KL 会同时比较每一维的均值和方差；均值相差过大或方差比例失衡都会受到惩罚。已公开代码直接计算 geometry posterior 相对 Wan posterior 的 KL，并用自适应权重平衡重建项与 KL 项。该约束只要求两类潜变量具有相容的统计尺度，并不要求对应位置取相同数值：左半仍编码颜色与纹理，右半仍编码相机和表面结构。

联合潜变量

训好 adapter 后，对一段图像序列 III，可同时得到：

A=EW(I)∈Rn×h×w×c,G=Eadp(EV(I))∈Rn×h×w×c,A=E_W(I)\in\mathbb R^{n\times h\times w\times c}, \qquad G=E_{\mathrm{adp}}(E_V(I)) \in\mathbb R^{n\times h\times w\times c}, A=EW​(I)∈Rn×h×w×c,G=Eadp​(EV​(I))∈Rn×h×w×c,

其中 EWE_WEW​ 是冻结的 Wan RGB VAE。Gen3R 采用 宽度拼接，沿空间维把两类潜变量并排：

Z=[A;G]∈Rn×h×2w×c.Z=[A;G] \in\mathbb R^{n\times h\times2w\times c}. Z=[A;G]∈Rn×h×2w×c.

官方实现中 c=16c=16c=16、h=w=70h=w=70h=w=70，因此 ZZZ 的形状为 n×70×140×16n\times70\times140\times16n×70×140×16。这样可以保留 Wan DiT 原有的 16 通道噪声输入投影，避免重新初始化最靠近输入的大量权重；代价是序列长度近似翻倍，外观与几何之间的交互交给全局自注意力完成。

直接拼成一个宽度加倍的“长图”有一个问题：左半的像素 (u,v)(u,v)(u,v) 与右半对应几何会得到不同位置编码。补充材料中的 DiT 专门修改 RoPE，使左右两半的对应像素共享同一组旋转位置编码。这相当于要求模型接受如下约定：

pos⁡(At,u,v)=pos⁡(Gt,u,v),\operatorname{pos}(A_{t,u,v}) =\operatorname{pos}(G_{t,u,v}), pos(At,u,v​)=pos(Gt,u,v​),

即左右两半对应位置的 token 属于同一时刻、同一图像位置的不同模态，从而更容易建立 RGB 边界与深度边界、外观运动与相机运动之间的对应。

条件构造

输入条件只有 RGB 图像，没有事先给定的 geometry latent。可见条件帧经 Wan VAE 编码为 AcondA_{\mathrm{cond}}Acond​，缺失帧的图像设为零。图像掩码下采样到潜分辨率，得到四通道 MaM_aMa​。几何分支的条件潜变量和掩码均设为零：

Gcond=0,Mg=0.G_{\mathrm{cond}}=0, \qquad M_g=0. Gcond​=0,Mg​=0.

先在通道维将潜变量与掩码拼接，再在宽度维拼接外观与几何：

Zcond=[Acond⊕Ma  ;  Gcond⊕Mg]∈Rn×h×2w×(c+4).Z_{\mathrm{cond}} =\left[ A_{\mathrm{cond}}\oplus M_a \;;\; G_{\mathrm{cond}}\oplus M_g \right] \in\mathbb R^{n\times h\times2w\times(c+4)}. Zcond​=[Acond​⊕Ma​;Gcond​⊕Mg​]∈Rn×h×2w×(c+4).

⊕\oplus⊕ 表示通道拼接，[ ; ][\,;\,][;] 表示宽度拼接。对 c=16c=16c=16 来说，条件有 20 个通道。它再与当前加噪潜变量 ZtZ_tZt​ 在通道上合并，DiT 实际接收 36 通道：

Zin=Zt⊕Zcond.Z_{\mathrm{in}}=Z_t\oplus Z_{\mathrm{cond}}. Zin​=Zt​⊕Zcond​.

已发布代码的掩码只在左半 appearance 区域标记已知帧，右半 geometry 区域始终为零。这种 零几何条件 保证推理时只需提供 RGB；VGGT 用于建立 geometry latent 的训练目标与最终解码，扩散模型则要从图像条件中自行推断整个 GGG。如果把 VGGT 预测直接放进右半区，任务会退化为修补已有几何，也无法训练单图未见区域的生成能力。

可选相机条件使用像素级 Plücker 射线，官方实现中为 24 通道时空特征。当用户不提供相机时，该条件可以被完全删除。官方推理实现还提供 zoom in、zoom out、arc left/right 等基本轨迹；在这种情况下，会先用 VGGT 估计初始内参和场景尺度，再构造轨迹。

扩散训练

设干净联合潜变量为 Z0=[A;G]Z_0=[A;G]Z0​=[A;G]，在时刻 ttt 添加高斯噪声：

Zt=αtZ0+σtϵ,ϵ∼N(0,I).Z_t=\alpha_tZ_0+\sigma_t\epsilon, \qquad \epsilon\sim\mathcal N(0,I). Zt​=αt​Z0​+σt​ϵ,ϵ∼N(0,I).

微调后的 Wan DiT GΘ\mathcal G_\ThetaGΘ​ 根据当前潜变量、时间步、文本、图像掩码和可选相机执行联合去噪：

GΘ:(Zt,t,y,Icond,M,Tcond)⟶Z^t−1.\mathcal G_\Theta: (Z_t,t,y,I_{\mathrm{cond}},M,T_{\mathrm{cond}}) \longrightarrow \hat Z_{t-1}. GΘ​:(Zt​,t,y,Icond​,M,Tcond​)⟶Z^t−1​.

重点在于两个模态位于同一个 联合去噪序列 中。某个去噪步修正椅子边缘的 RGB，注意力可以同时调整右半对应的深度边界；几何分支对相机运动和多视一致性的约束，也可以抑制外观分支的局部漂移。这种交互贯穿全部 DiT 层和时间步，视频误差尚未固化为最终像素时，几何分支便有机会参与修正。

训练时，三种图像条件各以 1/31/31/3 概率选择。文本以 20% 概率丢弃，用于 classifier-free guidance；相机条件以 50% 概率丢弃，使模型同时学会受控相机和自由相机生成。论文的重建比较统一删除相机条件，防止已知真值位姿为方法额外提供优势。

双路解码

去噪完成后，将 Z^0\hat Z_0Z^0​ 沿宽度拆回 A^\hat AA^ 与 G^\hat GG^。两条分支分别解码：

I^=DW(A^),\hat I=D_W(\hat A), I^=DW​(A^),

V^=Dadp(G^),(P^,D^,T^)=DV(V^).\hat V=D_{\mathrm{adp}}(\hat G), \qquad (\hat P,\hat D,\hat T)=D_V(\hat V). V^=Dadp​(G^),(P^,D^,T^)=DV​(V^).

DWD_WDW​ 是 Wan RGB VAE decoder，负责恢复高频外观；Dadp+DVD_{\mathrm{adp}}+D_VDadp​+DV​ 则恢复相机与稠密几何。geometry token 为结构判断保留了足够信息，却没有被要求无损编码颜色和纹理，因此很难替代专门为图像重建训练的 RGB VAE。双路解码由此避免让同一瓶颈同时承担两种相互竞争的压缩目标。

论文最终使用生成深度与相机反投影得到三维，这与 VGGT 的实践一致。对像素齐次坐标 u~=(u,v,1)⊤\tilde u=(u,v,1)^\topu~=(u,v,1)⊤，若外参为世界到相机变换，则：

X^i(u,v)=R^i⊤(D^i(u,v)K^i−1u~−t^i).\hat X_i(u,v) =\hat R_i^\top \left( \hat D_i(u,v)\hat K_i^{-1}\tilde u-\hat t_i \right). X^i​(u,v)=R^i⊤​(D^i​(u,v)K^i−1​u~−t^i​).

各帧 X^i\hat X_iX^i​ 在生成相机系中对齐，可合并为全局点云。重建指标在计算前使用 Umeyama 相似变换对齐预测与真值，这表明输出首先追求内部一致的相对几何，实验不要求直接恢复米制尺度。

训练数据

Gen3R 使用十个带相机标定的多视图数据集：RealEstate10K、DL3DV-10K、ACID、TartanAir、KITTI-360、Waymo、Co3Dv2、MVImgNet、Virtual KITTI 2 和 WildRGB-D。合计超过 30 万个多视一致场景，覆盖物体、室内、室外、自动驾驶和合成数据。每个场景的文本提示由多模态大模型生成。

数据集需要相机来构造受控轨迹，但 geometry adapter 的监督主要来自冻结 VGGT，所以不需要每个场景都提供统一形式的显式 3D 真值。这一点是数据可扩展性的关键：任意有足够多视一致 RGB 和相机的数据，都可先通过 VGGT 转换为统一 geometry token 目标。

训练分两阶段。第一阶段仅训练 geometry adapter：

  • 先使用 25 帧、560×560560\times560560×560 分辨率训练 1.5 万步，每卡 batch 2、梯度累积 4，使用 24 张 H20 96GB，有效 batch 192；
  • 再使用 49 帧微调 6000 步，每卡 batch 1、梯度累积 8，硬件不变。

第二阶段微调预训练 image-camera conditioned Wan2.1 DiT。每次采样连续 49 帧，统一缩放和中心裁剪到 560×560560\times560560×560，在 24 张 H20 上训练 8000 步，batch size 记为 4。这一资源需求明显高于常规 VGGT 推理，但它将重建模型与视频生成模型的预训练投入尽量复用了起来。

实验结果

Gen3R 在外观生成和三维补全上都有竞争力。单图 Co3Dv2 的点云 Chamfer Distance 约为 1.10，优于 WVD 的约 1.61；使用全部观测帧且不给真值相机时，重建精度与 VGGT 接近，生成式补全有时会牺牲已观测表面的局部精度。

串联的“先生成 RGB、再用 VGGT 重建”会把外观漂移传入深度和位姿。去掉 LKL\mathcal L_{\mathrm{KL}}LKL​ 后，RealEstate10K 单图 PSNR 从约 20.5 dB 降至 16.3 dB，说明联合去噪需要统计尺度相容的几何与外观潜变量。

特点与局限

Gen3R 将 VGGT 改造成非对称 geometry VAE，把多个层级的图像与相机 token 压缩为可解码深度、相机和 point map 的 16 通道几何潜变量，再通过 KL 对齐、共享 RoPE 和联合注意力将其与 Wan 的外观潜变量共同去噪。该接口让同一模型覆盖单图生成、首尾帧生成和全帧重建，使几何约束提升视频的多视一致性，同时借助生成先验补全未见区域并抑制部分重建噪声。

扩散采样需要多步去噪，推理速度、随机性和训练资源开销都明显高于确定性前馈重建；输出也主要是 RGB、深度、相机与点云，若要获得可在任意视角实时渲染且具有拓扑和材质的 3D 资产，仍需额外表示与后处理。几何监督依赖 VGGT，因此会继承其尺度、反光、透明、弱纹理和动态场景问题，Umeyama 对齐后的指标也不能证明绝对米制精度；对于少见结构、细薄边界和大幅非刚体运动，生成先验还可能产生平滑或不一致的几何。
