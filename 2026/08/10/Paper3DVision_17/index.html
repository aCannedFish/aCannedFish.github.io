CUT3R: Continuous 3D Perception Model with Persistent State

发表于2026-08-10|更新于2026-08-17|Note3DVision 论文阅读
|浏览量:

DUSt3R 一类方法把图像对直接映射为 point map，再通过全局对齐把多个局部坐标系拼成完整场景。这条路线明显缩短了传统 SfM/MVS 的处理链，但图像数量增加以后，图像对构造、重复特征计算和全局优化仍会带来较高开销。另一类多视图 Transformer 会让全部视图同时交换信息，适合离线重建，却很难直接用于持续到来的相机视频流。

CUT3R 研究的是连续三维感知。模型每次只接收当前图像，并维护一组固定长度的 持久状态。当前观测被写入状态，已经积累的场景信息又会参与当前帧解码，因此相机、几何和历史上下文可以在一次递归更新中共同求解。只要保留上一时刻的状态，模型便能持续处理视频或无标定照片序列，无需保存所有历史图像，也不依赖图像对图优化。

它的核心输出包括当前相机坐标系中的局部 point map、第一帧坐标系中的全局 point map、相机位姿及对应置信度。持久状态还可以在给定虚拟相机射线的条件下查询未直接观测的区域，使同一套模型兼具在线重建、定位和一定程度的新视角几何推断能力。

任务定义

设输入图像流为：

I=(I1,I2,…,IT),It∈RHt×Wt×3\mathcal I=(I_1,I_2,\ldots,I_T), \qquad I_t\in\mathbb R^{H_t\times W_t\times3} I=(I1​,I2​,…,IT​),It​∈RHt​×Wt​×3

模型在第 ttt 步接收图像 ItI_tIt​ 和上一步状态 St−1S_{t-1}St−1​，执行：

(St,Ot)=fθ(St−1,It)(S_t,O_t)=f_\theta(S_{t-1},I_t) (St​,Ot​)=fθ​(St−1​,It​)

其中 St∈RM×dS_t\in\mathbb R^{M\times d}St​∈RM×d 是持续更新的场景状态，长度 MMM 与已经处理的图像数量无关；OtO_tOt​ 是当前帧的几何输出：

Ot={X^tself,C^tself,X^tworld,C^tworld,P^t}O_t= \left\{ \hat X_t^{\mathrm{self}}, \hat C_t^{\mathrm{self}}, \hat X_t^{\mathrm{world}}, \hat C_t^{\mathrm{world}}, \hat P_t \right\} Ot​={X^tself​,C^tself​,X^tworld​,C^tworld​,P^t​}

X^tself∈RHt×Wt×3\hat X_t^{\mathrm{self}}\in\mathbb R^{H_t\times W_t\times3}X^tself​∈RHt​×Wt​×3 是当前相机坐标系中的 point map，X^tworld\hat X_t^{\mathrm{world}}X^tworld​ 是统一世界坐标系中的 point map，两个置信度图分别记为 C^tself\hat C_t^{\mathrm{self}}C^tself​ 和 C^tworld\hat C_t^{\mathrm{world}}C^tworld​。P^t\hat P_tP^t​ 表示当前相机到世界坐标系的六自由度位姿。

Point map 与普通深度图有一项重要区别。深度图的每个像素只保存沿光轴或射线方向的距离，而 point map 的每个像素直接保存三维坐标：

Xt(u,v)=[xt(u,v)yt(u,v)zt(u,v)] ⁣⊤X_t(u,v)= \begin{bmatrix} x_t(u,v)&y_t(u,v)&z_t(u,v) \end{bmatrix}^{\!\top} Xt​(u,v)=[xt​(u,v)​yt​(u,v)​zt​(u,v)​]⊤

因此，局部 point map 已经把深度和像素射线方向合成到三维坐标中；全局 point map 又进一步吸收相机外参。模型可以从局部图估计单帧形状，也可以直接融合全局图形成场景点云。

深度值只有结合内参才能反投影到三维；point map 已经完成这一步。代价是网络必须同时学会射线几何、尺度和坐标系约定，单个像素的输出维度也由 1 增至 3。

持久状态

初始状态 S0S_0S0​ 是一组可学习 token。论文最终模型使用 M=768M=768M=768 个状态 token，每个 token 的维度为 768。第一帧到来后，状态开始吸收场景的外观、几何与相机关系；后续图像继续修改同一组 token。无论序列包含 4 帧还是数千帧，状态张量的形状都保持不变。

这种表示与显式点云缓存有明显差异。点云会为每个观测点保留三维坐标，存储量随场景和帧数增长；CUT3R 的状态是一种学习得到的 有损场景摘要，网络自行决定哪些信息需要保留、合并或覆盖。它可以记录反复出现的结构，也可以用新观测修正旧估计，但状态中的单个 token 没有预先规定的几何含义，通常不能直接解释为某个三维点或某个相机。

固定状态带来线性的流式接口。若每帧产生 KKK 个图像 token，每次更新主要发生在当前 KKK 个 token 与固定 MMM 个状态 token 之间。忽略帧内编码开销后，处理 TTT 帧的总开销近似随 TTT 线性增长：

Cost⁡(T)≈T⋅O(KM+K2+M2)\operatorname{Cost}(T) \approx T\cdot O(KM+K^2+M^2) Cost(T)≈T⋅O(KM+K2+M2)

这里的 MMM 不随 TTT 增长。相比之下，将全部 TKTKTK 个 token 放入一次全局自注意力通常包含 O(T2K2)O(T^2K^2)O(T2K2) 项。不过，固定容量也意味着长序列中的所有信息都要竞争同一组 token，场景继续扩大时可能出现遗忘、混淆和漂移。

固定状态只保证跨时刻记忆的形状固定。官方实现可以先并行编码整段输入以提高吞吐量，此时图像特征和中间激活仍随帧数增长；若应用要求恒定历史显存，需要逐帧或分块编码，并及时释放已经写入状态的特征。

双向解码

当前图像先由共享的 ViT 编码器独立处理：

Ft=EI(It),Ft∈RK×dF_t=E_I(I_t), \qquad F_t\in\mathbb R^{K\times d} Ft​=EI​(It​),Ft​∈RK×d

编码器采用从 DUSt3R 初始化的 ViT-L，用于提取单帧视觉特征。模型随后在图像分支前加入一个可学习的 pose token zzz，并把 [z,Ft][z,F_t][z,Ft​] 与状态 St−1S_{t-1}St−1​ 送入两条相互连接的 Transformer 解码流：

[zt′,Ft′],St=D([z,Ft],St−1)[z'_t,F'_t],S_t =D\bigl([z,F_t],S_{t-1}\bigr) [zt′​,Ft′​],St​=D([z,Ft​],St−1​)

两条解码流在每一层都交换信息，可以概括为：

Ut(l+1)=ΦI(l) ⁣(Ut(l),St(l)),St(l+1)=ΦS(l) ⁣(St(l),Ut(l)),\begin{aligned} U_t^{(l+1)} &=\Phi_I^{(l)}\!\left(U_t^{(l)},S_t^{(l)}\right),\\ S_t^{(l+1)} &=\Phi_S^{(l)}\!\left(S_t^{(l)},U_t^{(l)}\right), \end{aligned} Ut(l+1)​St(l+1)​​=ΦI(l)​(Ut(l)​,St(l)​),=ΦS(l)​(St(l)​,Ut(l)​),​

其中 Ut(l)U_t^{(l)}Ut(l)​ 表示第 lll 层的图像与 pose token。图像分支通过交叉注意力读取历史状态，状态分支则通过另一组交叉注意力写入当前观测。这种 同步读写 可以理解为带视觉输入的循环单元：St−1S_{t-1}St−1​ 提供过去信息，UtU_tUt​ 提供新证据，而多层交互逐步决定当前输出和下一状态。两项操作发生在同一次解码中：

  • 状态更新把当前图像的新几何和相机关系写入 StS_tSt​；
  • 状态读取让当前图像特征利用过去帧提供的遮挡后结构、尺度和多视图对应关系。

如果只写入状态而不回读，当前帧仍接近单目预测；如果只读取而不更新，模型无法持续吸收新区域。CUT3R 将读写绑定在逐层解码过程中，使当前帧输出和下一时刻状态共同接受监督。

图像与状态解码器采用 ViT-B 规模。稠密三维输出由 DPT 风格的多尺度头恢复到像素分辨率，pose token 则交给轻量 MLP 预测位姿。整个递归单元共享参数，因此模型能够把训练时学到的更新规则重复应用到任意长度序列。

三类输出

解码后的图像特征同时连接两个几何头：

(X^tself,C^tself)=Hself(Ft′)(\hat X_t^{\mathrm{self}},\hat C_t^{\mathrm{self}}) =H_{\mathrm{self}}(F'_t) (X^tself​,C^tself​)=Hself​(Ft′​)

(X^tworld,C^tworld)=Hworld(Ft′,zt′)(\hat X_t^{\mathrm{world}},\hat C_t^{\mathrm{world}}) =H_{\mathrm{world}}(F'_t,z'_t) (X^tworld​,C^tworld​)=Hworld​(Ft′​,zt′​)

局部 point map 的坐标原点位于当前相机，主要描述像素射线对应的局部三维形状。它不需要同时解决全局刚体变换，通常能够保留更稳定的细节。全局 point map 直接把每个像素回归到第一帧相机坐标系，可以与其他帧的全局结果直接比较或融合。

pose token 经过位姿头得到：

P^t=Hpose(zt′)=(q^t,τ^t)\hat P_t=H_{\mathrm{pose}}(z'_t) =(\hat q_t,\hat \tau_t) P^t​=Hpose​(zt′​)=(q^​t​,τ^t​)

q^t\hat q_tq^​t​ 和 τ^t\hat \tau_tτ^t​ 分别表示旋转四元数与平移。若采用当前相机到世界坐标系的约定，理想情况下同一像素的两类 point map 满足：

X^tworld(u)≈R^tX^tself(u)+τ^t\hat X_t^{\mathrm{world}}(u) \approx \hat R_t\hat X_t^{\mathrm{self}}(u)+\hat \tau_t X^tworld​(u)≈R^t​X^tself​(u)+τ^t​

这三个输出存在冗余，但冗余具有实际用途。局部图提供相机无关的形状线索，全局图便于直接融合，位姿则提供紧凑的相机轨迹。它们共享主干，却由不同监督约束，相当于从三个角度检查同一几何关系；训练数据只提供部分标注时，模型也能使用已有监督。

坐标尺度

CUT3R 把第一张图像的相机坐标系作为世界坐标系，因此：

P1=I,X1self=X1worldP_1=I, \qquad X_1^{\mathrm{self}}=X_1^{\mathrm{world}} P1​=I,X1self​=X1world​

这个选择消除了任意全局旋转和平移，但第一帧仍会影响后续坐标表示。改变输入顺序后，世界原点、视角以及状态更新路径都会变化。论文所说的无序照片集合，含义是模型不要求真实时间顺序，也能把一组照片依次读入；模型本身没有严格的置换不变性。

尺度监督取决于数据来源。带度量深度与位姿的数据可以要求模型输出米制几何；只有 up-to-scale 标注的数据则需要在损失中消除全局尺度。对有效点集 XXX，论文采用类似 DUSt3R 的平均距离定义尺度：

σ(X)=1∣Ω∣∑u∈Ω∥X(u)∥2\sigma(X) =\frac{1}{|\Omega|} \sum_{u\in\Omega}\|X(u)\|_2 σ(X)=∣Ω∣1​u∈Ω∑​∥X(u)∥2​

非度量样本比较归一化后的 X/σ(X)X/\sigma(X)X/σ(X)，避免不同数据集的未知尺度互相冲突。对具有真实尺度的样本，训练时让预测使用真值尺度因子，从而保留米制约束。最终模型能在常见场景中给出度量预测，但这种能力来自训练分布中的尺度先验；相机类型、物体尺寸或场景分布发生较大变化时，绝对尺度仍可能失准。

射线查询

持久状态还可以接受一个虚拟相机查询。对于目标相机中的像素 uuu，已知内参和外参后可以构造世界坐标系中的射线原点 o(u)o(u)o(u) 与单位方向 d(u)d(u)d(u)。论文把二者拼成六通道 raymap：

R(u)=[o(u),d(u)]∈R6R(u)=\left[o(u),d(u)\right]\in\mathbb R^6 R(u)=[o(u),d(u)]∈R6

整张 raymap 经过独立的射线编码器：

FR=ER(R)F_R=E_R(R) FR​=ER​(R)

随后使用与图像观测相同的双流解码器读取状态。此时状态更新分支被关闭，只允许查询 token 从 StS_tSt​ 中取出信息。只读查询可以防止模型把自身生成的虚拟观测重新写回记忆，逐步放大幻觉。解码结果进入 point map、位姿和颜色头，其中颜色头预测目标视角图像：

I^R=Hrgb(FR′)\hat I_R=H_{\mathrm{rgb}}(F'_R) I^R​=Hrgb​(FR′​)

raymap 查询的用途接近“用指定相机查看当前记忆”。若目标视角落在已观测区域，状态可以结合多帧信息恢复目标方向的几何和外观；若射线指向遮挡后或从未看到的区域，输出主要依赖训练先验。因此，相邻视角的查询证据更充足，远距离外推则容易损失高频纹理和局部几何。

训练时，除第一帧外，输入帧会按一定概率被真实相机 raymap 随机替换，并以对应 RGB 和几何作为监督。raymap 训练只使用度量数据，因为一个带世界坐标的射线查询必须与状态中的场景尺度一致。它也意味着该功能需要用户先指定虚拟相机，而不能自动决定应当查询哪个未知区域。

监督目标

局部与全局 point map 都采用置信度调节的回归损失。设归一化后的单像素残差为：

r(u)=∥X^(u)σ^−X(u)σ∥2r(u)= \left\| \frac{\hat X(u)}{\hat\sigma} - \frac{X(u)}{\sigma} \right\|_2 r(u)=​σ^X^(u)​−σX(u)​​2​

对应损失写成：

Lconf=1∣Ω∣∑u∈Ω[C^(u)r(u)−αlog⁡C^(u)]\mathcal L_{\mathrm{conf}} =\frac{1}{|\Omega|} \sum_{u\in\Omega} \left[ \hat C(u)r(u)-\alpha\log\hat C(u) \right] Lconf​=∣Ω∣1​u∈Ω∑​[C^(u)r(u)−αlogC^(u)]

C^(u)>0\hat C(u)>0C^(u)>0。第一项让高置信度像素承担更大的几何误差，第二项阻止网络把所有置信度降到零。固定残差时，对 C^\hat CC^ 求导并令其为零可得 C^∗=α/r\hat C^*=\alpha/rC^∗=α/r；因此残差越小，最优置信度越高，遮挡边界、反射表面和错误标注等区域会自然获得较低权重。这里的 置信度学习既用于优化时抑制噪声，也为推理后的点云筛选提供依据。

位姿损失同时约束旋转和平移：

Lpose=∑t(∥q^t−qt∥2+∥τ^tσ^−τtσ∥2)\mathcal L_{\mathrm{pose}} =\sum_t \left( \|\hat q_t-q_t\|_2 + \left\| \frac{\hat\tau_t}{\hat\sigma} - \frac{\tau_t}{\sigma} \right\|_2 \right) Lpose​=t∑​(∥q^​t​−qt​∥2​+​σ^τ^t​​−στt​​​2​)

平移沿用 point map 的尺度处理，使 up-to-scale 数据也能参与相机监督。射线查询还增加 RGB 重建项：

Lrgb=∥I^R−IR∥22\mathcal L_{\mathrm{rgb}} =\|\hat I_R-I_R\|_2^2 Lrgb​=∥I^R​−IR​∥22​

总损失根据样本已有标注选择可用项。这样的多任务设计使仅有深度、仅有相机或具有完整三维标注的数据可以放在同一训练框架中，不必为每个数据集补齐全部标签。

数据训练

持续状态要同时适应室内外、静态与动态、视频与照片集合，训练数据的覆盖范围比单一重建数据集更重要。论文整合了 32 个数据集，包括 ARKitScenes、ScanNet++、TartanAir、Waymo、MapFree、BlendedMVS、HyperSim、MegaDepth、DL3DV、CO3Dv2、Dynamic Replica 和 PointOdyssey 等。数据同时覆盖真实与合成环境、场景与物体、完整与部分标注。

部分照片或视频数据只有相机参数，作者对 MapFree 和 DL3DV 等数据运行多视图立体匹配以补充稠密深度；RealEstate10K、CoP3D 和 MVImgNet 等样本则可以只提供相机监督。独立单图数据也能组成训练序列，但每张图后都会重置状态，防止模型把互不相关的场景错误合并。

训练采用四阶段课程：

  1. 先用以静态场景为主的 4 视图序列，在 224224224 分辨率学习基本几何和状态更新；
  2. 加入动态数据与不完整标注，扩大任务和场景分布；
  3. 使用多种长宽比并把最长边提高到 512512512，训练高分辨率输出；
  4. 冻结图像编码器，使用 4 到 64 视图序列重点训练解码器、状态和预测头，使递归模块适应更长上下文。

视频序列会随机改变采样间隔，照片集合则按视图重叠程度采样。大部分静态视频还会随机打乱顺序，促使模型处理一般照片集合；包含明显运动的序列保留时间顺序，以免动态物体的状态变化失去合理上下文。模型使用 AdamW，初始学习率为 10−410^{-4}10−4，经过 warmup 后按余弦策略衰减，并在 8 张 A100 80GB GPU 上训练。

这套课程反映了递归模型的训练难点。状态更新需要反向传播穿过多次读写，序列越长，显存和优化难度越高。最终模型可以推理远长于训练序列的输入，但训练只显式覆盖到 64 帧，超长序列仍属于长度外泛化。

在线推理

CUT3R 的标准推理过程可以写为：

S0←Slearnedfor t=1,…,T:Ft←EI(It)(St,Ft′,zt′)←D(St−1,Ft,z)Ot←{Hself(Ft′),Hworld(Ft′,zt′),Hpose(zt′)}输出 Ot，仅保留 St\begin{array}{l} S_0\leftarrow S_{\mathrm{learned}}\\ \textbf{for }t=1,\ldots,T:\\ \quad F_t\leftarrow E_I(I_t)\\ \quad (S_t,F'_t,z'_t)\leftarrow D(S_{t-1},F_t,z)\\ \quad O_t\leftarrow \{H_{\mathrm{self}}(F'_t), H_{\mathrm{world}}(F'_t,z'_t), H_{\mathrm{pose}}(z'_t)\}\\ \quad \text{输出 }O_t\text{，仅保留 }S_t \end{array} S0​←Slearned​for t=1,…,T:Ft​←EI​(It​)(St​,Ft′​,zt′​)←D(St−1​,Ft​,z)Ot​←{Hself​(Ft′​),Hworld​(Ft′​,zt′​),Hpose​(zt′​)}输出 Ot​，仅保留 St​​

第 ttt 帧只能读取 111 到 ttt 帧，因而满足因果在线处理要求。系统不需要等序列结束，也不需要随着时间增长保存完整 KV cache，单帧计算和持久状态的尺寸在给定分辨率下保持固定。

因果性也限制了早期结果。模型处理第一帧时还没有后续视角，已经输出的几何不会自动被未来观测修改。若应用需要全局一致的最终模型，可以保留最后状态，再把旧图像输入一次，形成“先建状态、再回访”的两遍流程。这会失去严格的一遍在线性质，却能让每一帧利用完整序列上下文。

动态场景

动态视频中，静态背景与运动物体会同时写入状态。CUT3R 通过动态数据学习哪些内容应长期保留、哪些内容需要随时间更新，并把每一帧的全局 point map 放到统一世界坐标系中。相机运动和物体运动因此可以在输出层面分离：背景点应保持稳定，运动物体的世界坐标会随时间改变。

模型没有显式预测 scene flow、物体身份或可变拓扑，状态也没有单独划分静态与动态槽位。它学习到的是隐式更新规律。若直接累积所有全局 point map，静态背景通常能够形成连贯结构，运动区域则可能留下拖影；处理动态物体时仍需时间戳、置信度筛选或后续运动分解。CUT3R 对动态场景的主要价值在于能够在线给出逐帧一致的几何，而非直接产出无拖影的静态场景网格。

实验结果

CUT3R 的视频深度推理约为 16.6 FPS，轨迹、深度和重建质量在在线方法中具有竞争力；7Scenes 的 Accuracy / Completeness 约为 0.126 / 0.154，优于需要全局对齐的 DUSt3R-GA（约 0.146 / 0.181）。轨迹指标经过 Sim(3) 对齐，反映的是相对运动和跨帧几何一致性，不能据此判断绝对尺度精度。

冻结最终状态并重新读取全部图像后，7Scenes 的 Accuracy / Completeness 可进一步改善到约 0.113 / 0.107，说明固定状态确实保存了后续视角带来的证据；代价是额外遍历一次序列。离线优化系统在部分长轨迹和表面指标上仍占优，raymap 对未观测区域的输出也包含生成先验，不能视作真实测量。

特点与局限

CUT3R 用固定长度的持久状态统一承载场景记忆、相机轨迹与几何信息，并在双流解码器中同步完成状态更新和当前帧读取。模型可逐帧输出局部与全局 point map 及位姿，无需构造图像对或执行测试时全局优化；raymap 查询还能从指定虚拟相机访问状态中的几何与颜色，使这套固定成本接口适合连续视频、机器人和移动设备上的在线三维感知。

固定容量也意味着场景必须被持续压缩，超长序列或大范围环境可能覆盖旧信息；递归更新依赖输入顺序，又缺少显式回环检测与束调整，因而容易积累漂移，已经输出的历史结果通常还需额外回访才能修正。模型对动态物体、透明反射表面和未见区域不确定性的处理仍较弱，raymap 依赖给定且尺度一致的目标相机；论文训练显式覆盖的序列最长为 64 帧，向更长、更复杂轨迹推广仍需验证。
