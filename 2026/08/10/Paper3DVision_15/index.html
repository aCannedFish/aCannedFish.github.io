RnG: A Unified Transformer for Complete 3D Modeling from Partial Observations

发表于2026-08-10|更新于2026-08-17|Note3DVision 论文阅读
|浏览量:

VGGT 一类前馈重建模型已经能够从少量无标定图像中估计相机、深度和 point map。它们的几何与输入像素一一对应：某个表面只有被输入相机看到，才会出现在结果中。这种部分观测重建在数张照片只覆盖物体正面和侧面时仍会缺少背面；同一表面在多张图中的预测略有偏差时，融合点云还会出现分层。

稀疏观测下的新视角合成可以补全看不见的外观，但许多方法只保证生成图像看起来合理，没有输出能在多视角间对齐的显式几何。基于扩散的统一模型 Matrix3D 可以同时生成外观和深度，以多步去噪为代价换取了更强的生成能力，单个新视角的延迟也因此较高。

RnG 将这两条路线合并到一个前馈 Transformer 中。给定少量无位姿物体图像，模型先建立可复用的潜在场景表示，再用任意目标相机的像素射线查询它，直接输出该视角的 RGB 和 point map。通过在物体周围连续查询并融合结果，可以得到同时包含可见区域与合理遮挡区域的 complete 3D 点云。

任务定义

设源视图为 {Is}s=1S\{I_s\}_{s=1}^{S}{Is​}s=1S​，其相机位姿在测试时未知。用户指定一个目标相机 gtg_tgt​，RnG 预测：

fΘ ⁣({Is}s=1S,gt)=({g^s}s=1S,I^t,P^t,Σ^t).f_\Theta\!\left(\{I_s\}_{s=1}^{S},g_t\right) =\left(\{\hat g_s\}_{s=1}^{S},\hat I_t,\hat P_t,\hat\Sigma_t\right). fΘ​({Is​}s=1S​,gt​)=({g^​s​}s=1S​,I^t​,P^t​,Σ^t​).

各输出的含义如下：

  • g^s\hat g_sg^​s​ 是源图像的相机位姿，用于建立全局坐标系和回贴源图纹理；
  • I^t∈RH×W×3\hat I_t\in\mathbb R^{H\times W\times3}I^t​∈RH×W×3 是目标视角的 RGB 图像；
  • P^t∈RH×W×3\hat P_t\in\mathbb R^{H\times W\times3}P^t​∈RH×W×3 是目标视角的 point map，每个像素存储一个全局三维坐标；
  • Σ^t∈RH×W\hat\Sigma_t\in\mathbb R^{H\times W}Σ^t​∈RH×W 是几何置信度，融合点云时用它清理遮挡边界附近的飞点。

这个任务同时受到规范自由度（gauge freedom）和遮挡歧义影响。相机与场景的全局坐标可以共同旋转、平移或缩放，而不改变投影图像；完全遮挡的表面也无法由观测确定唯一真值。RnG 将第一张源图的相机固定为：

gs=1=[I3×3∣[0,0,−1]⊤].g_{s=1} =\left[I_{3\times3}\mid[0,0,-1]^\top\right]. gs=1​=[I3×3​∣[0,0,−1]⊤].

训练物体被归一化到原点附近，第一相机位于单位球上。这个约定固定了网络内部的参考系，不会让单目 RGB 自动获得真实米制尺度。遮挡表面的结果则来自训练数据中的形状先验，应理解为与已观测内容相容的一种可能补全。

固定参考相机只消除了坐标表示上的歧义；它不会增加新的观测证据，也无法保证模型猜出的背面与真实物体完全相同。

完整三维

论文中的 complete 3D 首先表现为可查询的隐式表示：源图像经过 Transformer 后，各层注意力的 key/value 缓存编码了当前物体的外观、相机关系和形状先验。一个新视角可以读取这份表示，获得该视角的 RGBD 式结果。

要得到常规三维软件能处理的显式几何，还需对一组覆盖球面的目标相机 {gt(m)}m=1M\{g_t^{(m)}\}_{m=1}^{M}{gt(m)​}m=1M​ 分别查询，再将高置信度点合并为：

X=⋃m=1M{P^t(m)(u,v)  |  Σ^t(m)(u,v)>τ}.\mathcal X =\bigcup_{m=1}^{M} \left\{ \hat P_t^{(m)}(u,v) \;\middle|\; \hat\Sigma_t^{(m)}(u,v)>\tau \right\}. X=m=1⋃M​{P^t(m)​(u,v)​Σ^t(m)​(u,v)>τ}.

X\mathcal XX 是完整点云的初始形式。它仍需要多视图融合、去重、离群点过滤，如果下游任务需要网格，还要进行表面重建。因此 RnG 内部没有一个已经封装好的完整网格，其核心是能在多个目标视角上持续生成一致几何的隐式表示。

射线条件

要查询一个新视角，模型需要知道输出图像中每个像素对应世界中的哪条射线。设相机中心为 c∈R3c\in\mathbb R^3c∈R3，某像素的归一化射线方向为 d∈R3d\in\mathbb R^3d∈R3，射线上的点可写成：

x(λ)=c+λd,λ>0.x(\lambda)=c+\lambda d, \qquad \lambda>0. x(λ)=c+λd,λ>0.

RnG 用 Plücker 坐标编码这条射线：

r=(d,m),m=c×d.r=(d,m), \qquad m=c\times d. r=(d,m),m=c×d.

ddd 描述射线方向，矩 mmm 将射线相对世界原点的位置编码进去。若沿同一射线把参考点从 ccc 移到 c+αdc+\alpha dc+αd，则

(c+αd)×d=c×d,(c+\alpha d)\times d=c\times d, (c+αd)×d=c×d,

所以 mmm 与选择射线上的哪个点无关；它与方向还满足 d⊤m=0d^\top m=0d⊤m=0。当 ddd 已归一化时，(d,m)(d,m)(d,m) 因而能稳定表示一条有方向的空间直线。对目标相机的整张图像计算 Plücker ray map，就得到 H×W×6H\times W\times6H×W×6 的目标视图几何条件。线性层将其投影为 target token，模型随后为每条射线预测颜色和对应三维点。

这种条件比向网络仅提供一个相机向量更直接。每个 target token 从输入时就知道自己要渲染的空间射线，不必再由同一个全局相机向量隐式恢复像素级差异。同时，目标图像本身没有输入网络；模型只看到射线条件和源图像，不存在直接复制目标 RGB 的通道。LVSM 等前馈新视角模型也使用射线查询潜特征，RnG 进一步在同一主干中估计未知源相机并输出目标 point map，使查询结果可以融合成显式三维。

模型结构

RnG 继承 VGGT 的 DINO 图像特征、交替 Frame Attention / Global Attention 和相机头，并使用其预训练权重初始化。设 DINO 提取的源视图 token 为 zsIz_s^IzsI​，目标射线经 MLP 投影后的 token 为 ztrz_t^rztr​，每个视图还会加入 camera token 和 register token。所有 token 经过 L=24L=24L=24 层交替注意力，形成从源图到目标射线的统一数据流：

Z(ℓ+1)=FrameAttn⁡ℓ ⁣(GlobalAttn⁡ℓ(Z(ℓ))).Z^{(\ell+1)} =\operatorname{FrameAttn}_{\ell} \!\left( \operatorname{GlobalAttn}_{\ell}(Z^{(\ell)}) \right). Z(ℓ+1)=FrameAttnℓ​(GlobalAttnℓ​(Z(ℓ))).

Global Attention 负责在多张源图与目标射线之间传递全局几何；Frame Attention 在每个视图的 token 网格内整理局部轮廓、纹理和表面连续性。网络主干在源视图与目标视图上共享参数，两类 token 最后进入不同的输出头：

{g^s}=Dcam(Zsg),I^t=DRGB(Zt),P^t=Dpmap(Zt).\{\hat g_s\}=D_{\mathrm{cam}}(Z_s^g), \qquad \hat I_t=D_{\mathrm{RGB}}(Z_t), \qquad \hat P_t=D_{\mathrm{pmap}}(Z_t). {g^​s​}=Dcam​(Zsg​),I^t​=DRGB​(Zt​),P^t​=Dpmap​(Zt​).

DRGBD_{\mathrm{RGB}}DRGB​ 和 DpmapD_{\mathrm{pmap}}Dpmap​ 都是 DPT 式稠密解码器。RGB 头保留外观细节，point-map 头将同一 target token 中的几何信息恢复为像素对齐的三维坐标。这样的结构让几何与外观共享场景理解，又不要求同一个输出头用完全相同的局部统计同时复原 RGB 和三维坐标。

Causal Attention

如果直接对源与目标 token 执行双向全注意力，源 token 会随目标相机变化。每次换一个查询视角，都必须重新计算整组源图特征，也很难将中间状态解释为与视角无关的场景表示。

RnG 定义了 reconstruction-guided causal attention。将 query 放在行、key 放在列，允许关系可写成：

KsKtQs✓×Qt✓✓\begin{array}{c|cc} &K_s&K_t\\ \hline Q_s&\checkmark&\times\\ Q_t&\checkmark&\checkmark \end{array} Qs​Qt​​Ks​✓✓​Kt​×✓​​

源 query QsQ_sQs​ 只能读源 key KsK_sKs​，所以源视图的重建状态不受目标视角影响。目标 query QtQ_tQt​ 同时读取源视图与目标视图，因而可以在源场景证据上整合同一幅目标图内的局部关系。论文公式用二值矩阵简写掩码，官方实现传给 scaled_dot_product_attention 的则是布尔掩码。为明确被屏蔽位置的实际语义，下面采用等价的标准加性写法：

Attn⁡(Q,K,V)=softmax⁡(QK⊤dk+A)V,\operatorname{Attn}(Q,K,V) =\operatorname{softmax} \left( \frac{QK^\top}{\sqrt{d_k}}+A \right)V, Attn(Q,K,V)=softmax(dk​​QK⊤​+A)V,

被禁止的 source-query / target-key 位置在 AAA 中取 −∞-\infty−∞，其余位置取 000。这个方向符合任务的信息流：已观测内容决定生成结果，一个待生成的目标视角不会反过来改写对源图像的理解。

源 token 与目标 token 仍然共享同一组投影和 Transformer 层。因果掩码只改变注意力的可见关系，因此无需为重建和生成复制两套大型主干；同时，源分支的中间状态不再依赖当前目标相机，为后续缓存提供了结构条件。

缓存表征

因果掩码使源视图的中间状态与 gtg_tgt​ 无关，因此可将每个 Global Attention 层的 source KV cache 保存起来：

Ks′(ℓ)=Cache⁡(Ks(ℓ)),Vs′(ℓ)=Cache⁡(Vs(ℓ)).K_s^{\prime(\ell)}=\operatorname{Cache}(K_s^{(\ell)}), \qquad V_s^{\prime(\ell)}=\operatorname{Cache}(V_s^{(\ell)}). Ks′(ℓ)​=Cache(Ks(ℓ)​),Vs′(ℓ)​=Cache(Vs(ℓ)​).

后续查询一个新视角时，第 ℓ\ellℓ 层只需计算目标 token 的 Qt,Kt,VtQ_t,K_t,V_tQt​,Kt​,Vt​：

Ot(ℓ)=softmax⁡(Qt(ℓ)[Ks′(ℓ);Kt(ℓ)]⊤dk)[Vs′(ℓ);Vt(ℓ)].O_t^{(\ell)} =\operatorname{softmax} \left( \frac{Q_t^{(\ell)} [K_s^{\prime(\ell)};K_t^{(\ell)}]^\top}{\sqrt{d_k}} \right) [V_s^{\prime(\ell)};V_t^{(\ell)}]. Ot(ℓ)​=softmax(dk​​Qt(ℓ)​[Ks′(ℓ)​;Kt(ℓ)​]⊤​)[Vs′(ℓ)​;Vt(ℓ)​].

对每一层，目标 token 在读完对应的 source cache 后继续向下传播，而整组源 token 无需再通过帧内和全局模块。于是推理可分为两段：

  1. 重建与缓存：仅处理一次源图像，估计相机，并保存所有层的 source KV。
  2. 生成与查询：对每个目标相机构造射线 token，逐层查询已缓存的 KV，解码 RGB 和 point map。

传统的 KV cache 常用于避免自回归模型重复处理历史 token。RnG 进一步给它一个三维解释：这些 key/value 是多张源图经过几何预训练后形成的可查询场景记忆。这种表示没有明确的体素或网格拓扑，“完整性”也由后续目标视角的响应来检验。VGG-T³ 面对上千输入视图，会把增长的 KV 压进固定大小 MLP；RnG 的源图较少、目标查询较多，保留逐层 KV 能换取更充分的查询表达力。

多任务训练

RnG 同时学习目标视图外观、目标视图几何和源相机：

L=LRGB+λpmapLpmap+λcamLcam.\mathcal L =\mathcal L_{\mathrm{RGB}} +\lambda_{\mathrm{pmap}}\mathcal L_{\mathrm{pmap}} +\lambda_{\mathrm{cam}}\mathcal L_{\mathrm{cam}}. L=LRGB​+λpmap​Lpmap​+λcam​Lcam​.

RGB 损失将像素均方误差与感知损失结合：

LRGB=∥It−I^t∥22+λpPerceptual⁡(It,I^t).\mathcal L_{\mathrm{RGB}} =\left\|I_t-\hat I_t\right\|_2^2 +\lambda_p\operatorname{Perceptual}(I_t,\hat I_t). LRGB​=​It​−I^t​​22​+λp​Perceptual(It​,I^t​).

像素损失保证整体色彩与位置准确，感知损失在深层特征中比较结构和纹理，可减少单独使用 MSE 导致的模糊。

Lpmap=∥Σt⊙(Pt−P^t)∥1+∥Σt⊙(∇Pt−∇P^t)∥1−αlog⁡Σt.\begin{aligned} \mathcal L_{\mathrm{pmap}} =&\left\|\Sigma_t\odot(P_t-\hat P_t)\right\|_1\\ &+\left\|\Sigma_t\odot(\nabla P_t-\nabla\hat P_t)\right\|_1 -\alpha\log\Sigma_t. \end{aligned} Lpmap​=​​Σt​⊙(Pt​−P^t​)​1​+​Σt​⊙(∇Pt​−∇P^t​)​1​−αlogΣt​.​

位置残差项学习三维坐标，梯度残差项约束轮廓与表面斜率。对误差较大的像素，降低 Σt\Sigma_tΣt​ 可以减少其梯度；−αlog⁡Σt-\alpha\log\Sigma_t−αlogΣt​ 会在置信度趋近零时迅速增大，阻止网络通过关闭所有像素来逃避监督。边界、反光或模棱两可区域由此可以获得较小权重，最终的 Σt\Sigma_tΣt​ 又能直接服务点云过滤。

源相机使用 Huber 损失：

训练设置

训练数据来自 Objaverse，使用 LVIS 子集和 LGM 过滤列表，合计约 11.35 万个物体。每个物体在不同距离的 25 个视角渲染 RGBD。每次先随机选 7 张，其中 4 张是源视图，3 张分别作为目标视图。这三个训练样本共享同一组源图，因果掩码会迫使它们得到相同的 source state。

主模型使用 256×256256\times256256×256 输入、patch size 8，在 8 张 A800 上训练 4 万步，使用 bfloat16 和梯度检查点。DINO 单图特征提取器始终冻结。补充材料报告了对象 batch size 6、两次前向累积；结合 8 张 GPU 后，主文将有效对象 batch 记为 96。每个对象又展开为 3 个目标视图对。

学习率上限为 6×10−46\times10^{-4}6×10−4，前 3000 步线性预热，之后使用 cosine decay。VGGT 初始化为主干提供已经学成的多视几何对应、相机与深度表征，RnG 再在此基础上学习目标射线查询和外观解码；有限的物体 RGBD 数据很难从头建立同等完整的几何归纳偏置。

完整恢复

固定第一相机解决了网络中的参考系问题，却会把物体在图像中的上方向一起旋转。如果用户随后直接在球面上放置水平相机，目标视图可能带有训练中很少出现的大 roll angle。

补充材料使用一个简单的上方向恢复方法。它假定所有输入照片均保持相机竖直，然后沿世界 xxx 轴搜索一个仰角旋转，使所有已估计相机的 roll angle 总体最小。得到估计上方向后，再在物体周围均匀取样相机。

这个工程步骤暴露了一个重要边界：“任意目标位姿”指的是归一化世界中可由用户指定的相机，模型不会凭空知道现实物体的重力方向、真实中心和米制半径。手持输入的光轴如果没有大致交会于同一物体中心，世界原点还可能明显偏离理想位置。

实验结果

主实验同时评价相机、目标视图 RGB 与深度以及融合点云。RnG 在几何指标上优于无位姿生成基线，并在物体域超过直接重建的 VGGT，外观质量则接近使用真值相机的新视图模型；更多源视图会继续减少遮挡歧义。将相机估计与生成拆成两阶段后性能明显下降，说明共享场景表征能够抑制位姿误差向渲染和几何逐级传播。

最有代表性的消融是 VGGT 初始化：相机 RA@5 由随机初始化时约 8%8\%8% 提高到约 82%82\%82%。因果注意力与双向注意力的质量接近，却额外得到可复用的源表示；建立分层 KV cache 后，单个新视角查询约需 858585 ms。缓存只复用源图计算，多视角点云仍需逐视角查询，因此总耗时仍会随目标数量增长。

特点与局限

RnG 将无位姿重建、目标视角 RGB 合成和 point map 生成统一到一个前馈 Transformer 中。它继承 VGGT 的几何知识，以像素级 Plücker ray map 表达目标相机，并通过因果注意力阻止源视图读取目标信息；由源视图形成的分层 KV cache 因此是与查询视角无关的隐式三维表示，能够被不同相机反复读取，同时生成较一致的外观与几何。

其补全结果仍是由数据先验得到的合理猜测，无法保证遮挡表面、非对称背面或分布外结构真实存在；以合成、主体中心物体为主的训练与评测，以及 look-at、竖直方向和归一化坐标等假设，也限制了复杂场景中的泛化。256×256256\times256256×256 输入和确定性解码头容易损失高频纹理、透明及细薄结构，完整模型还需多视角查询并融合点云，不能直接输出带拓扑、绝对尺度可靠的 mesh；源 token 与缓存规模也会随输入视图增加。
