概率路径

概率路径与条件概率路径

流匹配 Flow Matching 的起点是 概率路径 Probability Paths。概率路径是随时间变化的分布序列 (pt)0≤t≤1{(p_t)}_{0 \le t \le 1}(pt​)0≤t≤1​，用于把简单先验分布连接到真实数据分布。

实际训练中无法直接观测 pdatap_{data}pdata​，也无法直接构造 pinitp_{init}pinit​ 到 pdatap_{data}pdata​ 的全局路径。

可行做法是对每个样本 z∼pdataz \sim p_{data}z∼pdata​ 构造从噪声到该样本的 条件概率路径 Conditional Probability Path pt(x∣z)p_t(x|z)pt​(x∣z)，并满足：

  1. t=0t=0t=0 时为初始噪声分布，通常设为 p0(⋅∣z)=pinit=N(0,Id)p_0(\cdot|z) = p_{init} = \mathcal{N}(0, I_d)p0​(⋅∣z)=pinit​=N(0,Id​)。
  2. t=1t=1t=1 时塌缩到数据点 zzz，即 p1(⋅∣z)=δzp_1(\cdot|z) = \delta_zp1​(⋅∣z)=δz​，其中 δz\delta_zδz​ 是以 zzz 为中心的 Dirac delta 分布。

这样即可定义从噪声到样本的条件演化路径。

边缘概率路径

给定条件路径 pt(x∣z)p_t(x |z)pt​(x∣z) 后，可通过边缘化得到 边缘概率路径 Marginal Probability Path pt(x)p_t(x)pt​(x)：

pt(x)=∫pt(x∣z)pdata(z)dzp_t(x) = \int p_t(x|z) p_{data}(z) dz pt​(x)=∫pt​(x∣z)pdata​(z)dz

边缘分布是所有条件分布的加权平均，权重由 pdata(z)p_{data}(z)pdata​(z) 给出。学习大量条件路径即可间接学习整体分布的演化。

由于条件路径满足边界条件，边缘路径也满足 p0=pinitp_0 = p_{init}p0​=pinit​ 且 p1=pdatap_1 = p_{data}p1​=pdata​。因此，只要找到驱动粒子沿 ptp_tpt​ 演化的机制，就能从噪声生成数据。

高斯条件概率路径

常用的中间路径是高斯条件路径：

pt(x∣z)=N(x;αtz,βt2Id)p_t(x|z) = \mathcal{N}(x; \alpha_t z, \beta_t^2 I_d) pt​(x∣z)=N(x;αt​z,βt2​Id​)

其中 αt\alpha_tαt​ 和 βt\beta_tβt​ 是噪声调度函数，满足 α0=0,β0=1\alpha_0 = 0, \beta_0 = 1α0​=0,β0​=1 和 α1=1,β1=0\alpha_1 = 1, \beta_1 = 0α1​=1,β1​=0。该路径通过线性变换和噪声缩放，使分布从标准高斯逐渐收敛到 zzz。常见调度如下：

调整 αt,βt\alpha_t,\beta_tαt​,βt​ 可得到不同几何路径。最优传输路径对应线性插值，轨迹直接、速度形式简单。

向量场

条件向量场

概率路径给出分布如何变化；向量场给出粒子在该路径上的速度。

对每个数据点 zzz，定义 条件向量场 Conditional Vector Field：

X0∼pinitddtXt=uttarget(Xt∣z)  ⟹  Xt∼pt(⋅∣z)(0≤t≤1)X_0 \sim p_{init} \quad \frac{d}{dt} X_t = u_t^{target}(X_t|z) \implies X_t \sim p_t(\cdot | z) \quad (0 \le t \le 1) X0​∼pinit​dtd​Xt​=uttarget​(Xt​∣z)⟹Xt​∼pt​(⋅∣z)(0≤t≤1)

其中 uttarget(Xt∣z)u_t^{target}(X_t|z)uttarget​(Xt​∣z) 是目标条件向量场。

X0∼pinitX_0 \sim p_{init}X0​∼pinit​ 是噪声起点。给定初始点后，ODE 定义的流 ψt(x0)\psi_t(x_0)ψt​(x0​) 确定粒子位置。向量场、ODE 和流分别对应速度规则、局部变化和全局轨迹。

连续性方程：向量场改变概率分布的基础是连续性方程，它描述概率质量在向量场下的守恒演化：

∂∂tpt(x)+div(ptut)(x)=0\frac{\partial}{\partial t}p_t(x) + \text{div}(p_t u_t)(x) = 0 ∂t∂​pt​(x)+div(pt​ut​)(x)=0

其中 div(ptut)\text{div}(p_t u_t)div(pt​ut​) 是概率流散度，∂tpt(x)\partial_t p_t(x)∂t​pt​(x) 是密度变化率。若向量场满足该方程，则概率质量只发生连续搬运，不凭空产生或消失。

对高斯条件路径 pt(x∣z)=N(x;αtz,βt2Id)p_t(x|z) = \mathcal{N}(x; \alpha_t z, \beta_t^2 I_d)pt​(x∣z)=N(x;αt​z,βt2​Id​)，可用流图 ψt(x0∣z)=αtz+βtx0\psi_t(x_0|z) = \alpha_t z + \beta_t x_0ψt​(x0​∣z)=αt​z+βt​x0​ 求条件向量场：

ddtψt(x0∣z)=α˙tz+β˙tx0=uttarget(ψt(x0∣z)∣z)\frac{d}{dt} \psi_t(x_0|z) = \dot{\alpha}_t z + \dot{\beta}_t x_0 = u_t^{target}(\psi_t(x_0|z) | z) dtd​ψt​(x0​∣z)=α˙t​z+β˙​t​x0​=uttarget​(ψt​(x0​∣z)∣z)

将 x0x_0x0​ 替换为 (x−αtz)/βt(x - \alpha_t z) / \beta_t(x−αt​z)/βt​，得到闭式解：

uttarget(x∣z)=(α˙t−β˙tβtαt)z+β˙tβtxu_t^{target}(x|z) = (\dot{\alpha}_t - \frac{\dot{\beta}_t}{\beta_t} \alpha_t) z + \frac{\dot{\beta}_t}{\beta_t} x uttarget​(x∣z)=(α˙t​−βt​β˙​t​​αt​)z+βt​β˙​t​​x

该速度由数据点 zzz 相关项和尺度变化项组成。对 CondOT 路径（αt=t,βt=1−t\alpha_t=t, \beta_t=1-tαt​=t,βt​=1−t），可简化为 ut(x∣z)=z−ϵu_t(x|z) = z - \epsilonut​(x∣z)=z−ϵ，其中 ϵ\epsilonϵ 是初始噪声。

边缘向量场

条件向量场可由条件路径直接构造。对所有可能的 zzz 做后验加权平均，即得到边缘向量场：

uttarget(x)=∫uttarget(x∣z)pt(x∣z)pdata(z)pt(x)dzu_t^{target}(x) = \int u_t^{target}(x|z) \frac{p_t(x|z) p_{data}(z)}{p_t(x)} dz uttarget​(x)=∫uttarget​(x∣z)pt​(x)pt​(x∣z)pdata​(z)​dz

权重 pt(x∣z)pdata(z)pt(x)\frac{p_t(x|z) p_{data}(z)}{p_t(x)}pt​(x)pt​(x∣z)pdata​(z)​ 是后验概率 pt(z∣x)p_t(z|x)pt​(z∣x)。因此，位置 xxx 的边缘速度等于所有条件速度的后验期望：

uttarget(x)=Ez∼pdata(⋅∣x)[uttarget(x∣z)]u_t^{target}(x) = \mathbb{E}_{z \sim p_{data}(\cdot|x)} [u_t^{target}(x|z)] uttarget​(x)=Ez∼pdata​(⋅∣x)​[uttarget​(x∣z)]

直观上，uttarget(x∣z)u_t^{target}(x|z)uttarget​(x∣z) 表示“若终点是 zzz，当前位置应如何移动”，pt(z∣x)p_t(z|x)pt​(z∣x) 表示当前位置最终对应各数据点的概率。二者加权积分得到当前位置的平均运动方向。

流匹配损失

定义概率路径和向量场后，目标是学习边缘向量场，即总体分布的演化速度。

理想的 流匹配损失 FM Loss 要求神经网络向量场 vθ(x,t)v_\theta(x, t)vθ​(x,t) 逼近真实边缘向量场 uttarget(x)u_t^{target}(x)uttarget​(x)：

LFM(θ)=Et∼Unif,x∼pt(x)[∥vθ(x,t)−uttarget(x)∥2]\mathcal{L}_{FM}(\theta) = \mathbb{E}_{t \sim \text{Unif}, x \sim p_t(x)} [\|v_\theta(x, t) - u_t^{target}(x)\|^2] LFM​(θ)=Et∼Unif,x∼pt​(x)​[∥vθ​(x,t)−uttarget​(x)∥2]

但 uttarget(x)u_t^{target}(x)uttarget​(x) 依赖未知的 pdatap_{data}pdata​，不能直接计算。因此使用可计算的 条件流匹配损失 CFM Loss：

LCFM(θ)=Et,z∼pdata,x∼pt(x∣z)[∥vθ(x,t)−uttarget(x∣z)∥2]\mathcal{L}_{CFM}(\theta) = \mathbb{E}_{t, z \sim p_{data}, x \sim p_t(x|z)} [\|v_\theta(x, t) - u_t^{target}(x|z)\|^2] LCFM​(θ)=Et,z∼pdata​,x∼pt​(x∣z)​[∥vθ​(x,t)−uttarget​(x∣z)∥2]

其中 uttarget(x∣z)u_t^{target}(x|z)uttarget​(x∣z) 和 pt(x∣z)p_t(x|z)pt​(x∣z) 可直接计算。可以证明 FM 与 CFM 对参数 θ\thetaθ 的梯度等价：

∇θLFM(θ)=∇θLCFM(θ)\nabla_\theta \mathcal{L}_{FM}(\theta) = \nabla_\theta \mathcal{L}_{CFM}(\theta) ∇θ​LFM​(θ)=∇θ​LCFM​(θ)

因此，训练时匹配条件速度即可得到正确的边缘向量场。
