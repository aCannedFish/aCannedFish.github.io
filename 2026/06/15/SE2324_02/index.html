预备知识

优化的定义

优化旨在从所有可行的配置方案中寻找最佳解 。优化问题通常被形式化为在满足一定约束条件（x∈Xx \in \mathcal{X}x∈X）的前提下，最小化或最大化一个目标函数 f(x)f(x)f(x) 。优化问题可以基于多维度进行分类，包括是否带有约束条件（无约束与有约束）、变量的连续性（连续与非平滑）以及函数的凸性（凸优化与非凸优化） 。计算机科学与机器学习领域主要关注有约束、连续的凸优化问题。

线代基础

  • 向量与内积： 向量 xxx 及其转置 xTx^TxT 构成了空间中的点或方向 。两个向量的内积定义为 xTy=∑ixiyix^T y = \sum_i x_i y_ixTy=∑i​xi​yi​ 。若内积为 0，则两向量正交 。

  • 向量范数： 用于衡量向量的“长度” ，常用作损失函数中的正则化项。常用的包括 L1L_1L1​ 范数（绝对值之和 ∣∣x∣∣1=∑∣xi∣||x||_1 = \sum |x_i|∣∣x∣∣1​=∑∣xi​∣）和 L2L_2L2​ 范数（欧几里得距离 ∣∣x∣∣2=∑xi2||x||_2 = \sqrt{\sum x_i^2}∣∣x∣∣2​=∑xi2​​） 。

  • 半正定与正定矩阵： 对于对称矩阵 AAA，若对任意向量 xxx，均有二次型 xTAx≥0x^T Ax \ge 0xTAx≥0，则称 AAA 为半正定矩阵（PSD，记为 A≥0A \ge 0A≥0） 。若严格有 xTAx>0x^T Ax > 0xTAx>0，则为正定矩阵（PD，记为 A>0A > 0A>0） 。

  • 半正定性： 在优化中，目标函数的二阶导数矩阵（海森矩阵）如果是半正定的，则证明该目标函数是凸函数。矩阵的半正定性是判断多元函数凸性的核心数学工具。

凸优化

线性规划

线性规划 Linear Programming, LP 的目标函数和约束条件均为线性方程 。

  • 规范形式： 最大化 cTxc^T xcTx，且满足不等式约束 aiTx≤bia_i^T x \le b_iaiT​x≤bi​ 与非负约束 xj≥0x_j \ge 0xj​≥0 。所有线性规划都可以通过变量代换、符号翻转等操作转化为规范形式 。
  • 几何视角： 每一个线性不等式约束 aiTx≤bia_i^T x \le b_iaiT​x≤bi​ 在几何上定义了一个半空间，多个半空间的交集构成了一个多面体，即优化的可行域 。优化过程等价于在这个多面体上沿着目标方向 ccc 寻找极值点 。
  • 补充前置知识： 线性规划的最优解必然出现在多面体的顶点上 。经典的单纯形法正是基于这一几何性质，通过在多面体的相邻顶点间不断跳跃来快速搜索最优解。

优化算法

无约束型

  • 梯度下降法： 梯度指向函数值增长最快的方向，因此算法沿着负梯度方向迭代寻找极小值 。迭代公式为：

    xt+1=xt−ηt∇f(xt)x_{t+1} = x_t - \eta_t \nabla f(x_t) xt+1​=xt​−ηt​∇f(xt​)

    步长 ηt\eta_tηt​ 过小会导致收敛极慢；步长过大则会导致在极小值附近震荡甚至发散 。当特征维度间的尺度差异过大时，梯度下降会产生锯齿状“震荡”轨迹 。

  • 牛顿法： 利用函数的二阶导数（海森矩阵 ∇2f(x)\nabla^2 f(x)∇2f(x)）进行二阶泰勒近似，直接计算抛物面的极小值点 。其迭代公式为：

    xt+1=xt−[∇2f(xt)]−1∇f(xt)x_{t+1} = x_t - [\nabla^2 f(x_t)]^{-1} \nabla f(x_t) xt+1​=xt​−[∇2f(xt​)]−1∇f(xt​)

    牛顿法引入了曲率信息，能够自动调整各个维度的步长。对于严格的凸二次函数，牛顿法只需一次迭代即可到达精确最优点，收敛速度远超梯度下降法 。

有约束型

针对带有严格不等式约束的问题，需要使用内点法或罚函数法 。

  • 对数闸函数： 直接将约束 fi(x)≤0f_i(x) \le 0fi​(x)≤0 作为硬边界会导致目标函数在边界处不可导 。为此，引入对数障碍函数 ϕ(x)=−∑log⁡(−fi(x))\phi(x) = -\sum \log(-f_i(x))ϕ(x)=−∑log(−fi​(x)) 。当变量逼近约束边界时，惩罚项趋于无穷大，从而将搜索过程强行“困”在可行域内部 。

  • 路径跟踪： 构造近似无约束问题 min⁡f0(x)+μϕ(x)\min f_0(x) + \mu \phi(x)minf0​(x)+μϕ(x) 。算法初始设定较大的惩罚系数 μ\muμ，然后不断成比例缩小 μ\muμ（例如 μ:=βμ\mu := \beta \muμ:=βμ），并在每个阶段用牛顿法求解 。最终迭代轨迹会形成一条“中心路径”并稳定逼近真实的最优解 。
