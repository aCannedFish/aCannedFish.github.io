基本术语

前缀与后缀

在高级数据结构的研究与工程实现中，字符串作为一种线性且连续的数据集合，具备严格的代数属性与边界定义。为了消除索引处理中的歧义，学术界与工程界通常采用半开半闭区间 [i,j)[i, j)[i,j) 来界定字符串的内部片段，其中包含起始索引 iii，但不包含终止索引 jjj。

抽象数据类型接口

字符串的抽象数据类型（ADT）提供了一组标准化、模块化的操作接口，用于支持高层算法的调度。这些操作覆盖了从标量属性获取到复杂序列搜索的多个维度。

字符串匹配

循模式访问

模式匹配算法的性能评估高度依赖于输入数据的分布特征。在标准的计算模型中，文本串 TTT 的长度设为 nnn，模式串 PPP 的长度设为 mmm。典型的工程应用场景通常满足 2≪m≪n2 \ll m \ll n2≪m≪n，即文本具备海量特征，而模式具备一定规模且远小于文本总长。

这种概率学特性揭示了一个关键的工程事实：在绝大部分搜索位移中，比对过程必然会在极早期的字符处触发失配。因此，算法的核心优化目标并非如何加速那极少部分成功的匹配，而是如何以最低的计算开销处理海量的必然失配情况，并尽可能拉大下一次尝试的物理步长。

蛮力匹配策略的逻辑与缺陷

在未引入复杂状态记录的条件下，最直观的解决方案为蛮力策略。其运行逻辑是：将模式串的起点依次与文本串的各个位置对齐并逐字检查。一旦发现任何一个字符失配，即刻判定当前对齐位置无效，并整体将模式串右移一个单位，重新启动完整的对比流程。

时空复杂度与瓶颈

由于仅依赖标量游标，蛮力策略的空间复杂度为 O(1)\mathcal{O}(1)O(1)。其时间复杂度则高度依赖于具体的字符序列组合：最优状态出现在模式串的首字符与文本串基本不匹配的场景（例如文本为反复交替的模式，而模式串首字符独一无二）。此时内层比较在首次操作即告终止，整体仅需扫描一遍文本，时间复杂度达到理论下界 Ω(n)\Omega(n)Ω(n)。最坏状态则发生在高度相似的重复片段中（例如文本串与模式串主体均为字符 0 构成，仅在末尾存在异类字符 X）。这种情况下，每一次对齐测试都会在深入模式串后才被判定失败。大量已知字符被反复重复扫描，导致算法效率劣化至二次多项式级别 O(n⋅m)\mathcal{O}(n \cdot m)O(n⋅m)。在大规模文本缓冲读取的应用中，这种指针往复倒退的操作会破坏文件流的单向性，产生明显的 I/O 停顿。

KMP 算法

匹配过程的不变性

为突破二次时间复杂度的理论瓶颈，需要推导挖掘扫描过程中潜藏的状态不变性。假设系统处于任一中间时刻，文本串指针 iii 与模式串指针 jjj 正在执行比对，且在当前时刻之前均处于匹配状态。根据算法推进逻辑，必然存在以下区间等式：T[i−j,i)==P[0,j)T[i-j, i) == P[0, j)T[i−j,i)==P[0,j)。

这一不变量宣告了一个核心事实：系统实际上已经完全掌握了文本串自 i−ji-ji−j 始直至 i−1i-1i−1 终的所有字符信息。这段长度为 jjj 的文本片段，在内容上与模式串的前缀 P[0,j)P[0, j)P[0,j) 具有完全一致的序列结构。蛮力算法的缺陷恰恰在于，在遇到失配点后，它清空了这段通过密集计算获取的等值记忆，使得随后的对齐测试沦为盲目的试错。

基于上述信息重用理论，一旦在 T[i]T[i]T[i] 与 P[j]P[j]P[j] 处发生比对失败，理想的策略应当是维持文本流的前进性，即指针 iii 绝不执行减法回退操作。取而代之的是，利用已经获取的相同区间信息，在模式串内部寻找一个新的指针刻度 ttt。该刻度需要满足模式串的更短前缀 P[0,t)P[0, t)P[0,t) 能够无缝对接当前已知的文本后缀。由于已知的文本后缀等价于已知的模式串后缀，这一机制成功将跨字符串的比对问题，转化为了模式串内部自身前后缀特征的预分析问题。

为了使 iii 永远不必回退，算法需要具备“过目不忘”的决策能力。当比对成功时，系统正常消耗一个输入字符，双指针同步向右递增。当在 P[j]P[j]P[j] 处发生失配时，系统不再复位 iii，而是将模式串指针 jjj 更新为某一个更小的值 ttt，随后直接比较 T[i]T[i]T[i] 与新的 P[t]P[t]P[t]。

确定此状态变量 ttt 的过程可以脱离实时的文本内容，仅依据模式串的前缀性质在离线阶段进行预处理。无论失败发生在哪一个具体的物理位置 jjj，系统均可通过查询预设的一维状态转移表 next[0, m) 来获取新的备选位置。该表的元素 next[j] 存储了在第 jjj 位失配时，模式串应跳转的下一个有效状态。这种通过空间换取时间的结构减少了重复扫描，使模式串在失配时可以向右移动多个位置。

next[j] 不是“下一位要比较谁”，而是“当模式串第 j 位失配时，已经匹配的前 j 个字符最多还能保留多少个”。文本指针 iii 不回退，模式串指针 jjj 回退到 next[j]，等价于把模式串整体右移，但不重新读取文本中已经确认过的字符。

边界集合与失效函数

算法有效运转的根基在于底层状态数组的精确建立。为了赋予 next[j] 严格的数学定义，需要对模式串的子串特征进行提取。定义任意字符位 jjj 的边界集合为 N(P,j)N(P, j)N(P,j)，它包含了所有使得模式串从索引 000 开始的前缀能够与其在 jjj 结尾的后缀完全相等的非负长度 ttt：∀j≥1,N(P,j)={0≤t<j∣P[0,t)=P[j−t,j)}\forall j \ge 1, \quad N(P, j) = \{ 0 \le t < j \mid P[0, t) = P[j-t, j) \}∀j≥1,N(P,j)={0≤t<j∣P[0,t)=P[j−t,j)}。

这个集合代表了所有可能的合法重合尺度。为了使模式串在失配时整体右移的幅度最小，从而杜绝漏过任何潜在正确匹配位的可能，必须选取该集合中的最大元素作为后续的对齐指导参数：next[j]=max⁡{N(P,j)}next[j] = \max \{ N(P, j) \}next[j]=max{N(P,j)}。为使递归边界完整，设定特解 next[0]=−1next[0] = -1next[0]=−1。

直接利用朴素算法计算所有前缀的边界集合将会产生较高的时间复杂度。但是，由于 N(P,j)N(P, j)N(P,j) 的结构依赖于字符串的线性延续性，其内部存在递归传递关系。

问题的复杂性在于，如果 P[j]≠P[t]P[j] \ne P[t]P[j]=P[t] 该如何处理？此时需要寻找一个更短的备选边界。根据集合对等的原则，由于已有 P[0,t)==P[j−t,j)P[0, t) == P[j-t, j)P[0,t)==P[j−t,j) 成立，寻找当前序列更短边界的任务，完全等价于在前缀串 P[0,t)P[0, t)P[0,t) 本身内部去寻找它的最大边界。于是，将测试目标缩小为 next[t]next[t]next[t]，并再次评估新的 P[next[t]]P[next[t]]P[next[t]] 与 P[j]P[j]P[j] 的相等性。这一循环下探的过程构成了“减而治之”的核心逻辑。在此阶段，由于所处理的双方均源自模式串自身，因此整个过程被称作模式串对其自身的“自匹配”操作。

构造 next 时，变量 j 相当于“正在扩展的后缀末端”，变量 t 相当于“当前候选前缀长度”。如果 P[j] 和 P[t] 能接上，边界长度就增加；如果接不上，就把候选长度缩短为 next[t]。这和匹配阶段失配时缩短 j 是同一套思想，只不过此时文本串换成了模式串自己。

在直观视觉上，KMP 算法的匹配模块包含着一层嵌套的 while 循环结构。考虑到每一个文本字符在匹配过程中都可能遭遇 O(m)\mathcal{O}(m)O(m) 级别的反复 next 查表回退（由黄色的模式状态指针退避造成），倘若文本中有 nnn 个位置，是否意味着最坏情况下渐近复杂度仍将退化回 Ω(n⋅m)\Omega(n \cdot m)Ω(n⋅m)？

  1. 成功匹配分支： 当 0>j0 > j0>j 或 T[i]==P[j]T[i] == P[j]T[i]==P[j] 成立时，执行语句 i++; j++;。在此状态转移下，新势能等于 2(i+1)−(j+1)=2i−j+12(i+1) - (j+1) = 2i - j + 12(i+1)−(j+1)=2i−j+1。较原势能 kkk，增量严格为 +1+1+1。
  2. 失配回退分支： 当触发 j = next[j] 时，由于文本指针 iii 被强制锁定不变，且根据底层结构定义，下一跳状态必定小于当前状态（next[j]<jnext[j] < jnext[j]<j）。因此减数项 jjj 缩小，导致总体势能 2i−j2i - j2i−j 必然增大。且由于 jjj 均为整数，其增量至少为 +1+1+1。

由此得出确凿结论：无论运行在哪一条执行链路中，系统内部虚拟监控变量 kkk 均伴随迭代而保持单调递增。由于算法在起始点赋值 k=2⋅0−0=0k = 2 \cdot 0 - 0 = 0k=2⋅0−0=0。当算法触发外层边界条件终止时，物理指针受到最大容量约束：文本游标极大值为 n−1n-1n−1，模式串回退极小值为 −1-1−1。此时的全局势能上界为：kmax=2⋅i−j≤2(n−1)−(−1)=2n−1k_{max} = 2 \cdot i - j \le 2(n-1) - (-1) = 2n - 1kmax​=2⋅i−j≤2(n−1)−(−1)=2n−1。

因为势能 kkk 在单次循环中至少增加 111，且总势能上限不能超过 2n−12n-12n−1，这限定了主 while 循环的总执行轮数不超过 O(n)\mathcal{O}(n)O(n)。同理，基于相同的减而治之逻辑，构造 next 数组的总迭代步数被限制在 O(m)\mathcal{O}(m)O(m)。两部分独立串行，因此全局最差时间复杂度为 O(n+m)\mathcal{O}(n+m)O(n+m)。
