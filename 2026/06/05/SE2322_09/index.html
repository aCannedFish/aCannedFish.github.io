前缀与后缀

字符串是线性连续的数据序列。为避免索引歧义，通常用半开半闭区间 [i,j)[i, j)[i,j) 表示字符串片段，其中包含起始索引 iii，不包含终止索引 jjj。

字符串抽象数据类型（ADT）提供标准操作接口，支持属性获取、子串截取、拼接和模式搜索等操作。

字符串匹配

循模式访问

模式匹配算法的性能依赖输入分布。设文本串 TTT 长度为 nnn，模式串 PPP 长度为 mmm。典型场景通常满足 2≪m≪n2 \ll m \ll n2≪m≪n，即模式串有一定长度但远短于文本。

对该过程进行随机性建模，假定可用字符集的规模为 s=∣Σ∣s = |\Sigma|s=∣Σ∣。在文本串与模式串均为随机独立生成的条件下，任意两个单一字符比对成功的概率为 s−1s^{-1}s−1。当要求模式串整体对齐时，连续 mmm 个字符均能顺利匹配的先验概率 PrmatchPr_{match}Prmatch​ 会呈现指数级衰减，近似等价于 n⋅s−mn \cdot s^{-m}n⋅s−m。随着字符集 sss 的增大或模式长度 mmm 的增加，该概率值 PrmatchPr_{match}Prmatch​ 迅速趋近于 000。

这一概率特性说明：大多数对齐位置会在较早字符处失配。因此，优化重点不是加速少数成功匹配，而是低成本处理大量失配，并尽量增加下一次尝试的位移。

蛮力匹配

最直接的方案是蛮力匹配：将模式串起点依次与文本串各位置对齐并逐字检查。一旦字符失配，就判定当前对齐无效，将模式串右移一位并重新比较。

第二种实现形式使用标准的双层嵌套循环，外层负责穷举对齐点，内层负责验证。

时空复杂度

蛮力策略只依赖标量游标，空间复杂度为 O(1)\mathcal{O}(1)O(1)。时间复杂度取决于字符序列：最优情况下，模式串首字符很少匹配文本，内层比较很快结束，整体接近 Ω(n)\Omega(n)Ω(n)；最坏情况下，文本和模式串存在大量相同前缀，只在末尾失配，每次对齐都会重复扫描较长片段，复杂度退化为 O(n⋅m)\mathcal{O}(n \cdot m)O(n⋅m)。在大规模文本流中，文本指针回退还会破坏顺序读取。

KMP 算法

状态不变性

要突破二次复杂度，需要利用扫描过程中的状态不变性。假设某一时刻文本指针 iii 与模式指针 jjj 正在比较，且此前 jjj 个字符均已匹配，则有区间等式：T[i−j,i)==P[0,j)T[i-j, i) == P[0, j)T[i−j,i)==P[0,j)。

该不变量表示：算法已经知道文本片段 T[i−j,i)T[i-j, i)T[i−j,i) 与模式串前缀 P[0,j)P[0, j)P[0,j) 完全相同。蛮力算法的问题在于，失配后丢弃了这段已知信息，并从下一个对齐位置重新试错。

一旦 T[i]T[i]T[i] 与 P[j]P[j]P[j] 失配，理想策略是保持文本指针 iii 不回退，只在模式串内部寻找新的位置 ttt。该位置需要满足更短前缀 P[0,t)P[0, t)P[0,t) 可以对接当前已知文本后缀。由于已知文本后缀等价于模式串后缀，问题转化为模式串内部前后缀性质的预处理。

为避免 iii 回退，匹配成功时双指针同步右移；在 P[j]P[j]P[j] 处失配时，不复位 iii，而是将模式串指针 jjj 更新为更小的 ttt，然后比较 T[i]T[i]T[i] 与新的 P[t]P[t]P[t]。

状态变量 ttt 可以只根据模式串前缀性质离线预处理得到。无论失配发生在位置 jjj，都可查询一维状态转移表 next[0, m) 获取新位置。next[j] 表示第 jjj 位失配时模式串应跳转到的有效状态。该表用额外空间减少重复扫描，使模式串在失配时可一次右移多个位置。

next[j] 不是“下一位要比较谁”，而是“当模式串第 j 位失配时，已经匹配的前 j 个字符最多还能保留多少个”。文本指针 iii 不回退，模式串指针 jjj 回退到 next[j]，等价于把模式串整体右移，但不重新读取文本中已经确认过的字符。

模式串与 DFA

KMP 可将每个模式串等效编译为一个确定性有限自动机（DFA）。模式串决定状态机结构，状态数为模式串长度加一，转移由输入字符控制。

失效函数

KMP 的关键在于准确构造状态数组。定义位置 jjj 的边界集合 N(P,j)N(P, j)N(P,j)：它包含所有使模式串前缀 P[0,t)P[0,t)P[0,t) 与以 jjj 结尾的后缀 P[j−t,j)P[j-t,j)P[j−t,j) 相等的非负长度 ttt：∀j≥1,N(P,j)={0≤t<j∣P[0,t)=P[j−t,j)}\forall j \ge 1, \quad N(P, j) = \{ 0 \le t < j \mid P[0, t) = P[j-t, j) \}∀j≥1,N(P,j)={0≤t<j∣P[0,t)=P[j−t,j)}。

该集合表示所有合法重合长度。为避免漏过潜在匹配，需要选择其中最大元素作为回退位置：next[j]=max⁡{N(P,j)}next[j] = \max \{ N(P, j) \}next[j]=max{N(P,j)}。边界条件设为 next[0]=−1next[0] = -1next[0]=−1。

若直接用朴素方法计算所有前缀的边界集合，复杂度较高。由于 N(P,j)N(P, j)N(P,j) 依赖字符串线性延续性，可以利用递归传递关系优化。

假定已知当前序列在第 jjj 位的最长边界为 t=next[j]t = next[j]t=next[j]。这意味着 P[0,t)=P[j−t,j)P[0, t) = P[j-t, j)P[0,t)=P[j−t,j)。随后考察下一位字符。如果 P[j]==P[t]P[j] == P[t]P[j]==P[t]，那么原有的前后缀相等关系可以向右无缝延伸一个单位。此时必然得出递推等式：next[j+1]=next[j]+1next[j+1] = next[j] + 1next[j+1]=next[j]+1。

若 P[j]≠P[t]P[j] \ne P[t]P[j]=P[t]，需要寻找更短的候选边界。由于已有 P[0,t)==P[j−t,j)P[0, t) == P[j-t, j)P[0,t)==P[j−t,j)，寻找当前序列更短边界等价于在前缀串 P[0,t)P[0, t)P[0,t) 内寻找最大边界。因此将候选长度缩短为 next[t]next[t]next[t]，并继续比较新的 P[next[t]]P[next[t]]P[next[t]] 与 P[j]P[j]P[j]。该过程称为模式串的自匹配。

构造 next 时，变量 j 相当于“正在扩展的后缀末端”，变量 t 相当于“当前候选前缀长度”。如果 P[j] 和 P[t] 能接上，边界长度就增加；如果接不上，就把候选长度缩短为 next[t]。这和匹配阶段失配时缩短 j 是同一套思想，只不过此时文本串换成了模式串自己。

复杂度分析

KMP 主循环中可能出现多次 next 回退，因此需要证明整体不会退化到 Ω(n⋅m)\Omega(n \cdot m)Ω(n⋅m)。

定义势函数 k=2⋅i−jk = 2 \cdot i - jk=2⋅i−j，分析循环分支对 kkk 的影响：

  1. 成功匹配分支： 当 0>j0 > j0>j 或 T[i]==P[j]T[i] == P[j]T[i]==P[j] 成立时，执行语句 i++; j++;。在此状态转移下，新势能等于 2(i+1)−(j+1)=2i−j+12(i+1) - (j+1) = 2i - j + 12(i+1)−(j+1)=2i−j+1。较原势能 kkk，增量严格为 +1+1+1。
  2. 失配回退分支： 当触发 j = next[j] 时，文本指针 iii 保持不变，且根据底层结构定义，下一跳状态必定小于当前状态（next[j]<jnext[j] < jnext[j]<j）。因此减数项 jjj 缩小，导致总体势能 2i−j2i - j2i−j 必然增大。由于 jjj 为整数，其增量至少为 +1+1+1。
