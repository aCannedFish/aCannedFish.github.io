分数函数

Why Score Function?

流匹配通过学习向量场训练流模型；扩散模型通常使用 分数函数 Score Function 描述分布局部结构。

对分类器而言，可用 Softmax 将非归一化分数归一化为概率。一般可写作 p(x)=p~(x)Zp(x) = \frac{\tilde{p}(x)}{Z}p(x)=Zp~​(x)​，其中 p~(x)\tilde{p}(x)p~​(x) 是非归一化模型，Z=∫p~(x)dxZ = \int \tilde{p}(x) dxZ=∫p~​(x)dx 是配分函数。

扩散模型需要处理整张图像的高维连续分布，直接计算配分函数 ZZZ 等价于对高维状态空间积分，通常不可行。

分数函数用于绕过配分函数计算。

分数函数的定义

对于任何概率分布 q(x)q(x)q(x)，其分数函数被定义为该分布对数似然函数对空间坐标的梯度，即：

s(x)=∇xlog⁡q(x)s(x) = \nabla_x \log q(x) s(x)=∇x​logq(x)

它是 xxx 处对数似然的梯度。由于配分函数 ZZZ 与 xxx 无关，∇xlog⁡p(x)=∇xlog⁡p~(x)−∇xlog⁡Z=∇xlog⁡p~(x)\nabla_x \log p(x) = \nabla_x \log \tilde{p}(x) - \nabla_x \log Z = \nabla_x \log \tilde{p}(x)∇x​logp(x)=∇x​logp~​(x)−∇x​logZ=∇x​logp~​(x)，因此无需显式计算 ZZZ。

分数函数在数据空间中定义向量场，方向指向概率密度上升最快处。扩散模型学习该向量场，用于指导噪声样本向数据分布演化。

条件分数函数与边缘分数函数

扩散模型和流匹配都使用时间参数 ttt 控制概率路径。路径从 pinitp_{init}pinit​ 演化到 pdatap_{data}pdata​，对应两类分数：条件分数函数和边缘分数函数。

定义与演化

令 δz\delta_zδz​ 表示集中在真实数据点 z∈Rdz \in \mathbb{R}^dz∈Rd 的狄拉克分布。条件概率路径 pt(x∣z)p_t(x|z)pt​(x∣z) 描述单个数据点的加噪/去噪分布，满足 p0(⋅∣z)=pinitp_0(\cdot|z) = p_{init}p0​(⋅∣z)=pinit​ 与 p1(⋅∣z)=δzp_1(\cdot|z) = \delta_zp1​(⋅∣z)=δz​。对应的条件分数函数为 ∇log⁡pt(x∣z)\nabla \log p_t(x|z)∇logpt​(x∣z)。

边缘概率路径 pt(x)p_t(x)pt​(x) 是条件路径对 pdata(z)p_{data}(z)pdata​(z) 的边缘化结果，即 pt(x)=∫pt(x∣z)pdata(z)dzp_t(x) = \int p_t(x|z)p_{data}(z) dzpt​(x)=∫pt​(x∣z)pdata​(z)dz。边缘分数函数为 ∇log⁡pt(x)\nabla \log p_t(x)∇logpt​(x)。

边缘分布函数的导出

目标是用可计算的条件分数表示边缘分数。推导如下：

由对数求导法则：

∇log⁡pt(x)=∇pt(x)pt(x)\nabla \log p_t(x) = \frac{\nabla p_t(x)}{p_t(x)} ∇logpt​(x)=pt​(x)∇pt​(x)​

代入边缘分布 pt(x)=∫pt(x∣z)pdata(z)dzp_t(x) = \int p_t(x|z)p_{data}(z) dzpt​(x)=∫pt​(x∣z)pdata​(z)dz，并将对 xxx 的梯度移入积分：

∇log⁡pt(x)=∇∫pt(x∣z)pdata(z)dzpt(x)=∫∇pt(x∣z)pdata(z)dzpt(x)\nabla \log p_t(x) = \frac{\nabla \int p_t(x|z)p_{data}(z) dz}{p_t(x)} = \frac{\int \nabla p_t(x|z) p_{data}(z) dz}{p_t(x)} ∇logpt​(x)=pt​(x)∇∫pt​(x∣z)pdata​(z)dz​=pt​(x)∫∇pt​(x∣z)pdata​(z)dz​

利用 ∇pt(x∣z)=pt(x∣z)∇log⁡pt(x∣z)\nabla p_t(x|z) = p_t(x|z) \nabla \log p_t(x|z)∇pt​(x∣z)=pt​(x∣z)∇logpt​(x∣z)：

∇log⁡pt(x)=∫[pt(x∣z)∇log⁡pt(x∣z)]pdata(z)dzpt(x)\nabla \log p_t(x) = \frac{\int \left[ p_t(x|z) \nabla \log p_t(x|z) \right] p_{data}(z) dz}{p_t(x)} ∇logpt​(x)=pt​(x)∫[pt​(x∣z)∇logpt​(x∣z)]pdata​(z)dz​

重排得：

∇log⁡pt(x)=∫∇log⁡pt(x∣z)pt(x∣z)pdata(z)pt(x)dz\nabla \log p_t(x) = \int \nabla \log p_t(x|z) \frac{p_t(x|z)p_{data}(z)}{p_t(x)} dz ∇logpt​(x)=∫∇logpt​(x∣z)pt​(x)pt​(x∣z)pdata​(z)​dz

权重 pt(x∣z)pdata(z)pt(x)\frac{p_t(x|z)p_{data}(z)}{p_t(x)}pt​(x)pt​(x∣z)pdata​(z)​ 是后验分布 pt(z∣x)p_t(z|x)pt​(z∣x)。因此，边缘分数是条件分数在后验分布下的期望。

高斯路径

条件分数函数

设噪声调度函数 αt,βt\alpha_t,\beta_tαt​,βt​ 满足 α0=0,β0=1\alpha_0=0, \beta_0=1α0​=0,β0​=1 与 α1=1,β1=0\alpha_1=1, \beta_1=0α1​=1,β1​=0。高斯条件路径为：

pt(x∣z)=N(x;αtz,βt2Id)p_t(x|z) = \mathcal{N}(x; \alpha_t z, \beta_t^2 I_d) pt​(x∣z)=N(x;αt​z,βt2​Id​)

对多维高斯密度取对数并对 xxx 求梯度，得到条件分数：

∇log⁡pt(x∣z)=∇x[−d2log⁡(2πβt2)−12βt2∥x−αtz∥2]=−x−αtzβt2\nabla \log p_t(x|z) = \nabla_x \left[ -\frac{d}{2} \log(2\pi\beta_t^2) - \frac{1}{2\beta_t^2} \|x - \alpha_t z\|^2 \right] = -\frac{x - \alpha_t z}{\beta_t^2} ∇logpt​(x∣z)=∇x​[−2d​log(2πβt2​)−2βt2​1​∥x−αt​z∥2]=−βt2​x−αt​z​

条件分数关于 xxx 与 zzz 线性，方向指向 αtz\alpha_t zαt​z。方差 βt2\beta_t^2βt2​ 越大，分数幅度越小；方差趋近于 0 时，分数幅度增大。

向量场与分数函数的数学等价性：高斯路径下，流匹配的目标向量场与扩散模型的分数函数存在线性转换。条件向量场为：

uttarget(x∣z)=(α˙t−β˙tβtαt)z+β˙tβtxu_t^{target}(x|z) = \left( \dot{\alpha}_t - \frac{\dot{\beta}_t}{\beta_t} \alpha_t \right) z + \frac{\dot{\beta}_t}{\beta_t} x uttarget​(x∣z)=(α˙t​−βt​β˙​t​​αt​)z+βt​β˙​t​​x

定义时间系数：

at=βt2α˙tαt−β˙tβta_t = \beta_t^2 \frac{\dot{\alpha}_t}{\alpha_t} - \dot{\beta}_t \beta_t at​=βt2​αt​α˙t​​−β˙​t​βt​

uttarget(x∣z)=(βt2α˙tαt−β˙tβt)(αtz−xβt2)+α˙tαtxu_t^{target}(x|z) = \left( \beta_t^2 \frac{\dot{\alpha}_t}{\alpha_t} - \dot{\beta}_t \beta_t \right) \left( \frac{\alpha_t z - x}{\beta_t^2} \right) + \frac{\dot{\alpha}_t}{\alpha_t} x uttarget​(x∣z)=(βt2​αt​α˙t​​−β˙​t​βt​)(βt2​αt​z−x​)+αt​α˙t​​x

由于 at,bta_t,b_tat​,bt​ 只依赖时间，边缘化后有：

uttarget(x)=at∇log⁡pt(x)+btxu_t^{target}(x) = a_t \nabla \log p_t(x) + b_t x uttarget​(x)=at​∇logpt​(x)+bt​x

因此，在高斯路径下，学习边缘目标向量场与学习边缘分数函数等价。

Denoiser 重参数化

由上述线性关系可得到 去噪器 Denoiser 视角。定义边缘去噪器为后验均值：

Dt(x)=∫zpt(x∣z)pdata(z)pt(x)dz=Ez∣x[z]D_t(x) = \int z \frac{p_t(x|z)p_{data}(z)}{p_t(x)} dz = \mathbb{E}_{z|x}[z] Dt​(x)=∫zpt​(x)pt​(x∣z)pdata​(z)​dz=Ez∣x​[z]

预测 Dt(x)D_t(x)Dt​(x) 后即可恢复无条件向量场和分数函数。工程上常预测原始图像或噪声残差，而不是直接预测分数，因为纯噪声阶段的分数模长可能很大，数值稳定性较差。

基于 SDE 的概率采样

扩散模型使用 SDE 采样，在确定性向量场外加入随机噪声，并通过分数项控制分布演化。

SDE Extension Trick

SDE Extension Trick：在确定性 ODE 轨迹中加入随机扰动，同时保持任意时刻的边缘分布仍为 pt(x)p_t(x)pt​(x)。

对任意时间依赖扩散系数 σt≥0\sigma_t \ge 0σt​≥0，构造 SDE：

dXt=[uttarget(Xt)+σt22∇log⁡pt(Xt)]dt+σtdWtdX_t = \left[ u_t^{target}(X_t) + \frac{\sigma_t^2}{2} \nabla \log p_t(X_t) \right] dt + \sigma_t dW_t dXt​=[uttarget​(Xt​)+2σt2​​∇logpt​(Xt​)]dt+σt​dWt​

初始条件为 X0∼pinitX_0 \sim p_{init}X0​∼pinit​。其中 σtdWt\sigma_t dW_tσt​dWt​ 注入布朗噪声，会扩散分布；σt22∇log⁡pt(Xt)\frac{\sigma_t^2}{2} \nabla \log p_t(X_t)2σt2​​∇logpt​(Xt​) 则沿密度上升方向补偿该扩散，使宏观边缘分布仍沿目标路径演化。

Fokker-Planck 方程

可用 Fokker-Planck 方程证明上述 SDE 的边缘分布确实为 pt(x)p_t(x)pt​(x)。FPE 描述 Ito SDE 所诱导的概率密度随时间演化。

对一般 Ito SDE：dXt=μt(Xt)dt+σtdWtdX_t = \mu_t(X_t) dt + \sigma_t dW_tdXt​=μt​(Xt​)dt+σt​dWt​，对应 FPE 为：

∂tpt(x)=−∇⋅(pt(x)μt(x))+σt22Δpt(x)\partial_t p_t(x) = -\nabla \cdot (p_t(x) \mu_t(x)) + \frac{\sigma_t^2}{2} \Delta p_t(x) ∂t​pt​(x)=−∇⋅(pt​(x)μt​(x))+2σt2​​Δpt​(x)

它包含两项：

  1. 对流/漂移分量 Drift Term [−∇⋅(ptμt)-\nabla \cdot (p_t \mu_t)−∇⋅(pt​μt​)]：对应确定性向量场对概率质量的搬运。
  2. 扩散分量 Diffusion Term [σt22Δpt(x)\frac{\sigma_t^2}{2} \Delta p_t(x)2σt2​​Δpt​(x)]：对应布朗噪声引起的密度扩散，形式类似热方程。

将 SDE Extension Trick 中的漂移项代入 FPE：

μt(x)=uttarget(x)+σt22∇log⁡pt(x)\mu_t(x) = u_t^{target}(x) + \frac{\sigma_t^2}{2} \nabla \log p_t(x) μt​(x)=uttarget​(x)+2σt2​​∇logpt​(x)

计算对流项：

−∇⋅(pt(uttarget+σt22∇log⁡pt))-\nabla \cdot \left( p_t \left( u_t^{target} + \frac{\sigma_t^2}{2} \nabla \log p_t \right) \right) −∇⋅(pt​(uttarget​+2σt2​​∇logpt​))

展开散度：

=−∇⋅(ptuttarget)−σt22∇⋅(pt∇log⁡pt)= -\nabla \cdot (p_t u_t^{target}) - \frac{\sigma_t^2}{2} \nabla \cdot (p_t \nabla \log p_t) =−∇⋅(pt​uttarget​)−2σt2​​∇⋅(pt​∇logpt​)

由 ∇log⁡pt=∇ptpt\nabla \log p_t = \frac{\nabla p_t}{p_t}∇logpt​=pt​∇pt​​，有 pt∇log⁡pt=∇ptp_t \nabla \log p_t = \nabla p_tpt​∇logpt​=∇pt​，因此第二项为：

−σt22∇⋅(∇pt)=−σt22Δpt-\frac{\sigma_t^2}{2} \nabla \cdot (\nabla p_t) = -\frac{\sigma_t^2}{2} \Delta p_t −2σt2​​∇⋅(∇pt​)=−2σt2​​Δpt​

漂移项贡献为：

−∇⋅(ptuttarget)−σt22Δpt-\nabla \cdot (p_t u_t^{target}) - \frac{\sigma_t^2}{2} \Delta p_t −∇⋅(pt​uttarget​)−2σt2​​Δpt​

代回 FPE：

∂tpt=(−∇⋅(ptuttarget)−σt22Δpt)+σt22Δpt\partial_t p_t = \left( -\nabla \cdot (p_t u_t^{target}) - \frac{\sigma_t^2}{2} \Delta p_t \right) + \frac{\sigma_t^2}{2} \Delta p_t ∂t​pt​=(−∇⋅(pt​uttarget​)−2σt2​​Δpt​)+2σt2​​Δpt​

扩散项与分数补偿项抵消，剩下：

∂tpt=−∇⋅(ptuttarget)\partial_t p_t = -\nabla \cdot (p_t u_t^{target}) ∂t​pt​=−∇⋅(pt​uttarget​)

这就是纯 ODE 流模型的连续性方程。因此，该 SDE 与目标 ODE 具有相同的边缘分布演化；随机性只改变样本路径，不改变宏观概率路径。

Langevin Dynamics

若目标分布不随时间变化，即 pt=pp_t=ppt​=p 且 ∂tpt=0\partial_t p_t=0∂t​pt​=0，则目标向量场可取 uttarget=0u_t^{target}=0uttarget​=0。

代入 SDE Extension Trick：

dXt=σt22∇log⁡p(Xt)dt+σtdWtdX_t = \frac{\sigma_t^2}{2} \nabla \log p(X_t) dt + \sigma_t dW_t dXt​=2σt2​​∇logp(Xt​)dt+σt​dWt​

该式为 过阻尼朗之万方程 Overdamped Langevin Equation。在 MCMC 和分子动力学中，它用于采样复杂平稳分布。若满足遍历性条件，过程最终收敛到目标分布 ppp。早期基于分数的生成模型也利用朗之万步骤进行降噪采样。

分数匹配

ODE/SDE 采样都需要边缘分数 ∇log⁡pt(x)\nabla \log p_t(x)∇logpt​(x)，但该量依赖未知的 pdatap_{data}pdata​。因此需要训练分数网络 stθ:Rd×→Rds_t^\theta: \mathbb{R}^d \times \rightarrow \mathbb{R}^dstθ​:Rd×→Rd 来近似它。

显式分数匹配

最直接的方法是最小化预测分数与真实边缘分数的距离，称为 显式分数匹配 Explicit Score Matching：

LSM(θ)=Et∼Unif,x∼pt[∥stθ(x)−∇log⁡pt(x)∥2]\mathcal{L}_{SM}(\theta) = \mathbb{E}_{t \sim Unif, x \sim p_t} \left[ \| s_t^\theta(x) - \nabla \log p_t(x) \|^2 \right] LSM​(θ)=Et∼Unif,x∼pt​​[∥stθ​(x)−∇logpt​(x)∥2]

该损失的问题是：一方面需要未知的 ∇log⁡pt(x)\nabla \log p_t(x)∇logpt​(x)；另一方面，即便通过积分分部消去显式依赖，低密度区域的分数估计仍不稳定。

去噪分数匹配

去噪分数匹配 Denoising Score Matching 将目标从未知边缘分数转为已知条件分数。

定义条件去噪分数匹配损失：

LCSM(θ)=Et∼Unif,z∼pdata,x∼pt(⋅∣z)[∥stθ(x)−∇log⁡pt(x∣z)∥2]\mathcal{L}_{CSM}(\theta) = \mathbb{E}_{t \sim Unif, z \sim p_{data}, x \sim p_t(\cdot|z)} \left[ \| s_t^\theta(x) - \nabla \log p_t(x|z) \|^2 \right] LCSM​(θ)=Et∼Unif,z∼pdata​,x∼pt​(⋅∣z)​[∥stθ​(x)−∇logpt​(x∣z)∥2]

这里先采样真实数据 zzz 和时间 ttt，再由已知条件路径采样 xxx。目标 ∇log⁡pt(x∣z)\nabla \log p_t(x|z)∇logpt​(x∣z) 可计算，高斯路径下有闭式解。

核心结论：

边缘分数匹配损失等同于去噪分数匹配损失加上一个常数项，即 LSM(θ)=LCSM(θ)+C\mathcal{L}_{SM}(\theta) = \mathcal{L}_{CSM}(\theta) + CLSM​(θ)=LCSM​(θ)+C。

两者对 θ\thetaθ 的梯度相同，因此最小化 LCSM\mathcal{L}_{CSM}LCSM​ 等价于优化不可直接计算的 LSM\mathcal{L}_{SM}LSM​。关键在于处理 LSM\mathcal{L}_{SM}LSM​ 展开后的交叉项。

利用贝叶斯重排公式 ∇log⁡pt(x)=∫∇log⁡pt(x∣z)pt(x∣z)pdata(z)pt(x)dz\nabla \log p_t(x) = \int \nabla \log p_t(x|z) \frac{p_t(x|z)p_{data}(z)}{p_t(x)} dz∇logpt​(x)=∫∇logpt​(x∣z)pt​(x)pt​(x∣z)pdata​(z)​dz：

∫01∫xpt(x)⋅stθ(x)T⋅[∫z∇log⁡pt(x∣z)pt(x∣z)pdata(z)pt(x)dz]dxdt\int_0^1 \int_x p_t(x) \cdot s_t^\theta(x)^T \cdot \left[ \int_z \nabla \log p_t(x|z) \frac{p_t(x|z)p_{data}(z)}{p_t(x)} dz \right] dx dt ∫01​∫x​pt​(x)⋅stθ​(x)T⋅[∫z​∇logpt​(x∣z)pt​(x)pt​(x∣z)pdata​(z)​dz]dxdt

外层 pt(x)p_t(x)pt​(x) 与后验表达式分母抵消，得到：

∫01∫x∫zstθ(x)T∇log⁡pt(x∣z)pt(x∣z)pdata(z)dzdxdt\int_0^1 \int_x \int_z s_t^\theta(x)^T \nabla \log p_t(x|z) p_t(x|z) p_{data}(z) dz dx dt ∫01​∫x​∫z​stθ​(x)T∇logpt​(x∣z)pt​(x∣z)pdata​(z)dzdxdt

这正是联合分布下的期望：Et∼Unif,z∼pdata,x∼pt(⋅∣z)\mathbb{E}_{t \sim Unif, z \sim p_{data}, x \sim p_t(\cdot|z)}Et∼Unif,z∼pdata​,x∼pt​(⋅∣z)​

展开平方项后，剩余差异只是不依赖 θ\thetaθ 的常数 CCC。因此，用条件分数训练即可得到边缘分数的最优估计。

DDPM

DDPM 是去噪分数匹配的工程化形式。考虑高斯条件路径 pt(x∣z)=N(x;αtz,βt2Id)p_t(x|z) = \mathcal{N}(x; \alpha_t z, \beta_t^2 I_d)pt​(x∣z)=N(x;αt​z,βt2​Id​)。

条件分数为 −x−αtzβt2-\frac{x - \alpha_t z}{\beta_t^2}−βt2​x−αt​z​。含噪样本通过重参数化得到：x=αtz+βtϵx = \alpha_t z + \beta_t \epsilonx=αt​z+βt​ϵ，其中 ϵ∼N(0,Id)\epsilon \sim \mathcal{N}(0, I_d)ϵ∼N(0,Id​)。

代入条件分数：
