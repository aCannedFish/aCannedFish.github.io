Surflo: Consistent 3D Surface Flow Model with Global State

发表于2026-07-23|更新于2026-08-05|Note读论文：三维重建
|浏览量:

前面的表示方法各有一组耦合关系：VGGT 的输出点数与输入图像像素数耦合，NOVA3R 的全局 token 数固定且主要训练在特定点数上，VolFill 的空间范围和精度与 2563256^32563 网格耦合。Surflo 希望同时满足两个条件：输入图像数量 NNN 可变，输出表面点数量 PPP 也可变。

它把系统拆成两个相对独立的部分：

{In}n=1N→Eϕz∈RK×D→vθ{(mp,np)}p=1P\{I_n\}_{n=1}^{N} \xrightarrow{E_{\phi}} z\in\mathbb{R}^{K\times D} \xrightarrow{v_{\theta}} \{(\mathbf{m}_p,\mathbf{n}_p)\}_{p=1}^{P} {In​}n=1N​Eϕ​​z∈RK×Dvθ​​{(mp​,np​)}p=1P​

无论输入 2 张还是 32 张图，场景始终压缩为 K=128K=128K=128 个 token；无论输出 8K、100K 还是一百万个点，都复用同一个 zzz，只改变查询数 PPP。

全局状态

编码器先使用冻结的 VGGT-1B。对于每张图，Surflo 读取第 ℓ∈{4,11,17,23}\ell\in\{4,11,17,23\}ℓ∈{4,11,17,23} 层的 patch token 和 camera token。不同层分别包含较低层的局部纹理、中层的匹配关系和高层的场景几何，将四层特征拼接后投影到 D=512D=512D=512：

Tn=Proj⁡ ⁣([Tn(4),Tn(11),Tn(17),Tn(23)])T_n=\operatorname{Proj}\!\left( [T_n^{(4)},T_n^{(11)},T_n^{(17)},T_n^{(23)}] \right) Tn​=Proj([Tn(4)​,Tn(11)​,Tn(17)​,Tn(23)​])

仅有视觉 token 时，解码器不知道某个 token 对应三维空间的哪个位置。Surflo 读取 VGGT point map 中每个 patch 中心的三维坐标 pnp_npn​，计算 Gaussian Fourier Features：

γ(p)=[sin⁡(2πBp),cos⁡(2πBp)]\gamma(\mathbf{p}) =\left[ \sin(2\pi B\mathbf{p}), \cos(2\pi B\mathbf{p}) \right] γ(p)=[sin(2πBp),cos(2πBp)]

BBB 的频率跨 16 个尺度采样，总特征维数为 512。位置先按场景的中位点和中位距离归一化，再与 patch token 相加：

Tˉn=Tn+γ(pn)\bar T_n=T_n+\gamma(p_n) Tˉn​=Tn​+γ(pn​)

解码器查询也使用完全相同的 γ\gammaγ。因此，一个查询点与附近图像 patch 的 Fourier feature 天然相似，cross-attention 可以通过空间邻近读取信息，不必为每个场景重新猜测 VGGT 坐标系与查询坐标的关系。

设当前待解码的三维查询位置为 xxx，其内容特征为 hxh_xhx​；某个图像 patch 的视觉特征与三维位置分别为 Tp,pT_p,pTp​,p。两侧输入 attention 的 token 可抽象为：

qx=hx+γ(x),kp=Tp+γ(p).q_x=h_x+\gamma(x),\qquad k_p=T_p+\gamma(p). qx​=hx​+γ(x),kp​=Tp​+γ(p).

若 BBB 的第 jjj 行记为 bj⊤b_j^\topbj⊤​，暂时忽略 attention 中的可学习投影，二者的位置编码内积为：

γ(x)⊤γ(p)=∑jcos⁡ ⁣(2πbj⊤(x−p)).\gamma(x)^\top\gamma(p) =\sum_j\cos\!\left(2\pi b_j^\top(x-p)\right). γ(x)⊤γ(p)=j∑​cos(2πbj⊤​(x−p)).

当 xxx 与 ppp 接近时，x−p≈0x-p\approx0x−p≈0，各频率项大多接近 111，位置部分的相似度较高；相距较远时，不同频率的余弦项会相互抵消。低频特征给出“是否位于同一大致区域”，高频特征再区分局部表面细节。因而，当查询点位于桌面附近时，它更容易从各视图中三维位置也落在桌面附近的 patch 读取证据，而不是从远处墙面读取信息。

实际 attention 使用可学习投影，位置并非硬性的最近邻规则：

a(x,p)=(WQqx)⊤(WKkp)d.a(x,p)= \frac{ \bigl(W_Qq_x\bigr)^\top\bigl(W_Kk_p\bigr) }{\sqrt d}. a(x,p)=d​(WQ​qx​)⊤(WK​kp​)​.

视觉纹理、遮挡、相机状态和训练得到的 WQ,WKW_Q,W_KWQ​,WK​ 也会影响权重；共享位置编码只提供一个可学习的三维邻近先验。图像 patch 的 ppp 来自 VGGT point map，训练表面点和解码查询则先对齐、归一化到同一 VGGT 坐标系。因此 x−px-px−p 本身有几何意义。若两侧坐标系未对齐，即使它们在真实世界中相邻，编码也会相差很大，网络就必须额外从外观中推断坐标变换，难以稳定复用跨场景的注意力模式。

随后用 Perceiver 压缩所有视图。KKK 个可学习 latent query 对 NNN 张图的全部 patch token 做 cross-attention，再在 latent 内做 self-attention：

矩阵 AAA 的第 kkk 行是一组对所有视图 patch 的权重，表示第 kkk 个 latent 应从哪些位置读取信息。某些 latent 可以聚合地面，某些聚合墙体或前景物体；这种分工由训练自动形成，不需要提前规定 token 的语义。

压缩的计算量约为 O(KLD)O(KLD)O(KLD)。由于 K=128K=128K=128 固定，输入视图增加时成本随 LLL 近似线性增长；若直接让所有 LLL 个 patch 做全 self-attention，成本会是 O(L2D)O(L^2D)O(L2D)。Perceiver 因而把“读取任意多观测”与“保存固定大小状态”分开：读取阶段可以随视图变长，后续解码始终只面对 128 个 token。

默认 K=128K=128K=128，每次 cross-attention 后接四个 self-attention block，整个过程重复四轮。patch 数量随 NNN 增加，只影响编码阶段读取多少证据；压缩后的 zp∈R128×512z_p\in\mathbb{R}^{128\times512}zp​∈R128×512 大小不变。

camera token 走一条更轻的 Perceiver 分支，压缩成单个 zc∈R1×512z_c\in\mathbb{R}^{1\times512}zc​∈R1×512。最终全局状态可写为：

z=[zp,zc]z=[z_p,z_c] z=[zp​,zc​]

zpz_pzp​ 保存场景表面内容，供解码器 cross-attention 查询；zcz_czc​ 记录当前世界坐标与相机布局，通过 AdaLN 调制解码器。固定长度表示删除了逐视图重复信息，也设置了信息瓶颈：新增视图只能更新 128 个 token 中的内容，不能无限扩张状态。

定向点

Surflo 生成 oriented surface point：

x=(m,n)∈R3×S2x=(\mathbf{m},\mathbf{n})\in\mathbb{R}^{3}\times\mathbb{S}^{2} x=(m,n)∈R3×S2

m\mathbf{m}m 是表面位置，n\mathbf{n}n 是单位法向。普通点云只说明“表面经过这里”，法向还说明局部表面的朝向，使每个点可以直接变成贴合曲面的各向异性 Gaussian，也便于后续三角化。

实现中没有直接在线性空间里插值单位法向。给定点 m\mathbf{m}m 和法向 n\mathbf{n}n，构造六维残差表示：

x=(m,m+εn)∈R6,ε=10−3×scene scalex=(\mathbf{m},\mathbf{m}+\varepsilon\mathbf{n})\in\mathbb{R}^{6}, \qquad \varepsilon=10^{-3}\times\text{scene scale} x=(m,m+εn)∈R6,ε=10−3×scene scale

解码后再恢复法向：

n^=x4:6−x1:3∥x4:6−x1:3∥2\hat{\mathbf{n}} =\frac{x_{4:6}-x_{1:3}} {\|x_{4:6}-x_{1:3}\|_2} n^=∥x4:6​−x1:3​∥2​x4:6​−x1:3​​

这个表示把位置与方向统一放进欧氏空间的速度预测中，避免直接对球面坐标做数值不稳定的 ODE。

为什么不能直接把法向三个分量与位置拼接？法向必须满足 ∥n∥2=1\|\mathbf n\|_2=1∥n∥2​=1，普通欧氏更新 n←n+Δn\mathbf n\leftarrow\mathbf n+\Delta\mathbf nn←n+Δn 会离开单位球面；每一步强制归一化又会改变速度方向。残差表示把方向编码成两个相近点之间的差，ODE 始终在 R6\mathbb{R}^6R6 中运行，最后只做一次归一化即可恢复 S2\mathbb{S}^2S2 上的方向。

ε\varepsilonε 不能太大，否则第二个点会引入与场景位置同量级的额外几何；也不能太小，否则 FP16 下两点之差容易丢失精度。论文按场景尺度取 10−310^{-3}10−3，并在最终 LayerNorm 与输出头使用 FP32，提高法向计算的数值稳定性。

表面流

目标分布 p1p_1p1​ 是完整表面的定向点，源分布 p0p_0p0​ 是表面附近的噪声点。采样 x0∼p0x_0\sim p_0x0​∼p0​、x1∼p1x_1\sim p_1x1​∼p1​ 后构造：

xt=(1−t)x0+tx1,u(xt,t)=x1−x0x_t=(1-t)x_0+t x_1, \qquad u(x_t,t)=x_1-x_0 xt​=(1−t)x0​+tx1​,u(xt​,t)=x1​−x0​

条件速度网络以全局状态 zzz 为条件：

LFM(θ,ϕ)=Et,x0,x1,{In}[∥vθ(xt,t∣z)−(x1−x0)∥22]\mathcal{L}_{\mathrm{FM}}(\theta,\phi) =\mathbb{E}_{t,x_0,x_1,\{I_n\}} \left[ \left\| v_{\theta}(x_t,t\mid z)-(x_1-x_0) \right\|_2^2 \right] LFM​(θ,ϕ)=Et,x0​,x1​,{In​}​[∥vθ​(xt​,t∣z)−(x1​−x0​)∥22​]

逐点独立解码对应一个条件分布分解：

p(x1(1),…,x1(P)∣z)≈∏p=1Pp(x1(p)∣z)p(x_1^{(1)},\ldots,x_1^{(P)}\mid z) \approx\prod_{p=1}^{P}p(x_1^{(p)}\mid z) p(x1(1)​,…,x1(P)​∣z)≈p=1∏P​p(x1(p)​∣z)

这个近似带来可扩展性，因为每个点可以单独采样和分批计算；它也忽略了点集的联合约束。例如两个点都可能各自合理地落在一张薄板附近，却分别落到薄板两侧，单点概率都高，组合起来却形成双层表面。后面的 rendering guidance 正是用一个依赖全体点的损失修正这个独立性假设。

当 PPP 足够大时，输出点集是条件表面分布的 Monte Carlo 近似：

p^P(x∣z)=1P∑p=1Pδ(x−x1(p))\hat p_P(x\mid z) =\frac{1}{P}\sum_{p=1}^{P}\delta(x-x_1^{(p)}) p^​P​(x∣z)=P1​p=1∑P​δ(x−x1(p)​)

增加查询数会降低采样稀疏性，使 p^P\hat p_Pp^​P​ 更密地覆盖同一表面；场景语义和几何细节仍由固定 latent 与速度网络决定。这就是“输出分辨率可变”与“信息容量无限”之间的区别。

t=0t=0t=0 为源点，t=1t=1t=1 为表面点，推理从 0 正向积分到 1。训练时 ttt 服从偏向 1 附近的 logit-normal 分布，让网络更多学习靠近真实表面的精修阶段。

若 x0x_0x0​ 直接从全局高斯 N(0,I)\mathcal{N}(0,I)N(0,I) 采样，大场景中多数查询会落入空白区域，模型要浪费大量容量寻找表面。Surflo 先从 VGGT point map 采样可见三维点，再添加标准差约 0.1 的各向同性高斯噪声，形成以可见几何为中心的 Gaussian mixture；噪声范围足以覆盖邻近遮挡面。初始法向则从 S2\mathbb{S}^2S2 均匀采样。

p0(m)=1J∑j=1JN(m;p~j,σs2I)p_0(\mathbf{m}) =\frac{1}{J}\sum_{j=1}^{J} \mathcal{N}(\mathbf{m};\tilde{\mathbf{p}}_j,\sigma_s^2I) p0​(m)=J1​j=1∑J​N(m;p~​j​,σs2​I)

这里的“噪声”不是固定长度的全局 latent，而是由 PPP 个三维空间中的独立定向点查询组成的集合：

X0={x0(1),…,x0(P)},x0(p)=(m0(p),n0(p)).X_0=\{x_0^{(1)},\ldots,x_0^{(P)}\}, \qquad x_0^{(p)}=(\mathbf{m}_0^{(p)},\mathbf{n}_0^{(p)}). X0​={x0(1)​,…,x0(P)​},x0(p)​=(m0(p)​,n0(p)​).

每个查询的位置从上述 Gaussian mixture 采样，法向从 S2\mathbb S^2S2 均匀采样；合起来才是输入 decoder 的噪声点云。若查询彼此独立，则：

p(X0∣I)=∏p=1Pp0(x0(p)∣I).p(X_0\mid I)=\prod_{p=1}^{P}p_0(x_0^{(p)}\mid I). p(X0​∣I)=p=1∏P​p0​(x0(p)​∣I).

PPP 是推理时选择的采样次数。例如 P=8KP=8\mathrm KP=8K 对应快速但稀疏的预览，P=100KP=100\mathrm KP=100K 对应更密的表面采样。所有查询共享同一个场景 latent zzz，并分别经过相同的速度网络 vθ(xt(p),t∣z)v_\theta(x_t^{(p)},t\mid z)vθ​(xt(p)​,t∣z)；因此改变 PPP 只增加或减少“粒子”数量，不会改变 decoder 的参数形状或重新编码场景。

这种 source distribution 给出一个粗几何起点，但不把输出锁死在输入射线上。消融中，换成纯全局高斯会使 DL3DV 的 F1 从 81.21 降到 73.57。

源分布的作用类似 proposal distribution。VGGT point map 告诉流“真实表面大概率在这些位置附近”，Gaussian 噪声则扩大搜索范围，使点能离开可见面、到达邻近的隐藏表面。σs\sigma_sσs​ 太小时，模型几乎退化为修正 VGGT 可见点，补全能力不足；太大时，大量点进入空空间，又失去高效初始化的意义。

源分布依赖输入，但目标仍由完整表面 p1p_1p1​ 监督。Flow matching 学到的是“怎样从当前场景的粗可见几何运输到完整表面”，因此 VGGT 只提供起点和条件，不是最终结果的硬约束。

独立解码

解码器是 12 层 Transformer。前六层让单个查询通过 cross-attention 读取 zpz_pzp​，后六层使用 MLP 精修；时间嵌入 τ(t)\tau(t)τ(t) 与相机状态 zcz_czc​ 共同生成 AdaLN 的 shift、scale 和 gate。核心约束是查询点之间没有 self-attention：

hp(ℓ+1)=MLP⁡ ⁣(CrossAttn⁡(hp(ℓ),zp);τ(t),zc)h_p^{(\ell+1)} =\operatorname{MLP}\!\left( \operatorname{CrossAttn}(h_p^{(\ell)},z_p); \tau(t),z_c \right) hp(ℓ+1)​=MLP(CrossAttn(hp(ℓ)​,zp​);τ(t),zc​)

第 ppp 个点只读取固定的 128 个全局 token，不直接访问第 qqq 个点。因此解码 PPP 个点的主要注意力复杂度是：

O(PK),K=128O(PK),\qquad K=128 O(PK),K=128

而查询之间全 self-attention 会达到 O(P2)O(P^2)O(P2)，在 P=105P=10^5P=105 时无法承受。独立结构允许把点分批送入 GPU，同一个 latent 可以生成从 10310^3103 到 10610^6106 个点。

推理用 Euler 法求解：

xt+Δt=xt+Δt vθ(xt,t∣z)x_{t+\Delta t} =x_t+\Delta t\,v_{\theta}(x_t,t\mid z) xt+Δt​=xt​+Δtvθ​(xt​,t∣z)

默认时间网格分两段：t<0.95t<0.95t<0.95 使用 50 步完成粗移动，t≥0.95t\ge0.95t≥0.95 使用 100 步处理表面附近的细节，总计 150 步，默认输出 100K 点。

Euler 法是 ODE 最简单的一阶离散化。若真实轨迹弯曲，单步局部截断误差约为 O(Δt2)O(\Delta t^2)O(Δt2)，累积全局误差约为 O(Δt)O(\Delta t)O(Δt)。表面附近的速度变化更快、渲染引导也只在后段启用，所以论文把更多的 100 个小步放在 [0.95,1][0.95,1][0.95,1]，而前 95% 的粗运输只用 50 步。计算预算由此集中到最影响最终表面的位置。

这里的“任意分辨率”指输出采样密度可以自由选择，并不保证点数翻倍就会产生两倍新信息。128 个 latent token 固定了场景内容容量；增加 PPP 主要让同一曲面被采样得更密，网格更细致。

渲染引导

逐点独立是可扩展性的来源，也会造成局部不一致。两个相邻噪声点可能分别落到墙的前后两层，或者停在表面附近形成 floater。训练损失可按点分解，缺少一个依赖整批点的共同信号。

Surflo 在 ODE 后段加入 communication via guidance。当 t≥0.95t\ge0.95t≥0.95 时，先由当前速度估计最终干净点：

x^1=xt+(1−t)vθ(xt,t∣z)\hat x_1=x_t+(1-t)v_{\theta}(x_t,t\mid z) x^1​=xt​+(1−t)vθ​(xt​,t∣z)

xt+(1−t)v=(1−t)x0+tx1+(1−t)(x1−x0)=x1\begin{aligned} x_t+(1-t)v &=(1-t)x_0+tx_1+(1-t)(x_1-x_0)\\ &=x_1 \end{aligned} xt​+(1−t)v​=(1−t)x0​+tx1​+(1−t)(x1​−x0​)=x1​​

所以不必等 ODE 真正走到 t=1t=1t=1，在任意时刻都能估计当前轨迹最终会落在哪里。ttt 越接近 1，这个估计越可靠，因此引导从 0.95 才开始；过早根据不稳定的 x^1\hat x_1x^1​ 渲染，会给粗几何施加错误梯度。

把所有 x^1\hat x_1x^1​ 解释为 oriented Gaussians，使用 VGGT 预测的相机从输入视角渲染 I^n(t)\hat I_n(t)I^n​(t)。全局渲染损失为：

Lrender=1N∑n=1N[λ∥I^n(t)−In∥1+(1−λ)DSSIM⁡(I^n(t),In)]+Ldepth−reg\mathcal{L}_{\mathrm{render}} =\frac{1}{N}\sum_{n=1}^{N} \left[ \lambda\|\hat I_n(t)-I_n\|_1 +(1-\lambda)\operatorname{DSSIM}(\hat I_n(t),I_n) \right] +\mathcal{L}_{\mathrm{depth-reg}} Lrender​=N1​n=1∑N​[λ∥I^n​(t)−In​∥1​+(1−λ)DSSIM(I^n​(t),In​)]+Ldepth−reg​

其中，DSSIM 负责衡量两张图在局部亮度、对比度和纹理结构上是否一致。(\mathcal L_{\mathrm{depth-reg}}) 是深度正则项，用在 Surflo 的推理期渲染引导中。它约束的是当前 Gaussian 点集渲染得到的深度 (\hat D_n)。

在每个后段 ODE step 内，对 Gaussian 的位置、尺度、旋转、透明度和球谐颜色做 M=32M=32M=32 次梯度更新。优化后的中心给出引导目标 x^1g\hat x_1^gx^1g​，再将目标换回速度：

vg=x^1g−xt1−t,xt+Δt=xt+Δt vgv_g=\frac{\hat x_1^g-x_t}{1-t}, \qquad x_{t+\Delta t}=x_t+\Delta t\,v_g vg​=1−tx^1g​−xt​​,xt+Δt​=xt​+Δtvg​

所有点共同决定一张渲染图，任一点的偏移都会影响遮挡、颜色和深度，再通过同一个图像损失反传。渲染梯度因此成为点与点之间的通信通道。低透明度且不贡献任何输入视图的点会被动态删除，少量 VGGT 相机误差也可以在引导阶段微调。

更具体地说，渲染图某个像素是多个 Gaussian 的 alpha compositing 结果：

I^(u)=∑pTp(u)αp(u)cp,Tp(u)=∏q<p(1−αq(u))\hat I(u)=\sum_p T_p(u)\alpha_p(u)c_p, \qquad T_p(u)=\prod_{q<p}(1-\alpha_q(u)) I^(u)=p∑​Tp​(u)αp​(u)cp​,Tp​(u)=q<p∏​(1−αq​(u))

一个点的位置 mpm_pmp​ 改变后，会改变自己的二维投影与 αp\alpha_pαp​，也会通过透射率 TqT_qTq​ 改变后面其他点的可见度。因此：

∂Lrender∂mp=∑u∂Lrender∂I^(u)∂I^(u)∂mp\frac{\partial\mathcal{L}_{\mathrm{render}}}{\partial m_p} =\sum_u \frac{\partial\mathcal{L}_{\mathrm{render}}}{\partial\hat I(u)} \frac{\partial\hat I(u)}{\partial m_p} ∂mp​∂Lrender​​=u∑​∂I^(u)∂Lrender​​∂mp​∂I^(u)​

这个梯度已经包含与同一像素上其他点的遮挡关系。独立 flow decoder 中没有直接通信的点，通过共同参与图像渲染获得了耦合信号。

还可以加入单目深度专家的相对深度排序损失。单目深度的绝对尺度和多视图一致性未必可靠，所以只约束像素对之间谁近谁远，不强迫渲染深度逐值匹配。最终的 oriented Gaussian 通过 Delaunay triangulation 转成三角网格。

引导是可选的推理阶段优化。无引导 Surflo 是“编码一次 + 150 步预训练流 ODE”，不为当前场景更新网络参数；开启引导后，还会针对当前输入做多轮可微渲染优化。论文把整体归入 feed-forward reconstruction，主要强调没有 NeRF/3DGS 那样从头训练一个场景模型，但带引导版本并非严格的一次前向传播。

表面数据

大规模真实场景数据常有图像、相机和稀疏点，却缺少适合监督 oriented point 的完整表面。DL3DV 约有 10.5K 个场景，原始数据不提供网格。Surflo 使用每个场景的完整密集视图运行 Gaussian Wrapping，得到水密网格，再从每个网格均匀采样约 10710^7107 个带法向点，构建 Meshed DL3DV。

训练时每次采样 12 个场景，每个场景随机取 N∈[2,16]N\in[2,16]N∈[2,16] 张无位姿输入图和约 8K 个表面查询。VGGT 坐标系与数据原始 COLMAP 坐标系不同，论文先用高置信深度对应估计相似变换，再做鲁棒加权仿射拟合，将真值点变到 VGGT 世界坐标。VGGT 主干始终冻结，Perceiver 与 flow decoder 联合训练 400K 次迭代。

坐标对齐可以写成：

min⁡L,t∑jwj ρ ⁣(∥pjCOLMAPL+t−pjVGGT∥2)\min_{L,t}\sum_j w_j\, \rho\!\left( \|p_j^{\mathrm{COLMAP}}L+t-p_j^{\mathrm{VGGT}}\|_2 \right) L,tmin​j∑​wj​ρ(∥pjCOLMAP​L+t−pjVGGT​∥2​)

L∈R3×3L\in\mathbb{R}^{3\times3}L∈R3×3、t∈R3t\in\mathbb{R}^3t∈R3，wjw_jwj​ 来自 VGGT 深度置信度与鲁棒筛选。若不做这一步，同一张墙在监督坐标和网络坐标中存在旋转、尺度或剪切差异，flow loss 会把坐标误差误认为需要学习的几何变化，最终表面会变厚或模糊。

这种数据构建方案扩大了真实场景表面监督规模，也引入 teacher bias：训练真值来自 Gaussian Wrapping，而 Gaussian Wrapping 本身依赖优化、遮挡假设和密集视图。论文在带原生网格真值的 ML-Hypersim、BlendedMVS、DTU、SCRREAM 上另外评估，用来检查模型是否只复现教师伪影。

实验结论

论文统一给各方法 16 张无位姿图，在 DL3DV、Tanks & Temples、Mip-NeRF 360、DeepBlending 以及四个原生表面数据集上比较 Chamfer Distance 和 F1。逐视图 point map 直接拼接时会出现多层表面，TSDF 融合又可能侵蚀细结构；NOVA3R 在这些跨数据集实验中常产生较粗、较稀的点云；少视图 2DGS、RaDe-GS 和 Gaussian Wrapping 则缺少足够图像约束。

在原生真值的四个数据集上，带引导 Surflo 的 CD 分别为 0.0079、0.0114、0.0240、0.0070；对应 VGGT+TSDF 为 0.0138、0.0270、0.0380、0.0226。它还在 2、4、8、32 视图设置中复用同一模型和同样大小的 latent，视图增多时表面逐步完整，编码后的状态大小不变。

引导的数值结果需要细看。它通常消除可见 floater、提升网格观感和部分数据集 F1，却并非在每个表格里都优于无引导版本。例如 DL3DV 上无引导 CD 为 0.0072，带引导为 0.0083；Tanks & Temples 少视图时无引导也可能更好。渲染损失偏向输入视角的颜色一致性，可能牺牲少量全局表面距离，因此论文同时报告两个版本是合理的。

缓存全局状态后，100K 点的无引导解码以 ODE 为主要耗时，论文在单张 H100 上报告为数秒量级；完整编码与解码仍远快于每场景优化数百轮的 2DGS 或 Gaussian Wrapping。引导会把耗时增加到约 30 秒至 3 分钟，取决于启用多少后段 step，适合追求最终曲面质量而非实时预览的场景。

方法特点

Surflo 的核心特点是把“场景包含什么”与“要采样多少表面点”分开。Perceiver 把所有输入压缩为一次性全局状态，flow decoder 把这个状态视为可重复查询的表面分布。与固定体素相比，它不需要为大块空空间付费；与逐视图 point map 相比，它不随输入图像复制表面；与固定点集 decoder 相比，它允许按任务选择采样密度。

代价也来自同一设计。点之间没有 self-attention，才可能扩展到百万点；没有 self-attention，又必然削弱局部一致性，需要渲染引导补偿。Surflo 的创新重点因此不只是 flow matching，而是“固定全局状态 + 独立点流 + 推理期全局通信”三部分共同形成的结构。

Surflo 存在以下局限：

  • 128 个全局 token 不随场景规模增长，超大场景和细密物体仍可能发生信息压缩；
  • 源分布、三维位置编码、相机和坐标系都依赖冻结 VGGT，极少视图、极端基线或 VGGT 失败时会一起退化；
  • 点查询在训练损失中彼此独立，无引导时仍会出现 floater 和局部双层面；
  • 默认 150 次速度网络评估，严格意义上并非一次神经网络前向，百万点输出也会线性增加解码时间；
  • 渲染引导需要逐场景优化，速度显著降低，还可能为了匹配图像而偏移几何；
  • 训练表面由 Gaussian Wrapping 生成，难以完全排除伪真值中的算法偏差；
  • 输出主要是几何与法向，颜色通过输入图像平均或引导中的 Gaussian 外观获得，还不是完整、可编辑的材质与光照表示。
