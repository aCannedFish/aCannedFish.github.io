DreamFusion: Text-to-3D using 2D Diffusion

发表于2026-07-23|更新于2026-08-17|Note3DVision 论文阅读
|浏览量:

前四篇研究的都是根据真实物体的多张照片进行三维重建。然而，对于“一只穿着宇航服的柯基犬”这类仅由文本描述、现实中未必存在的物体，无法预先获得对应照片。三维生成的目标是从文本或单幅图像生成新的三维对象。

一种直接方案是借鉴 Stable Diffusion 等文生图模型，训练文本到三维的扩散模型。然而，互联网中存在数十亿规模的图文对，可用三维模型通常只有数百万个，数据规模相差三至四个数量级，难以支撑同等规模的三维扩散模型训练。

DreamFusion 避开了从头训练三维扩散模型所需的数据，转而把预训练二维扩散模型作为监督信号，指导三维表示的优化。它接收文本提示，针对该提示从随机初始化开始优化一套 NeRF 参数，输出可从不同视角渲染的三维对象或场景。论文提出的**得分蒸馏采样（SDS）**随后成为许多文本到三维方法的基础。

整体流程如下：维护一个可微三维表示（DreamFusion 使用 NeRF），从随机视角渲染二维图像，利用扩散模型计算优化方向，再将梯度反向传播至三维表示。持续从不同视角施加二维先验约束，可以促使生成结果在多个方向上都呈现合理外观，并逐步形成一致的三维结构。

扩散模型

理解 SDS 之前，需要先明确扩散模型的基本训练过程。去噪网络 ϵϕ(zt;t,y)\epsilon_\phi(\mathbf{z}_t;t,y)ϵϕ​(zt​;t,y) 接收加噪图像 zt\mathbf{z}_tzt​、噪声等级 ttt 和文本条件 yyy，输出预测噪声。前向加噪过程为 zt=αtx+σtϵ\mathbf{z}_t=\alpha_t\mathbf{x}+\sigma_t\epsilonzt​=αt​x+σt​ϵ，其中 αt=αˉt\alpha_t=\sqrt{\bar\alpha_t}αt​=αˉt​​、σt=1−αˉt\sigma_t=\sqrt{1-\bar\alpha_t}σt​=1−αˉt​​、ϵ∼N(0,I)\epsilon\sim\mathcal{N}(0,I)ϵ∼N(0,I)。训练目标是加权去噪回归：

LDiff(ϕ)=Et,ϵ ⁣[w(t) ∥ϵϕ(αtx+σtϵ; t,y)−ϵ∥22]\mathcal{L}_{\text{Diff}}(\phi) = \mathbb{E}_{t,\epsilon}\!\left[w(t)\,\big\|\epsilon_\phi(\alpha_t\mathbf{x}+\sigma_t\epsilon;\,t,y) - \epsilon\big\|_2^2\right] LDiff​(ϕ)=Et,ϵ​[w(t)​ϵϕ​(αt​x+σt​ϵ;t,y)−ϵ​22​]

时间步 ttt 决定监督尺度：高噪声图像只保留大致轮廓，去噪器主要提供语义和整体形状方向；低噪声图像保留更多局部信息，监督更接近纹理与边缘。权重 w(t)w(t)w(t) 用来平衡这些噪声尺度，DreamFusion 采用与 σt2\sigma_t^2σt2​ 有关的权重。

SDS 所依赖的关键关系是：预测噪声 ϵϕ\epsilon_\phiϵϕ​ 与加噪图像分布的对数梯度成比例，后者即得分函数：

ϵϕ(zt;t,y)≈−σt ∇ztlog⁡pt(zt∣y)\epsilon_\phi(\mathbf{z}_t; t, y) \approx -\sigma_t\,\nabla_{\mathbf{z}_t}\log p_t(\mathbf{z}_t\mid y) ϵϕ​(zt​;t,y)≈−σt​∇zt​​logpt​(zt​∣y)

得分函数 ∇zlog⁡p(z)\nabla_{\mathbf z}\log p(\mathbf z)∇z​logp(z) 是概率密度对输入的梯度，指向当前噪声尺度下更可能出现的图像区域。去噪器虽然以“预测噪声”训练，其输出经过 −1/σt-1/\sigma_t−1/σt​ 缩放后就近似这个方向。

SDS 推导

设三维参数为 θ\thetaθ，可微渲染器为 ggg，从视角 vvv 得到图像 x=g(θ,v)\mathbf x=g(\theta,v)x=g(θ,v)。给它加入噪声后，当前渲染诱导出一个已知高斯分布：

qt(zt∣x)=N(αtx,σt2I),qquadzt=αtx+σtϵ.q_t(\mathbf z_t\mid\mathbf x) =\mathcal N(\alpha_t\mathbf x,\sigma_t^2I),qquad \mathbf z_t=\alpha_t\mathbf x+\sigma_t\boldsymbol\epsilon. qt​(zt​∣x)=N(αt​x,σt2​I),qquadzt​=αt​x+σt​ϵ.

文本扩散模型定义了目标分布 pϕ(zt∣y)p_\phi(\mathbf z_t\mid y)pϕ​(zt​∣y)。SDS 的概率解释是：在多个噪声尺度上，让当前渲染的 qtq_tqt​ 接近文本条件分布 pϕp_\phipϕ​。两者关于加噪图像的得分分别为

∇ztlog⁡qt=−ϵσt,∇ztlog⁡pϕ≈−ϵϕ(zt;t,y)σt.\nabla_{\mathbf z_t}\log q_t =-\frac{\boldsymbol\epsilon}{\sigma_t},\qquad \nabla_{\mathbf z_t}\log p_\phi \approx-\frac{\epsilon_\phi(\mathbf z_t;t,y)}{\sigma_t}. ∇zt​​logqt​=−σt​ϵ​,∇zt​​logpϕ​≈−σt​ϵϕ​(zt​;t,y)​.

第一式可以直接由高斯对数密度求导得到：采样点偏离均值的量是 zt−αtx=σtϵ\mathbf z_t-\alpha_t\mathbf x=\sigma_t\boldsymbol\epsilonzt​−αt​x=σt​ϵ。第二式来自去噪模型与得分函数的对应关系。二者之差与 ϵϕ−ϵ\epsilon_\phi-\boldsymbol\epsilonϵϕ​−ϵ 成正比，它衡量当前渲染在噪声尺度 ttt 上应朝哪个方向移动，才能更接近文本图像分布。

再沿 θ→x→zt\theta\rightarrow\mathbf x\rightarrow\mathbf z_tθ→x→zt​ 使用链式法则，∂zt/∂x=αtI\partial\mathbf z_t/\partial\mathbf x=\alpha_tI∂zt​/∂x=αt​I，与 1/σt1/\sigma_t1/σt​ 等只依赖时间步的尺度可以吸收到 w(t)w(t)w(t)，得到核心梯度：

∇θLSDS=Et,ϵ,v[w(t)(ϵ^ϕ(zt;t,y)−ϵ)∂x∂θ].\boxed{ \nabla_\theta\mathcal L_{\mathrm{SDS}} =\mathbb E_{t,\boldsymbol\epsilon,v} \left[ w(t)\big(\hat\epsilon_\phi(\mathbf z_t;t,y)-\boldsymbol\epsilon\big) \frac{\partial\mathbf x}{\partial\theta} \right].} ∇θ​LSDS​=Et,ϵ,v​[w(t)(ϵ^ϕ​(zt​;t,y)−ϵ)∂θ∂x​].​

这里 ϵ^ϕ\hat\epsilon_\phiϵ^ϕ​ 是经过文本引导的预测噪声，ϵ\boldsymbol\epsilonϵ 是实际加入的噪声，二者的残差先形成像素空间更新方向；渲染器雅可比 ∂x/∂θ\partial\mathbf x/\partial\theta∂x/∂θ 再把它传给密度、反照率等三维参数。一次迭代只约束一个随机视角，但不同视角共享同一套 θ\thetaθ，持续采样后会把二维先验汇聚为三维结构。

实现时对残差使用 stopgrad⁡\operatorname{stopgrad}stopgrad，使梯度经过可微渲染器，却不继续求去噪 U-Net 对输入的雅可比。若直接对去噪 MSE 关于渲染图求导，会额外出现 ∂ϵϕ/∂zt\partial\epsilon_\phi/\partial\mathbf z_t∂ϵϕ​/∂zt​；它计算昂贵，并对应对数密度的二阶曲率，容易造成尺度不均的更新。SDS 把冻结扩散模型当作提供一阶方向的教师，显著降低了外层三维优化的成本。

从分布角度看，这一过程对应一族带权反向 KL。反向 KL 倾向于让当前解集中到某个高概率模式，能够产生语义明确的对象，也容易带来过饱和、过平滑和结果多样性不足。ProlificDreamer 后续提出变分得分蒸馏，主要针对这一寻模倾向进行改进。

无分类器引导

为放大文本条件，DreamFusion 使用无分类器引导（CFG）。同一个去噪器分别预测带文本条件和空条件的噪声，再从条件预测沿二者差值继续外推：

ϵ^ϕ(zt;t,y)=(1+ω)ϵϕ(zt;t,y)−ωϵϕ(zt;t,∅).\hat\epsilon_\phi(\mathbf z_t;t,y) =(1+\omega)\epsilon_\phi(\mathbf z_t;t,y) -\omega\epsilon_\phi(\mathbf z_t;t,\varnothing). ϵ^ϕ​(zt​;t,y)=(1+ω)ϵϕ​(zt​;t,y)−ωϵϕ​(zt​;t,∅).

按论文的参数约定，ω=0\omega=0ω=0 时得到普通条件预测，增大 ω\omegaω 会强化“带条件”和“空条件”之间的文本语义方向。DreamFusion 使用 ω=100\omega=100ω=100 的高引导强度来抵消 SDS 的模糊倾向，使物体轮廓和文本属性更明确；相应代价是色彩容易过饱和，结果也更集中于少数模式。

表示与光照

DreamFusion 的三维表示基于 Mip-NeRF 360，但没有像普通 NeRF 那样让 MLP 直接输出最终颜色。由于训练中没有真实照片监督，只有扩散模型判断渲染结果是否符合文本，网络可能在错误几何上绘制正确纹理以降低损失。例如，在两块平面上分别绘制松鼠的正面和侧面，也可能通过对应视角的二维判断，但得到的三维结构仍是平面。这种现象称为“几何塌陷”，即颜色承担了本应由几何表示的内容。

物体密度主要限制在一个有界球体内，球体外的背景由另一个仅接收光线方向的环境 MLP 预测，再按光线累计不透明度与前景合成。这样可以防止主体 NeRF 在相机附近铺设大面积密度来“绘制背景”，也允许对象之外保留与文本相符的环境颜色。

DreamFusion 显式分离材质与光照。网络输出表示物体固有颜色的反照率 ρ\boldsymbol\rhoρ，着色结果由外部 Lambertian 模型计算：

c=ρ∘(ℓρ∘max⁡(0, n⋅ℓ^)+ℓa)\mathbf{c} = \boldsymbol{\rho}\circ\big(\boldsymbol{\ell}_\rho\circ\max(0,\ \mathbf{n}\cdot\hat{\boldsymbol{\ell}}) + \boldsymbol{\ell}_a\big) c=ρ∘(ℓρ​∘max(0, n⋅ℓ^)+ℓa​)

其中 n=−∇τ/∥∇τ∥\mathbf n=-\nabla\tau/\|\nabla\tau\|n=−∇τ/∥∇τ∥ 是由密度场 τ\tauτ 推导的法向。密度通常从物体外部向内部增大，负梯度因而近似指向外侧；直接从密度求法向，也让形状与着色使用同一几何。ℓ^\hat{\boldsymbol\ell}ℓ^ 是从表面指向随机光源的单位方向，max⁡(0,n⋅ℓ^)\max(0,\mathbf n\cdot\hat{\boldsymbol\ell})max(0,n⋅ℓ^) 是 Lambert 余弦项；ℓρ\boldsymbol\ell_\rhoℓρ​ 与 ℓa\boldsymbol\ell_aℓa​ 分别表示直射光颜色和环境光，∘\circ∘ 表示逐通道乘法。随机改变光源后，固定纹理难以在所有照明条件下伪装成正确明暗，几何法向会承担更多解释责任。

渲染在三种模式间随机切换：

  • albedo：c=ρ\mathbf c=\boldsymbol\rhoc=ρ，只监督固有颜色与语义外观；
  • diffuse：使用完整 Lambertian 公式，同时呈现材质与几何产生的明暗；
  • textureless：把反照率设为白色，只保留法向和光照造成的明暗变化，迫使扩散先验评价形状。

textureless 模式用于抑制几何塌陷。若只使用 albedo 和 diffuse，网络可能在平面上绘制目标图案：albedo 模式能够呈现正确颜色，diffuse 模式下图案也仍然存在。切换到 textureless 后，纹理信息被移除，平面只会呈现近似均匀的灰度，无法再匹配具有明确形状的目标。模型因而需要学习真实的表面起伏和法向变化，才能表现物体的轮廓与结构。

此外还有朝向正则，防止网络靠翻转法向来制造虚假高光：

Lorient=∑istopgrad⁡(wi) max⁡(0,ni⋅v)2\mathcal{L}_{\text{orient}} = \sum_i \operatorname{stopgrad}(w_i)\,\max(0, \mathbf{n}_i\cdot\mathbf{v})^2 Lorient​=i∑​stopgrad(wi​)max(0,ni​⋅v)2

其中 v\mathbf vv 是从相机沿光线指向场景的方向。可见外表面的法向通常朝向相机，因此 n⋅v<0\mathbf n\cdot\mathbf v<0n⋅v<0；若法向沿视线向内翻转，点积变正，惩罚便会激活。体渲染权重 wiw_iwi​ 使正则主要作用于真正参与成像的采样点，停止梯度则防止模型通过降低这些权重、缩小物体来逃避法向约束。

论文还对每条光线的累计不透明度 A=∑iwiA=\sum_iw_iA=∑i​wi​ 使用 Lopacity=A2+0.01\mathcal L_{\mathrm{opacity}}=\sqrt{A^2+0.01}Lopacity​=A2+0.01​。该项鼓励无需形成前景的光线保持透明，改善前景与背景的分离；它与朝向损失共同约束几何，而 SDS 继续承担文本语义监督。

视角相关的文本增强通过在球面上随机采样相机位置（仰角 [−10°,90°][-10°,90°][−10°,90°]、方位角 [0°,360°][0°,360°][0°,360°]），并根据相机方位在 prompt 后追加 "front view"、"side view"、"back view" 或 "overhead view" 等描述实现。这些提示用于明确当前视角应观察到物体的哪一侧。若缺少方位描述，扩散模型受训练数据中正面图像占比较高的影响，可能要求各个角度都呈现正面特征，形成多张脸或多个正面的 Janus 问题。加入方位提示后，不同视角能够获得更符合其观察方向的监督。

Janus 问题源于二维扩散模型缺少跨视角联合建模，并且训练图像导致模型倾向于生成正面视角，因此产生“多面”问题。后续多视图扩散与 Zero-1-to-3 一类方法进一步引入相机条件，为不同视角提供更直接的一致性先验。

实验结果

二维对照实验中，SDS 能生成符合文本的图像，但相较同一 Imagen 模型的祖先采样，细节更少且出现明显的过饱和与过平滑。由于此时优化变量直接是二维像素，实验排除了 NeRF 表示的影响，说明这些伪影主要来自蒸馏目标和较高的 CFG。完整三维生成每个对象约需在 4 芯 TPUv4 上优化 1.5 小时。

消融结果显示，缺少视角提示时更容易产生多头和扁平几何；加入方位提示、随机光照与 textureless 渲染后，Janus 现象有所缓解。后两项减少了模型用纹理代替几何的空间，但二维先验仍未直接约束不同视角之间的对应关系，因此无法彻底消除多面伪影。

特点与局限

DreamFusion 证明了冻结的二维扩散模型可以通过 SDS 为三维表示提供文本监督，无需成对的文本—三维训练数据；随机相机、视角相关提示以及材质与光照分离，使多视角一致性能够在逐场景优化中逐步形成。这一思路建立了从大规模二维生成先验到文本生成三维内容的有效路径，并成为后续大量方法的基础。

受 64×64 Imagen 监督和 SDS 模式寻求特性的影响，结果常有分辨率低、几何粗糙、过饱和、过平滑及多样性不足等问题，Janus 现象也只能缓解而难以消除。每个物体都需独立迭代优化，生成速度较慢，最终质量又依赖视角采样、提示词和多项正则；Magic3D、ProlificDreamer 等后续工作主要围绕这些限制展开改进。
