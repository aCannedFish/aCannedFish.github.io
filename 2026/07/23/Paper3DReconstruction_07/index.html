ProlificDreamer: High-Fidelity and Diverse Text-to-3D Generation with Variational Score Distillation

发表于2026-07-23|更新于2026-08-05|Note读论文：三维重建
|浏览量:

Magic3D 从工程角度改进 DreamFusion——提速、提分辨率、换表示。ProlificDreamer 追问的是另一个层级的问题：SDS 本身到底在优化什么？为什么优化出来的东西总是过饱和、过平滑、缺乏多样性？答案藏在两个 KL 散度的方向差异里。

SDS 与反向 KL

KL 散度 KL(q∥p)\mathrm{KL}(q\|p)KL(q∥p) 衡量分布 qqq 和 ppp 的差异，但它不是对称的——KL(q∥p)≠KL(p∥q)\mathrm{KL}(q\|p) \neq \mathrm{KL}(p\|q)KL(q∥p)=KL(p∥q)，两个方向的优化行为截然不同。

反向 KL KL(q∥p)=∫q(x)log⁡q(x)p(x)dx\mathrm{KL}(q\|p) = \int q(x)\log\frac{q(x)}{p(x)}dxKL(q∥p)=∫q(x)logp(x)q(x)​dx：当 p(x)p(x)p(x) 很大但 q(x)q(x)q(x) 很小，被积项 q⋅log⁡(q/p)q\cdot\log(q/p)q⋅log(q/p) 因为 qqq 趋近于 0 而微不足道——不惩罚"漏掉 ppp 的模式"。当 p(x)p(x)p(x) 很小但 q(x)q(x)q(x) 很大，被积项炸裂——严厉惩罚"跑到 ppp 的低密度区"。所以 KL(q∥p)\mathrm{KL}(q\|p)KL(q∥p) 是模式寻求的：qqq 宁可只抓牢 ppp 的一个高概率峰，也不愿冒险覆盖不完美的区域。

正向 KL KL(p∥q)=∫p(x)log⁡p(x)q(x)dx\mathrm{KL}(p\|q) = \int p(x)\log\frac{p(x)}{q(x)}dxKL(p∥q)=∫p(x)logq(x)p(x)​dx：当 p(x)p(x)p(x) 很大但 q(x)q(x)q(x) 很小，被积项炸裂——严厉惩罚"漏掉 ppp 的高概率区域"。所以 KL(p∥q)\mathrm{KL}(p\|q)KL(p∥q) 是模式覆盖的：qqq 必须覆盖 ppp 的所有模式，即使这意味着有些地方不太像。

DreamFusion 论文在附录里证明了 SDS 梯度等价于最小化如下优化目标：

min⁡θ  Et,c ⁣[(σt/αt) ω(t)⋅KL(qtθ(xt∣c) ∥ pt(xt∣yc))]\min_\theta\; \mathbb{E}_{t,c}\!\left[(\sigma_t/\alpha_t)\,\omega(t)\cdot\mathrm{KL}\big(q_t^\theta(\mathbf{x}_t|c)\,\big\|\,p_t(\mathbf{x}_t|y^c)\big)\right] θmin​Et,c​[(σt​/αt​)ω(t)⋅KL(qtθ​(xt​∣c)​pt​(xt​∣yc))]

其中 qtθq_t^\thetaqtθ​ 是"渲染图 x=g(θ,c)\mathbf{x}=g(\theta,c)x=g(θ,c) 经扩散前向过程加噪到时间 ttt 的分布"——因为 θ\thetaθ 是一个确定性参数，qtθq_t^\thetaqtθ​ 实际上是一个以 xt=αtg(θ,c)+σtϵ\mathbf{x}_t=\alpha_t g(\theta,c)+\sigma_t\epsilonxt​=αt​g(θ,c)+σt​ϵ 为中心的 delta 分布（加噪后的单点）。ptp_tpt​ 是扩散模型学到的真实图像加噪分布。

这是反向 KL——所以 SDS 只会扑向 ppp 的某一个高概率模式（一只"最像柯基"的柯基），而非覆盖"柯基"这个文本对应的所有可能性（不同毛色、姿态、朝向下都应该有对应的合理 3D）。作为补偿，SDS 被迫用极大的 CFG（ω=100\omega=100ω=100）来把选中的那个模式推向极端清晰的版本——代价就是过饱和和过平滑。

Variational Score Distillation

SDS 把 3D 参数 θ\thetaθ 当作一个确定性点来优化。把 θ\thetaθ 当成一个随机变量，服从某个分布 μ(θ∣y)\mu(\theta|y)μ(θ∣y)。不同的 θ\thetaθ 采样值对应不同的 3D 形状——这正是"多样性"的数学来源。

不是每步前向传播从分布里随机抽一组参数——那样计算图会爆炸。VSD 的做法是维护 KKK 个独立粒子（KKK 通常 1~4），每个是一套完整的 NeRF 参数，从不同随机种子初始化。这 KKK 个粒子合在一起代表分布——"采样"就是从 KKK 个里面挑一个。训练时每个粒子独立地被 VSD 梯度更新（各自渲染、各自加噪、各自算梯度），粒子之间通过 LoRA 隐式交互（LoRA 是在所有粒子的渲染图上训练的）。由于初始化和随机性（ttt、ϵ\epsilonϵ、相机视角），不同粒子收敛到目标分布的不同模式。

优化目标从"让这一个 θ\thetaθ 落在高概率区"变成"让 θ\thetaθ 的整个分布和文本条件的目标分布对齐"：

min⁡μ  Et,c ⁣[(σt/αt) ω(t)⋅KL(qtμ(xt∣c,y) ∥ pt(xt∣yc))]\min_\mu\; \mathbb{E}_{t,c}\!\left[(\sigma_t/\alpha_t)\,\omega(t)\cdot\mathrm{KL}\big(q_t^\mu(\mathbf{x}_t|c,y)\,\big\|\,p_t(\mathbf{x}_t|y^c)\big)\right] μmin​Et,c​[(σt​/αt​)ω(t)⋅KL(qtμ​(xt​∣c,y)​pt​(xt​∣yc))]

其中 qtμq_t^\muqtμ​ 是渲染图的边际加噪分布：qtμ(xt)=∫q0μ(x0) qt∣0(xt∣x0) dx0q_t^\mu(\mathbf{x}_t)=\int q_0^\mu(\mathbf{x}_0)\,q_{t|0}(\mathbf{x}_t|\mathbf{x}_0)\,d\mathbf{x}_0qtμ​(xt​)=∫q0μ​(x0​)qt∣0​(xt​∣x0​)dx0​。这里的 q0μq_0^\muq0μ​ 是"从 μ\muμ 采样 θ\thetaθ → 渲染得到 x0=g(θ,c)\mathbf{x}_0=g(\theta,c)x0​=g(θ,c)"的分布——它不像 SDS 那样是一个 delta 单点，而是能覆盖多种合理渲染图的真实分布。

ProlificDreamer 证明了一个关键定理：对所有 t>0t>0t>0，KL(qtμ∥pt)=0\mathrm{KL}(q_t^\mu\|p_t)=0KL(qtμ​∥pt​)=0 当且仅当 q0μ=p0q_0^\mu=p_0q0μ​=p0​。也就是说，你可以在任意噪声水平 ttt 上做 VSD 优化——得到的全局最优解是同样的（都是渲染分布完全匹配目标分布）。这给了 VSD 方法上的合法性：它可以同时在不同 ttt 上做优化。

Wasserstein 梯度流与粒子更新

怎么优化分布 μ\muμ？ProlificDreamer 用的是粒子变分推断：用 KKK 个 3D 参数粒子 {θ(k)}k=1K\{\theta^{(k)}\}_{k=1}^K{θ(k)}k=1K​ 来"代表"分布 μ\muμ，每个粒子是一个独立初始化的 NeRF。

粒子的演化遵循一条 ODE（Wasserstein 梯度流）。核心结论是：每个粒子的更新梯度为两个得分函数之差，通过渲染器反传：

∇θLVSD(θ)=Et,ϵ,c ⁣[ω(t)(−σt∇xtlog⁡pt(xt∣yc)⏟目标分布得分−(−σt∇xtlog⁡qtμ(xt∣c,y))⏟当前渲染分布得分)∂g(θ,c)∂θ]\nabla_\theta \mathcal{L}_{\text{VSD}}(\theta) = \mathbb{E}_{t,\epsilon,c}\!\Big[\omega(t)\big(\underbrace{-\sigma_t\nabla_{\mathbf{x}_t}\log p_t(\mathbf{x}_t|y^c)}_{\text{目标分布得分}} - \underbrace{(-\sigma_t\nabla_{\mathbf{x}_t}\log q_t^\mu(\mathbf{x}_t|c,y))}_{\text{当前渲染分布得分}}\big)\frac{\partial g(\theta,c)}{\partial\theta}\Big] ∇θ​LVSD​(θ)=Et,ϵ,c​[ω(t)(目标分布得分−σt​∇xt​​logpt​(xt​∣yc)​​−当前渲染分布得分(−σt​∇xt​​logqtμ​(xt​∣c,y))​​)∂θ∂g(θ,c)​]

第一个得分函数 −σt∇log⁡pt-\sigma_t\nabla\log p_t−σt​∇logpt​ 就是预训练扩散模型：ϵϕpretrain(xt,t,yc)\epsilon_\phi^{\text{pretrain}}(\mathbf{x}_t,t,y^c)ϵϕpretrain​(xt​,t,yc)。第二个得分函数 −σt∇log⁡qtμ-\sigma_t\nabla\log q_t^\mu−σt​∇logqtμ​ 是"当前渲染分布的得分"——它描述的是"从我现在的 NeRF 粒子渲染出来的图，经过加噪后，得分函数长什么样"。

LoRA

第二个得分函数怎么得到？它不是扩散模型自带的东西——扩散模型学的是真实图像分布，而不是你当前 NeRF 渲染出来的图的分布。ProlificDreamer 的解决方案：在预训练扩散模型上挂载一个 LoRA 分支，用当前粒子渲染的图来微调：

LLoRA=∑k=1KEt,ϵ,c ⁣[∥ϵϕLoRA(αtg(θ(k),c)+σtϵ,  t,  c,  y)−ϵ∥22]\mathcal{L}_{\text{LoRA}} = \sum_{k=1}^K \mathbb{E}_{t,\epsilon,c}\!\Big[\big\|\epsilon_\phi^{\text{LoRA}}(\alpha_t g(\theta^{(k)},c)+\sigma_t\epsilon,\;t,\;c,\;y) - \epsilon\big\|_2^2\Big] LLoRA​=k=1∑K​Et,ϵ,c​[​ϵϕLoRA​(αt​g(θ(k),c)+σt​ϵ,t,c,y)−ϵ​22​]

LoRA 是对预训练 U-Net 权重的低秩微调——冻结原权重，只训练新增的小型低秩矩阵（参数量约为原 U-Net 的 0.1%）。它在原扩散模型的"知识基础"上学习当前渲染分布的特异性，训练极其快。

LoRA 时刻反映"我这批 NeRF 粒子现在渲染出来的图，典型长什么样、典型带什么噪声"。当粒子分布还没对齐目标分布时，LoRA 的得分函数 ϵϕLoRA\epsilon_\phi^{\text{LoRA}}ϵϕLoRA​ 和预训练模型的得分函数 ϵϕpretrain\epsilon_\phi^{\text{pretrain}}ϵϕpretrain​ 有明显差异——这个差异就是 VSD 的驱动力。当渲染分布完全匹配目标时，两者一致、梯度归零、优化停止。

最终 VSD 梯度化简为：

∇θLVSD(θ)=Et,ϵ,c ⁣[ω(t)(ϵϕpretrain(xt,t,yc)−ϵϕLoRA(xt,t,c,y))∂g(θ,c)∂θ]\nabla_\theta \mathcal{L}_{\text{VSD}}(\theta) = \mathbb{E}_{t,\epsilon,c}\!\Big[\omega(t)\big(\epsilon_\phi^{\text{pretrain}}(\mathbf{x}_t,t,y^c) - \epsilon_\phi^{\text{LoRA}}(\mathbf{x}_t,t,c,y)\big)\frac{\partial g(\theta,c)}{\partial\theta}\Big] ∇θ​LVSD​(θ)=Et,ϵ,c​[ω(t)(ϵϕpretrain​(xt​,t,yc)−ϵϕLoRA​(xt​,t,c,y))∂θ∂g(θ,c)​]

其中 xt=αtg(θ,c)+σtϵ\mathbf{x}_t = \alpha_t g(\theta,c) + \sigma_t\epsilonxt​=αt​g(θ,c)+σt​ϵ。

VSD vs SDS

∇θLSDS=ω(t)(ϵϕpretrain−ϵ)∂g∂θ\nabla_\theta\mathcal{L}_{\text{SDS}} = \omega(t)\big(\epsilon_\phi^{\text{pretrain}} - \epsilon\big)\frac{\partial g}{\partial\theta} ∇θ​LSDS​=ω(t)(ϵϕpretrain​−ϵ)∂θ∂g​

∇θLVSD=ω(t)(ϵϕpretrain−ϵϕLoRA)∂g∂θ\nabla_\theta\mathcal{L}_{\text{VSD}} = \omega(t)\big(\epsilon_\phi^{\text{pretrain}} - \epsilon_\phi^{\text{LoRA}}\big)\frac{\partial g}{\partial\theta} ∇θ​LVSD​=ω(t)(ϵϕpretrain​−ϵϕLoRA​)∂θ∂g​

唯一的区别：SDS 减的是纯高斯噪声 ϵ\epsilonϵ（“随机噪声”），VSD 减的是 LoRA 预测的噪声 ϵϕLoRA\epsilon_\phi^{\text{LoRA}}ϵϕLoRA​（“当前渲染分布的得分”）。

SDS 拿当前图和纯噪声比——任何有纹理的区域都天然"像加了噪声"，于是一直被惩罚、一直被抹平，导致过平滑。VSD 拿当前图和当前自己的分布比——只有"和当前渲染分布不一致的偏差"才会推动更新。当渲染分布已合理时 ϵϕpretrain−ϵϕLoRA≈0\epsilon_\phi^{\text{pretrain}}-\epsilon_\phi^{\text{LoRA}}\approx 0ϵϕpretrain​−ϵϕLoRA​≈0，梯度归零，不会继续把纹理抹平。

和 SDS 的核心差异在于两层循环。SDS 每步只优化一个 θ\thetaθ：渲染 → 加噪 → U-Net → 减纯噪声 → 反传。VSD 每步交替做两件事：先让 LoRA 在所有粒子的渲染图上学习"当前渲染分布"（像镜子跟上现状），再用预训练模型和 LoRA 之差（而非纯噪声）更新每个粒子。LoRA 不参与 3D 参数的反传——它和粒子是交替独立更新的。

VSD 框架下，SDS 可以理解为"只用一个粒子 + 用 Dirac delta 分布 qtθ(xt)≈δ(xt−αtg(θ,c))q_t^\theta(\mathbf{x}_t)\approx\delta(\mathbf{x}_t-\alpha_t g(\theta,c))qtθ​(xt​)≈δ(xt​−αt​g(θ,c)) 作为渲染分布 + 用纯噪声 ϵ\epsilonϵ 作为该 delta 分布的得分函数近似"。纯噪声是极其粗糙的得分估计——它完全没有"我当前渲染图长什么样"的信息。VSD 用 LoRA 学到了更好的当前分布得分，这才是它能克服过平滑和多样性丧失的根本原因。

和 DreamFusion 一样，ProlificDreamer 也先在 2D 空间验证。设 g(θ,c)≡θg(\theta,c)\equiv\thetag(θ,c)≡θ——渲染函数退化为恒等映射，θ\thetaθ 本身就是一张 2D 图像的像素值。然后分别用 SDS（CFG=7.5 和 CFG=100）、DDPM 祖先采样（CFG=7.5）、VSD（CFG=7.5）生成同一文本条件的图像。结果：SDS 在两个 CFG 设置下都失败了——CFG=7.5 生成的图模糊到几乎看不清，CFG=100 过饱和但细节缺失；而 VSD 在 CFG=7.5 下生成的图像品质与祖先采样几乎相当——色彩自然、纹理丰富。这证明了 VSD 能像标准采样一样以正常 CFG 生成高质量结果，而不需要 SDS 那种极端的 ω=100\omega=100ω=100。

这篇工作还做了以下工程改进：

  • 蒸馏时间步调度：SDS 在 t∼U(0.02,0.98)t\sim\mathcal{U}(0.02,0.98)t∼U(0.02,0.98) 上均匀采样。VSD 在训练过程中切换调度——初期用 U(0.02,0.98)\mathcal{U}(0.02,0.98)U(0.02,0.98) 均匀覆盖所有噪声水平（宏观结构+细节都要推），后期切换到 U(0.02,0.50)\mathcal{U}(0.02,0.50)U(0.02,0.50)（只用中等以下噪声，专注雕细节不破坏已形成的结构）
  • 密度初始化：NeRF 初始化为以原点为中心的模糊高斯团块（而非随机），早期几何快速聚焦，避免密度弥散在空气中
