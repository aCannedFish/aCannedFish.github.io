VGGT: Visual Geometry Grounded Transformer

发表于2026-07-23|更新于2026-08-05|Note读论文：三维重建
|浏览量:

经典的 SfM/MVS 流水线会依次执行特征提取、特征匹配、相机求解、三角化、束调整和稠密重建。每个模块都有清晰的几何含义，也会把前一阶段的错误传给下一阶段。DUSt3R 将两张图直接回归到同一坐标系中的 point map，避开了显式匹配，但处理多张图时仍要建立图像对并做全局对齐。

VGGT 研究的是更统一的问题：输入同一场景的一张、数张乃至上百张无标定图像，一次前向传播同时给出相机、深度、三维点和跨帧轨迹。模型学习的并非某一个单独任务，而是这些任务共享的视觉几何状态。

设输入图像为 {Ii}i=1N\{I_i\}_{i=1}^{N}{Ii​}i=1N​，Ii∈R3×H×WI_i\in\mathbb{R}^{3\times H\times W}Ii​∈R3×H×W，VGGT 的输出写成：

f ⁣({Ii}i=1N)={gi,Di,Pi,Ti}i=1Nf\!\left(\{I_i\}_{i=1}^{N}\right) =\{g_i,D_i,P_i,T_i\}_{i=1}^{N} f({Ii​}i=1N​)={gi​,Di​,Pi​,Ti​}i=1N​

其中：

  • gi∈R9g_i\in\mathbb{R}^{9}gi​∈R9 是相机参数，由旋转四元数 qi∈R4q_i\in\mathbb{R}^{4}qi​∈R4、平移 ti∈R3t_i\in\mathbb{R}^{3}ti​∈R3 和二维视场角 fi∈R2f_i\in\mathbb{R}^{2}fi​∈R2 拼接而成；
  • Di∈RH×WD_i\in\mathbb{R}^{H\times W}Di​∈RH×W 是深度图；
  • Pi∈R3×H×WP_i\in\mathbb{R}^{3\times H\times W}Pi​∈R3×H×W 是 point map，每个像素直接存一个三维坐标；
  • Ti∈RC×H×WT_i\in\mathbb{R}^{C\times H\times W}Ti​∈RC×H×W 是稠密跟踪特征，后续跟踪头用它求同一个三维点在各图像中的二维位置。

任务变化

要理解 VGGT 的特点，需要先看经典 SfM 究竟在优化什么。假设已经知道第 jjj 个三维点 XjX_jXj​ 在第 iii 张图中的观测像素为 uiju_{ij}uij​，经典 Bundle Adjustment 会求解：

min⁡{Ri,ti},{Xj}∑(i,j)∈Oρ ⁣(∥π ⁣(Ki(RiXj+ti))−uij∥22)\min_{\{R_i,t_i\},\{X_j\}} \sum_{(i,j)\in\mathcal{O}} \rho\!\left( \left\| \pi\!\left(K_i(R_iX_j+t_i)\right)-u_{ij} \right\|_2^2 \right) {Ri​,ti​},{Xj​}min​(i,j)∈O∑​ρ(∥π(Ki​(Ri​Xj​+ti​))−uij​∥22​)

其中 O\mathcal{O}O 是可见观测集合，π([x,y,z]⊤)=[x/z,y/z]⊤\pi([x,y,z]^\top)=[x/z,y/z]^\topπ([x,y,z]⊤)=[x/z,y/z]⊤ 是透视除法，ρ\rhoρ 是抑制错误匹配的鲁棒损失。这个公式有一个隐藏前提：必须事先知道“哪些二维点来自同一个三维点”。因此经典系统要先检测特征、做两两匹配、用 RANSAC 去除外点，再进行三角化和 BA。视图越多，匹配图和初始化越复杂。

VGGT 学习一个带参数 Θ\ThetaΘ 的映射：

(g^,D^,P^,T^)=fΘ(I1,…,IN)(\hat g,\hat D,\hat P,\hat T)=f_{\Theta}(I_1,\ldots,I_N) (g^​,D^,P^,T^)=fΘ​(I1​,…,IN​)

训练阶段已经在大量场景上反复见过“图像外观—跨视图关系—三维结构”的对应。推理时，它把传统流程中每个场景都要重新求解的优化问题，转化为一次摊销推断：昂贵计算主要发生在预训练阶段，新场景只需前向传播。

这不表示网络完全抛弃了几何。Global Attention 可以学习寻找跨视图对应，camera head 学习相对位姿，depth/point-map head 学习三角测量后的结果，多任务监督把这些几何关系共同压入主干特征。区别在于这些步骤不再以显式模块依次执行，而是在共享 token 中联合完成。

坐标约定

多视图重建必须先决定“世界坐标系放在哪里”。VGGT 选择第一张图像的相机坐标系作为世界坐标系，因此：

q1=[0,0,0,1],t1=0q_1=[0,0,0,1],\qquad t_1=\mathbf{0} q1​=[0,0,0,1],t1​=0

除第一张图外，输入次序可以任意交换；网络对这些图像保持置换等变。第一张图承担参考系的角色，改变第一张图会改变输出坐标值，但不会改变场景本身的相对几何。

假设外参采用世界到相机的变换 xc=Rixw+ti\mathbf{x}_c=R_i\mathbf{x}_w+t_ixc​=Ri​xw​+ti​，像素齐次坐标为 u~=(u,v,1)⊤\tilde{\mathbf{u}}=(u,v,1)^\topu~=(u,v,1)⊤，则深度、相机与三维点之间满足：

xc=Di(u,v)Ki−1u~,Pi(u,v)=Ri⊤ ⁣(Di(u,v)Ki−1u~−ti)\mathbf{x}_c=D_i(u,v)K_i^{-1}\tilde{\mathbf{u}}, \qquad P_i(u,v)=R_i^\top\!\left(D_i(u,v)K_i^{-1}\tilde{\mathbf{u}}-t_i\right) xc​=Di​(u,v)Ki−1​u~,Pi​(u,v)=Ri⊤​(Di​(u,v)Ki−1​u~−ti​)

VGGT 假设主点位于图像中心，并预测水平、垂直视场角 (θx,θy)(\theta_x,\theta_y)(θx​,θy​)。若图像宽高为 (W,H)(W,H)(W,H)，视场角可以换算为焦距：

fx=W/2tan⁡(θx/2),fy=H/2tan⁡(θy/2)f_x=\frac{W/2}{\tan(\theta_x/2)},\qquad f_y=\frac{H/2}{\tan(\theta_y/2)} fx​=tan(θx​/2)W/2​,fy​=tan(θy​/2)H/2​

于是内参矩阵为：

Ki=[fx0W/20fyH/2001]K_i= \begin{bmatrix} f_x&0&W/2\\ 0&f_y&H/2\\ 0&0&1 \end{bmatrix} Ki​=​fx​00​0fy​0​W/2H/21​​

把反投影分成三步会更直观：

  1. Ki−1u~K_i^{-1}\tilde{\mathbf{u}}Ki−1​u~ 将像素变成相机坐标系中的一条射线方向；
  2. 乘以 Di(u,v)D_i(u,v)Di​(u,v)，得到射线上实际的三维点 xc\mathbf{x}_cxc​；
  3. 用 Ri⊤(xc−ti)R_i^\top(\mathbf{x}_c-t_i)Ri⊤​(xc​−ti​) 将点从第 iii 个相机坐标系变换到第一相机定义的世界坐标系。

point map 正是把第三步的结果直接存回每个像素。深度图每个像素只存一个标量，必须配合相机才能变成全局点；point map 每个像素存三个坐标，单独就能画出场景点云。

三维重建还存在 gauge freedom。若把所有相机平移与三维点同时乘以同一个尺度 sss，投影像素不会变化：

π ⁣(Ki(Ri(sXj)+sti))=π ⁣(sKi(RiXj+ti))=π ⁣(Ki(RiXj+ti))\pi\!\left(K_i(R_i(sX_j)+st_i)\right) =\pi\!\left(sK_i(R_iX_j+t_i)\right) =\pi\!\left(K_i(R_iX_j+t_i)\right) π(Ki​(Ri​(sXj​)+sti​))=π(sKi​(Ri​Xj​+ti​))=π(Ki​(Ri​Xj​+ti​))

因此只靠 RGB 多视图通常无法确定绝对米制尺度。VGGT 固定第一相机消除了全局旋转和平移自由度，再用训练时的场景归一化处理尺度；其输出首先应理解为内部一致的相对几何，不能在所有数据上直接当作精确米制测量。

这说明 gig_igi​、DiD_iDi​ 和 PiP_iPi​ 存在确定的几何联系：知道相机和深度就能计算 point map；知道质量足够高的 point map，也能通过 PnP 等算法反求相机。VGGT 仍然为三者分别设置输出头并联合监督，这是一种有意保留的过完备表示。

过完备输出的意义类似于让学生同时写答案、推导和验算。三个结果并不独立，却从不同角度约束了同一份内部几何表示。消融实验表明，去掉相机或 point map 监督都会损害重建精度。推理时反而常用“相机头 + 深度头”反投影得到点云，它比直接使用 point-map 头更准，说明把复杂任务分解成两个较简单任务仍有价值。

交替注意力

输入图像先由 DINOv2 的 patch embedding 切分成图像 token。设每张图有 KKK 个 patch，通道数为 CCC：

tiI∈RK×Ct_i^I\in\mathbb{R}^{K\times C} tiI​∈RK×C

每一帧还会附加一个相机 token tigt_i^gtig​ 和四个 register token tiRt_i^RtiR​。第一帧使用一组专门的可学习 token，其他帧共享另一组，从结构上告诉网络哪一帧定义世界坐标系。register token 不直接输出任务结果，主要吸收全局信息和注意力中的异常高值，完成主干计算后会被丢弃。

如果只在每张图内部做注意力，网络看不到跨视图对应关系；如果把所有 NKNKNK 个 token 一次放进全局注意力，计算量和显存近似为 O(N2K2)O(N^2K^2)O(N2K2)，而且不同图像的局部统计会混在一起。VGGT 交替使用两种自注意力：

t~i(ℓ)=FrameAttn⁡ ⁣(ti(ℓ)),{ti(ℓ+1)}i=1N=GlobalAttn⁡ ⁣({t~i(ℓ)}i=1N)\begin{aligned} \tilde t_i^{(\ell)} &=\operatorname{FrameAttn}\!\left(t_i^{(\ell)}\right),\\ \{t_i^{(\ell+1)}\}_{i=1}^{N} &=\operatorname{GlobalAttn}\!\left(\{\tilde t_i^{(\ell)}\}_{i=1}^{N}\right) \end{aligned} t~i(ℓ)​{ti(ℓ+1)​}i=1N​​=FrameAttn(ti(ℓ)​),=GlobalAttn({t~i(ℓ)​}i=1N​)​

Frame Attention 在单帧内部整理物体边界、纹理和局部深度线索；Global Attention 让不同视图交换信息，完成隐式匹配、尺度协调和相机关系推断。二者反复交替，使多视图信息逐步进入每一帧的 token。整个主干只使用 self-attention，没有额外设计 cross-attention，也没有把极线、三角化或光束法平差硬编码进网络。

标准缩放点积注意力为：

Attn⁡(Q,K,V)=softmax⁡ ⁣(QK⊤d)V\operatorname{Attn}(Q,K,V) =\operatorname{softmax}\!\left(\frac{QK^\top}{\sqrt d}\right)V Attn(Q,K,V)=softmax(d​QK⊤​)V

QK⊤QK^\topQK⊤ 中的每个元素衡量一个 query token 与一个 key token 的相似度。除以 d\sqrt dd​ 是为了防止通道维数 ddd 较大时点积幅值过大，导致 softmax 过早饱和。

在 Frame Attention 中，Q,K,V∈RK×dQ,K,V\in\mathbb{R}^{K\times d}Q,K,V∈RK×d，每张图独立计算，总复杂度约为 O(NK2d)O(NK^2d)O(NK2d)。在 Global Attention 中，所有图像拼成 NKNKNK 个 token，Q,K,V∈RNK×dQ,K,V\in\mathbb{R}^{NK\times d}Q,K,V∈RNK×d，复杂度约为 O(N2K2d)O(N^2K^2d)O(N2K2d)。前者便宜且保留帧内结构，后者昂贵但能建立任意两帧之间的联系。交替结构让网络不必在每一层都支付全局注意力的代价，同时让局部特征在下一轮全局层中带着更清晰的物体边界和位置线索参与匹配。

可以把一次交替理解为两阶段的信息传播：先在每张图内回答“这一片像素属于什么结构”，再跨图回答“其他视图中哪里看到了同一结构”。多轮堆叠后，camera token 聚合了视图级关系，image token 则同时包含外观与三维关系。

预测头

主干输出后，相机 token 和图像 token 进入不同的头。

相机头先在所有输出相机 token 之间再做四层 self-attention，然后用线性层回归 g^i\hat g_ig^​i​。相机之间继续通信很重要，因为单台相机的位姿只有相对于其他相机才有意义。

图像 token 进入 DPT 解码器，恢复到逐像素特征图 FiF_iFi​。不同的 3×33\times33×3 卷积头从 FiF_iFi​ 预测深度、point map、对应置信度和跟踪特征：

Fi=DPT⁡(t^iI),(D^i,P^i,Σ^iD,Σ^iP,Ti)=h(Fi)F_i=\operatorname{DPT}(\hat t_i^I),\qquad (\hat D_i,\hat P_i,\hat\Sigma_i^D,\hat\Sigma_i^P,T_i)=h(F_i) Fi​=DPT(t^iI​),(D^i​,P^i​,Σ^iD​,Σ^iP​,Ti​)=h(Fi​)

DPT 会融合 Transformer 不同层级的 token，因此兼顾全局几何和局部边界。Σ^iD\hat\Sigma_i^DΣ^iD​、Σ^iP\hat\Sigma_i^PΣ^iP​ 在论文的损失写法中充当置信度或精度权重：纹理重复、反光、天空和遮挡边界等区域通常会得到较低置信度，后处理时可以据此筛点。

跟踪部分沿用 CoTracker2 的思想。给定查询图像 IqI_qIq​ 中的点 yjy_jyj​，先从 TqT_qTq​ 双线性采样查询特征，再与其余 TiT_iTi​ 构造相关图，最终预测轨迹：

T ⁣(yj,{Ti}i=1N)={y^j,i,v^j,i}i=1N\mathcal{T}\!\left(y_j,\{T_i\}_{i=1}^{N}\right) =\{\hat y_{j,i},\hat v_{j,i}\}_{i=1}^{N} T(yj​,{Ti​}i=1N​)={y^​j,i​,v^j,i​}i=1N​

y^j,i\hat y_{j,i}y^​j,i​ 是对应位置，v^j,i\hat v_{j,i}v^j,i​ 是可见性。这个模块不假设帧有时间顺序，所以既能处理视频，也能处理无序照片集合。

多任务损失

总损失为：

L=Lcamera+Ldepth+Lpmap+λLtrack,λ=0.05\mathcal{L} =\mathcal{L}_{\mathrm{camera}} +\mathcal{L}_{\mathrm{depth}} +\mathcal{L}_{\mathrm{pmap}} +\lambda\mathcal{L}_{\mathrm{track}}, \qquad \lambda=0.05 L=Lcamera​+Ldepth​+Lpmap​+λLtrack​,λ=0.05

相机参数采用 Huber 损失：

Lcamera=∑i=1N∥g^i−gi∥ϵ\mathcal{L}_{\mathrm{camera}} =\sum_{i=1}^{N}\left\|\hat g_i-g_i\right\|_{\epsilon} Lcamera​=i=1∑N​∥g^​i​−gi​∥ϵ​

Huber 损失在小误差处近似 L2，在大误差处近似 L1，能降低异常相机标注对训练的冲击。

深度损失同时比较数值和空间梯度。省略无效像素掩码后，可以写成：

Ldepth=∑i=1N[∥Σ^iD⊙(D^i−Di)∥1+∥Σ^iD⊙(∇D^i−∇Di)∥1−αlog⁡Σ^iD]\mathcal{L}_{\mathrm{depth}} =\sum_{i=1}^{N}\left[ \left\|\hat\Sigma_i^D\odot(\hat D_i-D_i)\right\|_1 +\left\|\hat\Sigma_i^D\odot(\nabla\hat D_i-\nabla D_i)\right\|_1 -\alpha\log\hat\Sigma_i^D \right] Ldepth​=i=1∑N​[​Σ^iD​⊙(D^i​−Di​)​1​+​Σ^iD​⊙(∇D^i​−∇Di​)​1​−αlogΣ^iD​]

第一项保证深度正确，第二项保持边缘和局部斜率，最后一项阻止网络把所有置信度都降为零。point map 使用完全对应的三维版本：

Lpmap=∑i=1N[∥Σ^iP⊙(P^i−Pi)∥1+∥Σ^iP⊙(∇P^i−∇Pi)∥1−αlog⁡Σ^iP]\mathcal{L}_{\mathrm{pmap}} =\sum_{i=1}^{N}\left[ \left\|\hat\Sigma_i^P\odot(\hat P_i-P_i)\right\|_1 +\left\|\hat\Sigma_i^P\odot(\nabla\hat P_i-\nabla P_i)\right\|_1 -\alpha\log\hat\Sigma_i^P \right] Lpmap​=i=1∑N​[​Σ^iP​⊙(P^i​−Pi​)​1​+​Σ^iP​⊙(∇P^i​−∇Pi​)​1​−αlogΣ^iP​]

置信度项可以单独分析。对一个像素，暂时把数值误差与梯度误差合并为 r>0r>0r>0，损失近似为：

ℓ(Σ)=Σr−αlog⁡Σ,Σ>0\ell(\Sigma)=\Sigma r-\alpha\log\Sigma, \qquad \Sigma>0 ℓ(Σ)=Σr−αlogΣ,Σ>0

令导数为零：

∂ℓ∂Σ=r−αΣ=0⟹Σ∗=αr\frac{\partial\ell}{\partial\Sigma} =r-\frac{\alpha}{\Sigma}=0 \quad\Longrightarrow\quad \Sigma^*=\frac{\alpha}{r} ∂Σ∂ℓ​=r−Σα​=0⟹Σ∗=rα​

误差 rrr 小时，最优 Σ\SigmaΣ 大；误差大时，最优 Σ\SigmaΣ 小。所以这里的 Σ\SigmaΣ 更接近 precision/confidence，而不是通常记号中的方差。Σr\Sigma rΣr 允许模型降低困难区域的权重，−log⁡Σ-\log\Sigma−logΣ 又会惩罚无条件降低置信度，两项平衡后得到可用于筛点的可靠性估计。

梯度项 ∇D\nabla D∇D 也很重要。两张深度图即使像素平均误差相同，其中一张可能把桌面边缘抹成缓坡，另一张保留清晰跳变。比较 ∇D^\nabla\hat D∇D^ 与 ∇D\nabla D∇D 会直接惩罚边界位置和表面斜率错误，因此重建轮廓更锐利。point map 的梯度损失对三个坐标通道分别起同样作用。

跟踪损失包含位置误差和可见性二元交叉熵。训练数据的绝对尺度差异很大，模型会先用场景点到原点的典型距离统一归一化相机平移、深度和 point map。网络直接学习这个规范化后的尺度，不在输出端临时做对齐。

实验结论

VGGT 在相机位姿、多视图深度、稠密 point map 和点跟踪上都取得了很强的结果。更值得关注的是它改变了系统结构：过去需要成对匹配和迭代优化的多个步骤，被压进同一个共享 Transformer 中。论文报告 32 张图的重建前向时间低于一秒，而基于图像对的 DUSt3R 还需要耗时的全局对齐。

“前馈”并不意味着传统几何失去价值。VGGT 的预测可以直接作为 Bundle Adjustment 的高质量初始化。论文附录的 IMC 实验中，纯 VGGT 的相机结果已经很快，VGGT + BA 又显著提高精度，且省去了从零开始匹配和三角化的成本。学习先验负责给出接近正确答案的全局初始化，几何优化负责满足更严格的重投影约束，二者可以组合。

VGGT + BA 仍然优化前面的重投影目标，只是初值已经由网络给出。初值接近正确解时，局部优化不必在大量错误匹配和相机姿态中搜索，收敛更快，也更不容易进入错误局部极小值。这体现了 VGGT 的实际定位：它既可以直接交付几何，也可以作为传统系统的强初始化器和通用三维特征骨干。

方法特点

VGGT 最突出的特点不是某个新的投影公式，而是统一性：同一主干同时服务相机、深度、point map 和跟踪，输入规模从单图延伸到多图，输出还能直接接 BA、Gaussian Splatting 或下游跟踪模型。它说明大规模、多来源三维监督可以让 Transformer 在没有显式极线模块的情况下，内部形成足够强的几何计算能力。

这种统一也解释了它为何成为后续工作的起点。NOVA3R 需要的是 VGGT 已经对齐好的多视图 token，Surflo 需要的是其中间几何特征、相机和 point map；它们不必重新学习“图像怎样获得基础三维关系”，可以把研究重点放到场景表示与生成方式上。

VGGT 仍存在以下局限：

  • 世界坐标系、尺度和相机都由网络推断，极端焦距、弱纹理、镜面、透明物体和训练分布外场景仍可能产生系统误差；
  • 全局注意力对图像数仍有近似二次复杂度，上百视图可以运行，但长视频和大规模街区并不适合直接整批输入；
  • point map 与输入像素绑定，每增加一个视图都会新增一份稠密几何。同一表面在多张图里被重复表示，少量跨视图偏差会形成双层表面；
  • 输出主要覆盖输入图像中可见的区域，对完全遮挡的背面没有明确的生成机制；
  • 12 亿参数带来很强的统一能力，也提高了训练和部署成本。

后面的 NOVA3R、VolFill 和 Surflo 都以这些局限为出发点。它们保留 VGGT 已学到的几何特征，同时重新设计“一个场景应当怎样表示”和“输出几何应当怎样生成”。
