3D Gaussian Splatting for Real-Time Radiance Field Rendering

发表于2026-07-23|更新于2026-08-05|Note读论文：三维重建
|浏览量:

前面三篇都在优化 NeRF 这套"隐式神经场 + 沿光线体渲染"的框架。Instant-NGP 把训练压到了秒级，但渲染仍然慢——因为渲染每个像素都要沿光线采样几十上百个点，每个点都要查一次网络。想在 1080p 分辨率下实时渲染（>30 FPS）几乎不可能。

三维高斯泼贱不再用神经网络隐式地表示场景，而是用一堆看得见摸得着的"高斯椭球"显式地把场景拼出来。渲染时不再"沿光线一个点一个点地问网络"，而是把这些椭球像贴纸一样 splat 到屏幕上，再按深度混合。这一换，渲染速度直接达到 100+ FPS，而质量还能媲美 Mip-NeRF 360。

场景表示

3DGS 把场景表示为 NNN 个（通常几十万到几百万个）3D 高斯椭球。第 iii 个高斯由四组可学习参数完全定义：

  • 位置（均值） μi∈R3\boldsymbol{\mu}_i \in \mathbb{R}^3μi​∈R3：椭球中心在哪
  • 协方差矩阵 Σi∈R3×3\Sigma_i \in \mathbb{R}^{3\times 3}Σi​∈R3×3：椭球的形状和朝向（有多扁、朝哪个方向拉伸）
  • 不透明度 oi∈(0,1)o_i \in (0,1)oi​∈(0,1)：这片"棉花糖"有多实
  • 颜色 ci\mathbf{c}_ici​：用球谐函数 系数表示，使颜色可以随观察方向变化（体现高光、反射）

一个高斯在空间中任意一点 x\mathbf{x}x（相对中心的位移记 x−μi\mathbf{x}-\boldsymbol{\mu}_ix−μi​）的取值为：

Gi(x)=exp⁡ ⁣(−12(x−μi)⊤Σi−1(x−μi))G_i(\mathbf{x}) = \exp\!\left(-\tfrac{1}{2}(\mathbf{x} - \boldsymbol{\mu}_i)^\top \Sigma_i^{-1} (\mathbf{x} - \boldsymbol{\mu}_i)\right) Gi​(x)=exp(−21​(x−μi​)⊤Σi−1​(x−μi​))

注意这里没有归一化系数 1(2π)3/2∣Σ∣1/2\tfrac{1}{(2\pi)^{3/2}|\Sigma|^{1/2}}(2π)3/2∣Σ∣1/21​。3DGS 不把 GiG_iGi​ 当概率密度，而是当作一个取值在 (0,1](0,1](0,1] 的"影响权重"形状函数——离中心越近权重越接近 1，越远越接近 0。真正的"实心程度"由单独的可学习不透明度 oio_ioi​ 控制，混合时用 oi⋅Gio_i \cdot G_ioi​⋅Gi​。把"形状"（GiG_iGi​）和"浓度"（oio_ioi​）解耦，二者可以独立优化。

协方差矩阵必须半正定才有物理意义（它描述一个椭球）。如果直接用梯度下降优化 Σ\SigmaΣ 的 6 个独立分量，一步更新就可能让它跑出半正定流形，变成没有意义的矩阵。3DGS 的巧妙之处是把协方差分解为旋转和缩放——这正好对应"如何从一个标准球构造出任意椭球"：

Σi=RiSiSi⊤Ri⊤\Sigma_i = R_i S_i S_i^\top R_i^\top Σi​=Ri​Si​Si⊤​Ri⊤​

其中 Si=diag(sx,sy,sz)S_i = \text{diag}(s_x, s_y, s_z)Si​=diag(sx​,sy​,sz​) 是缩放矩阵（控制椭球三个半轴长度），RiR_iRi​ 由四元数 qiq_iqi​ 转换而来（控制朝向）。存储时只存 3 维的 sss 和 4 维的 qqq，用时再拼成 Σ\SigmaΣ。

这就像描述一个橄榄球：你不去直接写它那个复杂的椭球方程，而是说"先拿一个标准球，把它沿三个轴分别拉伸（缩放 SSS），再旋转到某个姿态（旋转 RRR）"。这样构造出的 Σ=(RS)(RS)⊤\Sigma = (RS)(RS)^\topΣ=(RS)(RS)⊤ 天生是 MM⊤MM^\topMM⊤ 的形式，无论 sss、qqq 怎么变都保证半正定——把约束"焊死"在了参数化里。作者甚至为 sss、qqq 手推了解析梯度，避免自动微分的开销。

每个高斯的颜色用 3 阶球谐表示（degree 3，每个 RGB 通道 161616 个系数，共 484848 个）。球谐是定义在球面上的一组正交基，用视线方向去"查表"就能得到该方向下的颜色，从而表达镜面高光这类视角相关外观。训练时还有一个 warm-up 技巧：先只优化 0 阶（各向同性的漫反射底色），之后每 1000 次迭代引入一个更高的频带，逐步放开到 3 阶——避免一上来就在高频视角分量上过拟合。

可微光栅化

有了这堆 3D 高斯，怎么渲染成一张图？3DGS 使用了 tile-based differentiable rasterizer。整个过程完全在 GPU 上并行，不含任何 MLP 查询。它沿用 EWA volume splatting。

1.投影。 把每个 3D 高斯投影到 2D 图像平面。相机坐标下协方差为 WΣW⊤W\Sigma W^\topWΣW⊤（WWW 是世界到相机的视图变换），再经透视投影得到图像平面上的 2D 协方差：

Σi′=J W Σi W⊤J⊤\Sigma'_i = J\, W\, \Sigma_i\, W^\top J^\top Σi′​=JWΣi​W⊤J⊤

关键是 JJJ——透视投影在该高斯中心处的雅可比矩阵。对相机坐标点 t=(tx,ty,tz)\mathbf{t}=(t_x,t_y,t_z)t=(tx​,ty​,tz​)，透视投影要除以深度 tzt_ztz​，其雅可比约为：

J=[fx/tz0−fxtx/tz20fy/tz−fyty/tz2000]J = \begin{bmatrix} f_x/t_z & 0 & -f_x t_x/t_z^2 \\ 0 & f_y/t_z & -f_y t_y/t_z^2 \\ 0 & 0 & 0 \end{bmatrix} J=​fx​/tz​00​0fy​/tz​0​−fx​tx​/tz2​−fy​ty​/tz2​0​​

高斯有一个性质：经过线性（仿射）变换后仍是高斯。但透视投影含"除以 tzt_ztz​"，是非线性的，投影后严格来说不再是高斯。EWA 的办法是在每个高斯中心处对投影做一阶泰勒展开，用其线性部分 JJJ 来近似——这样投影后仍能得到一个（近似的）2D 高斯，可解析、可微、可快速求值。近似误差随着离中心变远而增大，所以这是一个"局部"近似。

JWΣW⊤J⊤JW\Sigma W^\top J^\topJWΣW⊤J⊤ 本是 3×33\times33×3，但屏幕上的椭圆只需要一个 2×22\times 22×2 协方差。深度维在后面只用来排序、不参与椭圆形状，所以直接跳过第三行和第三列，得到的 2×22\times22×2 矩阵就定义了屏幕上那个椭圆 splat。

2.分块 + 一次全局排序。 把屏幕切成 16×1616\times 1616×16 的 tile。一个高斯若覆盖多个 tile，就复制多份，每份编一个 key = [tileID∣视空间深度][tile ID | 视空间深度][tileID∣视空间深度]。然后用一次 GPU 基数排序对所有实例按 key 全局排序——排完后同一 tile 的高斯天然连续、且按深度有序。

这是实时性能的最大功臣。 传统体渲染要求"每个像素各自把覆盖它的东西按深度排序"，成本极高。3DGS 大胆地放弃逐像素精确排序，改为"每个 tile 内所有像素共享同一份全局深度序"。代价是混合结果是近似的（同一 tile 里所有像素用同一个顺序），但当 splat 尺寸接近单像素时误差可忽略，收敛后几乎无可见伪影。把 N 次逐像素排序换成 1 次全局排序，这是从"能跑"到"实时"的关键一跃。**

3.α\alphaα-blending。 每个 tile 开一个线程块，协作地把该 tile 的高斯载入共享内存；每个像素按深度顺序从前往后（front-to-back） 累积颜色，某像素透过率饱和时该线程提前退出：

C=∑i∈Nci αi∏j=1i−1(1−αj),αi=oi⋅Gi′(u)C = \sum_{i \in \mathcal{N}} \mathbf{c}_i \, \alpha_i \prod_{j=1}^{i-1}(1 - \alpha_j), \qquad \alpha_i = o_i \cdot G'_i(\mathbf{u}) C=i∈N∑​ci​αi​j=1∏i−1​(1−αj​),αi​=oi​⋅Gi′​(u)

其中 αi\alpha_iαi​ 是把该高斯投影后的 2D 高斯值 Gi′G'_iGi′​ 在像素 u\mathbf{u}u 处的取值乘以不透明度 oio_ioi​。

回看 NeRF 的 C^=∑iTiαici\hat{C} = \sum_i T_i \alpha_i \mathbf{c}_iC^=∑i​Ti​αi​ci​，其中 Ti=∏j<i(1−αj)T_i = \prod_{j<i}(1-\alpha_j)Ti​=∏j<i​(1−αj​)——一模一样的 front-to-back alpha 合成。区别只在于：NeRF 的 αi\alpha_iαi​ 来自"MLP 输出的密度沿光线积分"，而 3DGS 的 αi\alpha_iαi​ 来自"2D 高斯的解析值"。3DGS 把"沿光线逐点查网络再积分"这个昂贵的连续操作，换成了"对排好序的离散高斯做加权和"这个廉价的并行操作。

反传需要对每个像素"重走一遍混合链"把梯度回流。为省内存，3DGS 有两招：(1) 复用前向的那次排序，反传时在每个 tile 内从后往前（back-to-front） 遍历同一份有序列表——所以排序结果必须保留；(2) 只存一个标量：混合链里每个高斯的权重含累乘透过率 ∏(1−αj)\prod(1-\alpha_j)∏(1−αj​)，3DGS 不逐点保存这些中间量，而是只存前向结束时的最终累计透过率，反传时每遇到一个高斯就把它的 (1−αi)(1-\alpha_i)(1−αi​) 除回去，即可逐步恢复中间透过率。这让每像素只需存 1 个标量而非整条链表，从而对"能接收梯度的高斯数量没有上限"。

自适应密度控制

初始时，3DGS 用 SfM（Structure-from-Motion） 稀疏重建出的点云来初始化高斯——每个点变成一个小高斯，初始协方差按"到最近 3 个邻居的平均距离"设为各向同性。但 SfM 点云稀疏，纹理平坦或反光区域几乎没有点。若高斯数量固定，欠重建区会一片模糊，过重建区又浪费资源。3DGS 因此在训练中动态增删高斯：

  • 克隆：复制一个高斯并沿位置梯度方向移动副本——往"缺料"的地方长出新高斯，同时增加高斯数量和总体积。
  • 分裂：把 1 个大高斯换成 2 个，尺度除以经验因子 ϕ=1.6\phi = 1.6ϕ=1.6，新位置以原高斯为概率密度采样——把"一个大高斯糊住一大片"细化开，保持总体积不变。
  • 不透明度周期重置：每 3000 次迭代把所有高斯的不透明度重置到接近 0，之后优化会重新把"真正需要"的高斯抬上来，其余保持很低而被剪除——这是抑制相机附近 floaters、防止密度失控增长的"泄压阀"。
  • 剪枝：定期删除不透明度 o<ϵαo < \epsilon_\alphao<ϵα​（ϵα=0.005\epsilon_\alpha = 0.005ϵα​=0.005）的"隐形"高斯，以及世界空间/屏幕空间过大的"糊屏"高斯。

克隆和分裂靠同一个信号触发：视图空间位置梯度的平均幅值（阈值 τpos=0.0002\tau_{\text{pos}} = 0.0002τpos​=0.0002）。梯度大说明这个高斯"不堪重负"——它所在区域还没拟合好，误差在拼命拉它。区别只在于此时高斯本身是小（该克隆去覆盖更多）还是大（该分裂去表达更细）。这套机制让高斯点云像细胞一样"哪里需要就在哪里增殖"，从稀疏 SfM 点自适应生长到贴合场景。

各参数还配了合适的激活函数保证合法范围与平滑梯度：不透明度 ooo 用 sigmoid 约束到 (0,1)(0,1)(0,1)；缩放 sss 用 exp 保证为正；四元数 qqq 归一化为单位四元数保证是合法旋转。

损失函数与训练

3DGS 的训练目标很简单——渲染图与真值图的 ℓ1\ell_1ℓ1​ 损失，加上一个衡量结构相似性的 D-SSIM 项：

L=(1−λ) L1+λ LD-SSIM,λ=0.2\mathcal{L} = (1 - \lambda)\,\mathcal{L}_1 + \lambda\,\mathcal{L}_{\text{D-SSIM}}, \quad \lambda = 0.2 L=(1−λ)L1​+λLD-SSIM​,λ=0.2

为什么加 D-SSIM？纯 ℓ1\ell_1ℓ1​ 只逐像素比对，容易得到"平均意义上对、但整体发糊"的结果。SSIM 关注局部结构（对比度、纹理），能逼迫模型还原出锐利的边缘和纹理细节。两者互补。
