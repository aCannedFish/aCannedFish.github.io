NeRF: Representing Scenes as Neural Radiance Fields for View Synthesis

发表于2026-07-23|更新于2026-08-05|Note读论文：三维重建
|浏览量:

要实现的任务是：给定一组从不同视角拍摄的稀疏 2D 图像（及对应的相机位姿），目标是生成场景在任意新视角下的逼真渲染图像。

想象你绕着桌上的一个花瓶拍了 20 张照片，每张照片都知道相机的位置和朝向。现在你走到一个没拍过的角度——你能"脑补"出从这个角度看花瓶应该长什么样吗？

传统方法大致分两类：

  • 基于几何的方法（如多视图立体匹配 MVS）：先用特征匹配恢复 3D 点云，再重建网格，最后贴纹理。问题是——半透明的玻璃杯怎么匹配特征点？毛发这种细结构怎么重建网格？镜面反射的高光怎么贴纹理？每一步都可能崩溃。
  • 基于离散表示的方法（体素网格、点云）：把空间切成小方块，每个方块存颜色和密度。但 2563256^32563 的体素网格已经很粗糙了，再翻一倍就是 5123512^35123 —— 内存暴涨 8 倍。分辨率瓶颈是致命的。

NeRF 另辟蹊径：能不能不存网格，而是让一个神经网络"学会"这个花瓶的 3D 外观？ 输入一个空间坐标，输出这个点是什么颜色、有多"实"——就像把整个场景压缩进了神经网络的权重里。

Neural Radiance Field

NeRF 将场景建模为一个连续函数 FΘF_\ThetaFΘ​，输入为 5D 坐标，输出为体积密度和颜色：

FΘ:(x,d)→(c,σ)F_\Theta: (\mathbf{x}, \mathbf{d}) \to (\mathbf{c}, \sigma) FΘ​:(x,d)→(c,σ)

其中：

  • x=(x,y,z)\mathbf{x} = (x, y, z)x=(x,y,z)：空间中一点的 3D 坐标
  • d=(θ,ϕ)\mathbf{d} = (\theta, \phi)d=(θ,ϕ)：观察方向（2D 球面坐标，通常用单位方向向量 (θ,ϕ)(\theta, \phi)(θ,ϕ) 或 3D 笛卡尔坐标表示）
  • c=(r,g,b)\mathbf{c} = (r, g, b)c=(r,g,b)：该点在该方向上发射的 RGB 颜色
  • σ\sigmaσ：该点的 volume density，可以理解为光线在该点被阻挡的概率。σ\sigmaσ 仅与位置 x\mathbf{x}x 有关，与观察方向无关，保证了几何一致性（多视图一致性）。

这个函数用 MLP 来近似，因此称为 Neural Radiance Field。

为什么 σ\sigmaσ 不能依赖视角方向？考虑一个具体的反例：物体表面的一个点，从左边看是"实"的（σ\sigmaσ 很大），从右边看是"虚"的（σ\sigmaσ 很小）——这物理上说不通，因为一个点要么是固体要么是空气，不随观察角度改变。颜色则不同：同一个点，从不同角度看确实可能有不同的高光和反射，因此 c\mathbf{c}c 允许依赖于 d\mathbf{d}d。

传统方法将场景离散化为体素网格或点云，高分辨率意味着巨大的内存开销。而神经网络作为连续函数的通用逼近器，可以用固定的参数量来表达任意精度的场景——查询任意 3D 点的属性只需一次前向传播，不再受网格分辨率的限制。

Volume Rendering

有了 FΘF_\ThetaFΘ​，下一个问题是如何从中生成图像。NeRF 借用计算机图形学中经典的体渲染理论。

物理直觉：想象你在一片雾中看远处的山。你看到的不只是山的颜色——空气分子也在散射光，越远的山被雾遮挡得越多。体渲染公式就是描述"沿着视线方向，在每一小段距离上，有多少光被发射、有多少光被吸收/散射"。

对于图像上的每个像素，从相机光心出发，沿像素方向发射一条光线 r(t)=o+td\mathbf{r}(t) = \mathbf{o} + t\mathbf{d}r(t)=o+td，参数范围为 t∈[tn,tf]t \in [t_n, t_f]t∈[tn​,tf​]（近平面到远平面）。

沿光线积累颜色，考虑遮挡效应：

C(r)=∫tntfT(t) σ(r(t)) c(r(t),d) dtC(\mathbf{r}) = \int_{t_n}^{t_f} T(t) \, \sigma(\mathbf{r}(t)) \, \mathbf{c}(\mathbf{r}(t), \mathbf{d}) \, dt C(r)=∫tn​tf​​T(t)σ(r(t))c(r(t),d)dt

逐项理解：

  • σ(r(t))\sigma(\mathbf{r}(t))σ(r(t))：在 ttt 处，每单位距离光线被阻挡的概率密度
  • c(r(t),d)\mathbf{c}(\mathbf{r}(t), \mathbf{d})c(r(t),d)：在 ttt 处向 d\mathbf{d}d 方向发出的颜色
  • T(t)T(t)T(t)：光线从起点走到 ttt 还没被挡住的概率——即"存活概率"

其中 T(t)T(t)T(t) 定义为：

T(t)=exp⁡ ⁣(−∫tntσ(r(s)) ds)T(t) = \exp\!\left(-\int_{t_n}^{t} \sigma(\mathbf{r}(s)) \, ds\right) T(t)=exp(−∫tn​t​σ(r(s))ds)

为什么是指数衰减？把光线走过的一小段 Δs\Delta sΔs 看成一次伯努利试验：以概率 σΔs\sigma \Delta sσΔs 被挡住，以概率 1−σΔs1 - \sigma \Delta s1−σΔs 存活。走过 nnn 段后存活的概率是 (1−σΔs)n(1 - \sigma \Delta s)^n(1−σΔs)n，取极限就是 exp⁡(−∫σ ds)\exp(-\int \sigma \, ds)exp(−∫σds)。

离散近似：实际计算时无法处理连续积分，需要离散化。在光线上采样 NNN 个点 {ti}i=1N\{t_i\}_{i=1}^N{ti​}i=1N​，相邻采样点间距 δi=ti+1−ti\delta_i = t_{i+1} - t_iδi​=ti+1​−ti​：

C^(r)=∑i=1NTi (1−exp⁡(−σiδi)) ci\hat{C}(\mathbf{r}) = \sum_{i=1}^{N} T_i \, \big(1 - \exp(-\sigma_i \delta_i)\big) \, \mathbf{c}_i C^(r)=i=1∑N​Ti​(1−exp(−σi​δi​))ci​

其中：

  • αi=1−exp⁡(−σiδi)\alpha_i = 1 - \exp(-\sigma_i \delta_i)αi​=1−exp(−σi​δi​) 是第 iii 段的 alpha 值——这段有多不透明
  • Ti=exp⁡ ⁣(−∑j=1i−1σjδj)=∏j=1i−1(1−αj)T_i = \exp\!\left(-\sum_{j=1}^{i-1} \sigma_j \delta_j\right) = \prod_{j=1}^{i-1}(1 - \alpha_j)Ti​=exp(−∑j=1i−1​σj​δj​)=∏j=1i−1​(1−αj​) 是到达第 iii 段时还剩下的"可见度"

如果你做过图形学，这就是标准的 alpha compositing（front-to-back blending）。把光线上的每一小段看作一个半透明薄片，从近到远依次叠加。σ\sigmaσ 大的地方（物体表面）贡献大，σ\sigmaσ 小的地方（空气）几乎透明。

Position Encoding

有了体渲染公式，理论上 MLP 直接吃 (x,y,z,θ,ϕ)(x, y, z, \theta, \phi)(x,y,z,θ,ϕ)、吐出 (σ,c)(\sigma, \mathbf{c})(σ,c)、渲染后和真实图像比较、反向传播——应该就行了。但实际上效果非常糊。

原因在于所谓的谱偏置：神经网络在学习时天然倾向于先拟合低频函数（光滑的大趋势），然后才逐渐拟合高频细节。如果直接输入 (x,y,z)(x, y, z)(x,y,z)，两个相邻很近的点在 MLP 看来几乎一样（输入差异太小），很难学会在它们之间画出清晰的边界——结果就是一片模糊。

让你仅凭 (x,y)(x, y)(x,y) 坐标画出一张高清人脸的像素值，两个只差 0.001 的坐标，你很难画出完全不同的颜色。但如果把坐标先展开成 sin⁡(2kπx)\sin(2^k \pi x)sin(2kπx) 和 cos⁡(2kπx)\cos(2^k \pi x)cos(2kπx) 的各种频率组合，两个很接近的点在高维空间中就可能被"拉开"——MLP 就能区分它们了。

NeRF 借鉴 Transformer 中的位置编码思想，在输入 MLP 之前，将坐标映射到高维傅里叶特征空间：

γ(p)=(sin⁡(20πp),cos⁡(20πp),sin⁡(21πp),cos⁡(21πp),…,sin⁡(2L−1πp),cos⁡(2L−1πp))\gamma(p) = \big(\sin(2^0 \pi p), \cos(2^0 \pi p), \sin(2^1 \pi p), \cos(2^1 \pi p), \ldots, \sin(2^{L-1} \pi p), \cos(2^{L-1} \pi p)\big) γ(p)=(sin(20πp),cos(20πp),sin(21πp),cos(21πp),…,sin(2L−1πp),cos(2L−1πp))

对于位置 x\mathbf{x}x 的每个分量 (x,y,z)(x, y, z)(x,y,z) 分别编码，使用 L=10L = 10L=10（每分量 202020 维，共 606060 维）；对于方向 d\mathbf{d}d，使用 L=4L = 4L=4（共 242424 维）。方向比位置用的频率层数少，因为视角变化相对平滑，不需要那么高频的细节。

更重要的一点：这个公式也解释了后面的 Mip-NeRF 为什么能反走样。频率 2L2^L2L 的傅里叶特征对应的波长约是 1/2L1/2^L1/2L。当 L=10L=10L=10 时，最高频能分辨约 1/10241/10241/1024 尺度的细节。如果渲染低分辨率图像，这些高频特征本不该被激活——但原始 NeRF 无法区分，这也是走样的根源。

Hierarchical Volume Sampling

如果沿光线均匀采样（比如 64 个点），大部分采样点会落在空白区域——对于没有物体的空气段，σ≈0\sigma \approx 0σ≈0，这些点在渲染时贡献几乎为零，但每次前向传播都要计算它们的位置编码和 MLP 输出。纯浪费。

NeRF 的解决方案是训练两个网络协同工作：

  1. Coarse Network：沿光线均匀采样 NcN_cNc​ 个点，得到粗略的密度分布。粗网络渲染出来的图像是模糊的，但密度分布的大致形状是对的——它知道物体大概在哪。

  2. Fine Network：将粗网络的体渲染权重 wi=Ti(1−exp⁡(−σiδi))w_i = T_i(1 - \exp(-\sigma_i \delta_i))wi​=Ti​(1−exp(−σi​δi​)) 沿光线归一化，作为概率密度函数（PDF），在这个 PDF 上做逆变换采样（inverse transform sampling），额外采样 NfN_fNf​ 个点。

逆变换采样的直觉：将 PDF 的累积分布函数（CDF）均匀采样，然后反查对应的 ttt 值。PDF 高的地方，CDF 梯度大，均匀采样自然会落到这些区域——恰好就是物体表面附近。把粗采样的 NcN_cNc​ 个点和精采样的 NfN_fNf​ 个点合并排序后送入精网络，精网络的采样点就集中在物体表面附近了。

为什么不用一个网络直接做？因为"哪里值得多采样"这件事——在学习之前你是不知道的。粗网络提供了一种自举（bootstrapping）机制：先用粗略的信息指导精细采样，两个网络同时学习、互相促进。

损失函数

NeRF 的训练损失非常简单——就是渲染结果与真实像素颜色的 L2 损失，同时对粗网络和精网络施加监督：

L=∑r∈R[∥C^c(r)−C(r)∥22+∥C^f(r)−C(r)∥22]\mathcal{L} = \sum_{\mathbf{r} \in \mathcal{R}} \Big[ \|\hat{C}_c(\mathbf{r}) - C(\mathbf{r})\|_2^2 + \|\hat{C}_f(\mathbf{r}) - C(\mathbf{r})\|_2^2 \Big] L=r∈R∑​[∥C^c​(r)−C(r)∥22​+∥C^f​(r)−C(r)∥22​]

其中：

  • R\mathcal{R}R：一个 batch 中随机采样的光线集合（每次迭代从所有训练图像中随机抽几千条光线，而不是整张图）
  • C^c(r)\hat{C}_c(\mathbf{r})C^c​(r)：粗网络渲染的颜色
  • C^f(r)\hat{C}_f(\mathbf{r})C^f​(r)：精网络渲染的颜色
  • C(r)C(\mathbf{r})C(r)：真实像素颜色

为什么粗网络也要监督？如果只监督精网络，粗网络就没有动力去学好密度分布——它可能输出均匀分布，导致精网络采样退化回均匀采样。给粗网络也加上图像损失，迫使其密度分布接近真实的物体表面分布。实际使用时仅用精网络的结果即可，粗网络的贡献只是训练期间的辅助。

训练流程

训练过程的核心是可微体渲染：整个 pipeline 从"光线采样 → 位置编码 → MLP前向 → alpha compositing → 像素颜色"都是可微的。这意味着 2D 像素颜色损失可以一路通过体渲染积分反向传播到 3D 空间中的密度和颜色预测，进而更新 MLP 权重。这也是 NeRF 最优雅的地方——仅靠 2D 监督就学到了 3D 表示。

具体分为以下阶段：

  • 步骤 1–3（粗网络）：先沿光线均匀采样并查询粗网络，得到密度和颜色的初步估计。粗网络的体渲染结果 C^c\hat{C}_cC^c​ 虽然模糊，但能提供一个大致的密度分布。
  • 步骤 4–6（精网络）：将粗网络的体渲染权重 wicw_i^cwic​ 作为概率密度函数进行重要性采样，在物体表面附近密集采样，在空白区域稀疏采样。精网络在这些更优的采样点上重新渲染，得到高质量的颜色 C^f\hat{C}_fC^f​。
  • 步骤 7：将粗细两个网络的渲染结果同时与真实像素颜色计算 L2 损失并反向传播。

训练完成后，推理阶段不再需要粗网络，也无需计算损失——直接用训练好的精网络对新视角的每个像素进行体渲染即可：

算法：NeRF 推理（新视角渲染）输入： 训练好的 MLP 参数 Θ，目标相机位姿 Pfor each 目标像素 p:根据相机位姿发射光线 r=(o,d)重复训练步骤 4–6（仅精网络）→C^f(r)像素 p 颜色=C^f(r)\begin{aligned} &\begin{array}{l} \hline \textbf{算法：NeRF 推理（新视角渲染）} \\[4pt] \hline \textbf{输入：}\ \text{训练好的 MLP 参数 } \Theta\text{，目标相机位姿 } P \\[6pt] \textbf{for each}\ \text{目标像素 } p: \\ \quad \text{根据相机位姿发射光线 } \mathbf{r} = (\mathbf{o}, \mathbf{d}) \\ \quad \text{重复训练步骤 4–6（仅精网络）} \rightarrow \hat{C}_f(\mathbf{r}) \\ \quad \text{像素 } p \text{ 颜色} = \hat{C}_f(\mathbf{r}) \\ \hline \end{array}&& \end{aligned} ​算法：NeRF 推理（新视角渲染）输入： 训练好的 MLP 参数 Θ，目标相机位姿 Pfor each 目标像素 p:根据相机位姿发射光线 r=(o,d)重复训练步骤 4–6（仅精网络）→C^f​(r)像素 p 颜色=C^f​(r)​​​​​

NeRF 实际上对每个不同的 3D 场景都需要重新渲染一遍，所以没有泛化能力，只是对单一场景过拟合得到其他视角的图片。
