替换 Windows 默认字体

发表于2026-01-01|更新于2026-08-17|Blog
|浏览量:

微软雅黑真的很丑！

之前的感觉并不是很明显，因为屏幕本身分辨率不高。但是换了一个 4K 屏幕之后，就能清楚地看到微软雅黑字体周围的锯齿——使用 ClearType 怎么调整都没有用，在显示比较复杂的汉字时尤其明显。相比之下 Mac 的字体显示就清晰很多，于是受强迫症驱使开始尝试替换系统字体。

鉴于 MacType 或者 noMeiryoUI 修改不够彻底且容易出现各种兼容问题，于是在初步尝试后舍弃了这两个方案，而是尝试通过将苹方字体伪装成微软雅黑放在 C:\Windows\Fonts 下覆盖原来的文件实现。

第二步-修改英文

这个时候系统的中文字体已经变成苹方了，但是英文和数字仍然是原样。接下来替换 Segoe UI 字体。

原理是一样的，找到对应的字体伪装成系统字体就行了，但是手动伪装也挺麻烦的，况且 Segoe UI 有一大堆字体。于是本着懒得动手的原则，在 GitHub 上找了一个工具：SyrianTurk/SyrianSegoe: A Next-Gen. Windows System Font Customization Tool

首先找一份全套的 San Francisco 字体：bradleyhodges/SFWindows: SFWindows - The entire collection of Apple fonts (San Francisco and New York families) for Windows 10/11 and other non-Apple platforms.
